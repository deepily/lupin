## What is in force today

1. **One style line, always on, in three places.** `DM_STYLE_TAG` in `hook_common.py` is byte for byte the line the source confirms. The MCP instructions section and the `dm_send` docstring addendum both splice it in, with no toggle. The source names the reply affordance as a third place. I did not open that code, but a comment in `cosa_voice_mcp.py` says the tag rides there.
2. **The toggles the source retired are gone.** A search of the Python and ini files finds none of these names. They are `dm style contract enabled`, `get_dm_style_contract_enabled` and `_peer_dm_reply_rider`. `PEER_DM_BREVITY_RIDER` appears in no non-test Python file. `BREVITY_TAG` remains for the voice rider.
3. **Grading is deferred, not synchronous.** The source runs the judge inside `execute_dm_send` before the call returns. The tree grades on a single background worker with a bounded backlog. A comment in `dm.py` records Rick's ruling. A refused deferral writes the corpus row with no grade.
4. **Length buckets match the source, and the sender never sees a number.** The defaults are 60, 90, 150 and 250 words. Each is its own ini key, and the ini sets the same values. The source's detail string `187 words, target ~60` is gone. A code comment says no word count or target may reach the sender. The face repeats once per 100 words, for display only.
5. **Overall is the source's formula, with one exception.** `combine_overall` takes half the length weight plus half the average of directness and tone. It rounds half up and clamps to the five levels. The worked example is in the docstring. If either qualitative weight is `None`, the overall grade is the length grade alone, and the note says so.
6. **A silent judge is not a neutral grade.** The source falls back to a 🤷 with weight 0. The tree returns weight `None` with the detail "judge unavailable". A comment in `judge.py` explains that 0 is a real grade, so a silence must not average as one. The retry count of three and the half-second-per-attempt backoff match the source.
7. **The 150-word ceiling holds, with a blunt message.** Past `QUALITATIVE_WORD_LIMIT` the model is not called. The detail is a refusal with no number in it, not the source's "N words > 150".
8. **The qualitative half is a separate switch, and the model is not the source's.** The ini holds three keys, all set. They are `dm quality judgment enabled`, `dm quality qualitative enabled` and `dm quality judge version = 2`. A comment in `judge.py` records Rick's ruling to keep length and pursue the qualitative grades by other means. The judge endpoint is `dm_quality_judge/phi_4`, a Phi-4 model on the vLLM box at port 3001. The source names Mistral Small.
9. **The factory chooses the version.** `get_dm_quality_judge()` returns v2 when the ini says 2 and v1 otherwise. The code default is 1, so a process that cannot read the ini runs v1. Version 2 extracts a value and checks it against the message text.
10. **The quality audit exists and is wider than the source.** `_dm_quality_audit` in `dm.py` tallies length, directness, tone and overall weights. It adds `qualitative_count`, so a `None` is never averaged as a zero. It also adds `total_overage`, because the length grade saturates at 251 words. A route at `/quality-audit` is registered.
