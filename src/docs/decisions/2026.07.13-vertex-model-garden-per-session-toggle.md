# Decision record: Vertex / Model Garden per-session toggle

**Source:** `src/rnd/v0.1.9/2026.07.13-vertex-model-garden-toggle-search-and-logging.md`, revision 4 of 2026-07-15 (an R&D design document, not a ruling).
**Status:** in force for the toggle, the region and the guards; the implementation landed in commits `0d513fc3` and `df69cee1`.
**Read from:** the source, whole sections 1, 2b, 2c, 5, 5c, 6a, 8, 9 and the spend-guardrail rows; the rest of its 1,900 lines is review history and was not needed for these decisions.

## What was decided

1. **Vertex is a per-session opt-in; Max stays the default.** Rick's direction of 2026-07-13, as the source quotes it: toggle between Max plan and Model Garden "on an ad hoc basis", piloted on one session first. A global `env` block in `~/.claude/settings.json` was rejected, because it would silently move the whole fleet onto metered billing.
2. **The mechanism is a `--vertex` flag on `start-cc-with-tmux.sh`, with no new launcher script.** The source marks this a ruling of its design review; it does not say that Rick made it.
3. **The Vertex region is `global`, held in its own variable `LUPIN_VERTEX_REGION`, never in `LUPIN_GCP_REGION`.** `claude-opus-4-8` is not servable in `us-central1` (a `rawPredict` returned 400), and `us` is an access-scope word, not a location. Only a `rawPredict` may certify a region; a metadata 200 may not. This was measured, not ruled.
4. **Guards run before the first token, in the process that runs `claude`.** `pane_guard()` runs inside the pane; `--vertex` never creates the tmux server (it refuses, or creates one from a scrubbed environment); Vertex variables are never forwarded to spawned workers. Landed in `df69cee1`.
5. **The pilot's acceptance oracle is Cloud Monitoring `PublisherModel` (`model_invocation_count` with its labels), not a BigQuery log row.** A log row cannot tell "the toggle never engaged" from "money was spent and nothing was logged". Criterion AC-D4b asserts that the `location` label equals the configured region.
6. **Spend is capped.** Rick ruled a Cloud Quotas rate cap on 2026-07-14 and ratified the split of 30, 10 and 10 dollars a day (Opus, DeepSeek, gpt-oss) on 2026-07-15, which the source puts at 47.55 dollars a day against his ceiling of 50.
7. **A gap in the audit trail is accepted for trivial probes.** Rick's ruling, as the source quotes it: if a 2-cent query cannot be audited that is fine, as long as the future billing export is enabled so the work can be audited.
8. **Vertex is recorded as a third cost path, a considered exception to the prefer-bounded-Claude-Code rule.** Bounded Claude Code is the Max path, which is what this feature exists to be an alternative to.
