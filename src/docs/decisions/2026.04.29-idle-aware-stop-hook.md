## What is in force today

1. **A Stop with no poke does one of three things, chosen by the ini key `stop hook idle behavior`: `none`, `ask` or `idle_announce`. The default is `idle_announce`.** `idle_announce` sends one low-priority notify in which the persona says it is idle, then allows the stop. `none` allows the stop silently. `ask` is the design's behaviour. `stop.py` reads the key through `_stop_hook_idle_behavior`, and any error or unknown value gives `idle_announce`. The key is set to `idle_announce` in `[Lupin: Baseline]` only.
2. **Under `ask`, the waiter is armed only when `idle_detection.enabled` is true.** With it false, the Stop asks "Anything else?" at once. The settings block lives in `~/.claude/settings.json`. The defaults are `enabled` true and `backoff_minutes` `[5, 10, 20, 40, 60]`. A `ValueError` from the loader makes `stop.py` log `idle_settings_invalid` and take the immediate ask.
3. **The waiter sleeps in 30-second slices.** It exits silently, with no ask and no successor, on any of four signals. They are a dead Claude Code process, `last_interaction_at` later than `waiter_started_at`, the speakerphone (conversation mode) on, and the bridge file gone. The sleep is `backoff_minutes[min(index, last)]` minutes.
4. **The ask is a yes/no card with a 60-second timeout and a default of "no".** A "yes" ends the waiter. A "no" or a timeout writes `backoff_index = min(index + 1, last)` to the bridge and spawns a successor at that index. A transport error spawns no successor. A comment on a yes or a no is injected by tmux.
5. **User activity resets the chain, whatever the flag says.** `UserPromptSubmit` kills the waiter, sets `backoff_index` to 0 and bumps `last_interaction_at`. `PostToolUse` for any tool named `mcp__cosa-voice__*` kills the waiter and bumps the stamp, and spawns nothing. `SessionEnd` kills the waiter. The `Stop` that arms a waiter kills the old one first, so the latest wins.
6. **`SessionStart` writes the `idle_detection` block with `backoff_index` 0 and no waiter; a `/clear` keeps the old `backoff_index`.**
7. **A bad `backoff_minutes` fails loudly.** The loader raises `ValueError` on a non-list, an empty list, a non-int, a bool or a value under 1. A missing file, a missing block or unparsable JSON returns the defaults instead.
8. **Bridge writes replace the whole file.** `set_idle_detection_field` reads, merges and writes through `atomic_write_json`, which uses `os.replace`. Two concurrent writers can still lose one update, and the helper's docstring accepts that.
9. **The conversation-mode skip is kept.** A Stop with the speakerphone on returns before the ask paths. The waiter checks the speakerphone again when it wakes.

## Planned in the source and not carried, or carried differently

- **"Replace direct `_ask_anything_else()` call with a `_spawn_idle_waiter()` call ... Legacy path stays as fallback when `enabled=false`" (Modified files, `stop.py`).** Carried, then put behind the 3-way key (rule 1). The source's default, the waiter on every idle Stop, is reversed.
- **"Refactor extraction of the current `stop.py:_ask_anything_else()` body" into the shared helper, with the Stop-time caller building its output from the result.** Only half-carried. `stop.py` imports `fire_anything_else_ask` and does not call it. `_ask_anything_else` still builds its own `NotificationRequest`. `stop.py` shares only `summarize_task`. The waiter uses `fire_anything_else_ask`. Two copies of the same request now exist.
- **"The waiter records `mono_start = time.monotonic()` and uses `time.monotonic() - mono_start`".** Not in `idle_waiter.py`. The sleep loop adds the slice length to a counter, and nothing in the file reads `time.monotonic`.
- **Names that differ.** The source says `--ppid`; the waiter takes `--cc-pid`. The source says `fire_anything_else`; the function is `fire_anything_else_ask`. The result's `answer` also takes the value `error`, which the source's three values do not include.
- **"Atomically claim the bridge `waiter_pid` slot."** `_claim_waiter_slot` reads the slot and then writes it; two claimants can both succeed. The source's race section calls this acceptable.
- **The bridge path `~/.claude/sessions/cc-{ppid}.json`.** The directory now comes from `sessions_dir()`, which `LUPIN_HOOK_SESSIONS_DIR` can redirect. `90-execution.md` says "No deviations from `01-design.md`"; it was written before the amendment in rule 1.
