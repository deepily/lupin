# Decision record: one registry owns agent registration

**Source:** `src/rnd/v0.2.0/2026.08.15-agent-registration-single-source.md`, whole document (453 lines). Its own status line reads "DRAFT".
**Status:** in force. The registry extension has since landed in `src/cosa/rest/v2/registry.py`: `CommandClass` and `resolve_agentic` exist there.

## What was decided

1. **One registry is the source of truth for agent registration.** The source quotes Rick's ruling of `2026-08-15`. He said: "one registry is the source of truth; generate what can be generated, test what cannot." The source is explicit that this extends `src/cosa/rest/v2/registry.py`. That registry already existed, so this is not a new build.
2. **Commands are classed in the registry.** The classes are conversational, agentic, control and none. The old bucket names are derived from the class. The agentic commands become registry entries, and `DEFERRED_COMMANDS` retires.
3. **`resolve()` stays scoped to conversational commands.** Agentic commands are read through a separate `resolve_agentic()`. Registering them must not change what the router-facing lookup returns.
4. **The router prompt list is generated from the registry.** Its order is held as registry data. Declared order keeps a byte comparison against the checked-in template an honest gate.
5. **The training corpus is reconciled by key and never generated.** Only the key set of the `agent-router-*.json` files is compared with the registry. The values are editorial. The `vox-cmd-*` files hold 23 browser commands that are not in the registry, so the scope rule is `agent-router-*.json`.
6. **The drift guard is class-aware and checks consistency, not voice reachability.** Every agentic command must appear in the registry, prompt, training keys and factory. Every conversational command must appear in the first three and in no factory branch. The confirmation-card list is a fifth surface, checked as a subset with a phantom arm and a dead-card arm. Every `cli_module` is checked by running `python -m <module> --help` and requiring return code 0.
7. **Exemptions carry a machine-checked reason and are scoped to a surface.** The count test `test_bucket_counts` is deleted in the commit that would invalidate it. A derived count cannot fail, and a hand-edited count cannot be told from a cover-up.
8. **Retraining buys reliability, not reachability.** A command is reachable once the prompt lists it. The source's measurement used one invented command at n=10, so it does not show that this generalizes. The source asks that this asymmetry be written beside the training generator.

## Not decided or left open in the source

- Whether the runtime router template equals the checked-in one. The source's reviewer marked this unverified.
- Whether the emitted command string always matches a registry key or alias for agentic commands.
- The source schedules five drift fixes, three unrunnable `cli_module` values and an unset `started_at` for its third and sixth phases. I did not check which have shipped.
