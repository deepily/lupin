## 6. Lessons for the failure-mode catalog

- **Merged under a running run.** Trigger: your tier is green and a peer's long job is measuring the same tree. Symptom: the peer's run measures a tree that changed partway. Guard: read the venue's busy state and ask the peers before the merge.
- **A test that writes the live switch.** Trigger: an e2e drives an endpoint whose state file the dev server also reads. Symptom: a failed test leaves fleet state changed. Guard: the test server gets its own state path, and the test asserts the path it writes is not the live one.
- **A runbook written from a plan and never run.** Trigger: steps that need another person's sudo. Symptom: the first run is in front of that person. Guard: measure every precondition you can without sudo before handing the runbook over.
