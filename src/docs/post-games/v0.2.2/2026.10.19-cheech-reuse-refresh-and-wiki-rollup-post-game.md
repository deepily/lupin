## 2. What went wrong, and the mechanism

1. **The classifier refused every reviewed cherry-pick.** Auto mode called it "Merge Without Review" even after a named pass. So each landing waited for Rick to paste a line, and five land asks timed out between 16:07 and 19:40.
2. **A mixed cherry-pick line ran out of order.** `git cherry-pick A B X..Y` is a revision walk, so git queued `73fd6501d` before its parent `f3447da29`. It stopped on a conflict and left main mid-pick for about 45 minutes. Give single commits and ranges as separate commands.
3. **The VM install hit four gaps, one per paste.** The repo venv lacked `requests`, and two variables were set only in the profile. The planning-is-prompting copy was stale too. A read-only probe of all four up front would have cost one paste instead of four.
4. **Plan 2 looked finished.** No open row said "Plan 2", the rows used team jargon, and the final accuracy test had no row. Rick read the board as done, and every open Plan 2 row now carries the plan name.
5. **A worker sat idle for over an hour.** Extra 1 stopped at 17:20 on an API server error. Nobody saw it until the next look-in at 18:30.
