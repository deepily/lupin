## 6. Lessons for the failure-mode catalog

- `gated-against-the-model-it-extends`: a stop rule names a model baseline and no model-free rule.
  The symptom is a learner that beats its baseline while losing to a rule with no model.
  The guard: every stop rule for a learner names the best model-free rule as a second yardstick, measured before the run.
- `totals-hide-failures`: a run stores its failures as abstentions.
  The symptom is totals that look complete.
  The guard: a run report prints abstentions by reason, and a non-zero count of input errors fails the report.
