## Lessons

1. **Moving a value is not changing it.** Rick ordered "Opus, not Fable". I moved the ids into the INI file but kept the Fable values while the switch waited behind a gate. Meanwhile the hourly cron kept judging a backlog of about 12,000 definitions. Each run made up to 800 calls. On 13 Nov that came to 5,936 judge calls by runs.jsonl, or 2,474 by Cheech's transcript count. The two counts are not yet reconciled. → Memory `feedback_model_switch_means_value_not_location`: list every scheduled caller of the old model the same day. Pause or cap them while a switch is gated.
2. **A merge into the main checkout moves the tree under any :8000 run.** I merged `886818382` while John's e2e_b run was going. → Memory `feedback_no_merge_during_8000_run`. Run venue_idle first. Then DM the peer manager.
3. **Stale values hide in conflict resolutions.** Maya wrote group B before the Opus switch. It still carried claude-fable-5-1. A plain merge would have reinstated it. We re-applied it with a cherry-pick on the new head. The brief ruled "never bring back Fable" (`d48fea6d6`).
4. **Review before build has to reach the seat before the build does.** Rick's review gate landed late. By then Krishna had drafted the API and the legacy client. Maria reviewed the draft and the plan together, and it cost little. Put a stated gate in the spawn brief, not after it.
5. **An environment-variable escape hatch is never "Rick only".** Every seat runs as the same user. Maria showed the hatch could be set through a sourced file, so it was removed, not patched (`c433b940a`).
6. **Condensed DMs drop shas.** Three times the sha I needed was missing from a worker's DM. `git log` in the seat's tree was the reliable source.
