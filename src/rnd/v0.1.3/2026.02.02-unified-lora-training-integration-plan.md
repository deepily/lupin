## Objective

Integrate the 3 new agentic job intents (Deep Research, Podcast Generator, Research→Podcast) into the unified LORA training pipeline, rather than training them in isolation.

---

## Design Decisions (User Confirmed)

1. **Sample Size**: 400 examples per agentic command (matching simple router commands)
   - Start with 400, adjust based on accuracy results for intent classification and argument extraction

2. **Instruction Template**: Use shared `agent_router_instruction_template` as-is
   - Keep existing hint: "Anything that isn't a part of the command itself should be treated as arguments"
   - Drop the isolated "agentic jobs run autonomously" hint (no added value)
   - Future optimization: Add examples of argument formats to the hint

### Phase 3: Update Unified Training Builder

**Goal:** Include agentic job prompts in `build_all_training_prompts()`.

**File:** `src/cosa/training/xml_coordinator.py`

**3.1 Update `build_all_training_prompts()` (around line 774):**

```python
def build_all_training_prompts(
    self,
    sample_size_per_compound_command: int=2000,
    sample_size_per_simple_command: int=400,
    sample_size_per_agentic_command: int=400  # NEW parameter - match simple router
) -> pd.DataFrame:
    """
    Builds all training prompts by combining all command types including agentic jobs.
    """
    compound_vox_cmd_qna_df = self.build_compound_vox_cmd_training_prompts( sample_size_per_command=sample_size_per_compound_command )
    simple_vox_cmd_qna_df   = self.build_simple_vox_cmd_training_prompts( sample_size_per_command=sample_size_per_simple_command )

    compound_router_qna_df  = self.build_compound_agent_router_training_prompts( sample_size_per_command=sample_size_per_compound_command )
    simple_router_qna_df    = self.build_simple_agent_router_training_prompts( sample_size_per_command=sample_size_per_simple_command )

    # NEW: Include agentic job commands
    agentic_job_qna_df      = self.build_agentic_job_training_prompts( sample_size_per_command=sample_size_per_agentic_command )

    # Stack ALL dataframes vertically (now includes agentic jobs)
    all_qna_df = pd.concat( [
        compound_vox_cmd_qna_df,
        simple_vox_cmd_qna_df,
        compound_router_qna_df,
        simple_router_qna_df,
        agentic_job_qna_df  # NEW
    ], ignore_index=True )

    # ... rest of stats calculation unchanged
```

### Phase 5: Update Shell Script for Unified Approach

**Goal:** Replace isolated training with unified approach.

**File:** `src/scripts/run-agentic-intent-training.sh`

**5.1 Update `generate` mode:**

```bash
case "$MODE" in
    generate)
        echo -e "${GREEN}Generating ALL training data (unified)...${NC}"
        python -c "
from cosa.training.xml_coordinator import XmlCoordinator
import cosa.utils.util as du

du.print_banner( 'Generating Unified Voice Command Training Data', prepend_nl=True )

coordinator = XmlCoordinator( debug=False, verbose=False, silent=True )

# Build ALL prompts including agentic jobs
print( 'Building all training prompts (vox cmd + router + agentic jobs)...' )
df = coordinator.build_all_training_prompts(
    sample_size_per_compound_command=2000,
    sample_size_per_simple_command=400,
    sample_size_per_agentic_command=400  # Match simple router commands
)
print( f'Generated {df.shape[0]} total training examples' )

# Use the existing unified splitter and writer
print( 'Splitting into train/test/validate...' )
# Calculate total sample size
train_df, test_df, validate_df = coordinator.get_train_test_validate_split( df, sample_size=df.shape[0] )
print( f'Train: {train_df.shape[0]}, Test: {test_df.shape[0]}, Validate: {validate_df.shape[0]}' )

print( 'Writing to unified JSONL files...' )
coordinator.write_ttv_split_to_jsonl( train_df, test_df, validate_df )

print( 'Done!' )
"
        ;;
```
