## Executive Summary

### Goal

Migrate Lupin's authentication and notification databases from SQLite (local filesystem) to Cloud SQL PostgreSQL to enable persistent data storage on Cloud Run's ephemeral filesystem environment.

### The Problem

**Current State** (Phase 2.6 Blocker #2):
- SQLite databases stored on container filesystem: `lupin-auth.db`, `lupin-notifications.db`
- Cloud Run containers use ephemeral storage
- **Impact**: All user accounts, JWT tokens, and notifications lost on every container restart/redeploy
- Makes testing impossible and production deployment non-viable

**From Parent Document** ([2025.11.12-phase-2.6-cloud-run-compatibility.md](2025.11.12-phase-2.6-cloud-run-compatibility.md)):
> "Phase 2.6.2: Local Database Dependencies - Cloud Run containers have ephemeral filesystems. Any data written to the local disk (including SQLite databases) is lost when the container restarts. This affects user accounts (lupin-auth.db) and notification state (lupin-notifications.db)."

### The Solution

**PostgreSQL-in-Docker + Cloud SQL Approach**:

1. **Development Environment**: PostgreSQL 16.3 running in Docker container
   - Local development uses `docker-compose up` (zero Cloud SQL dependency)
   - Fast local queries (0-1ms latency)
   - Works offline
   - Perfect data isolation per developer

2. **Production Environment**: Cloud SQL PostgreSQL 16
   - Persistent storage (survives container restarts)
   - Managed service (automatic backups, HA, scaling)
   - Cloud Run native integration (Unix socket connection)

3. **Factory Pattern**: Environment-aware database connection
   - `LUPIN_ENV=development` → PostgreSQL-in-Docker
   - `LUPIN_ENV=production` → Cloud SQL
   - Same PostgreSQL engine = same query behavior

### Key Decisions

**Decision #1: PostgreSQL-in-Docker (Not SQLite for dev)**

**Rationale**:
- **Version parity**: Same PostgreSQL 16 engine locally and in cloud
- **No SQL dialect surprises**: PostgreSQL `%s` vs SQLite `?` parameterization
- **Production-like testing**: Catch PostgreSQL-specific issues early
- **Minimal overhead**: Docker Compose adds ~1 hour setup time vs zero setup (but saves debugging time later)

**Trade-offs Considered**:
- ✅ Pros: Perfect env parity, same code paths, production confidence
- ⚠️ Cons: Requires Docker (but most devs have it), slightly more setup than SQLite

**Rejected Alternative**: SQLite (dev) + Cloud SQL (prod) with factory method
- Would save 1h initial setup time
- But creates risk of SQL dialect incompatibilities (parameterized queries, date handling, JSON operations)
- Analysis showed Lupin's auth queries are simple enough to work on both, but not worth the risk

**Decision #2: Cloud SQL Over Self-Managed PostgreSQL**

**Rationale**:
- **Managed backups**: Automatic daily backups + point-in-time recovery
- **High availability**: 99.95% SLA, automatic failover
- **Cloud Run integration**: Native Unix socket support, no VPC setup needed
- **Security**: IAM integration, automatic encryption at rest
- **Cost-effective at scale**: $12-15/month for db-f1-micro (test), scales to production

**Trade-offs Considered**:
- ✅ Pros: Zero operational overhead, production-ready, integrated with GCP
- ⚠️ Cons: $12-15/month ongoing cost (vs $0 for self-managed)

**Rejected Alternative**: Self-managed PostgreSQL on GCE
- Would save ~$5-10/month
- But requires manual backup scripts, monitoring setup, security hardening, OS patches
- Estimated 10-15 hours initial setup + 2-4 hours/month ongoing maintenance
- Not worth the effort for test deployment

**Decision #3: Alembic + Custom Scripts (Not Pure Alembic)**

**Rationale**:
- **Alembic for schema**: Version-controlled CREATE TABLE migrations
- **Custom Python for data**: SQLite → PostgreSQL data migration with transaction safety
- **Best of both**: Alembic's schema management + custom logic for one-time migration

**Trade-offs Considered**:
- ✅ Pros: Professional schema versioning, custom data migration logic, rollback capability
- ⚠️ Cons: Two migration systems (Alembic + custom script)

**Rejected Alternative**: Pure Alembic
- Alembic isn't designed for cross-database migrations (SQLite → PostgreSQL)
- Would require awkward Alembic version that imports SQLite data
- Custom script is cleaner separation of concerns

**Risk #1: Data Loss During Migration**

**Mitigation**:

- Backup SQLite databases before migration
- Rollback script (if migration fails)

**Risk #2: Downtime During Cutover**

**Mitigation**:

## Background & Context

### Why This Migration is Necessary

**Cloud Run Filesystem Characteristics**:
- Ephemeral storage: `/tmp` and container filesystem cleared on restart
- Read-only root filesystem: Cannot write to `/app` or most directories
- No persistent volumes: Unlike Kubernetes, Cloud Run doesn't support PersistentVolumeClaims

**Current SQLite Implementation**:
```python
# Current location: src/cosa/rest/auth_database.py
DB_PATH = f"{get_project_root()}/src/conf/long-term-memory/lupin-auth.db"
conn = sqlite3.connect(DB_PATH)
```

**What Happens on Cloud Run**:
1. Container starts, SQLite database doesn't exist
2. `init_auth_database()` creates fresh database
3. User registers account, data written to SQLite
4. Container restarts (new deployment, auto-scaling, crash)
5. **SQLite file is gone** - user account doesn't exist anymore
6. User cannot login (404 User Not Found)

**Impact Severity**: **CRITICAL** - Makes application unusable for any persistent user data

### Query Patterns Analysis

**Analyzed auth_database.py** - Found **ZERO complex SQL**:

**Common Patterns**:
```python
# Simple lookups (80% of queries)
cursor.execute("SELECT * FROM users WHERE email = ?", (email,))
cursor.execute("SELECT * FROM refresh_tokens WHERE jti = ?", (jti,))
cursor.execute("SELECT * FROM api_keys WHERE user_id = ? AND is_active = 1", (user_id,))

# Simple updates
cursor.execute("UPDATE users SET last_login_at = ? WHERE id = ?", (now, user_id))
cursor.execute("UPDATE refresh_tokens SET revoked = 1 WHERE jti = ?", (jti,))

# Simple deletes (with CASCADE)
cursor.execute("DELETE FROM users WHERE id = ?", (user_id,))  # Cascades to related tables

# Time-based cleanup
cursor.execute("DELETE FROM email_verification_tokens WHERE expires_at < ?", (now,))
```

**NO Complex SQL Found**:
- ❌ No JOINs (all relationships resolved in application code)
- ❌ No subqueries
- ❌ No window functions
- ❌ No CTEs (Common Table Expressions)
- ❌ No UNION queries
- ❌ No complex GROUP BY aggregations

**Conclusion**: Migration risk from SQL dialect differences is **VERY LOW**. Lupin's queries are simple enough to work identically on SQLite and PostgreSQL.

### Why PostgreSQL Over Other Options

**Considered Alternatives**:

**Option A: MySQL** (Cloud SQL supports MySQL too)
- ❌ Less feature-rich than PostgreSQL (no JSONB, weaker JSON support)
- ❌ Less popular in Python community
- ✅ Slightly cheaper ($1-2/month less)
- **Verdict**: Not worth sacrificing features for minimal savings

**Option B: NoSQL (Firestore, MongoDB)**
- ❌ Doesn't match relational schema (users → tokens is inherently relational)
- ❌ Requires major code rewrite (cannot reuse existing auth_database.py logic)
- ❌ Foreign key constraints must be enforced in application
- ✅ Better horizontal scaling (if needed at massive scale)
- **Verdict**: Wrong tool for auth data

**Option C: In-memory database (Redis)**
- ❌ Data lost on Redis restart (unless persistent mode)
- ❌ Not optimized for complex queries (no SQL)
- ❌ Limited transaction support
- ✅ Very fast (sub-millisecond)
- **Verdict**: Better for caching, not primary auth storage

**Option D: LanceDB** (user's original suggestion)
- ❌ Vector database, not relational
- ❌ No foreign keys, no CASCADE deletes
- ❌ No ACID transactions
- ✅ Already have GCS backend working
- **Verdict**: Rejected after analysis (see research findings in chat)

**Why PostgreSQL Wins**:
- ✅ Industry standard for relational data
- ✅ Full ACID transactions
- ✅ Foreign keys with CASCADE work correctly
- ✅ Rich data types (JSONB, UUID, TIMESTAMP WITH TIME ZONE)
- ✅ Excellent Cloud Run integration (Unix socket)
- ✅ Managed by Cloud SQL (automatic backups, HA, scaling)
- ✅ Large community, extensive documentation

## PostgreSQL Version Strategy

### Version Selection Rationale

**Chosen Version**: **PostgreSQL 16**

**Why PostgreSQL 16** (not 15, not 17):

1. **Current Stable LTS** (Long-Term Support):
   - PostgreSQL 16 released September 2023
   - 5 years of support (until September 2028)
   - Battle-tested in production for 1+ years

2. **Cloud SQL Support**:
   - Cloud SQL supports PostgreSQL 12, 13, 14, 15, **16**
   - PostgreSQL 17 not yet available on Cloud SQL (as of Nov 2025)
   - Future-proof: Can upgrade to 17 when Cloud SQL supports it

3. **Feature Improvements Over 15**:
   - Better JSON performance (JSONB improvements)
   - Parallel query improvements
   - Better monitoring/observability
   - Performance optimizations for common queries

4. **Not Too Cutting Edge**:
   - PostgreSQL 17 (latest) too new for production
   - Minor version stability: 16.3 has bug fixes from 16.0

**Version Parity Strategy**:
```
Development:  PostgreSQL 16.3 (Docker Official Image)
Production:   PostgreSQL 16   (Cloud SQL)
              ↑ Same major version = same behavior
```

### Cloud Run Connection Methods

**Method 1: Unix Socket Connection (RECOMMENDED)**

**Why Recommended**:
- ✅ No VPC setup required (simplest)
- ✅ Automatic by Cloud Run (no configuration)
- ✅ Secure (never leaves Google network)
- ✅ No public IP needed
- ✅ Zero latency overhead

**How It Works**:
1. Cloud Run mounts Cloud SQL instance at `/cloudsql/PROJECT:REGION:INSTANCE`
2. Application connects via Unix socket (not TCP)
3. Cloud Run manages connection lifecycle

**Cloud Run Deployment**:
```bash
gcloud run deploy lupin-api \
  --image=gcr.io/PROJECT_ID/lupin:latest \
  --region=us-central1 \
  --platform=managed \
  --add-cloudsql-instances=PROJECT_ID:us-central1:lupin-auth-db \
  --set-env-vars="LUPIN_ENV=production,CLOUD_SQL_CONNECTION=PROJECT_ID:us-central1:lupin-auth-db" \
  --set-secrets="AUTH_DB_PASSWORD=lupin-db-password:latest" \
  --allow-unauthenticated
```

**Connection String** (in Python):
```python
# Cloud Run automatically mounts socket at /cloudsql/
connection_name = os.environ["CLOUD_SQL_CONNECTION"]  # PROJECT:REGION:INSTANCE
socket_path = f"/cloudsql/{connection_name}"

# asyncpg connection (async)
connection_string = f"postgresql://{user}:{password}@/{database}?host={socket_path}"

# psycopg2 connection (sync)
conn = psycopg2.connect(
    host=f"/cloudsql/{connection_name}",
    dbname=database,
    user=user,
    password=password
)
```

**Method 2: Private IP Connection (VPC Connector)**

**Why Use Private IP**:
- ✅ More secure (no Cloud SQL Proxy)
- ✅ Better for high-connection-count apps
- ⚠️ Requires VPC setup (more complex)
- ⚠️ Requires Serverless VPC Connector ($0.07/hour = ~$50/month)

**Setup Steps**:

```bash
# 1. Allocate IP range for VPC peering
gcloud compute addresses create google-managed-services-default \
  --global \
  --purpose=VPC_PEERING \
  --prefix-length=16 \
  --network=default

# 2. Create VPC peering
gcloud services vpc-peerings connect \
  --service=servicenetworking.googleapis.com \
  --ranges=google-managed-services-default \
  --network=default

# 3. Update Cloud SQL instance to use private IP
gcloud sql instances patch lupin-auth-db \
  --network=default \
  --no-assign-ip

# 4. Create Serverless VPC Connector
gcloud compute networks vpc-access connectors create lupin-connector \
  --region=us-central1 \
  --network=default \
  --range=10.8.0.0/28 \
  --min-instances=2 \
  --max-instances=10

# 5. Deploy Cloud Run with VPC connector
gcloud run deploy lupin-api \
  --image=gcr.io/PROJECT_ID/lupin:latest \
  --region=us-central1 \
  --vpc-connector=lupin-connector \
  --vpc-egress=private-ranges-only \
  --set-env-vars="LUPIN_ENV=production" \
  --set-secrets="AUTH_DB_PASSWORD=lupin-db-password:latest"
```

**Connection String** (Private IP):

**Cost Comparison**:

| Method | Setup Complexity | Monthly Cost | Latency |
|--------|------------------|--------------|---------|
| Unix Socket | Simple (0 setup) | $0 | <1ms |

## Schema Migration Design

### SQLite to PostgreSQL Type Mappings

**Data Type Conversions**:

| SQLite Type | PostgreSQL Type | Notes |
|-------------|-----------------|-------|
| `TEXT` | `VARCHAR` or `TEXT` | VARCHAR for email (limited length), TEXT for JSON |
| `INTEGER` | `INTEGER` or `BIGINT` | Use BIGINT for large counts (e.g., audit log) |
| `INTEGER PRIMARY KEY AUTOINCREMENT` | `SERIAL` or `BIGSERIAL` | Auto-incrementing integers |
| `TEXT` (UUIDs) | `UUID` | Convert string UUIDs to native UUID type |
| `TEXT` (ISO 8601 timestamps) | `TIMESTAMP WITH TIME ZONE` | PostgreSQL native timestamp |
| `INTEGER` (booleans 0/1) | `BOOLEAN` | PostgreSQL native boolean |
| `TEXT` (JSON) | `JSONB` | PostgreSQL optimized JSON storage |
| `REAL` | `DOUBLE PRECISION` | Floating point (not used in Lupin) |

**Specific Table Migrations**:

**Table: users**
```sql
-- SQLite (current)
CREATE TABLE users (
    id TEXT PRIMARY KEY,                    -- UUID as TEXT
    email TEXT UNIQUE NOT NULL,
    password_hash TEXT NOT NULL,
    created_at TEXT NOT NULL,               -- ISO 8601
    email_verified INTEGER DEFAULT 0,       -- 0 or 1
    is_active INTEGER DEFAULT 1,
    roles TEXT DEFAULT '["user"]',          -- JSON string
    last_login_at TEXT
);

-- PostgreSQL (target)
CREATE TABLE users (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    email VARCHAR(255) UNIQUE NOT NULL,
    password_hash VARCHAR(255) NOT NULL,
    created_at TIMESTAMP WITH TIME ZONE NOT NULL DEFAULT NOW(),
    email_verified BOOLEAN DEFAULT FALSE,
    is_active BOOLEAN DEFAULT TRUE,
    roles JSONB DEFAULT '["user"]'::jsonb,
    last_login_at TIMESTAMP WITH TIME ZONE
);

CREATE INDEX idx_users_email ON users(email);
CREATE INDEX idx_users_is_active ON users(is_active);
CREATE INDEX idx_users_roles ON users USING GIN (roles);  -- GIN index for JSONB
```

**Table: refresh_tokens**
```sql
-- SQLite (current)
CREATE TABLE refresh_tokens (
    jti TEXT PRIMARY KEY,
    user_id TEXT NOT NULL,
    token_hash TEXT NOT NULL,
    expires_at TEXT NOT NULL,
    revoked INTEGER DEFAULT 0,
    created_at TEXT NOT NULL,
    last_used_at TEXT,
    user_agent TEXT,
    ip_address TEXT,
    FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE
);

-- PostgreSQL (target)
CREATE TABLE refresh_tokens (
    jti UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id UUID NOT NULL,
    token_hash VARCHAR(64) NOT NULL,        -- SHA-256 = 64 hex chars
    expires_at TIMESTAMP WITH TIME ZONE NOT NULL,
    revoked BOOLEAN DEFAULT FALSE,
    created_at TIMESTAMP WITH TIME ZONE NOT NULL DEFAULT NOW(),
    last_used_at TIMESTAMP WITH TIME ZONE,
    user_agent TEXT,
    ip_address INET,                        -- PostgreSQL IP address type
    FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE
);

CREATE INDEX idx_refresh_tokens_user_id ON refresh_tokens(user_id);
CREATE INDEX idx_refresh_tokens_expires_at ON refresh_tokens(expires_at);
CREATE INDEX idx_refresh_tokens_token_hash ON refresh_tokens(token_hash);
CREATE INDEX idx_refresh_tokens_revoked ON refresh_tokens(revoked) WHERE revoked = FALSE;  -- Partial index
```

**Table: failed_login_attempts**
```sql
-- SQLite (current)
CREATE TABLE failed_login_attempts (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    email TEXT NOT NULL,
    ip_address TEXT NOT NULL,
    attempt_time TEXT NOT NULL
);

-- PostgreSQL (target)
CREATE TABLE failed_login_attempts (
    id BIGSERIAL PRIMARY KEY,              -- BIGSERIAL for high-volume tables
    email VARCHAR(255) NOT NULL,
    ip_address INET NOT NULL,
    attempt_time TIMESTAMP WITH TIME ZONE NOT NULL DEFAULT NOW()
);

CREATE INDEX idx_failed_login_email ON failed_login_attempts(email);
CREATE INDEX idx_failed_login_attempt_time ON failed_login_attempts(attempt_time);
```

**Table: auth_audit_log**
```sql
-- PostgreSQL (target with partitioning for scalability)
CREATE TABLE auth_audit_log (
    id BIGSERIAL PRIMARY KEY,
    event_type VARCHAR(50) NOT NULL,
    user_id UUID,
    email VARCHAR(255),
    ip_address INET,
    details JSONB,                          -- Structured audit data
    success BOOLEAN DEFAULT TRUE,
    event_time TIMESTAMP WITH TIME ZONE NOT NULL DEFAULT NOW()

-- Create partitions for 2025 (example)
CREATE TABLE auth_audit_log_2025_11 PARTITION OF auth_audit_log
    FOR VALUES FROM ('2025-11-01') TO ('2025-12-01');

CREATE TABLE auth_audit_log_2025_12 PARTITION OF auth_audit_log
    FOR VALUES FROM ('2025-12-01') TO ('2026-01-01');

-- Indexes on partitions
CREATE INDEX idx_auth_audit_event_type_2025_11 ON auth_audit_log_2025_11(event_type);
CREATE INDEX idx_auth_audit_user_id_2025_11 ON auth_audit_log_2025_11(user_id);
```

### Data Migration Strategies

**Strategy 1: Bulk Copy (Recommended for Lupin)**

**Why Bulk Copy**:
- Small dataset (~550 records)
- One-time migration (not ongoing sync)
- Fast execution (<5 seconds)
- Easy to validate (compare record counts)

**Process**:
```python
# Pseudocode
1. Read all rows from SQLite table
2. Convert data types (TEXT → UUID, TEXT → TIMESTAMP, INTEGER → BOOLEAN)
3. Bulk INSERT into PostgreSQL (transaction-safe)
4. Verify record counts match
5. Commit or rollback
```

**Strategy 2: Incremental Sync (NOT needed for Lupin)**

**Why NOT Using**:
- Lupin's migration is one-time cutover (not dual-write)
- No need to keep SQLite and PostgreSQL in sync

## Factory Pattern Implementation

### Database Interface Abstraction

**Goal**: Same Python code works with both SQLite (legacy) and PostgreSQL (new), selected at runtime via environment variable.

**Architecture**:
```
Application Code (auth_database.py)
         ↓
DatabaseFactory.get_connection(env)
         ↓
    ┌────┴────┐
    ↓         ↓
SQLiteConn  PostgreSQLConn
    ↓         ↓
SQLite DB  PostgreSQL DB
```

**Interface Contract**:
```python
# All database connections must implement this interface
class DatabaseConnection(ABC):
    @abstractmethod
    def connect(self) -> Any:
        """Establish database connection."""
        pass

    @abstractmethod
    def execute(self, query: str, params: tuple) -> Any:
        """Execute parameterized query."""
        pass

    @abstractmethod
    def fetch_one(self, query: str, params: tuple) -> Optional[dict]:
        """Fetch single row as dictionary."""
        pass

    @abstractmethod
    def fetch_all(self, query: str, params: tuple) -> List[dict]:
        """Fetch all rows as list of dictionaries."""
        pass

    @abstractmethod
    def commit(self) -> None:
        """Commit transaction."""
        pass

    @abstractmethod
    def rollback(self) -> None:
        """Rollback transaction."""
        pass

    @abstractmethod
    def close(self) -> None:
        """Close connection."""
        pass
```

```python
Database Factory - Environment-aware database connection abstraction.

Provides unified interface for SQLite (legacy) and PostgreSQL (new) databases.
Automatically selects database based on LUPIN_ENV environment variable.
"""
import os
import sqlite3
from typing import Protocol, Optional, List, Dict, Any
from abc import ABC, abstractmethod

# PostgreSQL driver (asyncpg for async, psycopg2 for sync)
try:
    import psycopg2
    import psycopg2.extras  # For DictCursor
    POSTGRES_AVAILABLE = True
except ImportError:
    POSTGRES_AVAILABLE = False

import cosa.utils.util as cu

class DatabaseConnection(Protocol):
    """Protocol defining database connection interface."""

    def execute(self, query: str, params: tuple = ()) -> None:
        """Execute query without returning results."""
        ...

    def fetch_one(self, query: str, params: tuple = ()) -> Optional[Dict[str, Any]]:
        """Fetch single row as dictionary."""
        ...

    def fetch_all(self, query: str, params: tuple = ()) -> List[Dict[str, Any]]:
        """Fetch all rows as list of dictionaries."""
        ...

    def commit(self) -> None:
        """Commit current transaction."""
        ...

    def rollback(self) -> None:
        """Rollback current transaction."""
        ...

    def close(self) -> None:
        """Close connection."""
        ...

class SQLiteConnection:
    """
    SQLite database connection wrapper (legacy).
    """

    def __init__(self, db_path: str):
        """
        Initialize SQLite connection.

        Requires:
            - db_path is valid file path
        """
        self.db_path   = db_path
        self.conn      = None
        self.cursor    = None
        self._connect()

    def _connect(self) -> None:
        """Establish SQLite connection."""
        self.conn = sqlite3.connect( self.db_path )
        self.conn.row_factory = sqlite3.Row  # Return rows as dictionaries
        self.cursor = self.conn.cursor()

    def execute(self, query: str, params: tuple = ()) -> None:
        """Execute query (no results)."""
        self.cursor.execute( query, params )

    def fetch_one(self, query: str, params: tuple = ()) -> Optional[Dict[str, Any]]:
        """Fetch single row as dictionary."""
        self.cursor.execute( query, params )
        row = self.cursor.fetchone()
        return dict( row ) if row else None

    def fetch_all(self, query: str, params: tuple = ()) -> List[Dict[str, Any]]:
        """Fetch all rows as list of dictionaries."""
        self.cursor.execute( query, params )
        rows = self.cursor.fetchall()
        return [dict( row ) for row in rows]

    def commit(self) -> None:
        """Commit transaction."""
        self.conn.commit()

    def rollback(self) -> None:
        """Rollback transaction."""
        self.conn.rollback()

    def close(self) -> None:
        """Close connection."""
        if self.cursor:
            self.cursor.close()
        if self.conn:
            self.conn.close()

class PostgreSQLConnection:
    """
    PostgreSQL database connection wrapper (Cloud SQL or local).
    """

    def __init__(self, connection_string: str):
        """
        Initialize PostgreSQL connection.

        Requires:
            - connection_string is valid PostgreSQL DSN
            - psycopg2 installed
        """
        if not POSTGRES_AVAILABLE:
            raise RuntimeError( "psycopg2 not installed. Run: pip install psycopg2-binary" )

        self.connection_string = connection_string
        self.conn              = None
        self.cursor            = None
        self._connect()

    def _connect(self) -> None:
        """Establish PostgreSQL connection."""
        self.conn   = psycopg2.connect( self.connection_string )
        self.cursor = self.conn.cursor( cursor_factory=psycopg2.extras.DictCursor )

    def execute(self, query: str, params: tuple = ()) -> None:
        """Execute query (no results)."""
        # Convert SQLite placeholders (?) to PostgreSQL (%s) if needed
        query = self._convert_placeholders( query )
        self.cursor.execute( query, params )

    def fetch_one(self, query: str, params: tuple = ()) -> Optional[Dict[str, Any]]:
        """Fetch single row as dictionary."""
        query = self._convert_placeholders( query )
        self.cursor.execute( query, params )
        row = self.cursor.fetchone()
        return dict( row ) if row else None

    def fetch_all(self, query: str, params: tuple = ()) -> List[Dict[str, Any]]:
        """Fetch all rows as list of dictionaries."""
        query = self._convert_placeholders( query )
        self.cursor.execute( query, params )
        rows = self.cursor.fetchall()
        return [dict( row ) for row in rows]

    def commit(self) -> None:
        """Commit transaction."""
        self.conn.commit()

    def rollback(self) -> None:
        """Rollback transaction."""
        self.conn.rollback()

    def close(self) -> None:
        """Close connection."""
        if self.cursor:
            self.cursor.close()
        if self.conn:
            self.conn.close()

    @staticmethod
    def _convert_placeholders(query: str) -> str:
        """
        Convert SQLite placeholders (?) to PostgreSQL (%s).

        Example:
            "SELECT * FROM users WHERE email = ?"
            → "SELECT * FROM users WHERE email = %s"
        """
        return query.replace( "?", "%s" )

        else:

    def get_notifications_connection() -> DatabaseConnection:
```

**Tasks**:

**Task 3.1**: Create migration script skeleton (1 hour)

**File**: `src/scripts/migrate_sqlite_to_postgres.py`

```python
"""
SQLite to PostgreSQL Data Migration Script

Migrates data from SQLite databases (lupin-auth.db, lupin-notifications.db)
to PostgreSQL (local or Cloud SQL).

Usage:
    # Dry run (no writes)
    python src/scripts/migrate_sqlite_to_postgres.py --dry-run

    # Migrate to local PostgreSQL
    export LUPIN_ENV=development
    python src/scripts/migrate_sqlite_to_postgres.py

    # Migrate to Cloud SQL
    export LUPIN_ENV=production
    export AUTH_DB_PASSWORD=<secret>
    export CLOUD_SQL_CONNECTION=<connection-name>
    python src/scripts/migrate_sqlite_to_postgres.py
"""
import sys
import os
import argparse
import sqlite3
from typing import List, Dict, Any
from datetime import datetime
import json

# Add project root to path
sys.path.insert( 0, os.path.dirname( os.path.dirname( os.path.abspath( __file__ ) ) ) )

import cosa.utils.util as cu
from cosa.rest.database_factory import PostgreSQLConnection
from cosa.rest.database_config import build_postgres_connection_string

class SQLiteToPostgresMigrator:
    """
    Migrates data from SQLite to PostgreSQL.
    """

    def __init__(self, dry_run: bool = False, verbose: bool = True):
        """
        Initialize migrator.

        Requires:
            - LUPIN_ENV environment variable set
            - PostgreSQL target database exists
            - Alembic migrations applied
        """
        self.dry_run         = dry_run
        self.verbose         = verbose
        self.sqlite_auth_db  = cu.get_project_root() + "/src/conf/long-term-memory/lupin-auth.db"
        self.sqlite_notif_db = cu.get_project_root() + "/src/conf/long-term-memory/lupin-notifications.db"

        # Get target environment
        self.env = os.environ.get( "LUPIN_ENV", "" ).lower()
        if self.env not in ["development", "test", "production"]:
            raise RuntimeError( "LUPIN_ENV must be set to: development, test, or production" )

        # PostgreSQL connection
        auth_conn_string = build_postgres_connection_string( self.env, "lupin_auth" )
        self.pg_conn = PostgreSQLConnection( auth_conn_string )

        if self.verbose:
            cu.print_banner( f"SQLite → PostgreSQL Migration ({self.env})", prepend_nl=True )
            if self.dry_run:
                print( "🔍 DRY RUN MODE - No data will be written\n" )

    def migrate_all(self) -> bool:
        """
        Migrate all tables from SQLite to PostgreSQL.

        Returns:
            True if migration successful, False otherwise
        """
        try:
            # Auth database tables
            tables = [
                "users",
                "refresh_tokens",
                "api_keys",
                "email_verification_tokens",
                "password_reset_tokens",
                "failed_login_attempts",
                "auth_audit_log"
            ]

            for table in tables:
                self._migrate_table( table, self.sqlite_auth_db )

            # Notifications database
            # TODO: Implement when notifications schema finalized

            if not self.dry_run:
                self.pg_conn.commit()
                print( "\n✅ Migration completed successfully!" )
            else:
                print( "\n✅ Dry run completed (no changes made)" )

            return True

        except Exception as e:
            print( f"\n❌ Migration failed: {e}" )
            if not self.dry_run:
                self.pg_conn.rollback()
            return False

        finally:
            self.pg_conn.close()

    def _migrate_table(self, table_name: str, sqlite_db_path: str) -> None:
        """
        Migrate single table from SQLite to PostgreSQL.
        """
        if self.verbose:
            print( f"\n📋 Migrating table: {table_name}" )

        # Read from SQLite
        sqlite_conn = sqlite3.connect( sqlite_db_path )
        sqlite_conn.row_factory = sqlite3.Row
        cursor = sqlite_conn.cursor()

        cursor.execute( f"SELECT * FROM {table_name}" )
        rows = cursor.fetchall()

        if self.verbose:
            print( f"   Found {len( rows )} records in SQLite" )

        if len( rows ) == 0:
            sqlite_conn.close()
            return

        # Convert rows to dictionaries
        records = [dict( row ) for row in rows]

        # Transform data for PostgreSQL
        transformed = self._transform_records( table_name, records )

        # Write to PostgreSQL
        if not self.dry_run:
            self._bulk_insert( table_name, transformed )
            if self.verbose:
                print( f"   ✅ Inserted {len( transformed )} records into PostgreSQL" )
        else:
            if self.verbose:
                print( f"   🔍 Would insert {len( transformed )} records (dry run)" )
                print( f"   Sample record: {transformed[0]}" )

        sqlite_conn.close()

    def _transform_records(self, table_name: str, records: List[Dict[str, Any]]) -> List[Dict[str, Any]]:
        """
        Transform SQLite records to PostgreSQL format.

        Converts:
            - TEXT UUIDs → UUID type
            - TEXT ISO timestamps → TIMESTAMP WITH TIME ZONE
            - INTEGER booleans (0/1) → BOOLEAN
            - TEXT JSON → JSONB
        """
        transformed = []

        for record in records:
            new_record = {}

            for key, value in record.items():
                # UUID conversion (id, user_id, jti fields)
                if key in ["id", "user_id", "jti"] and value:
                    new_record[key] = value  # PostgreSQL will handle UUID conversion

                # Timestamp conversion (created_at, expires_at, etc.)
                elif key.endswith( "_at" ) and value:
                    # SQLite stores ISO 8601, PostgreSQL parses automatically
                    new_record[key] = value

                # Boolean conversion (email_verified, is_active, revoked, used, success)
                elif key in ["email_verified", "is_active", "revoked", "used", "success"]:
                    new_record[key] = bool( value ) if value is not None else False

                # JSON conversion (roles field in users table, details in audit_log)
                elif key in ["roles", "details"] and value:
                    # SQLite stores as TEXT, PostgreSQL expects JSONB
                    new_record[key] = value  # Already valid JSON string

                # All other fields
                else:
                    new_record[key] = value

            transformed.append( new_record )

        return transformed

    def _bulk_insert(self, table_name: str, records: List[Dict[str, Any]]) -> None:
        """
        Bulk insert records into PostgreSQL table.
        """
        if len( records ) == 0:
            return

        # Build INSERT statement
        columns = list( records[0].keys() )
        placeholders = ", ".join( ["%s"] * len( columns ) )
        column_names = ", ".join( columns )

        query = f"INSERT INTO {table_name} ({column_names}) VALUES ({placeholders})"

        # Execute for each record
        for record in records:
            values = tuple( record[col] for col in columns )
            self.pg_conn.execute( query, values )

def main():
    parser = argparse.ArgumentParser(
        description="Migrate data from SQLite to PostgreSQL"
    )
    parser.add_argument(
        "--dry-run",
        action="store_true",
        help="Dry run mode (no writes to PostgreSQL)"
    )
    parser.add_argument(
        "--quiet",
        action="store_true",
        help="Quiet mode (minimal output)"
    )

    args = parser.parse_args()

    migrator = SQLiteToPostgresMigrator(
        dry_run=args.dry_run,
        verbose=not args.quiet
    )

    success = migrator.migrate_all()
    sys.exit( 0 if success else 1 )

if __name__ == "__main__":
    main()
```

```python
"""
Migration validation script - compares SQLite and PostgreSQL record counts.
"""
import sqlite3
import sys
import os

sys.path.insert( 0, os.path.dirname( os.path.dirname( os.path.abspath( __file__ ) ) ) )

import cosa.utils.util as cu
from cosa.rest.database_factory import PostgreSQLConnection
from cosa.rest.database_config import build_postgres_connection_string

def validate_migration():
    """Compare record counts between SQLite and PostgreSQL."""

    cu.print_banner( "Migration Validation", prepend_nl=True )

    # Connect to SQLite
    sqlite_db = cu.get_project_root() + "/src/conf/long-term-memory/lupin-auth.db"
    sqlite_conn = sqlite3.connect( sqlite_db )
    sqlite_cursor = sqlite_conn.cursor()

    # Connect to PostgreSQL
    env = os.environ.get( "LUPIN_ENV", "development" )
    pg_conn_string = build_postgres_connection_string( env, "lupin_auth" )
    pg_conn = PostgreSQLConnection( pg_conn_string )

    # Tables to validate
    tables = [
        "users",
        "refresh_tokens",
        "api_keys",
        "email_verification_tokens",
        "password_reset_tokens",
        "failed_login_attempts",
        "auth_audit_log"
    ]

    all_match = True

    print( f"\n{'Table':<30} {'SQLite':<10} {'PostgreSQL':<12} {'Status'}" )
    print( "=" * 70 )

    for table in tables:
        # SQLite count
        sqlite_cursor.execute( f"SELECT COUNT(*) FROM {table}" )
        sqlite_count = sqlite_cursor.fetchone()[0]

        # PostgreSQL count
        pg_result = pg_conn.fetch_one( f"SELECT COUNT(*) FROM {table}" )
        pg_count = pg_result['count']

        # Compare
        match = sqlite_count == pg_count
        status = "✅ MATCH" if match else "❌ MISMATCH"

        print( f"{table:<30} {sqlite_count:<10} {pg_count:<12} {status}" )

        if not match:
            all_match = False

    sqlite_conn.close()
    pg_conn.close()

    print( "=" * 70 )

    if all_match:
        print( "\n✅ Validation PASSED - all record counts match!" )
        return True
    else:
        print( "\n❌ Validation FAILED - record count mismatch detected!" )
        return False

if __name__ == "__main__":
    success = validate_migration()
    sys.exit( 0 if success else 1 )
```

```python
"""
Database Interface - Abstract base class for all database connections.
"""
from abc import ABC, abstractmethod
from typing import Optional, List, Dict, Any, Protocol

class DatabaseConnection(Protocol):
    """
    Protocol defining required methods for database connections.

    All database implementations (SQLite, PostgreSQL, etc.) must implement these methods.
    """

    def execute(self, query: str, params: tuple = ()) -> None:
        """
        Execute query without returning results.

        Requires:
            - query is valid SQL
            - params match query placeholders

        Ensures:
            - Query executed successfully or exception raised

        Example:
            db.execute( "UPDATE users SET last_login_at = %s WHERE id = %s", (now, user_id) )
        """
        ...

    def fetch_one(self, query: str, params: tuple = ()) -> Optional[Dict[str, Any]]:
        """
        Fetch single row as dictionary.

        Requires:
            - query is valid SELECT statement
            - params match query placeholders

        Ensures:
            - Returns dictionary if row found
            - Returns None if no rows found

        Example:
            user = db.fetch_one( "SELECT * FROM users WHERE email = %s", (email,) )
        """
        ...

    def fetch_all(self, query: str, params: tuple = ()) -> List[Dict[str, Any]]:
        """
        Fetch all rows as list of dictionaries.

        Requires:
            - query is valid SELECT statement
            - params match query placeholders

        Ensures:
            - Returns list of dictionaries (empty list if no rows)

        Example:
            users = db.fetch_all( "SELECT * FROM users WHERE is_active = %s", (True,) )
        """
        ...

    def commit(self) -> None:
        """
        Commit current transaction.

        Ensures:
            - All pending changes persisted to database
        """
        ...

    def rollback(self) -> None:
        """
        Rollback current transaction.

        Ensures:
            - All pending changes discarded
        """
        ...

    def close(self) -> None:
        """
        Close database connection.

        Ensures:
            - Connection resources released
        """
        ...
```

```python
"""
Production-ready SQLite → PostgreSQL migration with validation and rollback.
"""
import sys
import os
import sqlite3
import argparse
from typing import List, Dict, Any, Tuple
from datetime import datetime
import hashlib
import json

sys.path.insert( 0, os.path.dirname( os.path.dirname( os.path.abspath( __file__ ) ) ) )

import cosa.utils.util as cu
from cosa.rest.database_factory import PostgreSQLConnection
from cosa.rest.database_config import build_postgres_connection_string

class ProductionMigrator:
    """
    Production-ready migration with validation, checkpointing, and rollback.
    """

    def __init__(self, env: str = "development", dry_run: bool = False):
        self.env     = env
        self.dry_run = dry_run

        # SQLite sources
        self.sqlite_auth_db = cu.get_project_root() + "/src/conf/long-term-memory/lupin-auth.db"

        # PostgreSQL target
        conn_string = build_postgres_connection_string( env, "lupin_auth" )
        self.pg_conn = PostgreSQLConnection( conn_string )

        # Checkpointing
        self.checkpoint_file = "/tmp/migration_checkpoint.json"
        self.checkpoints = self._load_checkpoints()

        cu.print_banner( f"Production Migration ({env})", prepend_nl=True )
        if dry_run:
            print( "🔍 DRY RUN MODE\n" )

    def migrate_with_validation(self) -> bool:
        """
        Migrate with full validation and rollback capability.
        """
        try:
            # Step 1: Pre-migration validation
            if not self._pre_migration_checks():
                print( "❌ Pre-migration checks failed" )
                return False

            # Step 2: Backup SQLite (safety)
            self._backup_sqlite()

            # Step 3: Migrate tables
            tables = [
                "users",
                "refresh_tokens",
                "api_keys",
                "email_verification_tokens",
                "password_reset_tokens",
                "failed_login_attempts",
                "auth_audit_log"
            ]

            for table in tables:
                if table in self.checkpoints.get( "completed_tables", [] ):
                    print( f"⏭️  Skipping {table} (already migrated)" )
                    continue

                if not self._migrate_table_with_checksum( table ):
                    print( f"❌ Migration failed at table: {table}" )
                    return False

                self._checkpoint_table( table )

            # Step 4: Post-migration validation
            if not self._post_migration_validation():
                print( "❌ Post-migration validation failed" )
                return False

            # Step 5: Commit
            if not self.dry_run:
                self.pg_conn.commit()
                print( "\n✅ Migration completed successfully!" )

            return True

        except Exception as e:
            print( f"\n❌ Migration failed: {e}" )
            if not self.dry_run:
                self.pg_conn.rollback()
                print( "🔄 Transaction rolled back" )
            return False

        finally:
            self.pg_conn.close()

    def _pre_migration_checks(self) -> bool:
        """Run pre-migration validation checks."""
        print( "\n📋 Pre-migration Checks:" )

        # Check 1: PostgreSQL tables exist
        result = self.pg_conn.fetch_one( "SELECT COUNT(*) as count FROM information_schema.tables WHERE table_schema = 'public'" )
        table_count = result['count']

        if table_count < 7:
            print( f"   ❌ Only {table_count} tables found (expected 7+). Run Alembic migrations first." )
            return False
        else:
            print( f"   ✅ Found {table_count} tables in PostgreSQL" )

        # Check 2: SQLite databases exist
        if not os.path.exists( self.sqlite_auth_db ):
            print( f"   ❌ SQLite database not found: {self.sqlite_auth_db}" )
            return False
        else:
            print( f"   ✅ SQLite database found" )

        # Check 3: PostgreSQL is empty (avoid duplicate migration)
        result = self.pg_conn.fetch_one( "SELECT COUNT(*) as count FROM users" )
        if result['count'] > 0:
            print( f"   ⚠️  PostgreSQL users table already has {result['count']} records" )
            print( "   Continue anyway? (y/n): ", end="" )

            if input().lower() != 'y':
                return False

        print( "   ✅ Pre-migration checks passed\n" )
        return True

    def _migrate_table_with_checksum(self, table: str) -> bool:
        """Migrate table and verify data integrity with checksum."""
        print( f"\n📦 Migrating: {table}" )

        # Read from SQLite
        sqlite_conn = sqlite3.connect( self.sqlite_auth_db )
        sqlite_conn.row_factory = sqlite3.Row
        cursor = sqlite_conn.cursor()

        cursor.execute( f"SELECT * FROM {table}" )
        rows = cursor.fetchall()
        sqlite_conn.close()

        print( f"   Source: {len( rows )} records" )

        if len( rows ) == 0:
            print( f"   ⏭️  Skipping (empty table)" )
            return True

        # Convert to dicts
        records = [dict( row ) for row in rows]

        # Calculate checksum of source data
        source_checksum = self._calculate_checksum( records )
        print( f"   Checksum: {source_checksum[:8]}..." )

        # Transform for PostgreSQL
        transformed = self._transform_records( table, records )

        # Insert into PostgreSQL
        if not self.dry_run:
            self._bulk_insert( table, transformed )

            # Verify
            result = self.pg_conn.fetch_one( f"SELECT COUNT(*) as count FROM {table}" )
            pg_count = result['count']

            if pg_count != len( rows ):
                print( f"   ❌ Record count mismatch: {len( rows )} → {pg_count}" )
                return False

            print( f"   ✅ Inserted {pg_count} records" )
        else:
            print( f"   🔍 Would insert {len( transformed )} records (dry run)" )

        return True

    def _calculate_checksum(self, records: List[Dict[str, Any]]) -> str:
        """Calculate SHA-256 checksum of records."""
        # Sort records by first column for consistent ordering
        sorted_records = sorted( records, key=lambda r: str( list( r.values() )[0] ) )

        # Serialize to JSON
        json_str = json.dumps( sorted_records, sort_keys=True, default=str )

        # Hash
        return hashlib.sha256( json_str.encode() ).hexdigest()

    def _backup_sqlite(self) -> None:
        """Create timestamped backup of SQLite database."""
        timestamp = datetime.now().strftime( "%Y%m%d_%H%M%S" )
        backup_path = f"{self.sqlite_auth_db}.backup_{timestamp}"

        import shutil
        shutil.copy2( self.sqlite_auth_db, backup_path )

        print( f"\n💾 SQLite backup: {backup_path}" )

    def _checkpoint_table(self, table: str) -> None:
        """Record checkpoint for completed table."""
        if "completed_tables" not in self.checkpoints:
            self.checkpoints["completed_tables"] = []

        self.checkpoints["completed_tables"].append( table )
        self._save_checkpoints()

    def _load_checkpoints(self) -> Dict:
        """Load checkpoint file if exists."""
        if os.path.exists( self.checkpoint_file ):
            with open( self.checkpoint_file, 'r' ) as f:
                return json.load( f )
        return {}

    def _save_checkpoints(self) -> None:
        """Save checkpoint file."""
        with open( self.checkpoint_file, 'w' ) as f:
            json.dump( self.checkpoints, f, indent=2 )

        # See validate_migration.py for full implementation

        return True
```

### Rollback Procedures

**Scenario 1: Migration Failed Mid-Process**

```bash
# PostgreSQL transaction rollback (automatic if script fails)
# No manual action needed if migration script used transactions

# Verify PostgreSQL is clean
docker-compose exec postgres psql -U lupin_dev -d lupin_auth -c "SELECT COUNT(*) FROM users;"

# Should show 0 or pre-migration count
```

**Scenario 2: Migration Complete But Data Issues Found**

```bash
# Rollback to SQLite
export LUPIN_ENV=""  # Fallback to SQLite

# Restart FastAPI with SQLite backend
pkill -f fastapi_app.main
python -m fastapi_app.main

curl http://localhost:7999/health
```

**Scenario 3: Cloud SQL Deployment Issues**

```bash
# Rollback Cloud Run to previous revision
gcloud run services update-traffic lupin-api \
  --to-revisions=PREVIOUS_REVISION=100 \
  --region=us-central1

# Or rollback completely
gcloud run revisions list --service=lupin-api --region=us-central1
gcloud run services update-traffic lupin-api \
  --to-revisions=WORKING_REVISION=100 \
  --region=us-central1
```

