## Key Technical Decisions

### Phase 2.4 Decisions:

1. **Server-Side Transcription over Web Speech API**
   - **Rationale**: Full control, privacy, existing infrastructure (`/api/upload-and-transcribe-mp3`)
   - **Trade-off**: Requires upload, but gains Whisper quality and privacy

2. **Reusable Audio Recorder Module**
   - **Pattern**: Class-based with callback architecture (matches existing `TTSAudioCache`, `SequentialAudioManager`)
   - **Export**: UMD pattern (works everywhere: script tags, CommonJS, ES6)
   - **Dependencies**: Zero external dependencies (vanilla JS, browser APIs only)

3. **30-Second Limit Display**
   - **Format**: Count-up with fraction (`🔴 05/30s`)
   - **Warning**: Yellow emoji at 25+ seconds (`🟡 27/30s`)
   - **Rationale**: Simple, clear, low-anxiety UX

4. **ESC Key Cancellation with Cancellation Flag**
   - **Pattern**: Flag-based race condition prevention
   - **Rationale**: Prevents async upload after destroy() is called
   - **Implementation**: `_cancelling` flag checked in `_handleRecordingStopped()`

5. **raw_transcription Field Preference**
   - **Rationale**: Preserves full capitalization and punctuation from Whisper
   - **Fallback**: `raw_transcription` → `transcription` → `text`

## Lessons Learned

### Phase 2.4 Learnings:

1. **Race Conditions in Async Cleanup**
   - **Problem**: MediaRecorder 'stop' event fires asynchronously after destroy()
   - **Solution**: Cancellation flag (`_cancelling`) to prevent late execution
   - **Pattern**: Always use flags for async cleanup coordination

2. **Performance Metrics for Debugging**
   - **Value**: Round-trip timing helps identify bottlenecks (base64 conversion, upload, transcription)
   - **Pattern**: Use `performance.now()` API, log in debug mode only

3. **Keyboard-First UX Design**
   - **Pattern**: Auto-focus + select all text for fastest workflow
   - **Result**: Press Enter (1s), Type (3s replaces), Arrows (insert mode)
   - **User Feedback**: Extremely positive

4. **User Testing Reveals Edge Cases**
   - **Example**: User discovered ESC race condition bug during manual testing
   - **Lesson**: Manual testing by users finds issues automated tests miss
