#### Phase 12: Inline Smoke Tests

**Pattern**: Every module has `quick_smoke_test()` with `if __name__ == "__main__"`

**Structure**:
```python
def quick_smoke_test():
    cu.print_banner( "Test Name", prepend_nl=True )
    try:
        # Test 1: Module import
        # Test 2: Instantiation
        # Test 3: ID format validation
        # Test 4: Property access
        print( "✓ All tests passed" )
        return True
    except Exception as e:
        print( f"✗ Test failed: {e}" )
        return False

def test_smoke():  # Pytest wrapper
    assert quick_smoke_test()

if __name__ == "__main__":
    sys.exit( 0 if quick_smoke_test() else 1 )
```

**Run**: `python -m cosa.agents.{agent_name}.job`

#### Phase 13: Dry-Run Mode Implementation

**Contract**:
1. Accept `dry_run: bool = False` parameter
2. Send breadcrumb notifications at each phase (low priority)
3. Return mock results with `cost_summary.total_cost_usd = 0.0`
4. Never call external APIs when `dry_run=True`
5. Complete in <30 seconds

**Pattern**:
```python
async def _execute_dry_run( self, voice_io, cosa_interface ) -> str:
    await voice_io.notify( "🧪 Dry run: Phase 1", priority="low" )
    await asyncio.sleep( 1.0 )
    # ... more phases
    self.artifacts[ "path" ] = f"dry-run-{self.id_hash}/output"
    return "Dry run complete."
```
