## Context

Lupin has a robust 5-tier testing strategy (1534+ unit, 50 smoke, 85+ integration, 50 WebSocket, 12 interactive proxy tests) but **zero browser-based E2E testing**. Research recommends **Playwright Python + pytest-playwright** as the clear choice for the FastAPI + vanilla HTML/JS stack.

## Architecture Decisions

| ID | Decision |
|----|----------|
| AD-01 | Separate `run-e2e-tests.sh` (not merged with integration runner) |
| AD-02 | Session-scoped server fixture (reuse integration pattern) |
| AD-03 | Dedicated `src/tests/e2e/conftest.py` |
| AD-04 | `data-testid="page-element-type"` naming convention |
| AD-05 | Real browser login (not token injection) for auth fixtures |
| AD-06 | `pytest-playwright-visual-snapshot` (Python-native, free) |
| AD-07 | `clean_test_db()` + fresh browser context per test |
| AD-08 | Test WebSocket through browser (not protocol client) |
| AD-09 | AI augments but humans approve all test changes (Round 2) |
