# The cosa tier runs OUTSIDE the worktree false-green guard's wiring

**Date:** 2026-08-16 (EDT) · **Found by:** Krishna 🦚 (Cheech's crew) while running condition 3 of job `a4d483e0` (cosa tier against HEAD) in a git worktree.
**Status:** FINDING — not fixed here; needs a row + ratification (touches the shared root conftest and the merge-pyramid's protection).

## Verdict

The worktree false-green guard (row `a9f87d29`, commit `24536cf9`) is wired **only** into `src/tests/conftest.py`. The **cosa tier** runs `pytest src/cosa/tests/`, whose conftest chain is `src/conftest.py` (root) + `src/cosa/tests/conftest.py` — it never loads `src/tests/conftest.py`. So the tier that joined the merge pyramid on 2026-08-13 (`src/tests/run-cosa-tests.sh`, row `d83d025b`) is exactly the tier the guard does **not** automatically protect.

## The guard, and where its wiring stops

`src/tests/worktree_tree_guard.py` (pure, unit-tested both directions) compares, at collection, each collected test file's git-tree-root against `LUPIN_ROOT`'s git-tree-root. If they differ, the file is imported from a different tree than it lives in → false-green risk → it fails loud. The trap it closes: run a worktree's test files while `LUPIN_ROOT` still points at the main tree, and `conftest.py`'s `sys.path[0]` insertion silently imports `cosa` from the **main** tree — a revert-to-verify / RED check reports GREEN because it exercised the wrong tree's code (proven 2026-08-16: a worktree RED check read 44-green until `LUPIN_ROOT` was set to the worktree, then flipped to 8 RED / 36 green).

Commit `24536cf9` added the guard **only** to `src/tests/conftest.py` (plus the pure module + its unit test). pytest loads conftest files from the rootdir down the path to each collected item. For `pytest src/cosa/tests/` that path does **not** pass through `src/tests/`, so `src/tests/conftest.py` — and the guard call inside it — never runs.

## Why it matters specifically for the cosa tier

- The cosa tier is `~8,788` tests and is a **merge-pyramid gate** as of 2026-08-13. A gate whose worktree runs can silently go false-green is the exact class of defect (`d8d019f6`) the fleet spent 2026-08-16 stamping out.
- The cosa tree has a long history of being un-protected because nothing referenced it (row `5bf28e07`: "a suite no gate references cannot go red, and a suite that cannot go red is indistinguishable from a suite that passes"). It has since joined the pyramid, but its worktree-safety wiring did not follow.
- Anyone running the cosa tier in a worktree (the natural way to test HEAD on a shared, dirty tree) gets **no guard and no warning**.

## Evidence from this run

Running condition 3 in a HEAD worktree, I confirmed the guard is functional and my setup consistent **by calling `check_paths` directly** (it is not loaded by the cosa conftest chain):

- SILENT on the correct setup (`LUPIN_ROOT` = worktree, matches the test files' tree) → `None`.
- FIRES on the trap (`LUPIN_ROOT` = main tree, file in worktree) → the diagnostic.
- `cosa.__file__` resolved to `<worktree>/src/cosa/__init__.py` (HEAD code, not main).

That confirmation was manual. A naive runner gets neither the guard nor the hand-check.

## Closing options

| # | Change | Tradeoff |
|---|---|---|
| **1 (recommended)** | Move the collection-time guard call into **`src/conftest.py`** — the ROOT conftest its own docstring says is "shared by BOTH test trees." One wiring covers `src/tests/**` AND `src/cosa/tests/**`. | `src/conftest.py` is meant to stay minimal (cross-tree isolation guards only) — but this IS a cross-tree guard, so it belongs there. Requires de-duping the existing `src/tests/conftest.py` wiring so there is one call site, not two. |
| 2 | Duplicate the wiring into `src/cosa/tests/conftest.py`. | Two-source drift — the guard's logic now has two wiring sites that can diverge. |
| 3 | Leave as-is; rely on runners to set `LUPIN_ROOT` + hand-check. | The exact discipline-dependence the guard was built to replace. Rejected. |

## Recommendation

Option 1. The guard is a hook-collection check (`pytest_collection_modifyitems`-shaped) that already lives in a pure, tree-agnostic module; the only change is moving its **wiring** up one level to the root conftest both trees load, and removing the now-redundant wiring in `src/tests/conftest.py`. That closes the gap for the cosa tier with a single call site and no new drift surface.
