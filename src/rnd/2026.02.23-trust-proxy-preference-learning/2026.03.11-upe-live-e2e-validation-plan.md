## Phase 2: Investigate Warm Prediction Threshold Issues

**Goal**: Determine why warm tests sometimes fall back to `cold_start`; fix if needed.

### Step 2.1 — Diagnostic: embedding similarity measurement
- Generate real embeddings for seed questions and query questions from `test_warm_yes_no_cbr_prediction`
- Compute pairwise cosine similarities
- Check if similarities cross 0.75 threshold (`prediction engine cbr similarity threshold`)
- Verify `similarity_pct` scale (0-100 vs 0-1) — engine divides by 100 at line ~289

### Step 2.2 — Category mismatch check
- Verify `NotificationCategoryClassifier` assigns same category to seed and query questions
- Category mismatch = `find_similar()` filters wrong bucket = no matches

### Step 2.3 — Threshold tuning (if needed)
- **Option A** (preferred): Lower threshold from 0.75 to 0.65 in INI
- **Option B**: Adjust seed question phrasing in tests to be closer to queries

### Step 2.4 — Re-run warm tests with debug
```bash
pytest src/tests/integration/test_prediction_engine_e2e.py::TestPredictionEngineWarm -v -s
```
**Success**: >= 80% of warm tests achieve CBR strategy instead of `cold_start`.
