## What's NOT Tested Yet (Phase 7 Gaps)

### 1. Manual E2E: Voice Pipeline End-to-End

The full pipeline has never been tested end-to-end in a single session:

```
Browser 🎤 → AudioRecorder → Whisper STT → POST /api/notify
  → WebSocket → CCNotificationListener → JSONL buffer
  → Hook fires → drain_voice_buffer() → format_voice_context()
  → emit_json( { hookSpecificOutput: { additionalContext: "[Voice]: ..." } } )
  → Claude Code receives and acts on voice content
```

**Test scenarios needed**:

| # | Scenario | Hook | Expected |
|---|----------|------|----------|
| E1 | Push voice text to buffer, next tool fires | PostToolUse | CC sees `[Voice]: text` in additionalContext |
| E2 | Push voice text to buffer, next tool fires | PreToolUse | CC sees `[Voice]: text` in additionalContext |
| E3 | Push voice text to buffer, CC tries to stop | Stop | CC blocked with reason containing voice text |
| E4 | Push voice text 4x, CC tries to stop each time | Stop | 3 blocks, then allows (counter safety valve) |
| E5 | Push voice text, CC asks permission for Bash | PermissionRequest | Deny + redirect message, CC re-evaluates |
| E6 | Empty buffer, CC asks permission for Read | PermissionRequest | Auto-allow (Path A) |
| E7 | Empty buffer, CC asks permission for Bash | PermissionRequest | Sync forward to user (Path C) |
| E8 | CC calls mcp__cosa-voice__notify | PostToolUse | Immediate passthrough, no drain |
| E9 | Browser 🎤 → STT → text appears in input | Phase 6 UI | Transcribed text in CC card input box |
| E10 | Browser Send button → notification → buffer | Phase 6 UI | Message appears in JSONL buffer |

**How to test E1-E8 without browser** (CLI simulation):
```bash
# Get session hash
SESSION_HASH=$(cat ~/.claude/sessions/cc-*.json | python3 -c "import sys,json; print(json.load(sys.stdin)['session_id_hash'])")

# Push voice text to buffer
echo '{"message": "also check the tests", "type": "user_initiated_message"}' >> ~/.claude/sessions/cc-buffer-${SESSION_HASH}.jsonl

# Next hook fires → drains buffer → injects as additionalContext
# Observe Claude Code's response to verify it received the voice content
```
