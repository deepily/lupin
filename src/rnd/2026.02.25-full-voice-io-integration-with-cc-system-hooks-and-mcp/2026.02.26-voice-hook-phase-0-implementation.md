## Phase 0 Implementation Steps

### Step 1: Create directory structure

`src/lupin_cli/` already exists (contains `notifications/` package). Add `claude_code/hooks/` subtree:

```
src/lupin_cli/
    __init__.py
    claude_code/
        __init__.py
        hooks/
            __init__.py
            lib/
                __init__.py
                hook_common.py           (shared: read stdin, log, emit JSON, TTS)
                session_bridge.py        (three-tier CC session_id resolution)
            logs/                        (gitignored)
            test_post_tool_use.py        (Tier 1 test hook)
            test_pre_tool_use.py         (Tier 1 test hook)
            test_stop.py                 (Tier 1 test hook)
            test_notification.py         (Tier 1 test hook)
            test_register_session.py     (Session bridge: SessionStart hook)
```

Add `src/lupin_cli/claude_code/hooks/logs/` to `.gitignore`.

### Step 2: Write `lib/hook_common.py`

Shared library for all hooks. Phase 0 includes logging AND "hello world" TTS notifications via `lupin_cli.notifications`:

- `read_hook_input()` — `json.load( sys.stdin )`, extract `session_id`, `hook_event_name`, `cwd`, `transcript_path`
- `log_payload( hook_name, payload )` — write timestamped JSON to `logs/{hook_name}-{timestamp}.json`
- `emit_json( data )` — `print( json.dumps( data ) )` to stdout
- `get_timestamp()` — ISO format helper
- `send_tts( message, priority="low" )` — fire-and-forget TTS via `lupin_cli.notifications.notify_user_async.notify_user_async()`
- `get_target_email()` — resolves from `LUPIN_DEV_EMAIL` env var
- `is_tts_enabled()` — checks `HOOK_TTS_ENABLED` env var (default `true`)

### Step 3: Write `lib/session_bridge.py`

Adapt from user's research at `src/rnd/.../creating-unique-session-id/session_bridge.py`:
- `get_claude_session_id()` — non-blocking, three-tier resolution (env > file > fallback)
- `wait_for_session_id( timeout, poll_interval )` — blocking with timeout
- `get_session_metadata()` — full metadata dict
- `_find_session_file()` — PPID-based file lookup with grandparent fallback
- Session dir: `~/.claude/sessions/`

### Step 4: Write 5 test hooks

Each hook: read stdin via `hook_common`, log full payload, send "hello world" TTS notification, emit valid response.

**`test_register_session.py`** (SessionStart):
- Extract `session_id`, `transcript_path`, `cwd` from stdin
- Write `~/.claude/sessions/cc-{PPID}.json`
- Write `CLAUDE_SESSION_ID` to `CLAUDE_ENV_FILE` (if set)
- Send TTS: `"Hook fired: SessionStart — session {session_id}"`
- Emit `additionalContext: "Session ID: {session_id}"`
- Log full payload

**`test_post_tool_use.py`** (PostToolUse):
- Log full payload (tool name, result, session_id)
- Send TTS: `"Hook fired: PostToolUse — tool {tool_name}"`
- Emit `{}` (passthrough)

**`test_pre_tool_use.py`** (PreToolUse):
- Log full payload (tool name, tool input, session_id)
- Send TTS: `"Hook fired: PreToolUse — tool {tool_name}"`
- Emit `{}` (passthrough)

**`test_stop.py`** (Stop):
- Log full payload (especially `stop_hook_active`)
- Send TTS: `"Hook fired: Stop"`
- Emit `{}` (allow stop)

**`test_notification.py`** (Notification):
- Log full payload (message, title, notification_type)
- Send TTS: `"Hook fired: Notification"`
- Emit `{}` (observation-only, output ignored)

**TTS noise management**: `HOOK_TTS_ENABLED=true|false` (default `true`) silences TTS. Logging always happens.

### Step 5: Register hooks in `.claude/settings.local.json`

Add `hooks` key to existing settings file with all 5 hooks.
