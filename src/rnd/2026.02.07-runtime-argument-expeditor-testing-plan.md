### Bug Fix: Optional Args Gate (Session 162)

**Root cause**: `expeditor.py` line 192 — `if parsed.is_complete()` checked only `all_required_met`. When true (e.g., query extracted from voice command), the entire missing-args block was skipped, so optional user-visible args (budget, audience, audience_context, languages) were never prompted.

**Fix**: Replaced the `if/else` gate with deterministic computation: `missing = [ arg for arg in user_visible if arg not in final_args ]`. Now the expeditor always prompts for any user-visible arg not already in `final_args`, regardless of whether required args are satisfied.

**Impact**: All "happy path" scenarios (DR_HAPPY, DR_BUDGET, DR_AUDIENCE, RTP_HAPPY) now prompt for optional args via batch collection. Confirmation summary shows ALL user-visible args.

### Timeout Chain Fix (Session 163)

**Problem**: Interactive scenarios either failed instantly (DR_HAPPY — within seconds, too fast for 120s timeout) or timed out when user couldn't respond quickly enough.

**Fix**: Increased notification timeouts across the chain:
- `_ask_for_arg`: 60→180s (3 min for single arg response)
- `_ask_for_confirmation`: 60→180s (3 min for review + response)
- `_batch_collect_args`: 120→300s (5 min for multi-field batch form)
- Smoke test `REQUEST_TIMEOUT`: 180→600s (10 min per scenario)
- Smoke test `MAX_POLL_SECONDS`: 90→120s (2 min polling)
- API endpoint default: 30→120s (doesn't affect expeditor, prevents confusion for other callers)

**Diagnostic logging**: Added `[Expeditor]` debug prints after all 3 `notify_user_sync` calls showing `success`, `status`, `exit_code`, `is_timeout`, `response_value`. Will reveal root cause of instant first-scenario failure (offline detection vs LLM cold start vs other).

### Implementation Notes

- **Patch target fix**: `TestCreateAgenticJob` required patching at source module paths (`cosa.agents.deep_research.job.DeepResearchJob`) rather than factory module, because `create_agentic_job()` uses local imports inside the function body.
- **Interactive test constraint**: Tests 4.1-4.9 call real LLM for gap analysis and `notify_user_sync()` which blocks waiting for user voice response. Cannot run in CI/CD or unattended.
- **Confirmation loop**: Sessions 144-157 added `_confirm_and_iterate()`, batch collection, request context abstract, display_name, and audience normalization — nearly doubling the test suite from 49 to 92.
- **Optional args fix**: Session 162 added 8 tests (Class 15: TestOptionalArgPrompting) and updated 1 existing test to reflect new deterministic missing-args computation.

## Mocking Strategy

| Component | Mock Target | How |
|-----------|-------------|-----|
| `subprocess.run` | `agent_registry.subprocess.run` | `@patch` with MagicMock |
