# Declared, correct, and never reaching the surface it was written for — six instances in one night

**Date**: 2026-09-04 (the night of 2026-09-03)
**Recorded by**: Pocholo 📣, at María 🌸's instruction
**Found by**: Maya 🌻 (1, 2, 5, 6), Pocholo 📣 (3, 4), across three seats
**Status**: 🔴 **A COUNT, NOT A RULE. Do not cite this as doctrine.**

---

## Why this exists, and what it is deliberately NOT

Six defects turned up on one evening that share a shape: **something was declared, the
declaration was correct, and it never reached the surface it was written for.** Three
different people found them in three different layers, and nobody recognised it as one
shape until they were set side by side.

🔴 **THIS IS NOT GRADUATED INTO A RULE, ON PURPOSE.** Six in one night is one night.
Rick's standing instruction is that a pattern accumulates **across sessions** before it
becomes doctrine, and this fleet has been wrong before by promoting a single evening's
coincidence into a law. Mr. Radio's retro holds a different family as an open question
for exactly this reason.

⇒ **The point of writing it down is COUNTABILITY.** When the seventh instance appears
next week it should be *counted against these six*, not rediscovered as novel. If none
appears, this ages into a curiosity and costs nobody anything — the correct outcome for
a pattern that turns out not to be one.

⚠️ **THE SHAPE IS STATED NARROWLY FOR THE SAME REASON.** "A declaration that does not
reach its surface" is broad enough to swallow half of software. What these six actually
share: **the declaration is present and correct in the source, a competent reader
inspecting the source concludes it is working, and something between source and surface
silently drops it.** A typo that fails loudly is not this. A feature nobody wrote is not
this.

## The six

### 1 · The clamp declared on the cell, inert on the cell

| | |
|---|---|
| **Declared** | `-webkit-line-clamp` on the `td`, to cap a row title at two lines |
| **Stopped at** | the `td` itself — declared `max-height: 39px`, **rendered 90px** |
| **Fixed / recorded** | `0df94e23` (stamp `g`); write-up `9e7eda24` |
| **Found by** | Maya 🌻 |

🔴 **WHAT MADE IT INVISIBLE: A COMPUTED PROPERTY THAT LIES.** The shared explanation —
*"`display` computes to `flow-root`, so the clamp never applies"* — was **false**, and
false in the most convincing way available: it is a true statement about the `td`, and
the `span` that clamps **correctly** also computes `flow-root`. Chrome returns the same
string for the element that works and the one that does not.

⇒ A reader who checked the computed style got a confident, self-consistent, wrong
answer. **The discriminator was never the property — it was the geometry**: `51/51` on
the span that works against `39/78` on the cell that does not.

⚠️ The artifact carries its own retraction: an explicit ⚠️ naming the `flow-root` story
as false, because *a retraction has to reach the artifact, not just the conversation*.

### 2 · The sticky rule that styles the same element two ways

| | |
|---|---|
| **Declared** | `position: sticky` for the row header across the panes |
| **Stopped at** | the pane boundary — scoped to `.task-list-table`, while the epic board is `.epic-board-table` |
| **Recorded** | `cf722c8a` |
| **Found by** | Maya 🌻 |

🔴 **WHAT MADE IT INVISIBLE: A POPULATION THAT AGREES WITH ITSELF WHERE YOU LOOK.** Of 5
matching elements, **3 computed `sticky` and 2 computed `static`**. Anyone inspecting
the pane where it *does* apply sees it working. The rule is correct and the selector is
correct; the markup was unified and the styling was not.

⇒ Maya's general form, the transferable half: **unifying the markup does not unify the
styling.** A shared renderer implies a shared stylesheet to a reader and implies
nothing at all to the browser.

### 3 · The caveat overwritten before anyone could read it

| | |
|---|---|
| **Declared** | a scope caveat on the flow-ratio readout, written into `title=` in the markup |
| **Stopped at** | the renderer — `_flowRatioLongForm` overwrites `title` on **every** render |
| **Fixed** | `95f1c41f` (moved to the writer); guard `11134444` |
| **Found by** | Pocholo 📣 |

🔴 **WHAT MADE IT INVISIBLE: THE SERVED BYTES CARRIED IT AND THE LIVE ELEMENT DID NOT.**
Every static check passes — the sentence is in the HTML, a fetch finds it, a repo
search finds it, view-source finds it. It is gone before a human could hover.

⚠️ **A SECOND LESSON, NOT ABOUT THE CAVEAT.** Moving it to the writer appended a line to
a string a test pinned, so `flow_ratio_controls`'s counts test went red at `95f1c41f`
and **stayed red on the shared branch for two hours** while other seats built on it.
Bisected rather than reasoned: **37/0** at `95f1c41f~1`, **36/1** at `95f1c41f`. **The
caveat had no guard of its own** despite having been moved specifically so a reader
would see it. The fix added one, and it discriminates: delete the caveat from the
writer and exactly one named test reddens while the counts test stays green.

### 4 · The gate wired to a door, with nothing proving the wire

| | |
|---|---|
| **Declared** | `approval_for_promotion` called from `transition_task`, so a promotion cannot skip Rick |
| **Stopped at** | nothing — the wiring was **correct**. What was absent is any test that could see it removed |
| **Closed** | `47cff912` |
| **Found by** | Pocholo 📣, by mutation rather than by reading |

🔴 **WHAT MADE IT INVISIBLE: THE SUITE GOT *GREENER* WHEN THE WIRING WAS REMOVED.** One
edit, `3f412770e409` → `5dac71c191a0`: across four test files the mutant reported **242
passed / 0 failed** against a baseline of **1 failed / 241 passed**. All 16 module tests
held, and the single door-level observation flipped **red to green**.

⇒ **The worst form this takes.** The other five fail to object. This one *rewards* you:
revert the install and the result looks cleaner than before.

⚠️ **AND THE ARM THAT CLOSED IT CAUGHT A VACUOUS TEST OF MY OWN.** A second mutant
(`eabfbf3e4523`) firing the gate on *every* transition should have reddened three
negative controls and reddened two. The third posted `not_approved → not_approved` and
stayed green — the door rejects that edge upstream with a **422 "not a legal edge"**, so
the request never reached the gate. Two sufficient causes, one assertion.

⇒ Recorded rather than buried: **the third conjunct is UNREACHABLE.** Maya's correction
makes it stronger than first written — the no-op refusal is general to **every X-to-X
edge**, not a `not_approved` special case, so it cannot drift with a status list.

### 5 · The gate that could not ask

| | |
|---|---|
| **Declared** | `_default_ask`, the gate's only live path to Rick |
| **Stopped at** | the import — `lupin_cli.notifications.models`; the module is `notification_models` |
| **Fixed** | `3509e4c4`, with Maya's guard merged rather than described |
| **Found by** | Maya 🌻, in adversarial review of `47cff912` |

🔴 **WHAT MADE IT INVISIBLE: THREE MECHANISMS AT ONCE, NO ONE OF THEM CARELESS.**

| | |
|---|---|
| the import sits **inside** the function | startup is clean; nothing fails at boot |
| `_default_ask` carried **`pragma: no cover`** | the coverage gate could not see it |
| **all 25 tests injected `ask_fn`** | the real default never ran, in any test, ever |

⇒ A manager who cleared the allowlist got a **500**, and **Rick was never asked** — from
a gate whose whole purpose is that he cannot be skipped.

⚠️ **THIS IS INSTANCE 4 ONE LEVEL DOWN, AND THE SAME AUTHOR MISSED IT.** I built a guard
proving the door calls the gate, and nothing proved the gate could do the one thing it
exists for. **Closing a hole at one level is not evidence about the level beneath it.**

### 6 · The claim that a test existed

| | |
|---|---|
| **Declared** | *"the timed-out default is explicitly exempt and a test proves it"* |
| **Stopped at** | a reader — the behaviour was right and **no test could see it** |
| **Fixed** | `49ed48ec` (Maya's one-line arm) |
| **Found by** | Maya 🌻, by deleting the clause rather than reading the tests |

🔴 **WHAT MADE IT INVISIBLE: EVERY TEST THAT SET THE FLAG ALSO SET THE OTHER OPERAND.**
Four tests pass `default_used=True`, and all four also pass `answer="yes"` — on a
`"yes"` the `not answer.startswith( "yes" )` half is already False, so the
`default_used` half can never decide anything. Maya removed the entire exemption and
**the file stayed green**. Only an answer that is **both defaulted and unrecognised**
reaches the clause.

⇒ Her arm is one line and discriminates: drop the exemption at `3a67cee09f12` and
exactly the attribution test reddens by name; restore gives 18 passed.

🔴 **THIS ONE IS DIFFERENT IN KIND AND THAT IS WHY IT IS HERE.** The first five are
declarations in **CODE**. This is a claim **ABOUT** code — present, correct-sounding,
and unbacked — and **the surface it failed to reach was a reader rather than a
runtime.** (María's framing, and the sharpest sentence in this document.)

⚠️ **AND IT HAD ALREADY TRAVELLED.** I said it to María; she repeated it to Rick in
writing an hour later. **A conjunct documented as UNGUARDED is honest** — instance 4's
`to_status` conjunct is exactly that and stands. **A conjunct CLAIMED as tested is
not.** That is why this could not wait for a follow-up row, and why María corrected the
record with Rick herself rather than delegating it.

## The interesting variable is the INVISIBILITY MECHANISM, and it differs every time

This is the part worth carrying forward, and why a bare count would have been useless:

| # | what hid it |
|---|---|
| 1 | a **computed property reporting the same value** for the working and the broken element |
| 2 | a **population that agrees with itself** in the pane you happen to inspect |
| 3 | the **served bytes carry it and the live element does not** — every static check passes |
| 4 | **removing it makes the suite greener** — the tree rewards the revert |
| 5 | **three at once** — an inner import, a coverage pragma, universal injection past the seam |
| 6 | **every test that set the flag also set the other operand**, so the clause could never decide |

⇒ **No two of these are caught by the same technique.** The geometry reading that caught
1 says nothing about 2. The per-pane census that caught 2 cannot see 3. The mutation
that caught 4 would not have found 5, because 5's seam was injected past by every test
including the harness's own baseline. And 6 was found by **deleting the code and
watching nothing happen** — the only one of the six needing no hypothesis at all.

⚠️ **So the tempting summary — "check that your declaration reaches the surface" — is
not actionable**, because in all six cases somebody competent believed they had.

## 🔴 THE OPEN QUESTION, POSED AND DELIBERATELY NOT ANSWERED

**Is there a general test shape for *is this thing actually installed*, or does each
seam need its own purpose-built guard?**

There are exactly **two data points**, and **they are different shapes**:

| | `test_the_transition_door_calls_the_promotion_gate` | `test_the_default_ask_path_is_exercised_not_injected_past` |
|---|---|---|
| **enters at** | HTTP, the real handler, mocked repository | a direct call with the **real** default |
| **technique** | **stands the seam UP** — patches `approval_for_promotion`, asserts it was reached | **refuses to inject** — patches one level LOWER, at `notify_user_sync` |
| **catches** | the call site being removed | the default path being unable to run |
| **why it works** | the door reaches the gate through a module attribute | the import resolves at **call time**, so a lower patch still exercises the default |

⇒ **Neither generalises to the other's case.** Standing the seam up would not have found
the import defect — that is precisely what 25 injecting tests were doing. Refusing to
inject would not have found the missing call site, because it never enters at the door.

**Two data points, two shapes, and no third to arbitrate.** Whether a general form
exists is genuinely unknown. Reaching for one here would be this document's own subject
committed inside it: **a unifying claim that is present, plausible, and never tested
against a surface.**

⚠️ Instance 6 does **not** give a third data point, and it is worth saying why rather
than quietly counting it: the technique that found it — *delete the thing and see
whether anything notices* — is ordinary mutation testing, which this fleet already has.
It is not a new shape of guard.

## What would make this doctrine, and what would kill it

**Promote it if** a seventh and eighth appear in later sessions with invisibility
mechanisms not on the list above. That shows the shape is real *and* the mechanism
genuinely varies, which is what would make it worth teaching.

**Kill it if** the next month produces none, or if every new one is instance 4's shape.
Six in one night, on one branch, during one redesign, is what selection bias looks
like: **three seats spent that evening staring at wiring, so wiring is what they
found.**

⚠️ **THE HONEST LIMIT: NOBODY WENT LOOKING.** All six were hit while doing something
else. That makes them a sample of what bites, not a survey of what exists, and **no rate
can be derived from them.**
