## Context

Rick dislikes the package name `arbiter_vigilance` and wants the Lupin services to read clearly and sit **side-by-side** in `src/`. Two directory renames:

| Current | Target |
|---|---|
| `src/fastapi_app/` | `src/lupin_app/` |
| `src/arbiter_vigilance/` | `src/lupin_arbiter_app/` |

**Why now:** do this **before** the `:8001` arbiter goes live (R0 cutover). Once a `systemd --user` unit is enabled and lingering, its name + ExecStart pin the old name and the rename gets costlier. Renaming first means the unit is born with the right name.

**Outcome:** `src/lupin_app/` (the FastAPI app, `:7999`/`:8000`) and `src/lupin_arbiter_app/` (the standalone `:8001` fleet watcher) sit adjacent, both clearly Lupin-branded. **Zero behavior change — pure rename.**

## Blast-radius summary (from exhaustive discovery — 3 parallel Explore sweeps)

**`fastapi_app` — WIDE (~195 refs, one distinctive token).** The main entry point.
- ~100 Python import sites — overwhelmingly the lazy `import fastapi_app.main as main_module` pattern inside route handlers (runtime imports → **`py_compile` will NOT catch a miss; only running the endpoint will**).
- Critical runtime targets: `uvicorn.run( "fastapi_app.main:app", … )` (`main.py:1107`); `reload_dirs = [ "fastapi_app", … ]` (`main.py:1105`); `python3 -m fastapi_app.main` (both run scripts).
- Two **string-literal introspection** sites a careful reader could miss — `if 'import fastapi_app.main' in source_lines:` (`jobs.py:323`, `websocket.py:783`). The substring sweep fixes them, but they MUST be re-verified, not assumed.
- Hardcoded path traversal: `pages.py:20` → `… "..", "..", "..", "fastapi_app", "static"`.
- Infra/build: `docker/lupin/Dockerfile:253` (COPY), `tsconfig.json`, `package.json`, `.stylelintrc.json`, test `patch('fastapi_app.main.…')` targets, `src/conftest.py` module-cache cleanup.
- **No `__init__.py`** (implicit namespace package) — rename carries nothing extra; still importable after the move.

**`arbiter_vigilance` — NARROW + self-contained (~19 refs).**
- **Nothing outside the package imports it** (the `:7999` proxy reaches it only over HTTP `:8001/state`). Low-risk.
- 11 intra-package + 3 test-file imports; uvicorn factory target `arbiter_vigilance.app:create_production_app --factory` (`run-arbiter-vigilance.sh:42`); has its own `__init__.py` (`__version__`).
- Adjacent **hyphen-named** artifacts (separate tokens): `run-arbiter-vigilance.sh`, `systemd/arbiter-vigilance.service` (+ unit Description), 3 `test_arbiter_vigilance_*.py` files.
- INI keys `arbiter vigilance state url` / `… timeout seconds` are **space-separated config-key names**, not package refs (value is a `:8001` URL) — see Decisions.

**Key runtime insight:** docker-compose bind-mounts `./src:/var/lupin/src`, which **overlays** the image's baked `COPY`. Dev/test pick up the rename with a **container bounce — no image rebuild required**. The Dockerfile COPY is for correctness/clean-build/GCP, not local validation.

## Mechanism

The two tokens are distinctive enough for a **scoped substring sweep** + targeted handling of named files:
1. `git mv` the directory (preserves history).
2. Scoped replace of the underscore token across **code/scripts/config/current-docs**, excluding: `.git`, `.venv`, `node_modules`, `src/lupin_app/static/dist/**` (build output), sub-repos (`lupin-mobile`, `lupin-plugin-firefox`), and **dated historical records** (`src/rnd/**`, `history.md`, `history/**`).
3. Rename the named files (`git mv` test files / run script / systemd unit) + sweep the hyphen token for the arbiter consistency set.
4. Re-verify the high-risk special-cases by hand (string-introspection literals, `reload_dirs`, `pages.py` path, test `patch()` targets, `.claude/settings.local.json` permission rules).
5. `grep -rn '<old_token>' src/` returns **only intentional leftovers** (historical docs) — the zero-residual gate.

## Decisions

1. **Consistency artifacts for the arbiter** (`run-arbiter-vigilance.sh` → `run-lupin-arbiter-app.sh`; `arbiter-vigilance.service` → `lupin-arbiter-app.service`; `test_arbiter_vigilance_*.py` → `test_lupin_arbiter_app_*.py`). → **Rename all** for full consistency (unit not yet enabled — free to rename now).
2. **INI keys `arbiter vigilance state url` / `timeout`.** → **Leave as-is.** Config-key *names* (spaces), not the package token; value is a port URL. Separate blast radius for zero functional gain.
3. **Historical / dated docs** (`src/rnd/**`, `history.md`, archived `history/**`). → **Leave** as a dated record. Update only current-architecture docs: root `CLAUDE.md`, `src/docs/**`, `src/cosa/CLAUDE.md` if it names the path.
4. **Sequencing.** → **Arbiter first, then fastapi_app**, two separate commits, both **held for Rick's push**. Land both **before** R0 cutover.
