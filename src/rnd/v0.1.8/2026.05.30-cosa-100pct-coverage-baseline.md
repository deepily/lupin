## 7. Tier 0 — proposed measurement config (PROPOSAL, not settled doctrine)

> **Status: PROPOSAL.** Excluding `quick_smoke_test()` / `__main__` blocks **redefines what "100%" means**, so the exclusion list is a methodology call Rick must bless before it is load-bearing. `training/` omit is clean (never-grab-GPU mandate). Measured on :7999 against the existing `.coverage` data (report-time re-report, no test re-run). **Not committed.**

### Proposed `pyproject.toml` addition (currently NO `[tool.coverage]` config exists)

```toml
[tool.coverage.run]
branch = true
source = ["cosa"]
omit = [
    "*/cosa/tests/*",            # CoSA's own test suites — test code, not a coverage denominator
    "*/cosa/agents/*/tests/*",   # per-agent test suites (podcast_generator, io_models)
    "*/test_*.py",               # individual test modules
    "*/cosa/agents/*/__main__.py", # CLI entrypoints — glue, run only via `python -m`
    "*/cosa/training/*",         # GPU + user-run-only; untestable in CI per never-grab-GPU mandate
]

[tool.coverage.report]
# exclude_also APPENDS to defaults (keeps `pragma: no cover` working)
exclude_also = [
    "def quick_smoke_test",      # house-style inline smoke block; never runs under pytest
    "if __name__ == .__main__.:",# inline main guards inside regular modules
]
```

*(In `pyproject.toml`, `[tool.coverage.run].omit` alone suffices — it applies at measurement time. The proposal `.coveragerc` mirrored `omit` into `[report]` only to re-report against already-collected data without a 3-minute test re-run.)*
