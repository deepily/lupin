*callers*, not the line. `run-js-tests-capped.sh` sets `-e` without `-u` and survives.

**Positive control** that `${PYTHONPATH:-}` is house style: **8 sibling files** already use it —
`restart-cc-listeners.sh` · `run-lupin-arbiter-app.sh` · `start-cc-with-tmux.sh` ·
`tfe_to_cc_matrix.sh` · `watch-cc-memory.sh` · `e2e/run-tfe-resume-e2e.sh` ·
`run-coverage-gate.sh` · `run-presentation-regression.sh`.

> difference is worth keeping.** `git grep -ln 'PYTHONPATH:-' HEAD -- src/scripts src/tests` returns

## 4. TRAPS — INHERIT THESE, THEY COST REAL TIME

1. **Persistence polarity.** `lupin.taskList.collapsedOwners` is an ARRAY of **collapsed** keys.
   `lupin.epicBoard.groupState` is a MAP of key → **isExpanded**. Porting one from the other
   **inverts a user's saved state and fails invisibly** — the surface renders correctly and a
   CSSOM-level tier cannot see it. *The behaviour tier must catch this specifically; if it cannot,
   it is not a behaviour tier.*
2. **`_renderRow` is shared deliberately** in the JS side (`notifications.js:13418`) with Rick's
   reason in the docstring: *"moving between the epic board and the task list meant re-parsing the
   layout."* ⇒ cell-for-cell row identity is a **behavioural requirement** the TS side must
   reproduce *without* the helper that provides it in JS.
3. **The parity methodology answers only half the ask.** Measured across all three of its documents:
   `behavior`/`behaviour` **0 hits**, `click` **0**, `keyboard` **0**, `persist`/`localStorage`
   **0**. Its scope line reads *"parity is equality of the CSSOM."* ⇒ **a behaviour tier is new work.**
4. 🔴 **No server on this box can serve unmerged branch work.** Both containers bind-mount
   `/projects/lupin/src`, and the branch tip is not an ancestor of main. **Screenshotting `:8000`
   measures MAIN and reports it as the branch's.** Krishna nearly hit this twice.
