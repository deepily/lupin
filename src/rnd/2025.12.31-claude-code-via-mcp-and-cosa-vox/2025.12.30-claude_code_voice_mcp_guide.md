# Claude Code Voice Integration via MCP

## A Minimalist Guide for CoSA/Lupin Orchestration

*December 30, 2025*

---

## Executive Summary

This document describes a voice-enabled MCP (Model Context Protocol) server that bridges Claude Code sessions with the CoSA/Lupin notification infrastructure. The design supports two operational modes:

| Mode | Use Case | Runtime | User Control |
|------|----------|---------|--------------|
| **Option A: Print Mode** | Bounded tasks with natural completion | `claude -p "task"` | Claude drives; user responds when asked |
| **Option B: SDK Client** | Interactive sessions across time | `ClaudeSDKClient` | Bidirectional; user can inject/interrupt |

Both modes use the **same MCP server** for voice I/O—the difference lies in how Claude Code is spawned and managed.

### Key Design Decisions

1. **One MCP process per Claude Code instance** (unavoidable—stdio is 1:1)
2. **All MCP processes call shared Lupin backend** (HTTP/SSE)
3. **Session ID in sender_id field** correlates all exchanges per project
4. **Lupin UI handles TTS/STT** — MCP server is pure message relay

### Print Mode Invocation

```bash
# Direct CLI
export COSA_PROJECT="lupin"
claude -p "Refactor auth module for better testability" \
    --mcp-config ~/.claude/cosa_mcp.json \
    --allowedTools "mcp__cosa__converse,mcp__cosa__notify,mcp__cosa__ask_yes_no,Read,Write,Bash" \
    --permission-mode acceptEdits \
    --output-format json \
    --max-turns 50

# Python subprocess wrapper
import subprocess
import json
import os

def run_bounded_task(prompt: str, project: str, max_turns: int = 50) -> dict:
    """Execute bounded Claude Code task with voice clarification support."""
    
    env = os.environ.copy()
    env["COSA_PROJECT"] = project.lower()
    
    result = subprocess.run(
        [
            "claude", "-p", prompt,
            "--mcp-config", os.path.expanduser("~/.claude/cosa_mcp.json"),
            "--allowedTools", ",".join([
                "mcp__cosa__converse",
                "mcp__cosa__notify", 
                "mcp__cosa__ask_yes_no",
                "Read", "Write", "Bash"
            ]),
            "--permission-mode", "acceptEdits",
            "--output-format", "json",
            "--max-turns", str(max_turns)
        ],
        env=env,
        capture_output=True,
        text=True,
        timeout=3600  # 1 hour max
    )
    
    return json.loads(result.stdout)
```

### SDK Client Implementation

```python
#!/usr/bin/env python3
"""
Interactive Claude Code session manager with voice I/O.

Requires: pip install claude-agent-sdk
"""

import asyncio
from claude_agent_sdk import (
    ClaudeSDKClient, 
    ClaudeAgentOptions,
    AssistantMessage,
    TextBlock,
    ToolUseBlock,
    ResultMessage
)


async def create_interactive_session(
    project: str,
    initial_prompt: str,
    working_dir: str = "/home/user/projects"
) -> None:
    """
    Create and manage an interactive Claude Code session with voice I/O.
    
    Args:
        project: Project name (lowercase, for session ID)
        initial_prompt: Starting instruction for Claude
        working_dir: Working directory for file operations
    """
    
    session_id = f"claude.code@{project.lower()}.deepily.ai"
    
    options = ClaudeAgentOptions(
        cwd=f"{working_dir}/{project}",
        permission_mode="acceptEdits",
        allowed_tools=[
            "Read", "Write", "Bash",
            "mcp__cosa__converse",
            "mcp__cosa__notify",
            "mcp__cosa__ask_yes_no"
        ],
        mcp_servers={
            "cosa": {
                "type": "stdio",
                "command": "python",
                "args": ["/opt/cosa/mcp/cosa_voice_mcp.py"],
                "env": {"COSA_PROJECT": project.lower()}
            }
        },
        system_prompt=f"""Session ID: {session_id}

You have voice communication tools available:
- converse(): Ask questions and wait for voice response
- notify(): Announce status updates (fire-and-forget)
- ask_yes_no(): Get yes/no decisions quickly

Use notify() for progress updates. Use converse() when you need input.
Keep the user informed but don't be chatty."""
    )
    
    async with ClaudeSDKClient(options=options) as client:
        # Initial query
        await client.query(initial_prompt)
        
        async for message in client.receive_response():
            if isinstance(message, AssistantMessage):
                for block in message.content:
                    if isinstance(block, TextBlock):
                        print(f"[Claude] {block.text[:100]}...")
                    elif isinstance(block, ToolUseBlock):
                        print(f"[Tool] {block.name}({list(block.input.keys())})")
                        
            elif isinstance(message, ResultMessage):
                print(f"\n[Complete] Cost: ${message.total_cost_usd:.4f}")
                print(f"[Session] {message.session_id}")
                
                # Session complete - could prompt for continuation here
                # This is where Cosa would ask user what to do next


async def resume_session(session_id: str, prompt: str) -> None:
    """Resume a previously suspended session."""
    
    options = ClaudeAgentOptions(
        resume_session=session_id,
        permission_mode="acceptEdits"
    )
    
    async with ClaudeSDKClient(options=options) as client:
        await client.query(prompt)
        async for message in client.receive_response():
            # Handle messages...
            pass


# Example usage
if __name__ == "__main__":
    asyncio.run(create_interactive_session(
        project="lupin",
        initial_prompt="Let's review the notification system architecture"
    ))
```

## The MCP Server (Shared by Both Modes)

This is the **single MCP server implementation** that works for both Option A and Option B:

```python
#!/usr/bin/env python3
"""
CoSA Voice MCP Server - Voice I/O bridge for Claude Code.

Provides three tools:
  - converse(): Speak to user, wait for voice/text response (blocking)
  - notify(): Announce to user without waiting (fire-and-forget)
  - ask_yes_no(): Quick yes/no decision (convenience wrapper)

Session ID Format: claude.code@{project}.deepily.ai

Configuration:
    COSA_PROJECT: Project name (required, will be lowercased)
    LUPIN_API_URL: Lupin server URL (default: http://localhost:7999)
    LUPIN_API_KEY: API key for authentication

Usage:
    export COSA_PROJECT="lupin"
    claude mcp add cosa -- python /path/to/cosa_voice_mcp.py
"""

import os
import sys
from typing import Optional
from pydantic import ValidationError
from fastmcp import FastMCP

# Import from cosa.cli (the updated notification library)
from cosa.cli.notification_models import (
    NotificationRequest,
    AsyncNotificationRequest,
    NotificationResponse,
    AsyncNotificationResponse,
    NotificationType,
    NotificationPriority,
    ResponseType
)
from cosa.cli.notify_user_sync import notify_user_sync
from cosa.cli.notify_user_async import notify_user_async


# ============================================================================
# Session Configuration
# ============================================================================

def _get_project() -> str:
    """Get project name from environment, lowercased."""
    project = os.getenv("COSA_PROJECT", "").strip()
    if not project:
        print("Error: COSA_PROJECT environment variable required", file=sys.stderr)
        print("Example: export COSA_PROJECT='lupin'", file=sys.stderr)
        sys.exit(1)
    return project.lower()


def _get_sender_id(project: str) -> str:
    """Generate sender_id in format: claude.code@{project}.deepily.ai"""
    return f"claude.code@{project}.deepily.ai"


# Initialize at module load
PROJECT = _get_project()
SENDER_ID = _get_sender_id(PROJECT)


# ============================================================================
# MCP Server
# ============================================================================

mcp = FastMCP(
    name="CoSA Voice Bridge",
    description=f"Voice I/O for Claude Code [Session: {SENDER_ID}]"
)


@mcp.tool
def converse(
    message: str,
    response_type: str = "open_ended",
    timeout_seconds: int = 120,
    response_default: Optional[str] = None,
    priority: str = "medium",
    title: Optional[str] = None
) -> str:
    """
    Speak to the user and wait for their voice/text response.
    
    Use this when you need input, clarification, or a decision from the user.
    The message will be converted to speech (TTS) and played to the user.
    Their response (via voice or text) will be returned to you.
    
    Args:
        message: What to say to the user
        response_type: "yes_no" for binary choices, "open_ended" for free-form
        timeout_seconds: How long to wait (1-600, default 120)
        response_default: Fallback if timeout or user offline
        priority: "low", "medium", "high", or "urgent"
        title: Optional short title for the notification
    
    Returns:
        User's response as text, or error/timeout message
    
    Examples:
        converse("Should I proceed with the refactor?", response_type="yes_no")
        converse("What naming convention should I use for the new module?")
        converse("The tests are failing. Should I continue?", response_default="yes")
    """
    try:
        request = NotificationRequest(
            message=message,
            response_type=ResponseType(response_type),
            notification_type=NotificationType.CUSTOM,
            priority=NotificationPriority(priority),
            timeout_seconds=timeout_seconds,
            response_default=response_default,
            title=title,
            sender_id=SENDER_ID  # Native field in updated library
        )
    except (ValidationError, ValueError) as e:
        return f"[validation error: {e}]"

    response: NotificationResponse = notify_user_sync(request=request, debug=False)

    if response.exit_code == 0:
        prefix = "[default used] " if response.default_used else ""
        return f"{prefix}{response.response_value or ''}"
    elif response.exit_code == 2:
        if response_default is not None:
            return f"[timeout - using default] {response_default}"
        return "[timeout - no response received]"
    else:
        return f"[error: {response.status}]"


@mcp.tool
def notify(
    message: str,
    notification_type: str = "progress",
    priority: str = "medium"
) -> str:
    """
    Announce something to the user without waiting for response.
    
    Use this for status updates, progress reports, or FYI messages.
    The message will be converted to speech (TTS) and played to the user.
    This call returns immediately - it does not wait for acknowledgment.
    
    Args:
        message: What to announce to the user
        notification_type: "task", "progress", "alert", or "custom"
        priority: "low", "medium", "high", or "urgent"
    
    Returns:
        Delivery status message
    
    Examples:
        notify("Starting code analysis...", notification_type="progress")
        notify("Build completed successfully", notification_type="task")
        notify("Warning: deprecated API detected", notification_type="alert", priority="high")
    """
    try:
        request = AsyncNotificationRequest(
            message=message,
            notification_type=NotificationType(notification_type),
            priority=NotificationPriority(priority),
            sender_id=SENDER_ID  # Native field in updated library
        )
    except (ValidationError, ValueError) as e:
        return f"[validation error: {e}]"

    response: AsyncNotificationResponse = notify_user_async(request=request, debug=False)

    if response.success:
        return f"Notification sent ({response.status})"
    else:
        return f"Failed: {response.message}"


@mcp.tool
def ask_yes_no(
    question: str,
    default: str = "no",
    timeout_seconds: int = 60
) -> bool:
    """
    Ask a yes/no question and get a boolean result.
    
    Convenience wrapper for quick binary decisions.
    
    Args:
        question: The yes/no question to ask
        default: Default answer if timeout ("yes" or "no")
        timeout_seconds: How long to wait (default 60)
    
    Returns:
        True if user said yes, False otherwise
    
    Examples:
        if ask_yes_no("Delete the old backups?"):
            # User said yes
        if ask_yes_no("Continue despite warnings?", default="no"):
            # User said yes (or default was overridden)
    """
    try:
        request = NotificationRequest(
            message=question,
            response_type=ResponseType.YES_NO,
            notification_type=NotificationType.CUSTOM,
            priority=NotificationPriority.MEDIUM,
            timeout_seconds=timeout_seconds,
            response_default=default,
            sender_id=SENDER_ID
        )
    except (ValidationError, ValueError):
        return default == "yes"

    response: NotificationResponse = notify_user_sync(request=request, debug=False)

    if response.exit_code == 0 and response.response_value:
        return response.response_value.lower().strip() == "yes"

    return default == "yes"


@mcp.tool
def get_session_info() -> dict:
    """
    Get current session identification.
    
    Returns:
        dict with project name and sender_id
    """
    return {
        "project": PROJECT,
        "sender_id": SENDER_ID
    }


if __name__ == "__main__":
    print(f"Project: {PROJECT}", file=sys.stderr)
    print(f"Sender ID: {SENDER_ID}", file=sys.stderr)
    mcp.run()
```

## Claude Agent SDK: Known Issues & Workarounds

*As of December 30, 2025*

### Installation

```bash
pip install claude-agent-sdk
npm install -g @anthropic-ai/claude-code  # Required CLI dependency
```

### Issue 1: TTY Detection Hang

**Symptom:** Claude Code hangs when spawned from Node.js or certain Python environments without a TTY.

**Workaround (macOS):**
```bash
script -q /dev/null claude -p "prompt" --output-format json
```

**Workaround (Python):** Use the SDK instead of raw subprocess—it handles this internally.

### Issue 2: MCP Tool Wildcards Not Supported

**Symptom:** `--allowedTools "mcp__cosa__*"` doesn't work as expected.

**Workaround:** List each tool explicitly:
```bash
--allowedTools "mcp__cosa__converse,mcp__cosa__notify,mcp__cosa__ask_yes_no"
```

### Issue 3: Environment Variable Expansion in MCP Config

**Symptom:** `${COSA_PROJECT}` in `cosa_mcp.json` may not expand.

**Workaround:** Set environment variable before spawning, or use the SDK's `mcp_servers` parameter which handles env injection properly.

### Issue 4: Session Resume Requires SQLite

**Symptom:** `--continue` and `--resume` fail in minimal containers.

**Workaround:** Ensure `~/.claude/` is writable and SQLite is available. For Docker:
```dockerfile
RUN apt-get install -y sqlite3 libsqlite3-dev
VOLUME /root/.claude
```

### Issue 5: MCP Server Crash on Shutdown

**Symptom:** SIGABRT during Claude Code exit due to MCP server termination failure.

**Workaround:** Ensure MCP server handles SIGTERM gracefully. FastMCP does this by default, but custom servers should trap signals:
```python
import signal
signal.signal(signal.SIGTERM, lambda *_: sys.exit(0))
```

### Best Practices

1. **Always use `--output-format json`** for programmatic parsing
2. **Set `--max-turns`** to prevent runaway loops (50-100 is reasonable)
3. **Use `--permission-mode acceptEdits`** in trusted environments
4. **Pre-authorize MCP tools** via `--allowedTools` (no interactive confirmation in headless)
5. **Store session IDs** for resume capability
6. **Set timeouts** at both client and server level

### Hybrid Dispatcher

```python
#!/usr/bin/env python3
"""
Cosa Task Dispatcher - Routes tasks to appropriate Claude Code runtime.
"""

import asyncio
import subprocess
import json
import os
from dataclasses import dataclass
from enum import Enum
from typing import Optional

from claude_agent_sdk import ClaudeSDKClient, ClaudeAgentOptions, ResultMessage


class TaskType(Enum):
    BOUNDED = "bounded"      # Option A: Print mode
    INTERACTIVE = "interactive"  # Option B: SDK client


@dataclass
class Task:
    id: str
    project: str
    prompt: str
    type: TaskType
    max_turns: int = 50
    working_dir: str = "/home/projects"


class CosaDispatcher:
    """Routes tasks to appropriate Claude Code runtime."""
    
    def __init__(self, lupin_url: str = "http://localhost:7999"):
        self.lupin_url = lupin_url
        self.active_sessions: dict[str, ClaudeSDKClient] = {}
    
    async def dispatch(self, task: Task) -> dict:
        """Dispatch task to appropriate runtime."""
        
        if task.type == TaskType.BOUNDED:
            return await self._run_bounded(task)
        else:
            return await self._run_interactive(task)
    
    async def _run_bounded(self, task: Task) -> dict:
        """Option A: Print mode for bounded tasks."""
        
        env = os.environ.copy()
        env["COSA_PROJECT"] = task.project.lower()
        
        result = subprocess.run(
            [
                "claude", "-p", task.prompt,
                "--mcp-config", os.path.expanduser("~/.claude/cosa_mcp.json"),
                "--allowedTools", ",".join([
                    "mcp__cosa__converse",
                    "mcp__cosa__notify",
                    "mcp__cosa__ask_yes_no",
                    "Read", "Write", "Bash"
                ]),
                "--permission-mode", "acceptEdits",
                "--output-format", "json",
                "--max-turns", str(task.max_turns)
            ],
            env=env,
            cwd=f"{task.working_dir}/{task.project}",
            capture_output=True,
            text=True,
            timeout=3600
        )
        
        if result.returncode == 0:
            return json.loads(result.stdout)
        else:
            return {"error": result.stderr, "exit_code": result.returncode}
    
    async def _run_interactive(self, task: Task) -> dict:
        """Option B: SDK client for interactive sessions."""
        
        sender_id = f"claude.code@{task.project.lower()}.deepily.ai"
        
        options = ClaudeAgentOptions(
            cwd=f"{task.working_dir}/{task.project}",
            permission_mode="acceptEdits",
            allowed_tools=[
                "Read", "Write", "Bash",
                "mcp__cosa__converse",
                "mcp__cosa__notify",
                "mcp__cosa__ask_yes_no"
            ],
            mcp_servers={
                "cosa": {
                    "type": "stdio",
                    "command": "python",
                    "args": ["/opt/cosa/mcp/cosa_voice_mcp.py"],
                    "env": {"COSA_PROJECT": task.project.lower()}
                }
            }
        )
        
        async with ClaudeSDKClient(options=options) as client:
            self.active_sessions[task.id] = client
            
            await client.query(task.prompt)
            
            result = None
            async for message in client.receive_response():
                if isinstance(message, ResultMessage):
                    result = {
                        "session_id": message.session_id,
                        "result": message.result,
                        "cost_usd": message.total_cost_usd,
                        "duration_ms": message.duration_ms
                    }
            
            del self.active_sessions[task.id]
            return result or {"error": "No result received"}
    
    async def inject_message(self, task_id: str, message: str) -> bool:
        """Inject a message into an active interactive session."""
        
        client = self.active_sessions.get(task_id)
        if client:
            await client.query(message)
            return True
        return False
    
    async def interrupt_session(self, task_id: str) -> bool:
        """Interrupt an active interactive session."""
        
        client = self.active_sessions.get(task_id)
        if client:
            await client.interrupt()
            return True
        return False


# Example usage
async def main():
    dispatcher = CosaDispatcher()
    
    # Bounded task (Option A)
    result = await dispatcher.dispatch(Task(
        id="task-001",
        project="lupin",
        prompt="Run the test suite and fix any failures",
        type=TaskType.BOUNDED
    ))
    print(f"Bounded result: {result}")
    
    # Interactive session (Option B)
    result = await dispatcher.dispatch(Task(
        id="session-001", 
        project="lupin",
        prompt="Let's work on the authentication refactor",
        type=TaskType.INTERACTIVE
    ))
    print(f"Interactive result: {result}")


if __name__ == "__main__":
    asyncio.run(main())
```

```
│                                                  │                           │
```

3. Parses intent (project, task type, prompt)

## Summary: When to Use Each Mode

| Scenario | Mode | Why |
|----------|------|-----|
| "Run tests and fix failures" | **Option A** | Bounded scope, natural completion |
| "Deploy to staging" | **Option A** | Discrete task with clear end |
| "Let's refactor auth" | **Option B** | Open-ended, user may redirect |
| "Help me debug this" | **Option B** | Exploratory, needs back-and-forth |
| CI/CD pipeline step | **Option A** | Automated, no human in loop |
| Pair programming | **Option B** | Interactive collaboration |
| Nightly code review | **Option A** | Scheduled, bounded report |
| "I'll be back in an hour" | **Option B** | Needs suspend/resume |

The MCP server is identical for both—the difference is purely in how Claude Code is spawned and managed.
