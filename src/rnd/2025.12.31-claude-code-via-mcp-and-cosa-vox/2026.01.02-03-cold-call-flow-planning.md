## Vision

### What is Cold Call Flow?

Cold Call Flow enables **voice-initiated Claude Code sessions** - starting work by speaking rather than typing. When Claude Code isn't already running, a voice daemon listens for commands and spawns appropriate sessions.

```
┌─────────────────────────────────────────────────────────────────┐
│                         COLD CALL FLOW                           │
│                                                                  │
│  Voice Daemon (background)         Cosa Orchestrator            │
│  ────────────────────────         ─────────────────────         │
│                                                                  │
│  User says: "Hey Claude, start    Watching for voice commands   │
│  working on the Lupin tests"      via Lupin WebSocket           │
│          │                                │                      │
│          ▼                                │                      │
│  STT → Transcript                         │                      │
│          │                                │                      │
│          └──────── WebSocket ────────────▶│                      │
│                                           │                      │
│                         Parse intent: project=lupin, task=tests  │
│                                           │                      │
│                         Dispatch new Claude Code session         │
│                         (Option A or B based on task type)       │
│                                           │                      │
│                                           ▼                      │
│                         ┌─────────────────────────┐              │
│                         │ Claude Code             │              │
│                         │ claude.code@lupin...    │              │
│                         │ Working on tests...     │              │
│                         └─────────────────────────┘              │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘
```

### Use Cases

| Use Case | Voice Command Example |
|----------|----------------------|
| **Hands-Free Start** | "Hey Claude, start working on Lupin" |
| **Project Switching** | "Claude, switch to the COSA project" |
| **Quick Tasks** | "Run the tests" (bounded task) |
| **Interactive Sessions** | "Let's debug the auth issue" (SDK session) |
| **Status Checks** | "What are you working on?" |

### Key Components

1. **Voice Daemon** - Background process listening for voice
2. **Wake Word Detection** - "Hey Claude" or hotkey trigger
3. **STT Pipeline** - Speech-to-text transcription
4. **Intent Parser** - Extract project, task type, prompt
5. **Dispatcher Integration** - Route to Option A or B

### Phase C1: Define Voice Command Grammar

**Goal**: Define the voice command patterns and intent schema

**Tasks**:
- [ ] Define supported command patterns
- [ ] Create intent schema (project, task_type, prompt)
- [ ] Document wake word variations
- [ ] Define fallback behaviors

**Voice Command Grammar**:

```
# Wake word patterns
WAKE_WORD := "hey claude" | "claude" | "okay claude"

# Command patterns
START_CMD := WAKE_WORD "," ("start" | "begin" | "let's") "working on" PROJECT
TASK_CMD  := WAKE_WORD "," TASK_DESCRIPTION
SWITCH_CMD := WAKE_WORD "," "switch to" PROJECT
STATUS_CMD := WAKE_WORD "," ("what are you" | "status" | "progress")
STOP_CMD  := WAKE_WORD "," ("stop" | "pause" | "wait")

# Intent extraction
PROJECT := word that matches known project names
TASK_TYPE := inferred from verb ("run tests" = bounded, "let's debug" = interactive)
PROMPT := remaining text after command parsing
```

**Intent Schema**:

```python
@dataclass
class VoiceIntent:
    command_type: str      # "start", "task", "switch", "status", "stop"
    project: Optional[str] # "lupin", "cosa", "phoenix", etc.
    task_type: TaskType    # BOUNDED or INTERACTIVE
    prompt: str            # The actual task prompt
    confidence: float      # 0.0-1.0 confidence score
    raw_transcript: str    # Original STT output
```

**Goal**: Integrate wake word detection for low-power listening

**Options Analysis**:

| Library | Pros | Cons |
|---------|------|------|

| **Custom** | Full control | Development effort |

**Recommended**: Start with Porcupine for accuracy, fall back to hotkey

```python
async def _start_session(self, intent: VoiceIntent):
    """Start new Claude Code session from voice command."""

    task = Task(
        id=f"voice-{datetime.now().strftime('%Y%m%d%H%M%S')}",
        project=intent.project or "default",
        prompt=intent.prompt,
        type=intent.task_type,
        max_turns=50 if intent.task_type == TaskType.BOUNDED else 200
    )

    # Announce start via TTS
    await self.speak(f"Starting work on {task.project}")

    # Dispatch to appropriate runtime
    result = await self.dispatcher.dispatch(task)

    # Announce result via TTS
    if result.success:
        await self.speak("Task completed successfully")
    else:
        await self.speak(f"Task failed: {result.error}")
```

```python
# Voice daemon connects to Lupin for:

async def connect_to_lupin(self):
    self.ws = await websockets.connect(
        f"{self.lupin_url}/ws/voice/{self.session_id}"
    )
```

### With STT Pipeline

```python
# Use existing Lupin STT infrastructure
# or local Whisper for lower latency

async def transcribe(self, audio_data: bytes) -> str:
    if self.stt_engine == "whisper":
        return await self.whisper.transcribe(audio_data)
    else:
        return await self.lupin_stt(audio_data)
```

### With TTS Pipeline

```python
# Use Lupin TTS for Claude responses
async def speak(self, text: str):
    await self.ws.send(json.dumps({
        "type": "tts_request",
        "text": text,
        "voice": "claude"
    }))
```
