## Overview

### What is Option A (Print Mode)?

Option A enables **bounded task execution** via Claude Code's print mode (`claude -p "task"`). Claude runs to completion with a defined scope, using MCP voice tools to ask clarifying questions when needed.

```
┌─────────────────────────────────────────────────────────────────┐
│                    OPTION A: Print Mode                          │
│                    "Fire-and-Forget with Voice Clarifications"   │
│                                                                  │
│  Orchestrator (Cosa)                                            │
│       │                                                         │
│       │  subprocess.run([                                       │
│       │      "claude", "-p", "Fix failing tests",               │
│       │      "--mcp-config", "cosa_mcp.json",                   │
│       │      "--output-format", "json"                          │
│       │  ])                                                     │
│       │                                                         │
│       ▼                                                         │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │  Claude Code Process                                     │   │
│  │                                                          │   │
│  │  Working... → MCP: converse("Mock OAuth?") → [BLOCKS]   │   │
│  │              ← User responds via voice                   │   │
│  │  Continuing... → Done.                                   │   │
│  │                                                          │   │
│  └─────────────────────────────────────────────────────────┘   │
│       │                                                         │
│       ▼                                                         │
│  Process exits with JSON result                                 │
│                                                                  │
│  KEY LIMITATION: User cannot push input unprompted.             │
│  Claude must decide to call MCP tools.                          │
└─────────────────────────────────────────────────────────────────┘
```

### Use Cases

| Use Case | Description |
|----------|-------------|
| **CI/CD Pipelines** | Automated code review, test fixing, PR preparation |
| **Scheduled Jobs** | Nightly code analysis, dependency updates |
| **Delegated Subtasks** | Parent orchestrator dispatches bounded work |
| **Batch Processing** | Process multiple tasks sequentially |

### Key Limitation

User **cannot push input unprompted** - Claude must decide to call MCP tools. For bidirectional control, see Option B (SDK Client).

```python
async def _run_bounded(self, task: Task) -> TaskResult:
    """Option A: Print mode for bounded tasks."""

    env = os.environ.copy()
    env["COSA_PROJECT"] = task.project.lower()

    cmd = [
        "claude", "-p", task.prompt,
        "--mcp-config", self.mcp_config_path,
        "--allowedTools", "mcp__cosa__converse,mcp__cosa__notify,...",
        "--permission-mode", "acceptEdits",
        "--output-format", "json",
        "--max-turns", str(task.max_turns)
    ]

    result = subprocess.run(
        cmd, env=env, cwd=f"{task.working_dir}/{task.project}",
        capture_output=True, text=True, timeout=task.timeout_seconds
    )

    # Parse JSON result and return TaskResult
```
