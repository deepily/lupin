## Vision

### What is Option B (SDK Client)?

Option B enables **interactive sessions** with **bidirectional control** via the Claude Agent SDK. Unlike Option A (print mode), the user can:
- Inject messages at any time
- Interrupt ongoing work
- Suspend and resume sessions
- Receive streaming output in real-time

**What `_run_interactive()` Does** (lines 243-319):

```python
async def _run_interactive(self, task: Task) -> TaskResult:
    """Option B: SDK client for interactive sessions."""

    options = ClaudeAgentOptions(
        cwd=f"{task.working_dir}/{task.project}",
        permission_mode="acceptEdits",
        allowed_tools=[
            "Read", "Write", "Bash",
            "mcp__cosa__converse",
            "mcp__cosa__notify",
            "mcp__cosa__ask_yes_no"
        ],
        mcp_servers={
            "cosa": {
                "type": "stdio",
                "command": "python",
                "args": [self.mcp_server_path],
                "env": {"COSA_PROJECT": task.project.lower()}
            }
        },
        system_prompt=f"Session: {task.sender_id}..."
    )

    async with ClaudeSDKClient(options=options) as client:
        self.active_sessions[task.id] = client
        await client.query(task.prompt)

        async for message in client.receive_response():
            self.on_message(task.id, message)
            if isinstance(message, ResultMessage):
                # Capture final result
```

**Session Management Methods**:

```python
async def inject(self, task_id: str, message: str) -> bool:
    """Inject message into active session."""
    client = self.active_sessions.get(task_id)
    if client:
        await client.query(message)
        return True
    return False

async def interrupt(self, task_id: str) -> bool:
    """Interrupt active session."""
    client = self.active_sessions.get(task_id)
    if client:
        await client.interrupt()
        return True
    return False
```

## Known Issues from Design Doc

The original design document identified 5 SDK issues with workarounds:

### Issue 1: TTY Detection Hang
**Symptom**: Claude Code hangs when spawned without TTY
**Workaround**: Use SDK instead of raw subprocess

### Issue 2: MCP Tool Wildcards Not Supported
**Symptom**: `--allowedTools "mcp__cosa__*"` doesn't work
**Workaround**: List each tool explicitly

### Issue 3: Environment Variable Expansion
**Symptom**: `${VAR}` in MCP config may not expand
**Workaround**: SDK's `mcp_servers` parameter handles env properly

### Issue 4: Session Resume Requires SQLite
**Symptom**: `--continue` and `--resume` fail in minimal containers
**Workaround**: Ensure `~/.claude/` writable, SQLite available

### Issue 5: MCP Server Crash on Shutdown
**Symptom**: SIGABRT during exit
**Workaround**: Handle SIGTERM gracefully (already done in our MCP server)

## ClaudeSDKClient API Reference

*Based on design document - verify against actual SDK*

### Key Classes

```python
from claude_agent_sdk import (
    ClaudeSDKClient,      # Main client class
    ClaudeAgentOptions,   # Configuration options
    AssistantMessage,     # Message from Claude
    TextBlock,            # Text content block
    ToolUseBlock,         # Tool invocation block
    ToolResultBlock,      # Tool result block
    ResultMessage         # Final result with cost/duration
)
```

### ClaudeAgentOptions

```python
options = ClaudeAgentOptions(
    cwd="/path/to/project",
    permission_mode="acceptEdits",  # or "ask"
    allowed_tools=["Read", "Write", "Bash", "mcp__*"],
    mcp_servers={
        "server_name": {
            "type": "stdio",
            "command": "python",
            "args": ["/path/to/server.py"],
            "env": {"KEY": "value"}
        }
    },
    system_prompt="Custom instructions...",
    resume_session="session_id"  # For resuming
)
```

### Client Methods

```python
async with ClaudeSDKClient(options=options) as client:
    # Send query
    await client.query("Your prompt here")

    # Receive streaming response
    async for message in client.receive_response():
        # Handle message types
        pass

    # Inject additional message
    await client.query("Additional input")

    # Interrupt current work
    await client.interrupt()
```
