# MCP Voice Integration - Implementation Trajectory Report

**Project**: LUPIN
**Date**: 2026.01.02
**Purpose**: Chronicle the design-to-implementation journey for MCP Voice Integration

---

## Executive Summary

The MCP Voice Integration project began with a comprehensive 935-line design document (December 30, 2025) outlining a vision for voice-enabled Claude Code sessions bridged through the Lupin notification infrastructure. The design specified **four major components**:

1. **MCP Server** - The shared voice I/O bridge (4 tools)
2. **Option A: Print Mode** - Bounded task execution via `claude -p "task"`
3. **Option B: SDK Client** - Interactive sessions via ClaudeSDKClient
4. **Cold Call Flow** - Voice-initiated session spawning

**Implementation Reality**: Only the MCP Server was completed and integrated (Sessions 26-28). The dispatcher code for Options A and B exists but was never moved to production, integrated, or tested. Cold Call Flow was never started.

### Four Components Designed

| Component | Use Case | Runtime Pattern |
|-----------|----------|-----------------|
| **MCP Server** | Shared voice I/O bridge | FastMCP stdio server |
| **Option A** | CI/CD, scheduled jobs, bounded tasks | `subprocess.run(["claude", "-p", "..."])` |
| **Option B** | Pair programming, interactive sessions | `async with ClaudeSDKClient(options)` |
| **Cold Call** | Voice-initiated sessions | Voice daemon + intent parsing |

### Key Design Decisions Made

1. **One MCP process per Claude Code instance** (stdio is 1:1)
2. **All MCP processes call shared Lupin backend** (HTTP/SSE)
3. **Session ID format**: `claude.code@{project}.deepily.ai`
4. **Lupin UI handles TTS/STT** - MCP server is pure message relay
5. **Graceful SDK fallback** - `SDK_AVAILABLE` flag for environments without SDK

    """Print mode for bounded tasks via subprocess.run()"""
    result = subprocess.run(

        capture_output=True, timeout=task.timeout_seconds

    """SDK client for interactive sessions via ClaudeSDKClient"""

        await client.query(task.prompt)
