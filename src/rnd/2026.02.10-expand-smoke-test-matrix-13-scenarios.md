## Context

## Design Note: Future LLM-Based Verification

The current `expected_args` soft check uses exact string matching. The proxy's LLM fallback strategy (`strategies/llm_fallback.py`) already has Anthropic API access. A future enhancement could route `expected_args` verification through an LLM judge that evaluates semantic equivalence (e.g., "quantum computing breakthroughs 2026" ~ "breakthroughs in quantum computing, 2026") rather than exact match. The soft-warning design (not hard failure) already accommodates this transition — no structural changes needed when the time comes.
