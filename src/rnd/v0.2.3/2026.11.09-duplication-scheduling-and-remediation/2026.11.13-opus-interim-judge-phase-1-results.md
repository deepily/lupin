## Gate A, on these numbers

| Gate A condition | Run A pass 0 (official) | Run B pass 0 (official) |
|---|---|---|
| Found ≥ 0.80 | pass, 71/80 | pass, 70/80 = 0.875 |
| Correct ≥ 0.80, unlabelled flags counted wrong | pass, 121/148 = 0.818 | **misses, 112/144 = 0.778** |
| Agrees with itself ≥ 0.90 | pass, 0.967 | pass, 0.969 |
| Lower bound of Opus-to-Fable kappa ≥ 0.75 | pass, 0.787 | **0.742, misses by 0.008** |

**Gate A: the plan's rule, read literally, says hold the backlog: one of the two official Opus records misses a bar.** What the numbers say beyond that:

- **The correct bar is the swing.** Opus's correct ranges 0.778 to 0.818 across four passes, and Fable's own is 0.809. The bar of 0.80 sits inside that spread, so another pass can land on either side. A further Opus run will not settle it.
- **The unlabelled flags decide each pass.** A pass's correct moves by about 0.03 depending on whether its 4 to 6 unlabelled flags are true. Labelling the 14 distinct pairs settles the figure for all four passes at once; the packet is built.
- **Kappa and agreement are sound.** Self-agreement is 0.967 and 0.969, and every kappa against Fable is 0.81 to 0.88. The kappa lower bound is 0.742 to 0.787, the part that decides sample against full Fable re-judge at Phase 4.

Recommendation: hold the backlog on Opus until the 14 unlabelled flags are labelled, then re-read correct for all four passes. Run B pass 0 needs 4 of its 5 unlabelled flags to be true to reach 0.80 (116/144 = 0.806); run A pass 1 needs 1 of its 6. If run B pass 0 gets there, Opus clears the bar on every official record and the backlog runs on Opus; if not, the third row stands and the backlog waits for Fable. The decision on the 0.80 and 0.75 thresholds is Rick's.

Open items: 14 distinct unlabelled Opus flags across the four passes are owed labels (the packet for all 14 is built; nobody has labelled it). The agreement, label and stratum figures come from the two ledgers and my pair map, and match Pocholo's record where both report them.

## The labelling packet

Two folders, same format. `io/semdup-labelling/2026.11.13-opus-unlabelled-flags-all-passes/` holds all 14 distinct unlabelled flags across the four Opus passes and is the one to use. `io/semdup-labelling/2026.11.13-opus-unlabelled-flags/` holds the first 9 (run A only) and is kept for its history; the 9 pairs have the same item ids in both. The rest of this section describes the first folder's files, and the all-passes folder has the same four files plus a map of which passes flagged each pair. Built in the pinned tree a6c83f82b with the same functions that built the run5 items (`flag_items.build_flag_items`, `packet_lines`):

- `opus-flags-packet-rick.jsonl` and `opus-flags-packet-reviewer-2.jsonl`: the blind items (9 in the first folder, 14 in the all-passes one), one file per reviewer, each in its own order, in the run5 item format (`item_id`, `payload` with the two sources, `type`).
- `opus-flags-key.json`: the answer key in the supplement shape. `label_load.supplement_rows` accepts it against both the run5 key and the first supplement's key, with no repeated item id and no repeated pair.
- `KEY-MAP-do-not-send.json`: item id to pair and ids, for the importer only; never send it to a reviewer.

The 9 pairs are the Opus flags (`near_duplicate` in every case) on pairs the proof's labels do not cover and that are not plant failures: 5 on pass 0, 6 on pass 1, 2 on both. Labels go back through the supplement path: `--supplement-key opus-flags-key.json --supplement-labels <rick> <reviewer-2>`, with `--supplement-third` for disputes.

"""Build { ledger key prefix | candidate : [ query id, candidate id ] } by replaying judge_all against the official ledger."""

vals = {}
for line in LED.read_text().splitlines():
    r = json.loads( line )
    if "key" in r: vals[ r[ "key" ] ] = r[ "value" ]

class Rec:
    def __init__( self ): self.hits = []; self.misses = []
    def get( self, key ):
        v = vals.get( key )
        ( self.hits if v is not None else self.misses ).append( key )
        return v
    def put( self, *a, **k ): raise RuntimeError( "would call the model" )

stash = {}
orig_pair = judge._pair
def pair( d, cands ):
    stash[ "id" ] = d[ "id" ]
    return orig_pair( d, cands )
judge._pair = pair
orig_key = judge.harness_runner.ledger_key
keymap = {}
def lkey( *a, **k ):
    key = orig_key( *a, **k )
    keymap[ key ] = stash[ "id" ]
    return key
judge.harness_runner.ledger_key = lkey

from cosa.repo.semdup import body_vectors
body_vectors.engine_tag = lambda c: "d093d02e5bb485ea"
class NoEmbed:
    def __getattr__( self, n ): raise RuntimeError( "the cache missed: would call the embedding service" )
root = cu.get_project_root()
cfg  = cfg_mod.verify_frozen( frozen.frozen_path(), frozen.live_config() )
print( "root", root, "model", cfg[ "model_id" ], file=sys.stderr )
parts = pc.live_parts( root, RUN, cfg, 4 )

res   = {}

    print( "slot", slot, "hits", len( rec.hits ), "misses", len( rec.misses ), "unjudged", len( out[ "unjudged" ] ), file=sys.stderr )
    res[ slot ] = out

from cosa.repo.semdup.proof import label_load
P = RUN / "packets"
SUPP = RUN / "supplement-proof1"
supp = { "key": SUPP / "supplement-key.json", "labels": [ P / "labels-rick-supp.jsonl", SUPP / "packets" / "labels-reviewer-2-supp.jsonl" ], "third": P / "labels-jason-supp.jsonl" }

rec2 = json.load( open( "/mnt/DATA01/include/www.deepily.ai/projects/lupin/io/semdup/proof-official-2026.10.31/2.json" ) )

canon = pool[ "canon" ]
