# Reuse review: group B model ids read from lupin-app.ini (row a3ecd4ea)

The slice moves four hard-coded ids into four INI keys: the need writer's sentence model, the duplicate-check proof's work-alike model, the reuse need set's second model, and the notification proxy's fallback model. Each is read through `code_health_settings.model_id`, the reader added in row 5fa4750e, so no reader is written for them. The constants `need_writer.DEFAULT_MODEL`, `label_prep.ALIKE_MODEL` and `SENTENCE_MODEL`, `smoke.SECOND_MODEL` and `config.LLM_FALLBACK_MODEL` are gone.

The slice adds one definition, `smoke.resolve_second_models( args, names )`. It fills each named argparse attribute that is None with the `reuse need second model` key. Four command lines (smoke, first_thousand, yield_trace, expansion_run) had `default=smoke.SECOND_MODEL` and now call it once each. `draft.drafter_model` has the same rule, caller's id else key, but it returns one value for the drafter key and takes no namespace. Folding the second model into it would give it a second key and a second shape, so it stays separate.
