# Reuse review: the judge ledger that survives a Claude Code update (row 395e4bcd)

The row stops the daily duplicate check from throwing away every saved ruling when the Claude Code binary updates. It adds `StampedLedger` (a ledger that stamps each new ruling with the writing version and accepts a binding that differs in the version alone) and `daily_ledger`, which opens it for the daily check.

The lookups came back uncertain (`LOW_CONFIDENCE`), so the candidates were read. `harness_runner.Ledger` is the base: `StampedLedger` extends it and overrides one method. `proof_ledger` binds the proof's ledger to the version on purpose, so the proof keeps it. `rotate_ledger_for_new_cli` is the behaviour this row replaces for the daily check: it renames the file and starts empty. `make_ledger` in the need set is a separate ledger of drafts. `ledger_agreement.read_ledger` only reads rulings.
