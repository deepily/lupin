# Reuse review: agent config model ids read from lupin-app.ini (row a3ecd4ea, group A)

The slice removes the claude-opus-4-6 and claude-sonnet-4-6 defaults from six agent config modules (bug fix expediter, test fix expediter, swe_team, deep_research, podcast_generator, presentation_generator). Their INI keys already existed and held claude-opus-5 and claude-sonnet-4-6. It adds two definitions to `cosa.agents.shared.config_loader`.

`required_model_id` reads one model key through `ConfigurationManager.get_required`, which already refuses an absent or blank key. It adds only the build of the process's own manager when none is passed, with the start-up banner sent to stderr. `model_field` declares a dataclass field with no default value whose `default_factory` is `required_model_id` for one key, so the 140 existing `Config()` call sites keep working and read the INI when they build the object.

`code_health_settings.model_id` does the same job for the code-health keys. It raises that module's `CodeHealthSettingError` and lives in `cosa.repo`, which imports the hook library. The agent configs sit in `cosa.agents`, so they read through `get_required` directly and raise its `MissingConfigKeyError`.
