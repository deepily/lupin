# Reuse review: duplicate-check triage fixes, chain B (row d922fc49)

Chain B applies three of the triage's one-line fixes. Two of them leave a definition with a new public name, so each needed a lookup: `skipped_topic_names` in `chained_pipeline_state.py` and `run_git` in `cosa/utils/main_checkout.py`.

`skipped_topic_names` replaces the comprehension the podcast agent and `AgenticJobBase` each held. The three nearest definitions the lookup returned are the methods that now call it, so none of them is a second copy. The mixin's own `_skipped_topic_names` returns an empty list on purpose, for pipelines that skip nothing.

`run_git` is the former private `_run_git`, made public so `worktree_straggler_tickets` and `orphan_bridge_reaper` can drop their own `_plain_run`. It runs one git command in a given directory under a 10 second timeout, and a non-zero exit does not raise. The nearest runners each add something this one lacks: an environment variable for the branch guard (`worktree_reaper._default_run`), a dict result with injectable runner (`worktree_reaper._git`), a raise on failure (`range_gate.git`), or an exit code of 127 on timeout (`reuse_harness.commands.run_command`). Replacing `run_git` with any of them would change what the two callers see.
