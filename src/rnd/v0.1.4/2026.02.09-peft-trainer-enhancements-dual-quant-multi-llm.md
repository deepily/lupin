# PEFT Trainer Enhancements: Dual Quantization, Markdown Dashboard, Multi-LLM

**Date**: 2026-02-09
**Status**: IMPLEMENTED
**Session**: 157

## Overview

Three enhancements to the PEFT training pipeline:

1. **Dual Quantization**: Compare 4-bit vs 8-bit quantization accuracy/speed tradeoffs
2. **Markdown Training Results**: Versioned markdown files with YAML frontmatter for machine-parseable results
3. **Multi-LLM Support**: `--llm` flag to target Ministral-8B or Qwen3-4B-Base

## Enhancement 1: Dual Quantization

### Changes

- `peft_trainer.py`: Added `--quantize-bits {both,4,8}` CLI arg (default: `both`)
- `peft_trainer.py`: Added `bits: int=4` parameter to `quantize_merged_adapter()`
- `peft_trainer.py`: Replaced single quantization block in `run_pipeline()` with loop over `quantize_bits_list`
- `peft_trainer.py`: New `self.quantized_model_dirs` dict mapping bits -> path
- `peft_trainer.py`: New `_parse_quantize_bits()` static method

### Stage Timing Keys

| Old Key | New Keys |
|---------|----------|
| `quantization` | `quantization_4bit`, `quantization_8bit` |
| `post_quantization_validation` | `post_quantization_4bit_validation`, `post_quantization_8bit_validation` |

### Dashboard Changes

- Table 1: No change (loops over all validation_results)
- Tables 2+3: Now rendered per quant variant, each compared to post-training baseline
- Table 4: Includes both legacy and new dual-quant timing keys

## Enhancement 2: Markdown Training Results

### Output Path

`io/peft/YYYY.MM.DD-at-HH-MM-peft-training-results-{model}-{4|8|4-and-8}-bits.md`

### Method

`_write_training_summary_to_file()` — placed after `_print_training_summary()`, writes:
- YAML frontmatter with all training metadata
- 4 tables in GitHub-flavored markdown (matching console dashboard)
- Output Paths section listing all pipeline artifacts

### Call Site

In `run_pipeline()` after `_print_training_summary()`, wrapped in try/except.

## Enhancement 3: Multi-LLM Support

### New Config

`src/cosa/training/conf/qwen3_4b.py` — Alpaca-format prompt template for base model:
- batch_size: 4 (larger, smaller model fits better)
- gradient_accumulation_steps: 4 (lower than Ministral's 8)
- lora_alpha: 32, r: 16 (standard for 4B-class)
- EOS token: `<|endoftext|>`

### Shell Script

`run-agentic-intent-training.sh` — added `--llm` and `--quantize-bits` flags:
```bash
./run-agentic-intent-training.sh full --llm qwen3-4b --quantize-bits 4
```

### Registry

- `model_config_loader.py`: Added `"Qwen3-4B-Base": "qwen3_4b"` to `MODEL_CONFIG_MAP`
- `peft_trainer.py`: Added `"Qwen3-4B-Base"` to `supported_model_names` and validation list
