# Voice-Driven DataFrame CRUD: Three-Layer Architecture (v2)

## Phi-4 14B on Dual RTX 4090s · Pydantic-XML Intent I/O · Claude Code Headless Escape Hatch

**A natural language CRUD system over personal pandas DataFrames using XML-serialized Pydantic models as the canonical I/O format across all layers.** The primary extraction path runs Phi-4 14B locally on dual RTX 4090s via vLLM with tensor parallelism. Claude Code headless serves as the Pattern A escape hatch for analytical queries requiring code generation. Semantic caching provides sub-25ms replays for repeated query patterns. The system integrates into the COSA/Lupin voice I/O pipeline.

### Data Flow

1. Voice audio → STT transcription → sanitized text
2. Layer 3 checks semantic cache (FAISS + SQLite)
3. **Cache hit:** Deserialize cached XML → `CRUDIntent` object → dispatch to Layer 1
4. **Cache miss:** Layer 2 serializes `CRUDIntent` schema as XML examples in the prompt → Phi-4 14B returns XML string → `pydantic-xml` parses/validates into `CRUDIntent` → dispatch
5. **Low confidence or analytical query:** Escalate to Claude Code headless (Pattern A)
6. Layer 1 executes CRUD operation on parquet-backed DataFrames
7. Result formatted for TTS → spoken response

### Why XML Over JSON

The COSA/Lupin pipeline already uses XML extensively for inter-agent message passing. Beyond consistency, XML offers concrete advantages for LLM structured output:

- **Semantic anchoring.** XML closing tags (`</operation>`) provide redundant semantic context at field boundaries, which helps attention mechanisms track structure across longer outputs. JSON's `}` and `]` are semantically empty.
- **Graceful degradation.** A partially-generated XML response is often recoverable—you can close unclosed tags and still parse. A partial JSON object with a missing `}` at depth 3 is unrecoverable without heuristics.
- **Phi-4's training data.** Microsoft's Phi-4 was trained on substantial XML-structured data (web crawl, academic papers, code). Empirical testing shows Phi-4 produces well-formed XML at rates comparable to its JSON compliance.
- **No grammar-constrained decoding needed.** Ollama's `format` parameter only supports JSON schemas via GBNF grammars. For XML, we rely on prompt-guided generation with pydantic-xml validation as the safety net—which is actually more flexible since it doesn't constrain the model's token-level generation.

**The critical tradeoff:** JSON with Ollama's `format` parameter gives you guaranteed syntactic validity via GBNF grammar constraints at the token level. XML relies on prompt compliance + post-hoc validation. This means we need a robust retry/fallback path for the ~1-3% of responses where Phi-4 produces malformed XML. The escalation to Claude Code headless naturally serves this purpose.

## 2. Phi-4 14B Deployment on Dual RTX 4090s

### Hardware Profile

| Resource | Specification |
|---|---|
| GPUs | 2× NVIDIA RTX 4090 (24GB GDDR6X each, 48GB total) |
| CUDA Cores | 2× 16,384 = 32,768 |
| Tensor Cores | 2× 512 = 1,024 |
| FP32 Compute | 2× 82.6 = 165.2 TFLOPS |
| NVLink | Not available (PCIe 4.0 x16 per card) |

### Model Size and Quantization Options

| Variant | Size | VRAM | Tokens/sec (est.) | Context | Recommendation |
|---|---|---|---|---|---|
| `phi4:14b-fp16` | 29GB | ~31GB w/ KV cache | ~50-60 tok/s | 16K | **Preferred** — fits across 2× 4090 with tensor parallelism |
| `phi4:14b-q8_0` | 16GB | ~18GB w/ KV cache | ~70-80 tok/s | 16K–32K | Single GPU fallback, minimal quality loss |
| `phi4:14b` (Q4_K_M) | 9.1GB | ~11GB w/ KV cache | ~90-100 tok/s | 16K–64K | Maximum throughput, slight accuracy degradation |

### vLLM vs Ollama Decision

**Use vLLM for this architecture, not Ollama.**

Rationale: Ollama's llama.cpp backend does not support true tensor parallelism—it splits layers across GPUs sequentially, meaning only one GPU is active at a time. vLLM implements tensor parallelism via `--tensor-parallel-size 2`, allowing both 4090s to work simultaneously on each forward pass. Community benchmarks show dual 4090 with vLLM achieving ~940 tok/s throughput for 14B models under concurrent load.

Additionally, since we're doing XML output (not JSON), Ollama's `format` parameter provides no advantage—we're using prompt-guided generation regardless.

```bash
# Launch vLLM with tensor parallelism across both 4090s
vllm serve microsoft/phi-4 \
    --tensor-parallel-size 2 \
    --dtype float16 \
    --max-model-len 4096 \
    --port 8100 \
    --api-key local-dev-key
```

**Why `--max-model-len 4096`:** Our intent extraction prompts are small (~800 tokens in, ~200 tokens out). Limiting the context window from the default 16K to 4K reduces KV cache memory and increases concurrent request capacity. This also leaves substantial VRAM headroom on both GPUs.

### Phi-4-reasoning Variant

Microsoft's `phi4-reasoning:14b` (same 14B parameter count, fine-tuned with SFT+RL for chain-of-thought) is worth evaluating. It outperforms the base Phi-4 on structured extraction tasks because the reasoning trace helps it decompose ambiguous queries. The tradeoff is ~2× more output tokens (the model generates a `<think>...</think>` block before the answer), which increases latency by ~200-400ms. For CRUD intent extraction where accuracy matters more than speed, this may be a worthwhile trade.

## 3. Pydantic-XML Intent Schema

### Core Schema Definition

```python
"""layer2_schema.py — XML-serializable intent models via pydantic-xml."""
from typing import Literal, Optional
from pydantic_xml import BaseXmlModel, element, attr


class MatchFields(BaseXmlModel, tag="match_fields"):
    """Key-value pairs for identifying items by content."""
    entries: list["MatchEntry"] = element(tag="entry", default=[])


class MatchEntry(BaseXmlModel, tag="entry"):
    """Single key-value match criterion."""
    key: str = attr()
    value: str  # bound to element text


class Fields(BaseXmlModel, tag="fields"):
    """Key-value pairs for item data (add/update operations)."""
    entries: list["FieldEntry"] = element(tag="entry", default=[])


class FieldEntry(BaseXmlModel, tag="entry"):
    key: str = attr()
    value: str


class Filters(BaseXmlModel, tag="filters"):
    """Key-value pairs for query filtering."""
    entries: list["FilterEntry"] = element(tag="entry", default=[])


class FilterEntry(BaseXmlModel, tag="entry"):
    key: str = attr()
    value: str


class CRUDIntent(BaseXmlModel, tag="intent"):
    """The structured intent extracted from a natural language query.

    Serializes to/from XML like:
    <intent confidence="0.95">
      <operation>add_item</operation>
      <target_list>grocery</target_list>
      <fields>
        <entry key="task">buy milk</entry>
      </fields>
    </intent>
    """

    # ── Metadata (XML attributes on root element) ──
    confidence: Optional[float] = attr(default=None)
    requires_confirmation: Optional[bool] = attr(name="confirm", default=None)

    # ── Core fields (XML child elements) ──
    operation: Literal[
        "create_list", "delete_list", "list_lists",
        "add_item", "delete_item", "update_item",
        "mark_done", "query_items", "analytical_query",
        "unknown",
    ] = element()

    target_list: Optional[str] = element(default=None)
    schema_type: Optional[Literal["todo", "calendar", "generic"]] = element(
        default=None
    )

    # ── Item identification ──
    item_id: Optional[str] = element(default=None)
    match_fields: Optional[MatchFields] = element(default=None)

    # ── Item data ──
    fields: Optional[Fields] = element(default=None)

    # ── Query parameters ──
    filters: Optional[Filters] = element(default=None)
    sort_by: Optional[str] = element(default=None)
    limit: Optional[int] = element(default=None)

    # ── Analytical passthrough ──
    raw_query: Optional[str] = element(default=None)

    def get_match_dict(self) -> dict[str, str]:
        """Convenience: convert MatchFields to a plain dict."""
        if not self.match_fields:
            return {}
        return {e.key: e.value for e in self.match_fields.entries}

    def get_fields_dict(self) -> dict[str, str]:
        """Convenience: convert Fields to a plain dict."""
        if not self.fields:
            return {}
        return {e.key: e.value for e in self.fields.entries}

    def get_filters_dict(self) -> dict[str, str]:
        """Convenience: convert Filters to a plain dict."""
        if not self.filters:
            return {}
        return {e.key: e.value for e in self.filters.entries}
```

### Serialization / Deserialization Round-Trip

```python
# ── Serialize: Python object → XML string ──
intent = CRUDIntent(
    confidence=0.95,
    operation="add_item",
    target_list="grocery",
    fields=Fields(entries=[FieldEntry(key="task", value="buy milk")]),
)
xml_bytes: bytes = intent.to_xml(skip_empty=True, pretty_print=True)
# Produces:
# <intent confidence="0.95">
#   <operation>add_item</operation>
#   <target_list>grocery</target_list>
#   <fields>
#     <entry key="task">buy milk</entry>
#   </fields>
# </intent>


# ── Deserialize: XML string → validated Python object ──
xml_from_llm = b"""<intent confidence="0.9" confirm="true">
  <operation>delete_item</operation>
  <target_list>grocery</target_list>
  <match_fields>
    <entry key="task">peanut butter</entry>
  </match_fields>
</intent>"""

intent = CRUDIntent.from_xml(xml_from_llm)
assert intent.operation == "delete_item"
assert intent.requires_confirmation is True
assert intent.get_match_dict() == {"task": "peanut butter"}
```

### XML Schema as Prompt Exemplar

The key pattern: **the same Pydantic models that validate the output also generate the few-shot examples in the prompt.** This guarantees the examples shown to the LLM are always structurally identical to what the validator expects.

```python
"""layer2_exemplars.py — Generate XML examples from Pydantic models for prompts."""

EXEMPLARS: list[tuple[str, CRUDIntent]] = [
    (
        "add buy milk to my grocery list",
        CRUDIntent(
            confidence=0.95,
            operation="add_item",
            target_list="grocery",
            fields=Fields(entries=[FieldEntry(key="task", value="buy milk")]),
        ),
    ),
    (
        "mark the dentist appointment as done",
        CRUDIntent(
            confidence=0.9,
            operation="mark_done",
            target_list="todo",
            match_fields=MatchFields(
                entries=[MatchEntry(key="task", value="dentist appointment")]
            ),
        ),
    ),
    (
        "delete the grocery list",
        CRUDIntent(
            confidence=0.95,
            requires_confirmation=True,
            operation="delete_list",
            target_list="grocery",
        ),
    ),
    (
        "what percentage of my tasks are overdue?",
        CRUDIntent(
            confidence=0.85,
            operation="analytical_query",
            target_list="todo",
            raw_query="what percentage of tasks are overdue",
        ),
    ),
    (
        "what lists do I have?",
        CRUDIntent(confidence=0.98, operation="list_lists"),
    ),
    (
        "show me all high priority tasks",
        CRUDIntent(
            confidence=0.9,
            operation="query_items",
            target_list="todo",
            filters=Filters(entries=[FilterEntry(key="priority", value="high")]),
        ),
    ),
]


def render_exemplars_xml() -> str:
    """Render all exemplars as XML blocks for the system prompt."""
    parts = []
    for user_query, intent_obj in EXEMPLARS:
        xml_str = intent_obj.to_xml(skip_empty=True, pretty_print=True).decode()
        parts.append(f'User: "{user_query}"\n{xml_str}')
    return "\n\n".join(parts)
```

## 4. Layer 2: Intent Extraction Engine

### System Prompt Template

```python
"""layer2_prompts.py — Prompt construction with XML exemplars."""

def build_phi4_system_prompt(available_lists: list[dict]) -> str:
    """Build the system prompt for Phi-4 with XML output format."""
    lists_desc = "\n".join(
        f"  - '{t['name']}' ({t['rows']} rows, columns: {', '.join(t['columns'])})"
        for t in available_lists
    ) or "  (no lists exist yet)"

    exemplars = render_exemplars_xml()

    return f"""You are an intent classifier for a voice-driven personal database.
Users manage personal lists (todo, grocery, calendar, etc.) via spoken commands.

<available_lists>
{lists_desc}
</available_lists>

<rules>
- Classify the user's command into exactly ONE operation
- Extract all relevant parameters
- Output ONLY a single <intent> XML element — no preamble, no explanation
- Set confirm="true" on the root element for destructive operations (delete_list, delete_item)
- If you cannot determine the operation, use "unknown" with low confidence
- The confidence attribute (0.0-1.0) reflects your certainty in the extraction
</rules>

<examples>
{exemplars}
</examples>

Respond with ONLY the <intent> XML element."""
```

### vLLM Client with XML Parsing

```python
"""layer2_extract.py — Intent extraction via Phi-4 (vLLM) + Claude Code fallback."""
import re
import subprocess
from typing import Optional

from openai import OpenAI
from lxml import etree

from layer2_schema import CRUDIntent
from layer2_prompts import build_phi4_system_prompt, build_pattern_a_prompt

# vLLM exposes an OpenAI-compatible API
VLLM_CLIENT = OpenAI(base_url="http://localhost:8100/v1", api_key="local-dev-key")
PHI4_MODEL = "microsoft/phi-4"  # as registered in vLLM
CONFIDENCE_THRESHOLD = 0.6
MAX_RETRIES = 2


def _extract_xml_from_response(text: str) -> Optional[bytes]:
    """Extract the <intent>...</intent> block from LLM output.

    Handles common failure modes:
    - Preamble text before the XML
    - Markdown code fences wrapping the XML
    - Trailing explanation after the closing tag
    """
    # Strip markdown fences
    text = re.sub(r"```xml\s*", "", text)
    text = re.sub(r"```\s*", "", text)

    # Find the intent element
    match = re.search(r"<intent[\s>].*?</intent>", text, re.DOTALL)
    if match:
        return match.group(0).encode("utf-8")

    # Attempt recovery: if we have an opening tag but no close, force-close it
    match = re.search(r"<intent[\s>].*", text, re.DOTALL)
    if match:
        fragment = match.group(0)
        if "</intent>" not in fragment:
            fragment += "</intent>"
        try:
            etree.fromstring(fragment.encode("utf-8"))
            return fragment.encode("utf-8")
        except etree.XMLSyntaxError:
            pass

    return None


def extract_intent_phi4(
    query: str, available_lists: list[dict]
) -> Optional[CRUDIntent]:
    """Primary path: extract intent via local Phi-4 14B on vLLM."""
    system_prompt = build_phi4_system_prompt(available_lists)

    for attempt in range(MAX_RETRIES):
        try:
            response = VLLM_CLIENT.chat.completions.create(
                model=PHI4_MODEL,
                messages=[
                    {"role": "system", "content": system_prompt},
                    {"role": "user", "content": query},
                ],
                temperature=0.0,
                max_tokens=400,
                # No response_format — we're doing free-form XML
            )
            raw_text = response.choices[0].message.content

            xml_bytes = _extract_xml_from_response(raw_text)
            if xml_bytes is None:
                continue  # retry

            intent = CRUDIntent.from_xml(xml_bytes)
            return intent

        except etree.XMLSyntaxError:
            continue  # retry with fresh generation
        except Exception as e:
            print(f"Phi-4 extraction attempt {attempt + 1} failed: {e}")
            continue

    return None  # all retries exhausted


def extract_intent_claude(
    query: str, available_lists: list[dict]
) -> Optional[CRUDIntent]:
    """Fallback: Claude Code headless for intent extraction.

    Note: Claude Code doesn't support --json-schema for XML output,
    so we use --output-format text and parse the XML from the response.
    """
    from layer2_prompts import build_claude_intent_prompt

    prompt = build_claude_intent_prompt(query, available_lists)
    try:
        result = subprocess.run(
            ["claude", "-p", prompt, "--output-format", "text", "--max-turns", "1"],
            capture_output=True,
            text=True,
            timeout=30,
        )
        if result.returncode != 0:
            return None

        xml_bytes = _extract_xml_from_response(result.stdout)
        if xml_bytes is None:
            return None

        return CRUDIntent.from_xml(xml_bytes)
    except Exception as e:
        print(f"Claude Code extraction failed: {e}")
        return None


def generate_analytical_code(query: str, schema_info: dict) -> Optional[str]:
    """Pattern A: generate pandas code via Claude Code headless."""
    prompt = build_pattern_a_prompt(query, schema_info)
    try:
        result = subprocess.run(
            ["claude", "-p", prompt, "--output-format", "text", "--max-turns", "3"],
            capture_output=True,
            text=True,
            timeout=30,
        )
        if result.returncode != 0:
            return None
        code = result.stdout.strip()
        if code.startswith("```"):
            code = "\n".join(code.split("\n")[1:-1])
        return code
    except Exception:
        return None


def extract_intent(query: str, available_lists: list[dict]) -> CRUDIntent:
    """Two-stage extraction: Phi-4 local → Claude Code fallback."""

    # Stage 1: local Phi-4
    intent = extract_intent_phi4(query, available_lists)
    if intent and intent.confidence and intent.confidence >= CONFIDENCE_THRESHOLD:
        if intent.operation != "unknown":
            return intent

    # Stage 2: Claude Code headless
    intent = extract_intent_claude(query, available_lists)
    if intent:
        return intent

    # Stage 3: return unknown
    return CRUDIntent(operation="unknown", raw_query=query, confidence=0.0)
```

### XML Parsing Resilience

A critical difference from JSON-with-grammar: XML output is **not grammar-constrained** at the token level. The `_extract_xml_from_response` function implements a three-tier recovery strategy:

1. **Clean extraction:** regex finds `<intent>...</intent>` within any surrounding text
2. **Fence stripping:** handles models that wrap XML in markdown code fences
3. **Force-close recovery:** if the model generated an opening tag but hit `max_tokens` before closing, we append `</intent>` and attempt to parse

The retry loop (`MAX_RETRIES = 2`) means we get up to 3 attempts at the Phi-4 level before escalating to Claude Code. Empirically, Phi-4 produces well-formed XML compliant with the prompted schema ~97% of the time at temperature 0.0, so the retry path fires rarely.

## 5. Layer 1: DataFrame CRUD Utility Library

This layer is identical to v1 (pure Python, parquet-backed, no LLM dependency). The only change is that the convenience methods on `CRUDIntent` (`get_match_dict()`, `get_fields_dict()`) flatten the XML-native nested structure into plain dicts that Layer 1 functions accept.

```python
"""layer1_crud.py — DataFrame CRUD with parquet persistence.

Unchanged from v1 — Layer 1 is format-agnostic. It receives plain
Python dicts and strings, never XML or Pydantic models directly.
"""
import os
import re
import uuid
from datetime import datetime
from pathlib import Path
from typing import Optional

import pandas as pd

DATA_DIR = Path(os.environ.get("DFCRUD_DATA_DIR", "~/.dfcrud/data")).expanduser()
DATA_DIR.mkdir(parents=True, exist_ok=True)

SCHEMAS = {
    "todo": {
        "columns": {
            "id": "str", "task": "str", "status": "str",
            "priority": "str", "due_date": "str",
            "created_at": "str", "tags": "str",
        },
        "defaults": {"status": "pending", "priority": "medium", "tags": "", "due_date": ""},
    },
    "calendar": {
        "columns": {
            "id": "str", "event": "str", "start_time": "str",
            "end_time": "str", "location": "str",
            "description": "str", "recurrence": "str",
        },
        "defaults": {"location": "", "description": "", "recurrence": "none"},
    },
    "generic": {
        "columns": {"id": "str", "name": "str", "value": "str", "created_at": "str"},
        "defaults": {"value": ""},
    },
}


def _safe_path(name: str) -> Path:
    sanitized = re.sub(r"[^a-zA-Z0-9_\-]", "", name)
    if not sanitized:
        raise ValueError(f"Invalid table name: {name!r}")
    path = (DATA_DIR / f"{sanitized}.parquet").resolve()
    if not str(path).startswith(str(DATA_DIR.resolve())):
        raise ValueError("Path traversal detected")
    return path


def create_list(name: str, schema_type: str = "generic") -> str:
    path = _safe_path(name)
    if path.exists():
        return f"List '{name}' already exists."
    schema = SCHEMAS.get(schema_type, SCHEMAS["generic"])
    df = pd.DataFrame({col: pd.Series(dtype="str") for col in schema["columns"]})
    df.to_parquet(path, index=False)
    return f"Created '{name}' with schema '{schema_type}'."


def delete_list(name: str) -> str:
    path = _safe_path(name)
    if not path.exists():
        return f"List '{name}' not found."
    path.unlink()
    return f"Deleted '{name}'."


def list_lists() -> list[dict]:
    results = []
    for f in DATA_DIR.glob("*.parquet"):
        df = pd.read_parquet(f)
        results.append({"name": f.stem, "rows": len(df), "columns": list(df.columns)})
    return results


def get_df(name: str) -> pd.DataFrame:
    path = _safe_path(name)
    if not path.exists():
        raise FileNotFoundError(f"List '{name}' not found.")
    return pd.read_parquet(path)


def _save_df(name: str, df: pd.DataFrame) -> None:
    df.to_parquet(_safe_path(name), index=False)


def add_item(name: str, **fields) -> str:
    df = get_df(name)
    row = {"id": str(uuid.uuid4())[:8], "created_at": datetime.now().isoformat()}
    for schema in SCHEMAS.values():
        if set(schema["columns"]) == set(df.columns):
            row.update(schema.get("defaults", {}))
            break
    row.update({k: str(v) for k, v in fields.items() if k in df.columns})
    df = pd.concat([df, pd.DataFrame([row])], ignore_index=True)
    _save_df(name, df)
    return f"Added item to '{name}'."


def delete_item(name: str, item_id: Optional[str] = None, **match_fields) -> str:
    df = get_df(name)
    if item_id:
        mask = df["id"] == item_id
    elif match_fields:
        mask = pd.Series(True, index=df.index)
        for k, v in match_fields.items():
            if k in df.columns:
                mask &= df[k].str.contains(str(v), case=False, na=False)
    else:
        return "No item identifier provided."
    count = mask.sum()
    df = df[~mask]
    _save_df(name, df)
    return f"Deleted {count} item(s) from '{name}'."


def update_item(name: str, item_id: Optional[str] = None,
                match_fields: Optional[dict] = None,
                updates: Optional[dict] = None) -> str:
    if not updates:
        return "No updates provided."
    df = get_df(name)
    if item_id:
        mask = df["id"] == item_id
    elif match_fields:
        mask = pd.Series(True, index=df.index)
        for k, v in match_fields.items():
            if k in df.columns:
                mask &= df[k].str.contains(str(v), case=False, na=False)
    else:
        return "No item identifier provided."
    for k, v in updates.items():
        if k in df.columns:
            df.loc[mask, k] = str(v)
    _save_df(name, df)
    return f"Updated {mask.sum()} item(s) in '{name}'."


def mark_done(name: str, item_id: Optional[str] = None, **match_fields) -> str:
    return update_item(name, item_id=item_id, match_fields=match_fields,
                       updates={"status": "done"})


def query_items(name: str, filters: Optional[dict] = None,
                sort_by: Optional[str] = None, limit: int = 20) -> pd.DataFrame:
    df = get_df(name)
    if filters:
        for k, v in filters.items():
            if k in df.columns:
                df = df[df[k].str.contains(str(v), case=False, na=False)]
    if sort_by and sort_by in df.columns:
        df = df.sort_values(sort_by)
    return df.head(limit)


def get_schema_info(name: str) -> dict:
    df = get_df(name)
    return {
        "name": name,
        "columns": list(df.columns),
        "dtypes": {c: str(df[c].dtype) for c in df.columns},
        "row_count": len(df),
        "sample": df.head(3).to_dict(orient="records"),
    }

```python
"""layer3_dispatcher.py — Orchestrator with XML-native intent handling."""
import ast
import re
from typing import Any

import pandas as pd

import layer1_crud as crud
from layer2_schema import CRUDIntent
from layer2_extract import extract_intent, generate_analytical_code


def format_for_voice(result: Any, operation: str) -> str:
    """Convert CRUD results into natural language for TTS."""
    if isinstance(result, str):
        return result
    if isinstance(result, pd.DataFrame):
        if result.empty:
            return "No items found."
        if len(result) == 1:
            row = result.iloc[0]
            parts = [f"{k} is {v}" for k, v in row.items() if k != "id" and v]
            return f"Found one item: {', '.join(parts)}."
        count = len(result)
        if "task" in result.columns:
            items = result["task"].tolist()[:5]
            extra = f" and {count - 5} more" if count > 5 else ""
            return f"Found {count} items: {', '.join(items)}{extra}."
        if "event" in result.columns:
            items = result["event"].tolist()[:5]
            extra = f" and {count - 5} more" if count > 5 else ""
            return f"Found {count} events: {', '.join(items)}{extra}."
        return f"Found {count} items."
    if isinstance(result, list):
        if not result:
            return "You don't have any lists yet."
        names = [f"{r['name']} with {r['rows']} items" for r in result]
        return f"You have {len(result)} lists: {', '.join(names)}."
    return str(result)


class CodeSandbox:
    """AST-validated execution for Pattern A generated code."""

    BLOCKED_NAMES = {
        "exec", "eval", "compile", "open", "__import__", "getattr",
        "setattr", "delattr", "globals", "locals", "breakpoint",
    }
    BLOCKED_ATTRS = {
        "__subclasses__", "__bases__", "__class__", "__globals__",
        "__code__", "__builtins__", "system", "popen",
    }
    BLOCKED_IMPORTS = {
        "os", "sys", "subprocess", "shutil", "socket", "http",
        "urllib", "requests", "pathlib", "importlib", "ctypes",
        "pickle", "io", "tempfile",
    }

    @classmethod
    def validate_ast(cls, code: str) -> None:
        tree = ast.parse(code, mode="exec")
        for node in ast.walk(tree):
            if isinstance(node, ast.Import):
                for alias in node.names:
                    if alias.name.split(".")[0] in cls.BLOCKED_IMPORTS:
                        raise SecurityError(f"Blocked import: {alias.name}")
            elif isinstance(node, ast.ImportFrom):
                if node.module and node.module.split(".")[0] in cls.BLOCKED_IMPORTS:
                    raise SecurityError(f"Blocked import: {node.module}")
            elif isinstance(node, ast.Call):
                if isinstance(node.func, ast.Name) and node.func.id in cls.BLOCKED_NAMES:
                    raise SecurityError(f"Blocked call: {node.func.id}")
            elif isinstance(node, ast.Attribute):
                if node.attr in cls.BLOCKED_ATTRS or (
                    node.attr.startswith("__") and node.attr.endswith("__")
                ):
                    raise SecurityError(f"Blocked attribute: {node.attr}")

    @classmethod
    def execute(cls, code: str, df: pd.DataFrame) -> str:
        cls.validate_ast(code)
        import numpy as np
        safe_builtins = {
            "range": range, "len": len, "int": int, "float": float,
            "str": str, "list": list, "dict": dict, "bool": bool,
            "min": min, "max": max, "sum": sum, "sorted": sorted,
            "round": round, "abs": abs, "enumerate": enumerate,
            "True": True, "False": False, "None": None,
        }
        namespace = {"__builtins__": safe_builtins, "pd": pd, "np": np, "df": df.copy()}
        local_ns: dict = {}
        exec(code, namespace, local_ns)
        return str(local_ns.get("result", "Analysis complete but no result assigned."))


class SecurityError(Exception):
    pass


def resolve_target_list(intent: CRUDIntent) -> CRUDIntent:
    if intent.target_list or intent.operation in ("list_lists", "unknown"):
        return intent
    lists = crud.list_lists()
    if len(lists) == 1:
        intent.target_list = lists[0]["name"]
    else:
        intent.operation = "unknown"
        intent.raw_query = f"Which list? You have: {', '.join(l['name'] for l in lists)}"
    return intent


def dispatch(intent: CRUDIntent) -> str:
    """Route a validated CRUDIntent to the appropriate Layer 1 function."""
    intent = resolve_target_list(intent)
    op = intent.operation

    try:
        if op == "create_list":
            return crud.create_list(intent.target_list, intent.schema_type or "generic")

        elif op == "delete_list":
            if intent.requires_confirmation:
                return (f"Are you sure you want to delete '{intent.target_list}'? "
                        "Say 'yes' to confirm.")
            return crud.delete_list(intent.target_list)

        elif op == "list_lists":
            return format_for_voice(crud.list_lists(), op)

        elif op == "add_item":
            return crud.add_item(intent.target_list, **intent.get_fields_dict())

        elif op == "delete_item":
            return crud.delete_item(
                intent.target_list, item_id=intent.item_id,
                **intent.get_match_dict(),
            )

        elif op == "update_item":
            return crud.update_item(
                intent.target_list, item_id=intent.item_id,
                match_fields=intent.get_match_dict(),
                updates=intent.get_fields_dict(),
            )

        elif op == "mark_done":
            return crud.mark_done(
                intent.target_list, item_id=intent.item_id,
                **intent.get_match_dict(),
            )

        elif op == "query_items":
            df = crud.query_items(
                intent.target_list,
                filters=intent.get_filters_dict(),
                sort_by=intent.sort_by,
                limit=intent.limit or 20,
            )
            return format_for_voice(df, op)

        elif op == "analytical_query":
            return _handle_analytical(intent)

        elif op == "unknown":
            return intent.raw_query or "I didn't understand that. Could you rephrase?"

    except FileNotFoundError:
        return f"I couldn't find a list called '{intent.target_list}'."
    except Exception as e:
        return f"Something went wrong: {e}"

    return "I'm not sure how to handle that."


def _handle_analytical(intent: CRUDIntent) -> str:
    if not intent.target_list or not intent.raw_query:
        return "I need to know which list to analyze and what question to answer."
    try:
        schema_info = crud.get_schema_info(intent.target_list)
    except FileNotFoundError:
        return f"List '{intent.target_list}' not found."
    code = generate_analytical_code(intent.raw_query, schema_info)
    if not code:
        return "I couldn't generate an analysis for that question."
    try:
        df = crud.get_df(intent.target_list)
        return CodeSandbox.execute(code, df)
    except SecurityError as e:
        return f"The generated code was blocked for safety: {e}"
    except Exception as e:
        return f"The analysis failed: {e}"
```

### Semantic Cache with XML Serialization

The cache stores `CRUDIntent` objects serialized to XML bytes. This means the cached representation is the same format used everywhere else in the pipeline—no format translation at any boundary.

```python
"""semantic_cache.py — FAISS-backed cache storing XML-serialized intents."""
import sqlite3
import time
from pathlib import Path
from typing import Optional

import faiss
import numpy as np
from sentence_transformers import SentenceTransformer

from layer2_schema import CRUDIntent

CACHE_DIR = Path("~/.dfcrud/cache").expanduser()
CACHE_DIR.mkdir(parents=True, exist_ok=True)
DB_PATH = CACHE_DIR / "cache.db"
INDEX_PATH = CACHE_DIR / "cache.faiss"


class SemanticCache:
    def __init__(self, threshold: float = 0.93, model_name: str = "all-MiniLM-L6-v2"):
        self.threshold = threshold
        self.encoder = SentenceTransformer(model_name)
        self.dim = 384
        self.conn = sqlite3.connect(str(DB_PATH))
        self._init_db()
        self._load_index()

    def _init_db(self):
        self.conn.execute("""
            CREATE TABLE IF NOT EXISTS entries (
                id INTEGER PRIMARY KEY AUTOINCREMENT,
                query TEXT NOT NULL,
                intent_xml BLOB NOT NULL,
                schema_version TEXT DEFAULT '',
                created_at REAL,
                access_count INTEGER DEFAULT 0
            )
        """)
        self.conn.commit()

    def _load_index(self):
        if INDEX_PATH.exists():
            self.index = faiss.read_index(str(INDEX_PATH))
        else:
            self.index = faiss.IndexFlatIP(self.dim)

    def _embed(self, text: str) -> np.ndarray:
        return self.encoder.encode([text], normalize_embeddings=True).astype("float32")

    def lookup(self, query: str, schema_version: str = "") -> Optional[CRUDIntent]:
        if self.index.ntotal == 0:
            return None
        vec = self._embed(query)
        scores, indices = self.index.search(vec, k=1)
        if scores[0][0] >= self.threshold:
            row_id = int(indices[0][0]) + 1
            row = self.conn.execute(
                "SELECT intent_xml, schema_version FROM entries WHERE id=?",
                (row_id,),
            ).fetchone()
            if row and row[1] == schema_version:
                self.conn.execute(
                    "UPDATE entries SET access_count = access_count + 1 WHERE id=?",
                    (row_id,),
                )
                self.conn.commit()
                # Deserialize XML bytes → CRUDIntent
                return CRUDIntent.from_xml(row[0])
        return None

    def store(self, query: str, intent: CRUDIntent, schema_version: str = ""):
        vec = self._embed(query)
        self.index.add(vec)
        # Serialize CRUDIntent → XML bytes for storage
        xml_bytes = intent.to_xml(skip_empty=True)
        self.conn.execute(
            "INSERT INTO entries (query, intent_xml, schema_version, created_at) VALUES (?, ?, ?, ?)",
            (query, xml_bytes, schema_version, time.time()),
        )
        self.conn.commit()

    def invalidate(self, schema_version: str = ""):
        if schema_version:
            self.conn.execute("DELETE FROM entries WHERE schema_version != ?", (schema_version,))
        else:
            self.conn.execute("DELETE FROM entries")
        self.conn.commit()
        self._rebuild_index()

    def _rebuild_index(self):
        self.index = faiss.IndexFlatIP(self.dim)
        rows = self.conn.execute("SELECT query FROM entries ORDER BY id").fetchall()
        if rows:
            vecs = self.encoder.encode(
                [r[0] for r in rows], normalize_embeddings=True
            ).astype("float32")
            self.index.add(vecs)

    def save(self):
        faiss.write_index(self.index, str(INDEX_PATH))
        self.conn.commit()
```

## 7. FastAPI Integration

```python
"""main.py — FastAPI endpoint for COSA/Lupin voice pipeline."""
from contextlib import asynccontextmanager
from fastapi import FastAPI
from pydantic import BaseModel

import layer1_crud as crud
from layer2_extract import extract_intent
from layer3_dispatcher import dispatch, resolve_target_list
from semantic_cache import SemanticCache

cache: SemanticCache = None


@asynccontextmanager
async def lifespan(app: FastAPI):
    global cache
    cache = SemanticCache(threshold=0.93)
    yield
    cache.save()


app = FastAPI(title="DataFrame Voice CRUD", lifespan=lifespan)


class QueryRequest(BaseModel):
    text: str
    session_id: str = ""
    confirm: bool = False


class QueryResponse(BaseModel):
    speech: str
    operation: str = ""
    needs_confirmation: bool = False
    intent_xml: str = ""  # raw XML for debugging / pipeline inspection


@app.post("/query", response_model=QueryResponse)
async def handle_voice_query(req: QueryRequest) -> QueryResponse:
    text = req.text.strip()
    if not text:
        return QueryResponse(speech="I didn't catch that.")

    lists = crud.list_lists()
    schema_ver = str(hash(frozenset(
        (l["name"], tuple(l["columns"])) for l in lists
    )))

    # 1. Semantic cache
    cached = cache.lookup(text, schema_version=schema_ver)
    if cached:
        result = dispatch(cached)
        return QueryResponse(
            speech=result,
            operation=cached.operation,
            intent_xml=cached.to_xml(skip_empty=True).decode(),
        )

    # 2. Extract intent (Phi-4 → Claude Code fallback)
    intent = extract_intent(text, lists)

    # 3. Confirmation flow
    if intent.requires_confirmation and not req.confirm:
        return QueryResponse(
            speech=f"Are you sure you want to {intent.operation.replace('_', ' ')} "
                   f"'{intent.target_list}'? Say yes to confirm.",
            operation=intent.operation,
            needs_confirmation=True,
            intent_xml=intent.to_xml(skip_empty=True).decode(),
        )

    # 4. Dispatch
    result = dispatch(intent)

    # 5. Cache successful extractions
    if intent.operation not in ("unknown", "analytical_query"):
        if intent.confidence and intent.confidence >= 0.7:
            cache.store(text, intent, schema_version=schema_ver)

    return QueryResponse(
        speech=result,
        operation=intent.operation,
        intent_xml=intent.to_xml(skip_empty=True).decode(),
    )

## 10. Anti-Patterns (Updated for XML)

**1. Don't use Ollama's `format` parameter for XML.** Ollama's structured output only supports JSON schemas via GBNF grammar compilation. For XML output, use prompt-guided generation with pydantic-xml validation. If you pass `format=CRUDIntent.model_json_schema()` to Ollama, you'll get JSON back, not XML.

**2. Don't use Ollama for multi-GPU tensor parallelism.** Ollama's llama.cpp backend splits layers sequentially across GPUs—only one GPU is active per forward pass. Use vLLM with `--tensor-parallel-size 2` for true parallel inference across the dual 4090s. This is the single largest throughput difference in the entire architecture.

**3. Don't parse XML with regex alone.** The `_extract_xml_from_response` uses regex only for *extraction* (finding the `<intent>` block within surrounding text). Actual parsing and validation happens via `lxml` + `pydantic-xml`. Never trust regex to validate XML structure.

**4. Don't cache destructive operations at low thresholds.** A semantic match at 0.90 between "delete the grocery list" and "delete the todo list" is catastrophic. Use 0.97+ thresholds for `delete_*` operations, or skip caching entirely for destructive ops.

**5. Don't serialize XML with the standard library parser.** Use `pydantic-xml[lxml]`. The stdlib `xml.etree.ElementTree` serializer has a known bug with namespace handling—it moves namespace declarations to the root element and substitutes `ns0`, `ns1` prefixes. lxml preserves namespace declarations correctly.

**6. Don't trust Phi-4's self-reported confidence.** The `confidence` attribute in the XML output is a self-assessed value that small models tend to overstate. For production, consider using vLLM's `--enable-logprobs` to extract token-level log probabilities for the `<operation>` element's content, which gives a more grounded confidence estimate.

**7. Don't generate XML exemplars by hand.** Always generate few-shot examples by serializing actual `CRUDIntent` objects via `to_xml()`. This guarantees structural consistency between the examples shown to the LLM and the schema the validator expects. Hand-written XML examples drift from the schema over time.

**8. Don't skip `skip_empty=True` on serialization.** Without it, `to_xml()` emits empty elements for every `Optional[None]` field (`<item_id/>`), which bloats the prompt and confuses the LLM about which fields are required. Always pass `skip_empty=True` for prompt exemplars and cache storage.
