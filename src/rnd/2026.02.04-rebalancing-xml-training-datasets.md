# Plan: Rebalance Training Data to 400 Samples Per Command

## Goal

Make all 32 routing commands equally represented at **400 samples per command** in the pre-split dataset. After the 80/10/10 train/test/validate split: ~320 train, ~40 test, ~40 validate per command.

**Total**: 32 commands × 400 = 12,800 pre-split → ~10,240 train / ~1,280 test / ~1,280 validate.

## Current State (19x imbalance)

| Tier | Commands | Current Count | Root Cause |
|------|----------|--------------|------------|
| Compound vox (12) | search/go-to + engine + tab | 1,600 | 2,000 target, 80% split |
| Compound agent router (4) | weather, calendar, receptionist, date-time | 1,600 | 2,000 target, 80% split |
| Simple agent router (2) | todo, math | 322-326 | ~400 raw + interjections |
| `none` (1) | none | 320 | Appears in 2 builders, ~200 raw |
| Agentic jobs (3) | deep research, podcast, r2p | 200 | 200 target from agentic builder |
| Simple vox clipboard (10) | clipboard variants | 83-160 | ~200 raw, NO interjections, dedup kills overlap |

**Root cause of imbalance**: Compound commands cross-multiply (100 lines × 100+ args = 10,000+), while simple commands have only ~200 raw lines with no augmentation.
