## Executive Summary

Replace the current file-based JSON solution snapshot system with **LanceDB vector database** while maintaining 100% functional compatibility through a swappable interface architecture. This approach enables empirical comparison between implementations and provides native semantic similarity search capabilities.

### Key Goals
- **True swappability**: Identical interfaces allowing runtime switching via configuration
- **Empirical validation**: Built-in performance metrics and comparison framework  
- **Zero regression**: Maintain all existing functionality while improving performance
- **Baseline establishment**: Measure current system performance for comparison

## Current System Analysis

### File-Based Implementation Issues
- **Scalability**: JSON files don't scale, slow I/O operations
- **Memory intensive**: Loads all snapshots into memory at startup  
- **Manual similarity**: Custom numpy dot product calculations
- **Complex indexing**: Multiple in-memory dictionaries (question, synonymous, gists)
- **No persistence**: QuestionEmbeddingsTable cache lost between sessions

### Existing Database Infrastructure
- **Database Location**: `src/conf/long-term-memory/lupin.lancedb` (already exists)
- **New Table**: Will create `solution_snapshots` table within existing database
- **Integration**: Leverages existing LanceDB infrastructure in the project

## Interface Design

### Abstract Base Interface

```python
from abc import ABC, abstractmethod
from typing import List, Tuple, Optional, Dict, Any
from dataclasses import dataclass
import time

@dataclass
class PerformanceMetrics:
    """Standard performance metrics for empirical comparison."""
    search_time_ms: float
    memory_usage_mb: float
    result_count: int
    cache_hit_rate: float
    initialization_time_ms: float

class SolutionSnapshotManagerInterface(ABC):
    """
    Abstract interface for solution snapshot storage and retrieval.
    
    Ensures both file-based and LanceDB implementations are truly 
    swappable with identical contracts and testable behaviors.
    """
    
    @abstractmethod
    def __init__(self, config: Dict[str, Any], debug: bool = False, verbose: bool = False):
        """Initialize manager with configuration dictionary for flexibility."""
        pass
    
    @abstractmethod
    def initialize(self) -> PerformanceMetrics:
        """Load/initialize storage backend and return initialization metrics."""
        pass
    
    @abstractmethod
    def add_snapshot(self, snapshot: SolutionSnapshot) -> bool:
        """Add snapshot, return success status."""
        pass
    
    @abstractmethod
    def delete_snapshot(self, question: str, delete_physical: bool = False) -> bool:
        """Delete snapshot, return success status."""
        pass
    
    @abstractmethod
    def find_by_question(self, 
                        question: str,
                        question_gist: Optional[str] = None,
                        threshold_question: float = 100.0,
                        threshold_gist: float = 100.0,
                        limit: int = 7) -> Tuple[List[Tuple[float, SolutionSnapshot]], PerformanceMetrics]:
        """Search by question similarity, return results + metrics."""
        pass
    
    @abstractmethod
    def find_by_code_similarity(self,
                               exemplar_snapshot: SolutionSnapshot,
                               threshold: float = 85.0,
                               limit: int = -1) -> Tuple[List[Tuple[float, SolutionSnapshot]], PerformanceMetrics]:
        """Search by code similarity, return results + metrics."""
        pass
    
    @abstractmethod
    def get_all_gists(self) -> List[str]:
        """Return all available question gists."""
        pass
    
    @abstractmethod
    def get_stats(self) -> Dict[str, Any]:
        """Return storage statistics (count, size, etc.)."""
        pass
    
    @abstractmethod
    def health_check(self) -> Dict[str, Any]:
        """Return health status and diagnostics."""
        pass
```

### Factory Pattern for Runtime Swapping

```python
from enum import Enum
from typing import Union

class ManagerType(Enum):
    FILE_BASED = "file_based"
    LANCEDB = "lancedb"

class SolutionSnapshotManagerFactory:
    """Factory for creating swappable solution snapshot managers."""
    
    @staticmethod
    def create_manager(manager_type: Union[ManagerType, str], 
                      config: Dict[str, Any], 
                      debug: bool = False, 
                      verbose: bool = False) -> SolutionSnapshotManagerInterface:
        """Create manager instance based on type and configuration."""
        if isinstance(manager_type, str):
            manager_type = ManagerType(manager_type)
        
        if manager_type == ManagerType.FILE_BASED:
            return FileBasedSolutionManager(config, debug, verbose)
        elif manager_type == ManagerType.LANCEDB:
            return LanceDBSolutionManager(config, debug, verbose)
        else:
            raise ValueError(f"Unknown manager type: {manager_type}")
```

## Testing Strategy

### Empirical Comparison Framework

```python
class ManagerComparisonSuite:
    """Compare multiple manager implementations empirically."""
    
    def __init__(self, managers: Dict[str, SolutionSnapshotManagerInterface]):
        self.managers = managers
        self.test_suite = {name: SolutionSnapshotManagerTestSuite(mgr) 
                          for name, mgr in managers.items()}
    
    def run_comparative_analysis(self) -> Dict[str, Any]:
        """Run tests on all managers and compare results."""
        all_results = {}
        
        for name, suite in self.test_suite.items():
            print(f"Testing {name} implementation...")
            all_results[name] = suite.run_full_suite()
        
        comparison = self._generate_comparison_report(all_results)
        return {
            "individual_results": all_results,
            "comparison": comparison
        }
```
