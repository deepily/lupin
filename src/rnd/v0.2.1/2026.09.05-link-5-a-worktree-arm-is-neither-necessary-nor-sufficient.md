# Link 5 reachability: my proxy's RATIO survived and its EXPLANATION did not

**Row**: `fa583462` (out of `d2dd3ee3`, María's fifth-link amendment)
**Author**: Rachel 🕊️ · 2026-09-05
**Repo under measurement**: `planning-is-prompting/workflow/scripts`

---

## 0. The one-paragraph version

I reported that **17 of 27** memento-family test files "cannot, by construction, see a Link 5
defect." María minted a row on it with an explicit first action: *do not start by writing
tests — demonstrate the blindness*. Doing that replaced my text-keyed proxy with a real
mutation, and the proxy was **wrong in both directions and wrong about its own denominator**.
The corrected figure is **9 of 15**. ⚠️ **63% blind became 60% blind — the ratio barely moved,
and every mechanical claim under it was false.** A reader checking only the headline would
have concluded my finding held.

---

## 1. The mutation, which is not invented

`slot_base_dir`'s own docstring names the historically real defect: *"This function used to
answer `repo_root` for BOTH io and root, and that single line … made every worktree seat
unable to self_respin (row 6c64d2f5)."*

```python
    if slot == "root":
        ...
        return seat_root          #  ->  return repo_root      THE MUTATION
```

⇒ In the **main checkout** the two roots COINCIDE, so nothing observable changes.
⇒ In a **linked worktree** they DIVERGE, and the root record lands in the wrong tree.

That is a Link 5 defect by construction: present in every checkout, executing on every run,
and invisible to anything that cannot make the two roots differ.

---

## 2. The demonstration María asked for — two arms, one variable

Baseline green first, mutation sha-verified, restore verified, restore control green.

| arm | file | result |
|---|---|---|
| **A** — no worktree | `test_memento_root_pointer_is_persona_blind.py` | `6 passed` — ⚪ **BLIND** |
| **B** — real worktree | `test_memento_root_slot_lands_in_the_seats_tree.py` | `2 failed, 4 passed` — 🔴 **CAUGHT** |

Arm B is the whole point. **Arm A alone would only show that one test is weak.** The same
mutation, the same module, the same moment, caught the instant the environment can express
divergence — that isolates the ENVIRONMENT as the variable rather than the assertions.

⚠️ **And Arm A's file is not a bad test.** It is named `..._is_persona_blind` and it is about
persona-blindness. It was never aimed at root divergence. The blindness is structural; reading
this as a criticism of that file is the misuse.

## 3. Then the census — and it demolished my proxy

María's row said explicitly: *"NOT ESTABLISHED: whether the remaining 10 actually DO exercise
divergence, or merely could. DO NOT ASSUME 10 IS THE ANSWER."* So I ran the same mutation
against every file and recorded who catches it.

**First correction — my denominator was the directory, not the family.** `test_*.py` in that
directory is **27** files; the ones that actually import or exercise `memento_io` are **15**.
The other twelve are doc-parity, rsync-backup, mandate-census and friends, which have no
business in a memento reachability figure. I keyed on location instead of subject.

**Second correction — the predicate.** "Contains the text `worktree add`" versus "catches a
real Link 5 mutation":

| | catches it | blind | |
|---|---|---|---|
| **has a worktree arm** | 5 | **5** | ⇐ a worktree arm is **NOT SUFFICIENT** |
| **no worktree arm** | **1** | 4 | ⇐ and **NOT NECESSARY** |
| **total (15 memento-family)** | **6** | **9** | |

- **Five of the ten worktree-building files are blind.** They construct a real linked worktree
  and still cannot see this defect — building the environment is not the same as *exercising
  the divergence inside it*.
- **One file with no worktree at all catches it**: `test_memento_io_tmp_slot.py`, which calls
  `slot_base_dir` directly with two different roots. **No git, no fixture, no subprocess.**

---

## 4. What that changes about the remedy

The obvious remedy — *"add a worktree arm to these tests"* — is now measurably the wrong one.
It would leave five files that already have one and still cannot see the defect, and it would
be an expensive way to buy what the cheapest catching test in the set gets for free.

⇒ **The remedy is to PASS DIVERGENT ROOTS, not to build a divergent environment.** The failure
mode is "one value, two derivations, and they differ." A unit test can express that in one
line by handing the function two different paths. The worktree is one way to *produce* the
divergence; it was never the thing being tested.

---

## 5. The transferable half

**A proxy can keep its headline number while every mechanism under it is false.** My ratio
moved 63% → 60% and would have passed any sanity check a reader applied to it. What changed
completely is *which files*, *why*, and *what to do about it* — and those are the only parts
anyone acts on.

⇒ So when a finding is going to be acted on, **the proxy has to be cashed out for the thing
itself before the remedy is designed, not after.** This one was, only because María's row
refused to accept the count and named the demonstration as the first action instead.

⚠️ It is the same shape as § *A HIT IS NOT A USE*, one level up: there a grep counts names
where you meant uses; here a grep counts *environments* where I meant *reachability*. In both
the search is correct and the population is not the one the question was about.

---

## 6. What is NOT established

- **One mutation, one defect site.** "Blind to this Link 5 mutation" is not "blind to every
  Link 5 defect". The 9 is a floor on the blind set for this site, not a general verdict.
- **No Link 5 defect is known to have SHIPPED through this gap.** The gap is structural; the
  harm is unmeasured, and María's row already says so.
- **`test_doc_deploy_parity_live.py` was RED at baseline** and is excluded from the verdict.
  It is outside the memento family in any case.
- **The six catchers were not read.** They are catchers by measurement; whether each does so
  for a good reason is unexamined.
