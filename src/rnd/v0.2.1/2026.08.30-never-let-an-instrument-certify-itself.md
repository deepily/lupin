## 2. The principle

> ## 🔴 NEVER LET AN INSTRUMENT CERTIFY ITSELF.
> **The fix is always the same: a second reading that does not come from the thing under test.**

## 4. The discharge — the two-independent-readings pattern

**Written by Maya 🌻; forced by Tiberius 👑 reviewing `177c3542`. In the tree at `aab06b9c`
(`src/tests/unit/test_secret_scan.py`).**

A test that polices a record *through the helper that expresses the record* cannot fail. A dead
helper — one returning `[]` for any input — makes the assertion pass **vacuously**, and a vacuous
pass is indistinguishable from a real one.

```python
# 1. read the live record DIRECTLY — not through the thing under test
direct = [ row for row, reason in recorded[ "branch_accepted" ].items()
           if reason == GRANDFATHER_REASON ]

# 2. cross-check the helper against it — a broken helper REDDENS instead of certifying
assert sorted( riding ) == sorted( direct ), (
    f"amnesty_rows disagrees with a direct read of the record: helper says "
    f"{len( riding )}, the file says {len( direct )}. The helper is wrong, or the "
    "record's shape changed under it — either way the bound below means nothing." )

# 3. assert the record is NON-EMPTY — the test cannot pass on nothing
assert direct, ( "NO row rides the amnesty. Either every row was individually re-triaged — "
                 "worth saying out loud and re-pinning AMNESTY_ROWS to 0 — or this test is "
                 "reading an empty record and would pass on anything." )
```

### 4.1 Move 3 is the quiet load-bearer, and the reason is a recursion

Moves 1 and 2 build a control: two readings that must agree. **On an empty record they agree
perfectly.** So a cross-check without move 3 is *itself* an instrument that cannot fail — it reports
*"the helper is honest"* in exactly the case where it checked nothing.

> **The control you built to escape §2 has walked straight back into §2.**

⇒ **Generalised, and it outlives this file: any two-reading control needs a third assertion that
there was something to read. A comparison is not a measurement until you know both sides are
non-empty.**

### 4.2 A fourth move, from the reference implementation

`heartbeat_hold_io.py:472` does all three and adds one more — its success line carries the
load-bearing phrase, *read back through the reader the hook uses*:

```python
hold      = write_hold( ... )
read_back = read_hold( args.session_id, base_dir=args.base_dir )   # the CONSUMER's reader
if not is_honored( read_back ):
    path.write_bytes( prior_bytes ); os.utime( path, prior_times ) # 4. ROLL BACK
    return EXIT_NOT_HONORED
```

**Not its own parser — the consumer's.** A write that verifies with its own reader proves the bytes
round-trip, which is the thing least in doubt. And on failure it **restores the previous state**: a
verify that reports failure and leaves the broken artifact in place has told the truth and still
done harm.

### 4.3 🔴 The boundary is load-bearing, not a caveat

**This pattern applies ONLY where an independent second reading actually exists.**

*A rule that claims to apply everywhere becomes a ritual.* Without the boundary it gets satisfied by
**manufacturing** a second reading — deriving the "independent" read from the same helper, or from a
source sharing its assumption. **A fake second reading is worse than none, because it also reports
success.**

Where no second reading exists — two agreeing sites, no second record — the fallback is
**annotation and review**; see §5.

## 5. `masked-invariant` — where the discharge is unavailable

*A fact stated twice on one path, where every test observing a return value sees the two sites
agree, so neither can be independently proved.*

**Written three times, refuted twice, both times by Tiberius 👑, both times because a claim was
checked instead of accepted.** The retraction path is the finding:

1. **Rachel's draft** — *"a test can assert the mechanism and still be unable to fail if the fact is
   stated in two places."* **Refuted**: it condemns a *healthy* arrangement.
2. **Tiberius's fix** — *"pin each site directly with its own unit test."* **He reproduced it and
   refuted his own fix**: the outer site's direct test resolves through the inner one. **Measured at
   `a35ce8ef`**: neuter the outer site → **127 passed**, including
   `test_an_unreadable_live_comm_refuses_rather_than_passes`, the unit test written against that
   exact function. Neuter the inner → **rc=1**.
3. **Surviving rule** — below.

- **Trigger**: deliberate defence-in-depth. **The redundancy is usually there ON PURPOSE** — a proof
  obligation, not a defect to delete.
- **Obligation, one of two**: drop the second statement, **or** keep it and **state the price in the
  comment**, so the line is defended by **review** rather than by the harness.
- **Discharge**: **show each site pinned.** Arguing the path-level test is good enough does not clear
  the flag — that argument is the failure mode restating itself.
- 🔴 **Anti-pattern**: deleting the line because a mutation harness reports it dead. **It is dead to
  the harness, not to the contract.**

**Shipped as an annotation in the file it came from** (`03b90812`), replacing one that over-claimed.
**A rule that ships as an annotation in the code it was derived from is installed; one that ships
only as a retro line is not.**

## 6. Every measurement carries the coordinates that make it falsifiable

**PROPOSED for CLAUDE.md — Rick's decision. Not installed.**

This repo already says *state the root count and the sha*. **It is stated only for git**, and on
2026-08-30 that gap produced a wrong accusation against two named seats.

**What happened**: a census read four memento slots at ~15:36 and found two pointing at stale
sessions. One was repaired at **15:40:12**, the other at **15:13:53**. The reading was **TRUE when
taken and FALSE when circulated**, and it was re-published for an hour, reaching a task-store row and
two peers. **A filesystem census with no clock reads a repaired state as a broken one** — and it
named seats.

⇒ The rule is not *"add a timestamp"*. It is that **every measurement has coordinates, and which
ones depend on what kind of thing you measured:**

| You measured | The coordinate that makes it falsifiable |
|---|---|
| the git tree | the **sha** |
| coverage | the sha **and** the frame (`source` list, never a `--cov` scope) |
| a file count / population | the **root set** and its size |
| **mutable local state** — a directory, a slot, a pointer, a process table | the **wall-clock time of the read** |
| a running fleet | the time **and** the count, because it is a distribution, not a value |

**Without them a measurement is not wrong — it is unfalsifiable**, which is worse: a reader cannot
tell whether disagreeing means they are mistaken or merely later.

### 6.1 Proposed CLAUDE.md text (verbatim, for Rick to accept or refuse)

```markdown
### 🔴 NEVER LET AN INSTRUMENT CERTIFY ITSELF

If a check derives its success criterion from the thing it is checking, it cannot fail. The remedy
is always the same: **a second reading that does not come from the thing under test.**

3. **Assert the record is NON-EMPTY.** Two readings of an empty file agree perfectly — without this,
   the cross-check passes on nothing, which is the same defect one level up.

A fourth move where a write must land somewhere a *different* reader will look

delete such a line because a mutation harness calls it dead** — it is dead to the harness, not to

mutable local state** (a directory, a slot, a process table). Measured 2026-08-30: a memento census
```
