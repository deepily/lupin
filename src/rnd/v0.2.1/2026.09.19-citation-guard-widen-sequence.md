| arm | result |

requirement has to come from the rule's design, backed by a purpose-built test.

## The backward-compatible recogniser — no flag day

Two filters, each accepting **27/27** live `.test.ts` claims:

| filter | accepts | rejects the TS table row | rejects the guard's docstring |
|---|---|---|---|
| claim not inside quotes | 27/27 | ✗ | ✓ |
| claim line is not a table row | 27/27 | ✓ | ✗ |
| **conjunction** | **27/27** | ✓ | ✓ |

⇒ **Zero edits to the 27.** Ship the conjunction as the **transitional arm**: the recogniser accepts
the old shape via the conjunction **and** the new marker; new files must use the marker.

🔴 **Caveat, stated because it will outlive whoever reads this**: that conjunction was **fitted to the
two negatives we happened to find**. It has no denominator — nothing says a third prose shape does not
exist. It is a proxy, not the predicate.

**Do not make it a prose note.** A note protects only the reader who reads it. Make it mechanical:

1. **Pin both known negatives as committed fixtures.** Delete either filter and a *named* test reddens.
2. **Make the transitional arm self-retiring**: the guard states how many claims still use the old
   shape, beside its denominator, and that count may **only shrink** — the `GRANDFATHERED` pattern.
   Then the proxy's blast radius is a number someone watches go to zero.
