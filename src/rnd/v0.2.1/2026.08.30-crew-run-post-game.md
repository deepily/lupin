## 3. What went wrong (fix)

### 3.1 The retro prompt itself was a leading instrument — mine

I wrote 8 DMs and **5 carried a leading question**: a finding pre-attributed to a seat, a grievance
pre-sized before the witness spoke, a firsthand account demanded from a seat whose firsthand context
had died.

⇒ **A LEADING QUESTION IS AN INSTRUMENT, AND MINE COULD NOT HAVE RETURNED A "NO".** That is the
same defect this crew spent the entire day naming in test fixtures — an instrument that cannot
distinguish the good state from the bad one — arriving **inside the retro built to harvest it.**

The doctrine already says *cross-examine the source before graduating a rule*. It does **not** say
the cross-examination can itself be shaped so the source can only agree. It can. Mine was.

⇒ **And the control was the seats, not my marking.** I asked re-spun seats to tag entries
`from-memento` so I would read them as depositions. **Nobody needed the tag** — Rio and Clayton
volunteered the boundary of their own knowledge unprompted. *A label the moderator applies is a
hope; a seat that names where its own knowledge stops is a mechanism.*

## 6. Lessons for the failure-mode catalog

**`leading-harvest`** — *the retro instrument that cannot return a "no".*

- **Trigger**: a moderator drafting per-seat retro prompts under time pressure, from a memento that
  already names who found what.
- **Symptom**: contributions that agree with the moderator. Indistinguishable from a run that went
  well, which is why it survives.
- **The guard that would have caught it**: ask for the **provenance** and the **boundary of
  knowledge** and nothing else — never name the finding you expect back. The seat supplies the
  attribution; the moderator supplies only the question.
- **Sibling entries**: `blind-fixture` (a fake that ignores its input), `vacuous-verify` (a clean
  exit on a tree with nothing to judge), `wrong-tree` (a confident verdict about a tree you were not
  asking about). All four are one shape: **an instrument that cannot distinguish the good state from
  the bad one, reporting the good one.**
