## 6. Lessons for the failure-mode catalog

**`leading-harvest`** — *the retro instrument that cannot return a "no".*

- **Trigger**: a moderator drafting per-seat retro prompts under time pressure, from a memento that
  already names who found what.
- **Symptom**: contributions that agree with the moderator. Indistinguishable from a run that went
  well, which is why it survives.
- **The guard that would have caught it**: ask for the **provenance** and the **boundary of
  knowledge** and nothing else — never name the finding you expect back. The seat supplies the
  attribution; the moderator supplies only the question.
- **Sibling entries**: `blind-fixture` (a fake that ignores its input), `vacuous-verify` (a clean
  exit on a tree with nothing to judge), `wrong-tree` (a confident verdict about a tree you were not
  asking about). All four are one shape: **an instrument that cannot distinguish the good state from
  the bad one, reporting the good one.**
