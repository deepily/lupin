## What the night actually found

### 1. The manifest answered a different question than everyone read it as

The LANDED/OWED test is `git grep <anchor> HEAD` — **the merged tip only**. It answers *"is this
merged"* while every reader takes it as *"has anyone built this"*. Eight rows were found already
built; Krishna's own row was the ninth. Self-reinforcing: unmerged reads OWED → the row is
re-staffed → the duplicate is also unmerged.

Ruled: three states (MERGED / BUILT-UNMERGED / OWED) plus a supersession rule.

🔴 **And the re-measure flipped the headline.** Built-unmerged came back **0**; 9 of 22 OWED rows
were **already merged**. So the dominant defect is **rotted anchors**, not blindness to branches —
a worse finding than the one that prompted the row. *Stated as a limit: 0 built-unmerged is a
statement about 20:43, after I had spent the evening merging. A census taken after a drain records
no backlog.*

### 2. A green that lies — and its honest twin in the same codebase

A `dry_run` job writes a results file headed **"ALL PASSED"**, every suite `Duration 0.1s`,
including the two ~25-minute e2e halves. Maya read one as evidence of a green tree and built a
"moving red" escalation on it, then withdrew in full.

🔴 **The same machinery, the same night, wrote `"# Test Suite Report — NOT EXECUTED" / "NOT RUN"`**
when a suite name didn't resolve. **Two no-op paths, one honest, one indistinguishable from a pass.**
So the fix is not a feature — it is *"make the dry run do what the not-found path already does"*.
That reframing is Maya's, found by accident from Rio's typo. Rows `255f5346` / `f146aeb3` (dup).

### 3. Tests that passed while testing nothing

Rio's e2e asserted a `data-state` the pending card never carries. Two failed — **and the same wrong
assumption sat in two assertions that were PASSING**: `wait_for_selector(..., state="detached")` on a
selector matching nothing succeeds instantly. Four sites, one assumption, two wearing green.

Repair proven to discriminate: both detach waits now assert `count() == 1` **before** the wait;
under the old code that assertion would have read 0 and failed.
