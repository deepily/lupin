## 1. Phase A — fixes to panes that already exist

### A-1. The one theme: the multiplexer repaints and forgets

**This is a single piece of work in five places, not five bugs.** Legacy protects an operator's in-progress state across its repaints; the multiplexer replaces its DOM wholesale and loses it. Building these together means one mechanism, not five patches.

| # | What is lost | Where | Legacy's answer |
|---|---|---|---|
| 1 | A half-typed reason, the chosen verb, the open disclosures, the focused control | Task List, every 60 s poll | `_captureOperatorState` / `_restoreOperatorState` (`notifications.js:13231-13435`) |
| 2 | A click whose press and release straddle a repaint | Task List | press-hold guard: `mousedown` holds the repaint, `mouseup`/`mouseleave`/`blur` replays it (`:14274-14283`) |
| 3 | The batch-reason box and disclosures | Holding Area | same capture/restore (A9 H13) |
| 4 | Disclosed rows and group state | Epic Board | A10 E11 |
| 5 | An opened queue bucket, and an expanded job card, on every job event | Jobs pane | `lupin_queue_expand_state` (`:15429-15460`), restored on load |
| 6 | A pending Action Required prompt, its active id, pause state and half-answered stepper | Action Required, on reload | `notifications_action_required` (`:21332-21519`) |

**Done means**: an operator can type a reason, press a button, open a bucket or answer half a prompt, and a poll, a job event or a reload does not take it away. A test per surface that mutates state mid-repaint and asserts survival.

## 5. How a Phase A or Phase B item is finished

1. Tests first where the behaviour is observable: a unit test for the changed unit, and a test that fails against today's code.
2. The mechanism, not the symptom — especially A-1, which is one mechanism across six surfaces.
3. Peer review before merge, adversarial where state or timing is involved.
4. Green suite plus a rebuilt multiplexer bundle, because a saved file is not a served file.
5. The Phase 2 row's id in the commit message, so a reader can find the behaviour it restores.
