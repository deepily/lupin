## 3. The live cause: a name mismatch with a silent default

| | |
|---|---|
| `src/cosa/rest/db/database.py:117` reads | **`DB_PASSWORD`**, defaulted to `""` so it cannot raise at import |
| the untracked repo-root `.env` supplies | **`POSTGRES_PASSWORD`** and `JWT_SECRET_KEY` — **no `DB_PASSWORD` at all** |
| the only translation between them | **`docker-compose.yml:277` and `:475`** — `DB_PASSWORD: ${POSTGRES_PASSWORD:?…}` |
| who that serves | **containers** |
| who does it for a host-side process | **nothing** |

Every `cc_notification_listener` is host-side (`/…/lupin/.venv/bin/python3 -m lupin_cli…`).
`Gister.get_gist` (`src/cosa/memory/gister.py:127`) reads the Postgres-backed cache
**before** calling the LLM, unguarded, so the connection refusal escapes `get_gist`
entirely and the listener's bare `except Exception` converts it into five words.

⇒ **The gist cache has been unreachable from any host-side process by construction.**

## 4. The discriminating pair — one variable, novel utterance

|---|---|

NAME, not the value**, and without that arm I would have "confirmed" my dead hypothesis.

probe). Stated, not hidden.

## 7. What is fixed, what is open

**Recommended fix (A)** — a cache read/write failure falls through to the LLM instead of
aborting the gist. It is the smallest change, the cache is only an optimisation, and it
closes **158 of 158** current failures. Awaiting Rick's ruling on altitude; two wider
options (make an empty `DB_PASSWORD` loud; supply the credential host-side) carry real
regression and secret-handling risk respectively.

**Open, deliberately, not silently:**

1. **Already-cached bad gists.** `gister cache enabled = True`; a hit serves a stale gist
   indistinguishable from a live one. Fixing the credential does not repair rows already
   written. Untouched pending a ruling.
2. **The durable defect is the indistinguishability**, not any one cause. Five failures
   produce one output. Until a degraded gist is visibly degraded *where someone looks*,
   the sixth cause will cost another thirteen days.
3. **Neighbour, not duplicate**: row `3658ec66` recorded `exact_gist` firing 0 times
   across 5,028 asks with `gist_cache` unexamined. If the gister has been degraded for
   long stretches — and §2 says it has — that zero may be a **consequence**, not a
   curiosity.
