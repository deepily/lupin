## 4. The fix — marker preservation, and why not the other option

The row offered two routes. **Marker preservation was chosen**, on Mr. Radio's steer:
attaching the source commit's subject line only helps when a claim happens to name an
artifact, and an inverted claim naming nothing would still be undetectable. Detecting this
one cost a single grep purely because it happened to cite `2df3aefb`.

**The rule, and it is the narrowest one that catches the measured case**: a literal the
sender wrote ONLY inside a retraction scope must not appear in the rewrite OUTSIDE one.
Absence stays legal — dropping a retraction wholesale is a lossy summary, which is the
design. Asserting its retracted value as current is not.

**Scope is the LINE, opening at the CLAUSE that carries the marker.** Both word orders
occur in real banners: `USED TO NAME 12 AM – 9 AM` puts the marker first, `12 AM – 9 AM
was wrong` puts it last, so a scope anchored at the marker misses the second. Scope stops
at end-of-line because the replacement value lives in a different paragraph or table row,
and swallowing it would protect the very figure the document is promoting.

**The two sides get different vocabularies, deliberately.** Of the original we ask *is this
a retraction?* — narrow, because the answer protects a value. Of the rewrite we ask *did
the retraction survive?* — generous, because admitting a weaker word can only ever CLEAR a
rewrite that kept a marker, never block one. `CORRECTED` in caps opens a scope; `corrected`
in lower case does not, because "I corrected the test at abc1234" is an ordinary work
sentence and admitting it would make that sha a protected literal.

Also added, same family, not a second design: one `Requirement:` line in
`src/conf/prompts/agents/dm-tutor.txt` telling the model to keep tense and retraction
words. **The guard is the control; the prompt line is a courtesy** — a habit is not a
control, so the refusal is what actually holds.

### 🔴 WHAT IS STILL UNCOVERED AFTER THE `29a986df` FIX SHIPS — read this before trusting a DM

At Mr. Radio 🦉's instruction, stated up front rather than left to be discovered: **a green
condenser does NOT mean your message arrived intact.** The guard is narrower than the failure,
and saying so plainly is worth more than a guard that implies wider reach.

| covered | NOT covered |
|---|---|
| a **retraction** phrased with one of the marker words in `dm-tutor.txt` | a **recommendation** inverted — case #1, the one that would have stripped a live guard |
| | a **measurement** flipped — case #3, "survived" delivered as "killed" |
| | a **state report** that was true when sent and stale on arrival — case #2 |
| | **non-delivery** — nothing to inspect; that is row `298af249`, a different mechanism |
| | any retraction phrased without a marker word — the limit §6 already declared |

**Why the gap cannot be closed by adding markers.** A retraction has a vocabulary — "used to",
"no longer", "corrected". **A recommendation does not.** "Delete the site-packages clause" and
"keep the site-packages clause" are both ordinary, well-formed, self-consistent English, and no
marker distinguishes them. The guard can detect that a *retraction* was reversed because the
reversal leaves a grammatical fingerprint; reversing an *instruction* leaves none.

⇒ **The only check that caught all three real cases was opening the artifact the DM pointed
at.** That is a habit, and this document's own §4 says a habit is not a control. Stated as a
known, unclosed gap rather than dressed up as a mitigation:

- **When you send**, put the verdict in the path, not only in the prose. The prose is the part
  that gets rewritten; a committed file is not.
- **When you receive**, open the path before acting — and specifically before acting on any
  message that tells you to *delete*, *disable*, *skip* or *relax* something.
- **A message that reads fine is not evidence.** Two of Clayton's corrections travelled intact
  the same evening. The instrument does not mangle everything, which is exactly why "this one
  looks fine" cannot be used to clear it.
