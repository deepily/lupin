# Guard audit — the sixteen test files added 2026-09-01, run against broken arms

**Rio ⚡ · 2026-09-01 · pinned sha `3500696d` · detached worktree, all three pins**

## Why

Sixteen test files landed on 2026-09-01 carrying 155 tests. Three had ever been run
against a broken arm. A guard that has only been seen passing is a guard nobody has
measured — coverage says a line RAN, never that the test could have noticed it
running wrong.

## Method

Detached worktree at the pinned sha, `LUPIN_ROOT="$PWD"`, `PYTHONPATH="$PWD/src"`,
venv symlinked, primed then purge-and-reconverted (a fresh tree verifies checked-hash
**vacuously** — there is nothing there to judge). The verifier's `scanned roots` line
was read to confirm it described this tree and not the main repo.

**Baseline first: 154 passed, 1 skipped, 0 failed.** Every verdict below is against a
green baseline, so `rc == 1` means a passing test now fails rather than a pre-existing
red being recounted.

Each arm asserts it APPLIED — anchor matched exactly once AND the on-disk sha changed
— before its result is read, and restores by `cp` from a backup, never
`git checkout -- <path>`. `rc` 2/4/5 is could-not-run, never a kill.

## The one genuine gap found — CLOSED at `29c61aed`

> **Closed the same evening.** The fix is an **acceptance** case, not another refusal:
> lowering a ceiling makes values in (new, old] newly REFUSED, so only a case asserting
> one is still ACCEPTED can see it. Measured two ways on one mutated state — literal
> bounds (500.0, 1_000_001) give **1 failed** naming the new test; bounds derived from
> the constant (MAX/2, MAX+1) give **16 passed, blind**, because a derived bound moves
> with the constant it is meant to police.


`MAX_ALLOW_BELOW = 1000.0` can be lowered to `10.0` with all 14 endpoint tests still
green. The tested values are 1.4, 1.25, 0.8, 1.9, 1.0, −1 and `"banana"` — **nothing
between 10 and 1000, so the upper clamp is asserted nowhere.** The lower clamp IS
guarded (`MIN_ALLOW_BELOW` reddens a test). Small, real, and cheap to close with one
parametrised case.

## What this does not establish

A pass reports on the mutations someone thought of. Twelve guards broke under ONE
arm each; that is evidence they are not blind, not evidence they are complete. A
second harness aimed at the same files would find different things — that, and not a
matching sha, is the argument for one.
