**Date**: 2026-02-05
**Model**: Ministral-8B-Instruct-2410
**Current Performance**: 85% exact match, 94.4% command accuracy, 88.6% args accuracy
**Status**: **✅ PHASE 1 COMPLETE** — 92.2% exact match (target: 89%)

---

## Executive Summary

Analysis of 8,508 training samples across 32 commands reveals that struggling commands (50-67% accuracy) share common patterns: **semantic ambiguity**, **alias fragmentation**, and **implicit context**.

This plan addresses each root cause through:
1. **Quality improvements** - Better keywords, disambiguation, structured negative examples
2. **Quantity increase** - Double sample size from 400 → 800 per command (~25,600 total samples)

Three implementation phases with measurable targets.

## Root Cause Analysis

### 1. "receptionist" (61.9%) - Alias Fragmentation

**Problem**: Training uses `RECEPTIONIST_TITLE` placeholder replaced with 30+ aliases:
- "Front Desk Clerk", "Administrative Assistant", "Concierge", "Information Clerk", etc.
- The word "receptionist" NEVER appears in training data!

**Evidence**: `src/ephemera/prompts/data/placeholders-receptionist-titles.txt` contains 30+ titles, none say "receptionist"

**Fix**: Add explicit "receptionist" keyword to 50% of training templates

### 2. "weather" (64.7%) - Implicit Context

**Problem**: Many templates omit "weather" keyword entirely:
```
"What will the temperature peak be today in GEOGRAPHIC_LOCATION?"
"Is GEOGRAPHIC_LOCATION expecting any hurricanes soon?"
"Forecast for this weekend in GEOGRAPHIC_LOCATION?"
```

**Evidence**: `src/ephemera/prompts/data/synthetic-data-agent-routing-weather.txt` - only ~30% of templates contain "weather"

**Fix**: Inject "weather" keyword into 50% of examples

### 3. "deep research" (53.3%) & "research to podcast" (50%) - Semantic Overlap

**Problem**: Both commands share "research" keyword:
- "deep research" templates: "research TOPIC thoroughly", "investigate TOPIC in depth"
- "research to podcast" templates: "turn this research into a podcast"

**Evidence**: Templates in `src/cosa/training/xml_coordinator.py:655-704` show overlap

**Fix**: Add contrastive disambiguators:
- deep research: "investigate", "analyze", "thorough", "in-depth study"
- research to podcast: "create audio", "generate podcast", "make episode"

### 4. "none" (61.9%) - Negative Learning Problem

**Problem**: Diverse unrelated requests without structure:
- "mute the TV" (home automation)
- "reboot the router" (IT)
- "open the garage" (home automation)
- General questions with no command intent

**Evidence**: grep of "none" examples shows random, unstructured negative examples

**Fix**: Create structured negative example categories (see Phase 2)

### 5. Sample Imbalance (Contributing Factor)

**Problem**: Unequal distribution
- "research to podcast": 182 samples (57% of 320 target)
- clipboard variants: 160 samples (50% of 320 target)

**Note**: Some 160-sample commands achieve 100% accuracy, so quality > quantity. However, imbalance still hurts.

### Phase 2: Product Name Disambiguation + Validation Improvements (Revised 2026-02-06)

**Goal**: Fix research_to_podcast regression (30%) and google_scholar_clipboard_new_tab (16.67%) through:
- Product name anchors as disambiguation vocabulary
- Template file loading (replace hardcoded templates)
- Disambiguation confirmation loop in routing pipeline
- Stratified validation sampling
- Near-miss examples in "none" category

**Phase 1 Lessons Learned**:
- Strengthening deep research keywords ("investigate", "analyze", "thorough") caused research_to_podcast to regress from 50% → 30%
- The two commands share "research" vocabulary — Phase 1 widened the gap in the wrong direction
- Hardcoded 10 templates per command in xml_coordinator.py were ignored; 50-line template files existed but weren't loaded
- Sample imbalance persists: research_to_podcast had only 181 samples vs 320 for other commands due to fewer document_path placeholders (24 vs 50 research_topics)

#### 2.1 Product Names + Template Disambiguation

Each agentic command gets a distinct brand name plus STT-decompressed variations:

| Command | Product Name | Training Variations |
|---------|-------------|-------------------|
| deep research | **Deep Dive** | "deep dive", "do a deep dive", "deep dive into", "take a deep dive" |
| podcast generator | **PodMaker** | "PodMaker", "pod maker", "podcast maker", "make a podcast about" |
| research to podcast | **Doc-to-Pod** | "Doc-to-Pod", "doc to pod", "document to podcast", "transform document to podcast" |

Three simultaneous disambiguation strategies per template:
1. **Action verbs**: investigate/analyze vs create/produce vs convert/transform
2. **Temporal signals**: "go research" (future) vs "create a podcast" (creation) vs "take **the** research" (existing artifact)
3. **Output anchors**: deep research never says "podcast"; podcast generator = podcast+topic; doc-to-pod = podcast+document

Template files expanded from 50 → 65 templates each.

#### 2.2 Template File Loading (Code Change)

**File**: `src/cosa/training/xml_coordinator.py` (lines 655-704)

Replace 10 hardcoded `template_patterns` per command with file-loaded templates using `du.get_file_as_list()`:
- `synthetic-data-agent-routing-deep-research.txt` → 65 templates
- `synthetic-data-agent-routing-podcast-generator.txt` → 65 templates
- `synthetic-data-agent-routing-research-to-podcast.txt` → 65 templates

#### 2.3 Document Path Placeholder Expansion

**File**: `src/ephemera/prompts/data/placeholders-document-paths.txt`

Expand from 24 → 50 entries to match research_topics count. This eliminates the quantity gap that caused research_to_podcast to have only 181 samples vs 320 for other commands.

#### 2.4 Disambiguation Confirmation Loop (Code Change)

**File**: `src/cosa/rest/todo_fifo_queue.py`

New `_confirm_agentic_routing()` method inserted before `_handle_agentic_command()`. Uses `notify_user_sync()` with `MULTIPLE_CHOICE` response type. Shows product names, offers alternatives, 30s timeout defaults to detected command.

#### 2.5 Google Scholar Clipboard Template Fixes

**Files**: `synthetic-data-search-clipboard-google-scholar-in-{new,current}-tab.txt`

Ensure ALL templates contain "clipboard" + "Google Scholar" + explicit tab direction. Fix templates that drop "Scholar" or use ambiguous "window" instead of "new tab".

#### 2.6 "None" Examples Restructuring

**File**: `src/ephemera/prompts/data/synthetic-data-none-of-the-above.txt`

Restructure 200 examples into 5 categories with comments. Add ~50 near-miss examples (critical for boundary learning): vague commands that resemble valid commands but lack specificity.

#### 2.7 Stratified Validation Sampling (Code Change)

**File**: `src/cosa/training/peft_trainer.py` (line 593)

Replace random `.sample()` with stratified `groupby("command")` sampling for equal representation per command in validation set.
