## Prerequisites

Before testing, ensure:

1. **Lupin server is running** on port 7999:
   ```bash
   ./src/scripts/run-fastapi-lupin.sh
   ```

2. **MCP server is registered** (check with):
   ```bash
   claude mcp list
   # Should show: cosa-voice: ... - ✓ Connected
   ```

   If not registered, run:
   ```bash
   ./src/scripts/install-mcp-server.sh
   # OR manually:
   claude mcp add cosa-voice --transport stdio \
     --env LUPIN_APP_SERVER_URL=http://localhost:7999 \
     --env PYTHONPATH=$LUPIN_ROOT/src \
     -- $LUPIN_ROOT/src/cosa/.venv/bin/python \
     $LUPIN_ROOT/src/lupin_mcp/cosa_voice_mcp.py
   ```

3. **You have the Lupin UI open** in a browser to see notifications:
   ```
   http://localhost:7999/admin/notifications
   ```

## Test Procedure

### Step 1: Start a Fresh Claude Code Session

Open a **new terminal** and navigate to a project directory:

```bash
# For Lupin project (auto-detects as "lupin")
cd /mnt/DATA01/include/www.deepily.ai/projects/lupin
claude

# OR for Planning-is-Prompting (auto-detects as "plan")
cd /mnt/DATA01/include/www.deepily.ai/projects/planning-is-prompting
claude

# OR from /tmp to test "unknown" fallback
cd /tmp
claude
```

### Step 2: Verify MCP Server Loaded

When Claude Code starts, check that the MCP server was detected:
```
# You should see in the startup output something like:
# MCP servers: cosa-voice
```

Or run:
```
/mcp
```

### Step 3: Test `notify()` Tool (Fire-and-Forget)

In Claude Code, say or type:

```
Use the notify tool to say "Hello from MCP test!"
```

**Expected Result**:
- Notification appears in Lupin UI (http://localhost:7999/admin/notifications)
- Sender shows as `claude.code@lupin.deepily.ai` (or appropriate project)
- Claude Code returns immediately (doesn't wait)

### Step 4: Test `converse()` Tool (Blocking)

In Claude Code, say or type:

```
Use the converse tool to ask me "What is your favorite color?"
```

**Expected Result**:
- Notification appears in Lupin UI with response input
- Claude Code WAITS for your response
- After you respond in UI, Claude Code receives your answer

### Step 5: Test `ask_yes_no()` Tool

In Claude Code, say or type:

```
Use ask_yes_no to ask "Should I continue with the test?"
```

**Expected Result**:
- Yes/No prompt appears in Lupin UI
- Returns boolean (true/false) to Claude Code

### Step 6: Test `get_session_info()` Tool

In Claude Code, say or type:

```
Use get_session_info to show the current session details
```

**Expected Result**:
- Returns dict with: project, sender_id, server_url, version
- Project should match auto-detected value based on cwd

## Troubleshooting

### MCP Server Not Loading

1. Check if server is registered:
   ```bash
   claude mcp list
   ```

2. If not registered, add it:
   ```bash
   ./src/scripts/install-mcp-server.sh
   ```

3. Verify Python path is correct:
   ```bash
   ls -la /mnt/DATA01/include/www.deepily.ai/projects/lupin/src/cosa/.venv/bin/python
   ```

4. Test MCP server manually:
   ```bash
   PYTHONPATH="/mnt/DATA01/include/www.deepily.ai/projects/lupin/src" \
   /mnt/DATA01/include/www.deepily.ai/projects/lupin/src/cosa/.venv/bin/python \
   /mnt/DATA01/include/www.deepily.ai/projects/lupin/src/lupin_mcp/cosa_voice_mcp.py
   ```

5. Check ~/.claude.json for MCP config (NOT ~/.claude/settings.json):
   ```bash
   cat ~/.claude.json | grep -A 15 "mcpServers"
   ```

### Notifications Not Appearing

1. Check Lupin server is running:
   ```bash
   curl http://localhost:7999/api/health
   ```

2. Check browser is on notifications page:
   ```
   http://localhost:7999/admin/notifications
   ```

3. Check browser console for WebSocket errors

### "Unknown" Project Warning

If you see the warning:
```
WARNING: PROJECT DETECTION FAILED - USING 'unknown'
```

This means:
- You're running Claude Code from a directory that doesn't match known patterns
- Solution: `cd` to a known project directory before starting `claude`
