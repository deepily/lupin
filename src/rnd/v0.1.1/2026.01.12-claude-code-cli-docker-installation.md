## Problem Statement

The Claude Code Dispatcher (implemented in Session 51) spawns `claude -p "task"` subprocesses to execute bounded tasks. When the FastAPI server runs in Docker, the Claude Code CLI must be available inside the container.

**Previous blocker** (Session 51):
```

```

## Implementation Details

### Files Created

#### 1. `docker/lupin/claude-config/settings.json`

```json
{
  "hasCompletedOnboarding": true,
  "autoUpdaterStatus": "disabled"
}
```

**Purpose**:
- `hasCompletedOnboarding: true` - Skips first-run prompts in headless mode
- `autoUpdaterStatus: disabled` - Containers should be immutable; update by rebuilding image

#### 2. `docker/lupin/claude-config/mcp.json`

```json
{
  "mcpServers": {
    "cosa-voice": {
      "command": "python3",
      "args": [ "/var/lupin/src/lupin_mcp/cosa_voice_mcp.py" ],
      "env": {
        "LUPIN_ROOT": "/var/lupin",
        "LUPIN_APP_SERVER_URL": "http://localhost:7999",
        "MCP_PROJECT": "lupin"
      }
    }
  }
}
```

**Purpose**: Configure cosa-voice MCP server with container-internal paths.

**Key path mappings**:
| Host Path | Container Path |
|-----------|----------------|
| `src/lupin_mcp/cosa_voice_mcp.py` | `/var/lupin/src/lupin_mcp/cosa_voice_mcp.py` |
| Project root | `/var/lupin` |
| FastAPI server | `http://localhost:7999` (same container) |

### Files Modified

#### 3. `docker/lupin/Dockerfile`

Added ~30 lines before final `CMD`:

```dockerfile
# Install Node.js 20.x LTS (required for Claude Code CLI)
RUN curl -fsSL https://deb.nodesource.com/setup_20.x | bash - \
    && apt-get install -y nodejs \
    && rm -rf /var/lib/apt/lists/*

# Install Claude Code CLI globally
RUN npm install -g @anthropic-ai/claude-code

# Create Claude config directory and copy pre-configured settings
RUN mkdir -p /root/.claude

# Copy MCP configuration and settings
COPY docker/lupin/claude-config/settings.json /root/.claude/settings.json
COPY docker/lupin/claude-config/mcp.json /root/.claude/.mcp.json
```

**Image size impact**: ~200MB additional (Node.js + npm + Claude CLI)

## API Key Handling

### Security Principle

**NO API keys are baked into the Docker image.**

Keys are provided at runtime via the `ANTHROPIC_API_KEY` environment variable. Claude Code CLI reads this automatically.

### Local Development (Interactive)

Use prompt-style input to avoid shell history exposure:

```bash
read -s -p "Anthropic API Key: " KEY && \
docker run -it \
  -e ANTHROPIC_API_KEY="$KEY" \
  -p 7999:7999 \
  lupin:latest
```

**Security properties**:
- Key not in shell history (`read -s` suppresses echo)
- Key provided at container start
- Key visible in `docker inspect` (acceptable for dev)

### Alternative: Environment File

```bash
# Create file (add to .gitignore!)
echo "ANTHROPIC_API_KEY=sk-ant-api03-..." > ~/.lupin-secrets.env
chmod 600 ~/.lupin-secrets.env

# Use with docker run
docker run --env-file ~/.lupin-secrets.env -p 7999:7999 lupin:latest
```

## GCP Deployment

### Option A: Environment Variable (Simple, Less Secure)

```bash
gcloud run deploy lupin \
  --image gcr.io/PROJECT_ID/lupin:latest \
  --set-env-vars="ANTHROPIC_API_KEY=sk-ant-api03-..." \
  --set-env-vars="LUPIN_CONFIG_MGR_CLI_ARGS=config_path=/src/conf/lupin-app.ini splainer_path=/src/conf/lupin-app-splainer.ini config_block_id=Lupin:+Testing-GCS"
```

**Downsides**:
- Key visible in Cloud Run console
- Key visible via `gcloud run services describe`
- Key may appear in logs

### Option B: GCP Secret Manager (Recommended for Production)

#### Step 1: Create the Secret

```bash
# Create secret from stdin (key never in shell history)
read -s -p "Anthropic API Key: " KEY && \
echo -n "$KEY" | gcloud secrets create anthropic-api-key --data-file=-

# Or from a file
gcloud secrets create anthropic-api-key --data-file=./api-key.txt
```

#### Step 2: Grant Cloud Run Access

```bash
# Get the service account
SA=$(gcloud run services describe lupin --format='value(spec.template.spec.serviceAccountName)')

# Grant access to the secret
gcloud secrets add-iam-policy-binding anthropic-api-key \
  --member="serviceAccount:$SA" \
  --role="roles/secretmanager.secretAccessor"
```

#### Step 3: Deploy with Secret

```bash
gcloud run deploy lupin \
  --image gcr.io/PROJECT_ID/lupin:latest \
  --set-secrets="ANTHROPIC_API_KEY=anthropic-api-key:latest" \
  --set-env-vars="LUPIN_CONFIG_MGR_CLI_ARGS=config_path=/src/conf/lupin-app.ini splainer_path=/src/conf/lupin-app-splainer.ini config_block_id=Lupin:+Testing-GCS"
```

#### Step 4: Rotate Keys (When Needed)

```bash
# Add new version
echo -n "sk-ant-new-key..." | gcloud secrets versions add anthropic-api-key --data-file=-

# Cloud Run will automatically use "latest" on next cold start
# Or force update:
gcloud run services update lupin --set-secrets="ANTHROPIC_API_KEY=anthropic-api-key:latest"

# After verification, disable old version
gcloud secrets versions disable anthropic-api-key --version=1
```

**Benefits of Secret Manager**:
- Key encrypted at rest and in transit
- Audit logging for access
- Key rotation without redeployment
- Not visible in Cloud Run console

## Troubleshooting

### Issue: "claude: command not found"

**Cause**: Node.js or Claude CLI not installed.

**Solution**: Rebuild image, check build logs for npm errors.

### Issue: MCP server not connecting

**Cause**: Path mismatch between host and container.

**Solution**: Verify `/var/lupin/src/lupin_mcp/cosa_voice_mcp.py` exists in container:
```bash
docker run --rm lupin:latest ls -la /var/lupin/src/lupin_mcp/
```

### Issue: "ANTHROPIC_API_KEY not set"

**Cause**: API key not provided at runtime.

**Solution**: Ensure `-e ANTHROPIC_API_KEY="..."` is passed to `docker run`.

### Issue: cosa-voice can't reach FastAPI

**Cause**: `LUPIN_APP_SERVER_URL` misconfigured.

**Solution**: In container, both Claude CLI and FastAPI run in same network namespace. `localhost:7999` should work. If using Docker Compose with separate containers, use `host.docker.internal` or service name.
