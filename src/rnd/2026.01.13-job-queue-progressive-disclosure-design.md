# Job Queues Progressive Disclosure with User Interaction History

**Status**: Design complete, saved for future implementation
**Session**: 56 (2026.01.13)
**Decision**: User requested design exploration only - implementation deferred

---

## Summary

Enhance the existing "Job Queues" section in the notification UI with:
1. **Progressive disclosure**: Summary counts that expand to show full job cards
2. **Full job cards**: Question, status, timestamps, agent type, runtime stats
3. **User interaction history**: Show notification conversations between job/process and user

## The Core Problem

Jobs and notifications are currently **disconnected**:
- Jobs have `user_id` but no link to notification conversations
- Notifications have `sender_id` (with session identifier) but no link to jobs
- Users can't see "what did Claude say to me about this job?"

## Solution Architecture

```
Job Card (collapsed)
├── Status Emoji (🟡 pending, 🔵 running, ✅ done, ❌ dead)
├── Agent Badge (MATH, CALENDAR, etc.)
├── Question Summary (truncated)
├── Timestamp
└── Expand Toggle (+)

Job Card (expanded)
├── Full Question
├── Response Text
├── Agent Type
├── Runtime Stats
├── Created/Run Dates
└── Notification Conversation Section
    ├── notify() messages sent
    ├── converse() questions asked
    ├── ask_yes_no() / ask_multiple_choice() prompts
    └── User's responses to each
```

### Phase 4: JavaScript Logic
**File:** `src/fastapi_app/static/js/notifications.js`

**New Methods:**
- `toggleQueueCategory(queueName)` - Expand/collapse queue
- `loadQueueJobCards(queueName)` - Fetch and render job cards
- `renderJobCard(job)` - Generate job card HTML
- `toggleJobCard(jobId)` - Expand/collapse individual job
- `loadJobInteractions(jobId)` - Fetch notification history (THE KEY FEATURE)
- `renderInteractionItem(interaction)` - Render notification/response pair

### Phase 5: CSS Styling

### Phase 6: WebSocket Integration
**File:** `src/fastapi_app/static/js/notifications.js`

- Update `handleQueueUpdateWithCards()` to refresh expanded categories

## Key UI Patterns

**Status Indicators:**
- 🟡 TODO (yellow) - Pending
- 🔵 Running (blue, pulsing) - Active
- ✅ Done (green) - Completed
- ❌ Dead (red) - Failed

**Progressive Disclosure:**
1. Queue header shows count badge only
2. Click header → Expand to show job cards (collapsed)
3. Click job card → Expand to show details + interaction section
4. Click "Notification Conversation" → Load and show interaction history

**Interaction History Display:**
```
┌─────────────────────────────────────────┐
│ 📋 task • 14:30 EST                      │
│ Starting analysis of your question...   │
├─────────────────────────────────────────┤
│ ❓ alert • 14:31 EST                     │
│ Should I use the cached result?         │
│ Your response: Yes                       │
└─────────────────────────────────────────┘
```

   - Click "Notification Conversation" → verify interactions load
