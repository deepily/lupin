## 4. The one real gap

```python
# todo_fifo_queue.py:670-676 — the explicit-mode branch
if user_mode and user_mode in AGENTIC_MODE_MAP:
    command = AGENTIC_MODE_MAP[ user_mode ]
    args    = ""          # ← the gap
```

Choosing the mode explicitly skips the router for the **command** — correct, that is the whole
point — but discards its **argument extraction** along with it.

**Consequence**: the explicit path, the one Rick wants to demo, does strictly *more* LLM work than
plain auto-routing and is *more* likely to fall through to interactive prompts, because phi-4 must
re-derive from raw text what the LoRA had already extracted.

### 4a. A secondary quality issue

The fuzzy matcher's auto-resolve is seeded with the **whole utterance** (`expeditor.py:1160`) —
noise words included. *"Generate"*, *"podcast"*, *"based on"* all feed the keyword-overlap
prefilter (`fuzzy_file_prefilter.py`), diluting the real signal (*"KISS protocol document"*) and
raising the odds of a 0-match or 2+-match outcome — which is exactly what forces the
"which document?" prompt Rick wants to skip.

## 6. Phase 1 — recover the extracted arguments

**File**: `src/cosa/rest/todo_fifo_queue.py:670-676`

Consult the router for its **arguments** while keeping the user's explicit **command**:

```python
if user_mode and user_mode in AGENTIC_MODE_MAP:
    command = AGENTIC_MODE_MAP[ user_mode ]
    # The user picked the agent; the router is consulted ONLY for the arguments it
    # already extracts. Its command choice is discarded by construction.
    _, args = self._get_routing_command( salutation_plus_question )
```

**Reused, not built**: `_get_routing_command()` (`todo_fifo_queue.py:945-987`),
`_parse_lora_args()` (`expeditor.py:684-721`), and the registry's `arg_mapping`
(`agent_registry.py:56-62`) which already folds `topic` and `document_path` onto `research`.

### 6a. Why this is safe now and was not this morning

The LoRA maps `topic="the KISS protocol document"` → `research`, so the slot holds a
**description, not a path**. Historically that produced the `FileNotFoundError` in row `ae7fdc9f`.

**Fix B** (`edb40604`, `expeditor.py:390-418`) now detects a slot holding a non-path and re-runs
the fuzzy matcher. **Phase 1 depends on Fix B**; without it, this change would reintroduce the bug
it appears to solve.

### 6b. The guard this needs

The routing LoRA is measurably wrong about *commands* for topic-first sentences — row `fc4ccfe6`,
3/3 mis-picks. Phase 1 keeps only its **arguments**.

A test must prove that separation: force the router to return a **wrong command with good args**,
assert the explicitly-chosen command survives untouched. **Control-first** — confirm the test fails
with a predicted signature before accepting any green.

**Cost**: one line. **Risk**: one extra LoRA call (~200 tokens) on the explicit path.

## 12. Observations logged in passing

Found while tracing; **not** part of this plan, recorded so they are not rediscovered:

1. **`expeditor.py:293` + `:307-308` mutate the module-level registry in place.** `fallback_defaults`
   is taken by reference, not copied, so an `original_question` default leaks into `AGENTIC_AGENTS`
   for the life of the process. Observed, not asserted as a live bug.
2. **The mode selection is sticky and unpersisted.** `user_mode_state` (`todo_fifo_queue.py:181`) is
   an in-memory dict, never cleared after a job, lost on restart. A mode chosen once governs every
   later utterance until explicitly cleared — worth knowing before a live demo.
3. **`args-extraction-*.jsonl`** (3,153 rows under `src/ephemera/prompts/data/jsonl/`) has zero code
   references anywhere in `src/` — dead data from the browser-command era.
