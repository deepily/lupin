## Why deletion, not lazy imports

The obvious cheap fix is to move `import lancedb` inside the `else` branch so the package stops loading. **Rejected** — under a total-removal ruling that is work we would immediately undo, and it leaves a dead path that reads as supported. One wrinkle worth knowing if anyone revisits it: several modules annotate `def _get_schema( self ) -> pa.Schema:`, which evaluates `pa` at class-definition time, so lazy imports would also need `from __future__ import annotations`. Deleting the schema builders removes that problem instead of working around it.
