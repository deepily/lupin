## 🔴 The finding — `isAutoRoute` fails OPEN, and its unit guard is a tautology

```js
export function isAutoRoute( value, payload ) {
    const autoRoute = payload && payload.auto_route;
    if ( !autoRoute || !autoRoute.value ) return true;      // <-- falsy sentinel ⇒ everything is auto-route
    return value === autoRoute.value;
}
```

Fail-open is the right *direction* for a missing payload — posting a bare sentinel to `/api/v2/submit` as though it were a command is worse than routing normally, and the docstring says so. But the guard keys on **truthiness of the sentinel**, so a sentinel that is present and *blank* takes the same branch. Executed:

```
sentinel "__auto_route__"  → picking math is auto-route? false     ✅
sentinel ""                → picking math is auto-route? true      ⚠️ every pick silently auto-routes
```

**The failure is silent and total**: the dropdown still renders, users still pick agents, every request goes to `/api/v2/ask`, and nothing on the page looks different. It is the "a shortened list looks exactly like a working one" failure that `renderAgentSelect`'s own docstring warns about — arriving on the other axis.

**And the unit tier cannot see it**, because the assertion that should is an equality against the same constant:

| assertion | if `AUTO_ROUTE_VALUE` became `""` |
|---|---|
| `assert auto[ "value" ] == AUTO_ROUTE_VALUE` | `"" == ""` → **green** |
| `assert AUTO_ROUTE_VALUE not in REGISTRY` | `"" not in REGISTRY` → **green** |
| `assert auto[ "label" ]` / `assert auto[ "description" ]` | truthiness → would red on those fields |

Both sides move together — the same tautology shape as the `display_name` gate. **The tell is the two lines directly beneath it**: `label` and `description` are checked for truthiness and `value` is not, which reads as an oversight rather than a decision.

**Fix, one line**: `assert auto[ "value" ]` beside the equality.

Tiberius's `BLANK VALUE` arm *would* catch this — but one tier out, on `:8000`, where it costs a scheduled 17-minute run to learn something a unit assertion can state for free.

## Not blocking, for the record

`AUTO_ROUTE_VALUE = "__auto_route__"` is a non-empty constant today, so the fail-open is **latent, not live**. I am reporting it as the missing assertion it is, not as a live defect.
