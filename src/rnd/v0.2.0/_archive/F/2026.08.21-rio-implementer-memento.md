## The five defects, in the order they surfaced

Each one was invisible until the one before it was fixed. That ordering is the lesson.

1. **The three fences** (`5bc22180`, known going in). Auto-resolve, the choice card and
   the present-but-unresolvable rescue were gated on `command == podcast`, so
   presentation's `source` was degraded and a topic phrase killed the job with
   `FileNotFoundError`.

2. **The card spoke podcast to every caller.** `_choose_document_from_matches`
   hardcoded the arg name `research` and *"Which document should I use for the
   podcast?"*. Row `ea184d06` had fixed exactly this on the two `_ask_for_arg`
   surfaces and never reached the card — invisible while podcast was the only agent
   that could see one. **Fixing fence 2 is what exposed it.**

3. **No answer file answered the card.** The filing said "podcast has the entry to
   mirror". It did not — *no* profile answered a document choice card, and podcast had
   carried the same hole since `bd0ce120` without anyone hitting it.

4. **A prose directive is not a contract.** My first entry read *"Pick the first
   document option in the list"*, trusting the matcher prompt to turn it into a label.
   The live run returned that sentence verbatim; the expeditor saw a label the card had
   never offered, refused to guess, and cancelled — the exact failure the entry existed
   to prevent. Replaced with the `__first_option__` sentinel plus
   `option_sentinels.py`, which resolves it against the options that arrive *with* the
   notification.

5. **A near-miss sentinel fell through** (María's catch). `__frist_option__` was
   returned unchanged and would be submitted verbatim — defect 4 under a new name. It
   now raises, and the *shape* `__word__` is recognised even when the token is not,
   which is what makes a typo catchable rather than silent.

## Things a successor would otherwise re-derive the hard way

**`~/.claude/settings.json` is where the test password LIVES.** A by-value credential
scan finds it and it is *not* a leak. Scrubbing it replaces the working password with
`***REDACTED***` and breaks every authenticated test on the box. `--exclude` it, and say
in the report that you did — a silent skip reads as coverage.

**The scrubber cannot see two common shapes**, and this bit me in my own run: the proxy
printed a live JWT into my scratchpad and neither arm caught it. The by-value arm only
sees credentials *this process's environment* holds (a minted token is invisible), and
the by-name arm needs a *quoted* value (`Token : Bearer eyJ…` on a bare line is not).
I redacted that one by hand. Widening the by-name arm to unquoted values risks shredding
ordinary prose, so it is a real decision, not an oversight to tidy up.

**A behaviour already green at HEAD cannot be captured red.** Step 3 of the fences
proposal had already landed in `7c2d0b0b`; I said so instead of manufacturing a red.
Conversely a guard meant to be *green on both sides* must assert the **effective**
behaviour, not the mechanism — my podcast rescue guard first asserted the kwargs and
went red on the pre-fix tree, which would have demanded an impossible red from a guard
whose whole job is to stay green.

**Two existing tests asserted the fences.** I inverted them in place with a note saying
what each used to claim, rather than deleting them — a deleted guard is indistinguishable
from a guard that was never there.

**Podcast's card wording is byte-identical on purpose.** `_document_choice_question`
drops a trailing " generator" so `"Podcast Generator"` yields *"for the podcast"*. Pass
the display name through whole and you silently move a sentence podcast users have always
been read — **and** break `podcast.json`, whose key is that string.
`test_proxy_scripts_answer_the_choice_card.py` derives the question from the code and
demands the file carry it, so the two cannot drift in silence.

**`/api/mock-job/submit` is the right live surface for expeditor work.** It runs the real
expeditor on the running server and then creates a *dry-run* job: real job id, real
terminal state, no deck generated, no LLM spend on content.

## Operational scars

- **Never switch branches in the main checkout.** I did once and knocked it off the chain
  carrying María's four commits plus my own; she had to rescue them to a tag. Use
  `git worktree add`. I worked from `lupin-wt-fences` and `lupin-wt-proxycard` after that.
- **`pgrep -f` / `pkill -f` match your own shell.** A `for p in $(pgrep -f …); kill -9`
  loop killed the very command that was launching the proxy, and a bare `pgrep` check
  reports "still running" when nothing is. Match on a distinctive argument
  (`--profile presentation`), and read a "still running" result sceptically.
- **`grep` exits 2 on one unreadable file.** An early draft of the scrubber treated that
  as failure and threw away every match from an 8 GB scan. Keep the matches, report the
  hole.
- **The store rejects invented receipt ids.** `test_run` must be `ts-<8 hex>` (a `:8000`
  run mints one; the `:7999` unit tier does not) and `qid` must be a UUID. Cite a
  `doc_path` rather than fabricating an id.
