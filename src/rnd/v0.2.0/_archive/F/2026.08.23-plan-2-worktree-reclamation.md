## Phases

### Phase 1 — Bundle everything, delete nothing

```bash
mkdir -p io/worktree-reclamation-2026.08.23/bundles
# for every branch with >0 unique commits:
git bundle create io/worktree-reclamation-2026.08.23/bundles/<branch>.bundle \
    <branch> --not wip-v0.2.0-2026.08.03-present-and-demo
```
Bundles are self-contained: a deleted branch is recoverable from one file. **This is the step
that makes every later deletion reversible**, and it is cheap — the unique commits are few.

Also capture the manifest: `git worktree list --porcelain`, and per worktree the HEAD sha,
dirty/untracked counts, and unique-commit count. That manifest is the receipt that the
classification above was true at deletion time.

### Phase 2 — Tier A removal

```bash
git worktree remove <path>              # refuses if dirty — that refusal is a feature
git worktree prune
git branch -d <branch>                  # -d, never -D: it refuses unmerged branches
```

**Use `-d` and let git veto.** If `git branch -d` objects, the classification was wrong for
that branch and it belongs in Tier B. Never reach for `-D` to make the objection go away.

### Phase 3 — Tier B disposition

Per worktree: merge to the integration branch, or drop with a recorded reason. Then Phase 2's
removal sequence.

### Phase 4 — Tier D judgment

One decision per branch, made from the diff, presented to Rick with a recommendation rather
than decided unilaterally — these are two months of somebody's work and the call is his.

### Phase 5 — Sweep the leftovers

```bash
git worktree prune -v          # clears administrative entries for paths already gone
git remote prune origin
```

## Exit criteria

- Bundles exist for every branch with unique commits, and a scratch clone restores one
- `git worktree list` down from 49 to the working set (main + genuinely live lanes)
- ≥6 GB reclaimed
- Every deletion traceable to a manifest row and a bundle
- No branch deleted with `-D`

## What this plan deliberately does not do

It does not stop the problem recurring. **49 worktrees accumulated because nothing removes
them** — that is Plan 3's subject, and doing this cleanup without Plan 3 buys a few months.
