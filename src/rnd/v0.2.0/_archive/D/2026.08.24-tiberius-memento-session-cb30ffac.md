## Defects to hand to whoever owns them

**The receipt validator rejects legitimate receipts** (Mr. Radio says it has now hit María too).
`task_transition(to_status="done")` refuses `test_run` unless it matches `ts-<8hex>`, and `log_line`
unless it is `<scope>/<rel>:<lineno>`. **A local pytest run has no `ts-` id**, so real measurements
cannot be attached as receipts and end up prose-only in `reason`. `doc_path` also needs the scope
prefix (`lupin/src/rnd/…`, not `src/rnd/…`).

**The git index is shared across this checkout.** `git add <path>` then a bare `git commit` commits
**the whole index**, including whatever a peer staged in that window — that is how `a507f1e5` swept
in three of John's files. **The control is `git commit -- <paths>`**, which ignores the index.
⚠️ It only reaches **tracked** paths, so a NEW file still needs `git add` first. And **never** run
`git reset HEAD` to tidy up — it unstages everyone's work; I did that once.
