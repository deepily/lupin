## Step 1 — put LUPIN_V1_ARM_BASE_URL into the :8000 CONTAINER env

**Why the container env, not the submit `env`:** the submit `env` field is prefix-filtered to
`TFE_ / BFE_ / LUPIN_TEST_` (`src/cosa/agents/test_suite/attestation.py:27`), so
`LUPIN_V1_ARM_BASE_URL` submitted with the job is silently DROPPED. The pytest subprocess
inherits the whole container env (`attestation.py:24-30`), so the var must live on the
container.

Add to the `lupin-rest-test` service in `docker-compose.yml`:
```yaml
    environment:
      - LUPIN_V1_ARM_BASE_URL=http://host.docker.internal:7997
```

**`host.docker.internal` on Linux needs `extra_hosts`.** Unlike Docker Desktop (mac/win),
Linux does not resolve `host.docker.internal` automatically. `lupin-rest-test` ALREADY has it:
```yaml
    extra_hosts:
      - "host.docker.internal:host-gateway"
```
Verify it is still present before relying on the URL. Without it, the container cannot reach
the host's :7997 and the v1-arm readback fails.
