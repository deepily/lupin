## What it does

A second collapsible section immediately below the Task List showing the SAME
rows grouped on `correlation_key` ("epic:&lt;slug&gt;") instead of `owner_persona`,
with a 🗂️ toolbar button. Three sections mirroring the board generator: the
waiting-on-Rick highlight (rows also stay under their epic), the per-epic
groups, and drift.

Built as methods on `NotificationsUI` in `static/js/notifications.js` — **not**
as the `.ts` artifacts the plan's §3 named. Those belong to the multiplexer
bundle; the card Rick actually sees is the classic-script one. María confirmed
and is fixing §3.

**One fetch, one clock**: `refreshTaskList()` renders both panes off a single
composite. There is no second timer and no second fetch against `/api/tasks`.

## Two decisions a successor should not undo without reading this

**Open/closed state is stored as CHOICES, not as a collapsed set** — a plain
map of group key → `isExpanded`, holding only groups the viewer actually
toggled. An epic minted later is ABSENT from the map and therefore takes the
closed default. A stored collapsed-set would have handed every new epic
whatever membership the old set implied, which quietly breaks "collapsed by
default" the first time someone mints an epic.

**The drift group renders even when EMPTY**, as a green all-clear. A section
that vanishes once it is satisfied cannot be told apart from one that failed to
render — and zero-drift is exactly the fact a reader wants confirmed.

## Three findings that outlived the task

**The cache-bust guard earned its keep.** Editing `notifications.js` without
bumping its `?v=` token would have shipped the whole card behind a stale cached
script — the feature simply absent on a page whose HTML says it is there.
Caught by `test_task_body_overlay_cache_bust.py`, not by me.

**The TS-tier crash hazard is `assert.equal`, not `assert.ok`.** Measured with
four isolated probes: a FAILING `assert.equal( <DOM node>, … )` hangs the runner
indefinitely (90s, exit 124, output stops at `TAP version 13`, no `not ok` line
ever emitted) because node's deep-equal diff walks the happy-dom node graph. A
failing `assert.ok( <DOM node> )` fails cleanly, as does the boolean form
`assert.equal( node !== null, … )`. María widened the rule to *never on either
side of an equality assert* to avoid the cost of confirming each case, and
banned the tier pending Rick's ruling — recorded in TODO.md as a pending
decision. **This file's 95 equality arguments are all scalars**, verified by
enumeration rather than by a green run.

**`npm test` is broken repo-wide** and predates this work:
`src/scripts/run-js-tests-capped.sh:14` sets `PROJECT_ROOT` to `<repo>/src`,
then line 16 sources `"$PROJECT_ROOT/src/scripts/lib/jstest-slice.sh"` →
`<repo>/src/src/...`. Fails identically in the main tree. Not fixed —
moratorium. Worth knowing, because a broken front door may be feeding the
impression that the tier itself is unsafe.
