## The pattern is fixable, and the fix is already in the tier

`src/tests/integration/test_cross_container_auth.py` carries this:

```python
def test_at_least_one_container_is_reachable():
    """Sanity: don't let a silent env failure mark every parametrize case as skipped."""
    assert _server_up( DEV_URL ) or _server_up( TEST_URL ), (
        "Neither :7999 (dev) nor :8000 (test) is reachable — nothing to validate."
    )
```

One unconditional test that asserts the precondition instead of skipping on it. That file **cannot**
go fully silent: if every parametrized case skips, this one fails and says why.

It does not appear in the table above — its skip lives in a helper, not a module fixture. **So the
safe pattern already exists in this tier, written by one of us, in the file that needed it least.**
Whatever the ten modules need, it is not invention.

## Second defect: the suite's own headline over-reports skips

The job's `response_text` for `ts-827a54cd` reads **32 skipped**. The pytest summary inside the same
report reads:

```
= 2 failed, 414 passed, 26 skipped, 9 deselected, 6 xfailed, 39 warnings in 2717.05s (0:45:17) =
```

`26 + 6 = 32`. **The `test_suite` reporter folds xfails into the skip count**, so the headline
inflates skips by however many xfails ran and cannot be reconciled against the log.

This matters beyond neatness: **the skip count is the instrument you would watch to catch the first
defect recurring**, and it currently disagrees with pytest.

## Method, and how to re-derive it

Parse every `src/tests/integration/test_*.py` with `ast`; find fixtures declared
`scope="module"` whose body calls `.skip(`; take the transitive closure over module-scoped fixtures
that depend on a quiet one; count test functions taking any quiet fixture as a parameter.

```python
# see the census script in this doc's commit message, or re-derive:
#   quiet  = module-scoped fixtures whose body calls .skip(
#   quiet += module-scoped fixtures depending on a quiet fixture (to fixpoint)
#   hidden = test functions whose params intersect quiet
```

### What this count is NOT

- **Test FUNCTIONS, not items.** Parametrized tests expand, so the item count is higher than 60.
- **"Can go quiet", not "did".** In this run only **2** of the 60 actually skipped.
- **An exposure ceiling, not a defect count.** A fixture is credited as quiet if it calls `skip`; one
  that fails loudly by some other means is not counted, and some of these preconditions are
  legitimately optional (the `verify_claude_cli` family gates on tooling that may be absent by design).
- **One run, one tier.** The unit and cosa tiers were not examined.
