## The caveat that limits the claim

**76% of Flash-Lite's blocks are capitalised-token novelty alone.** Drop that one detector class
and re-run the identical test: **p goes from 2.7e-07 to 0.42**. On numbers, hex ids and paths the
two arms are indistinguishable.

So the honest claim is: **this guard flags Flash-Lite's output more often.** It is *not*
established that Flash-Lite invents more facts. The result stands **operationally** — that guard
is what ships, and a blocked rewrite never reaches anyone.

Found by Tiffany, by re-deriving every number from the payload and then re-running the test with
one class removed. Nobody asked for the second part.

## Found along the way, not in the study's scope

**Eight guards that could not fire.** Every one was correct-looking code with no test that ever
made it raise:

1. Freeze guard aimed at `/var/lupin` — a container path that never matches on the host
2. A test that misstated its own input to go green; its comment admitted it
3. `client.model_name` asserted against the descriptor we passed in — input compared to itself
4. The reachability census excluded itself inside `.claude/worktrees` — clean exactly where new
   work is written
5. `\bcredentials\b` never matched `application_default_credentials.json` — an underscore is a
   word character
6. The v1 baseline store's clean primitive was a **silent no-op** — 69 stale rows would have
   contaminated this very run and produced a plausible median-Δ
7. A content check whose fixture carried a PEM header, so the one shape that still blocked was
   the one being looked at
8. A review condition written against a classifier that was never built

**Two live defects fixed today, both proven on the running tree:**
- The **doc viewer was serving service-account keys** (`service-account.json`, `sa_key.json`,
  `token.json`, `keyfile.json` and more). Now blocked by a *content* detector keyed on
  `type: service_account` / `private_key` — names alone had already failed twice.
- The **context monitor was blind to live seats** whose bridge file was over 12 hours old — two
  seats alive 15 hours were invisible to the very sensor meant to catch them.
