## The one thing to watch, and it is not a 410

`/api/upload-and-transcribe-mp3` is **door 8**, and it **came back out of `RETIRED_DOORS`** on
2026-08-21. `src/cosa/rest/routers/_retired_doors.py` states the reason in its own words: the
route accepts base64 MP3, transcribes with Whisper, runs the result through `MultiModalMunger`,
and queues **only** on the `munger.is_agent()` branch — otherwise it returns the transcription
and queues nothing. `/api/v2/ask` takes text and cannot accept audio, so retiring this route
*"would take browser dictation, the admin snapshot search, and the multiplexer's
insert-at-cursor down with it and offer them nothing."*

**Browser dictation is this plugin.** The single call site is `js/recorder.js:500`.

⇒ If door 8 is ever retired, or its queueing tail is moved onto `ask`, **this line is the whole
blast radius in this repo** — one line, one file. That is a watch item, not a cutover.

## How to re-run this probe

From the repo root, and it takes seconds:

```bash
grep -rn "/api/" . --exclude-dir=node_modules --exclude-dir=.git \
  | grep -oE "/api/[a-zA-Z0-9/_-]+" | sort | uniq -c | sort -rn
```

**A caveat on the instrument, stated rather than buried**: my first pass scanned `js/ scripts/
__mocks__/ *.js` and missed `html/`, `rnd/` and `__tests__/`. The table above is from the second,
repo-wide pass. An exclusion is only as wide as the path the probe ran — so re-run the wide one.
