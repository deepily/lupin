## 2. V1 excision — the steps

**Step 1 — Prove the blast radius before deleting anything.**
`grep -rn 'v1_eval_arm\|paired_eval\|V1_PIN\|LUPIN_PAIRED_N\|LUPIN_V1_ARM\|paired_eval_live'` across `src/`, `docker-compose.yml`, `pytest.ini`, `.claude/`, and `src/scripts/*.sh`. Every hit is either **delete**, **edit**, or **keep** — written down per hit, not decided in the moment. Nothing is deleted until this list is complete and reviewed.

**Step 2 — Relocate what v2 still needs.** Move `make_ws_recv_events` + `WsJobEventListener` + `_TERMINAL_STATES` out of `v1_eval_arm.py` into a v2-owned module (proposed: `src/scripts/ws_job_listener.py`). Repoint `v2_eval.py`. Run `test_v2_terminal_wait.py` + `test_v1_ws_recv_events.py` green **before** anything is deleted — the listener tests move with the code.

**Step 3 — Delete, in one commit per layer** so a bisect can land between them: (a) integration test + marker, (b) unit tests, (c) scripts, (d) compose env + launcher shells.

**Step 4 — The worktree.** `git worktree remove` if registered, else `rm -rf`. Confirm `git worktree list` is clean. ~1 GB back.

**Step 5 — Re-measure.** Full frame, isolated `COVERAGE_FILE`, clean tree, recorded sha. **Do not predict the number** — deleting code *and* its tests moves the ratio in both directions and the sign is not knowable in advance.

**Step 6 — Full pyramid**, in the CLAUDE.md order, before this is called done.

### What could go wrong, and the guard for each

| Risk | Guard |
|---|---|
| v2's terminal wait dies with the listener | Step 2 relocates it first, with its tests green, before any delete |
| An agent class gets deleted as "v1" | §1's KEEP row; the registry import list is the authority |
| A shared guard (`eval_isolation_guard`) goes with the harness | Step 1 classifies every hit; nothing blanket-deleted |
| Compose env removed but container not recreated | `--force-recreate` + `docker exec … printenv` to prove absence |
| The `paired_eval_live` marker removed but still in addopts | `--strict-markers` turns a stale marker into a hard error — the suite tells us |

### 3a. 🔴 The stdlib is in our denominator

`[tool.coverage.run] source` lists only `src/` directories, so `/home/rruiz/.local/share/uv/python/…/lib/python3.13/json/*` has no business being measured. It is there because **a subprocess recorded it and the data was combined in**: `site-packages/a1_coverage.pth` calls `coverage.process_startup()` whenever `COVERAGE_PROCESS_START` (or `_CONFIG`) is set, and a child started that way with no source config measures everything it imports.

- **Find the setter** — `grep -rn 'COVERAGE_PROCESS_START\|COVERAGE_PROCESS_CONFIG' src/` and the runner scripts. Several unit tests spawn pytest subprocesses.
- **Fix at the source**, then belt-and-braces with an `omit` for anything outside `src/`.
- **Guard it**: a test asserting **every file in the coverage report is under `src/`**. This is the class of defect that returns; a percentage cannot see it.
- Worth **~1 point** and it is unambiguously correct — nothing of ours is hidden.

### 3b. `src/lib` — Rick's call, not a coverage task

524 statements at 0% because the package **cannot be imported**: `pyaudio` is not installed; `lupin_client_cmd.py` does a bare `import lupin_client`. Last touched 2026-01-28; every in-tree reference is commented out except `run-lupin-gui.sh`, which invokes `python3.10` in a 3.13 repo.

**A. Delete** — removes 524 from the denominator by removing the *code*, worth ~0.84 pts, zero tests written. **B. Revive** — install PortAudio, fix the import, repoint the launcher, then cover it: a project. **C. Leave** — carry a permanent zero no ramp can close.

**Recommendation: A.** This is not the narrow-the-wording option Rick rejected — nothing is hidden; the lines stop existing.
