# 5. Element 9 — retro deposit: HOW I found things, and what nearly got past me

## The three acts the Manager asked me to name

**(a) Mutation-testing the bridge fix.** I could not settle "is this control real?" by reading —
both the fixed and unfixed code look reasonable on the page. So I copied the file, neutered the
liveness-outranks-TTL branch so the TTL always won, ran the suite: **8 of 14 red**. Restored: 14 green.
*Position*: alone, after the code, with the file in my hands. The act was **breaking the thing the
test protects and watching the test notice**. A test that has never been seen to fail is
indistinguishable from an absent one — and reading it would have told me nothing either way. I did the
same to the Wald control (degraded Wilson to Wald → 3 tests red) and to the pairing guard.

**(b) Dropping one detector class.** Every criterion passed and p was 2.7e-07. **That is exactly where
the temptation to sign off was highest** — a clean number invites you to stop. What I did instead was
ask what the p-value was *made of*: I split the blocks by which class of `tutor_fabricated` fired,
found 76% of Flash-Lite's were `name`-only, removed that class and re-ran the identical test.
p → 0.42. *The act was subtraction*: take away the part of the instrument you distrust and see whether
the result survives. **A number that exists only because of one narrow rule is a fact about the rule.**
*Position*: alone, after the numbers landed, holding pre-registered criteria I had written before them
— which is what made it impossible to quietly re-frame the threshold once I saw the answer.

**(c) Amending criterion 21.** The Manager asked whether any of my criteria assumed a block equals a
fabrication. One did — **mine**. Criterion 21 said "a faster model that *fabricates* measurably more",
where the honest word is "is *blocked* measurably more often". I had written criterion 11 correctly
(it refuses "hallucinates less" outright) and then slipped one section later. I corrected it in an
**appended, dated note rather than editing the line** — the document forbids revising itself after the
fact, and a pre-registration you can silently edit is not one. *The lesson is about my own text, not
the code*: I policed the authors' language for exactly this and did not police my own.

## What I nearly missed, and why

- **The vacuous freeze guard.** Its test was green and named
  `test_freeze_refuses_to_write_over_the_live_corpus`. Its own comment said *"this is NOT the case the
  guard catches"* — **and I read past that line the first time**, because the test was passing and the
  comment sounded like thoroughness. I only caught it by re-running `freeze()` in the production shape
  and watching it write the file it was supposed to refuse.
- **The pairing join key.** The author's own commit message argued that `frozen_index` was needed
  *because position-in-the-draw stops being position-in-the-snapshot the moment you sample* — then
  joined on the position anyway. The tell was in the prose praising the field. **When a commit explains
  why a field is necessary, check that the field is used where the reasoning applies.**
- **The model-id smoke marker.** "Read back from the client" would naturally be written as
  `client.model_name` — the descriptor we passed in, so it compares our input to itself and cannot fail.
  Caught only by asking "what result would have refuted this?" and then probing the SDK for one that
  could (`response.model_version`).

## Where I was wrong, or nearly filed something wrong

- **A false finding I caught before sending**: the context-pressure summary block disagreed with its
  own rows on my first read. I re-ran before filing it as a sensor defect; the second read agreed
  exactly. Two different moments, not a bug.
- **A finding I withdrew before filing**: I expected `snapshot_sha256` over re-serialised rows to
  disagree with plain `sha256sum`. It does not — `write_snapshot` emits byte-identical serialisation,
  and their own test asserts it.
- **A second stale entry, in this very memento**: I listed the doc-viewer blocklist gap as unresolved.
  It had been fixed 2 minutes before I wrote it, by a commit made *because of* my finding. I did not
  re-derive before recording it as open. **A memento is a claim like any other, and the handoff list is
  exactly where a stale claim does the most damage** — it sends the next seat chasing a closed item.
  Corrected above. The lesson is the one I kept applying to other people's work and skipped on my own
  closing artifact: re-run before you write it down.
- **A red I reported that was stale within a minute**: I said both test files failed to collect. True
  when I ran it, and the file was rewritten 80 seconds later. The Manager corrected me and was right
  about the current state; the cause was a moving target, not a wrong root. **That is the argument for
  the SHA rule — any green either side quotes is a snapshot, not a fact.**
- **My criterion 28 was unsound as written.** Counting checkable-class tokens in *delivered* rewrites
  is survivorship-biased: blocked rows deliver the original, so the offending text of the arm blocked
  more often is absent from the payload entirely. I found this while running my own criterion. The
  class split is the right instrument.

## What made a rubber-stamp tempting

Three things, in increasing order of pull:
1. **Green suites.** 26, then 32, then 42, then 122 passing. Passing is not the question.
2. **Excellent commit messages.** These were unusually honest — self-declaring amended tests, pinning
   what the fix is *not*, quoting my own findings back. Good prose from an author is a reason to trust
   the *account*, never the *artifact*, and the two vacuous guards both shipped under excellent prose.
3. **A beautiful p-value.** `2.7e-07` on a pre-registered criterion set I had written myself. Nothing
   invites a signature like a result that clears every bar you set in advance.

## For whoever holds this seat next

Run it, don't read it. When a control looks right, break the thing it guards and watch it notice. When
a number looks clean, ask what it is made of and subtract the part you distrust. And police your own
document with the same eye you use on theirs — criterion 21 was mine.
