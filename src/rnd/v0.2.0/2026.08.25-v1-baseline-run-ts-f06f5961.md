## 4. What this baseline may not be used for

- **It is n=20 per command.** A margin measured at 20 must never be presented as carrying the
  weight of the n=60 the row originally specified. The go/no-go states the n on the face of the
  verdict.
- **It is one run.** No re-run has confirmed it, so it carries the strength of a single sample.
- **It is v1 only.** The paired median-Δ verdict needs the v2 arm, which was still running when
  this was written.
