# The DM condenser invented a filename and put it in the protected path slot

**Related**: `cf1587cd` (attribution), `a0151611` (Rick's path ruling), `68601b65` (path-slot guard), `7a560d94` (Mr Radio's mechanism measurement, folded into the row)

## 1. What happened

Mr Radio's DM to María arrived condensed, carrying the filename **`seven-guards-in-dm.py`**.
No such file exists. The phrase "seven guards" appears nowhere in this project's history —
not in the tree, not in the DM corpus, not in any commit. The condenser manufactured it out
of the prose "seven guards in dm.py" and placed it in the slot Rick ruled protected in
`a0151611`.

A second name, `four-guards-in-dm.py`, was in circulation the same afternoon. **It is not a
second instance.** Traced through the corpus, the earliest hop carrying it — 18:57:14, Mr
Radio → María — already has the string in its *submitted* body. Every later appearance is a
faithful carry of a quote. Counting it would have doubled the rate on pairs the condenser
handled correctly, which is what María said when she filed the row.

**The single true fabrication hop in 14,739 corpus rows is 2026-08-26T19:31:04.**

## 2. The guard was not broken — it was never asked the question

Three shapes were possible: existence-checked, shape-checked, or restore-only. It is
restore-only, **and** the pattern would not have matched anyway.

| Component | What it does | Why the name walked through |
|---|---|---|
| `_restore_dropped_pointers` | puts back a pointer the rewrite **dropped** | one-way by design; it never inspects what the rewrite **invented** |
| `_FAB_PATH` (deleted) | the fabrication check's own path pattern | required a URL scheme or a slash, so a bare `filename.py` was not a path to it |
| `restorable_pointers` | the restore side's recogniser | **does** recognise bare filenames — its own docstring says "a path, URL or bare filename" |

Two patterns for one idea in one module, and the gap between them is the defect. Measured:

```
_FAB_PATH.findall( "seven-guards-in-dm.py" )     -> []
restorable_pointers( "seven-guards-in-dm.py" )   -> ['seven-guards-in-dm.py']
```

## 3. The fix: reuse the recogniser, not a fourth pattern

`_FAB_PATH` is **deleted**. `_fabricated_paths` asks `restorable_pointers` what looks like a
pointer, and asks the original whether it vouches for it.

**Membership is a substring test, not a set difference** — the exact mirror of the restore
side, which asks `p not in rewritten`. That is the part that costs mail if you get it wrong:
`restorable_pointers` lifts the *whole* path out of the original, so a token-set difference
reads a rewrite abbreviating `src/cosa/rest/todo_fifo_queue.py` to `todo_fifo_queue.py` as an
invention. It is not one.

Three relaxations, each earned by reading the flagged pairs rather than assumed:

| Relaxation | Why | Share of the 26 in-sample hits |
|---|---|---|
| case-insensitive | "Registry.py" opening a sentence is `registry.py` | 11 |
| elided line suffix | the sender wrote "executor.py:106, :108"; the rewrite expands it | 22 token-flags |
| product-name allow-list | "the Node.js test" cites nothing | 1 |

**🔴 A list and not a shape rule (María's ruling).** The shape rule reached for first — "a
slashless token whose stem is a single capitalised word is a product name" — **fails open**:
`README.md`, `CLAUDE.md` and `TODO.md` all fit it, this fleet cites them constantly, and a
fabricated `CLAUDE.md` would have walked straight through. A list **fails closed**: a token
it has never been told about is still checked. The list is an INI key,
`dm tutor fabrication guard product names`, read per send, so extending it the day someone is
wrongly refused costs an edit and a bounce rather than a deploy.

**A dial that selects a recogniser, on María's ruling.** `dm tutor path fabrication guard
mode`, read per send. `pointer` (default) asks the restore side's recogniser; any other value
rolls back to the pre-2026-08-26 pattern. **There is no "off" value**, and that is her point
in her words: *"a kill switch whose OFF position is weaker than the state before the change is
not a rollback, it is a downgrade."* My first cut had exactly that defect — off meant the
check was not called, which would have stopped refusing the invented SLASHED paths the old
pattern did catch. Both branches are pinned by tests so the rollback branch cannot rot. **And a typo cannot roll
it back either**: only the exact word `legacy` selects the old pattern; anything unrecognised
resolves to `pointer` and prints what it saw. "Anything that is not `pointer` means legacy"
was my first cut of that too, and it would have let `Pointr` in the ini weaken the fleet's
guard silently.

**A sentence-final full stop hid a fabricated path**, and an existing test caught it before
this shipped: `"See src/cosa/rest/routers/dm.py."` tokenises with the trailing dot, so it no
longer ends in a code extension and the recogniser's own path-signal test discards it.
Terminal punctuation is now lifted off the word before the recogniser reads it. This is the
family of the trailing-lookahead lesson already recorded on `_RESCOPE_QUANTITY`.

## 4. Measurement

### 4.1 In-sample — the variant comparison

Denominator: the **4,489** corpus rows whose `tutor_outcome == "rewritten"` — every rewrite
that passed all shipped guards and was delivered. Any new flag on that set is mail this
change would newly refuse.

| Variant | Flagged | Denominator | Rate | Catches the specimen |
|---|---|---|---|---|
| A — current `_FAB_PATH` set difference | 0 | 4,489 | 0.00% | no |
| B — `restorable_pointers` token-set difference | 47 | 4,489 | 1.05% | yes |
| C — `restorable_pointers` + substring test | 26 | 4,489 | 0.58% | yes |
| D — C + the three relaxations (**shipped**) | 3 | **4,492** | 0.07% | yes |

⚠️ **D's denominator is not A/B/C's**, and the column says so rather than letting one number
stand for four runs: D was measured later in the same session and the corpus is live traffic
(see §4.3). The three extra rows do not change any rate to two significant figures, but a
table that silently mixes denominators is the kind of thing this row exists to catch.

C is a strict subset of B: the 21 pairs B flags and C does not are all abbreviations of a
path the sender did write.

⚠️ **These four numbers are IN-SAMPLE and none of them is the cost.** The relaxations were
derived by reading C's 26 hits and then scored on the same data. María caught this; the
figure below is the one that answers the question.

### 4.3 Does lifting terminal punctuation CREATE flags?

María's question, and the right one to ask of any change that edits text before a
recogniser reads it: strip a full stop off `0.58.` and you could manufacture a
filename-shaped token out of a decimal. Measured over the whole corpus, shipped rule with
the lift versus the same rule with the lift disabled:

| | flagged |
|---|---|
| with the lift | 3 |
| without the lift | 0 |
| **tokens the lift introduces** | **3 — and all three are the genuine finds**, including the specimen |

Zero decimals, zero junk. The lift is doing only what it was added for.

⚠️ **THE DENOMINATOR MOVED WHILE I WAS WORKING: 4,489 → 4,492.** The corpus is live DM
traffic and this session is writing some of it. Any rate here is against the corpus as of
its stated size, not a frozen set.

## 5. What I did not check

- **Whether the model can be stopped from fabricating at all.** This is a refuser, not a
  cure. The condenser still invents; the message is now delivered in the sender's own words
  instead.
- **The `four-guards-in-dm.py` hop upstream of the corpus.** The string is present in the
  earliest corpus body that carries it, so wherever it was first generated is outside the
  window this corpus covers.
- **Whether an invented LINE NUMBER should also be refused.** The corpus shows real
  instances — `flow.py:291` where the sender wrote `:263` and `:327`, `v2_eval.py:574` where
  the sender wrote `:431`. The relaxations here deliberately let those through, because the
  row is about a fabricated filename and widening into citation fidelity is a separate
  argument with its own false-positive cost. **Named, not fixed.**
- ~~Coverage of the changed lines~~ — **now measured, and it found something.** `dm.py` is
  at **90%, 55 uncovered, none of them mine**; the file's percentage is unchanged by this
  change. It took two attempts: the first was refused by a guard I did not know existed
  (`COVERAGE_FILE` unset would have written the shared repo-root `.coverage` that every
  session erases at startup — row `aa41fa66`, where a tier reported 96.59% with ~28,000
  statements quietly out of the denominator). The second run named two uncovered lines of my
  own — the rollback branch's `except`, at 1094-1095. The live check's fail-soft was tested;
  its rollback twin was not, which is an untested path that only runs on the day somebody
  reaches for it. Tested rather than pragma'd, and the count moved 57 → 55.

## 8. A pattern, not two fixes — punctuation adjacent to a token

María named this and she is right to: this component has now been bitten **three times** by
the same shape, and each was found by a different route.

| Where | What one adjacent character did |
|---|---|
| `is_bare_row_id` (row `68601b65`) | `#fb9faba7` defeated an anchored pattern, so a bare hash arrived as its own line |
| `_RESCOPE_QUANTITY` | a trailing-`.` exclusion made every sentence-FINAL quantity invisible while every mid-sentence one was seen |
| `_fabricated_paths` (this row) | a sentence-final full stop rode into the token, cost it its extension, and hid a fabricated path |

The shape: **a pattern is written against a token seen mid-sentence, and prose puts
punctuation against it.** Each fix was local, and the third arrived anyway. Worth a shared
normalisation the next time one of these is touched — named here rather than done, because
`pointer_tokens` is also the body of the whole-line structure rule and moving it moves the
sentence counter (its own docstring says so).
