## 0. Scope — compression only

**This document covers one thing: rewriting DMs in transit to make them shorter and plainer, without corrupting what they carry.** Rick, 2026-08-06: *"the plan should focus on compression only. We're not focusing on anything else. This is the fourth arm that we're looking at right now."*

Existing arms, for context only: **A** = feedback-only grading, **B** = returning errors (live now, `effective_arm: "rejecting"`).

> 🗄️ A public-shaming variant was modelled the same evening and is **out of scope here**. Summary for the record: it is net negative below ~33% deterrence, and compression beats it by 3.2× even against a perfect 100% deterrence rate. Not pursued.

**The two goals, in priority order:**
1. **Length** — fewer tokens on the wire and in every recipient's context.
2. **Quality** — strip hedging, ceremony, and coined vocabulary. Rick's framing: *"raise the signal to noise ratio and reduce the jargon and other distracting bullshit that accumulates over longer spans of interaction."*

## 3. The freeze protocol

Rick's formulation, 2026-08-06: *"Are you literally detecting/regexing for the strings you want to preserve, pulling them out, substituting a substitution flag that the LLM is then ordered to leave intact? That way all the LLM has to do is respect the placeholder's boundaries and the placeholder names themselves — which is also testable."*

Yes. Exactly that. **Extract → placehold → compress → restore.**

```
original    "The leak is at judge.py:572, shipped in d256e25a."
extracted    L00 = "judge.py:572"   L01 = "d256e25a"
sent         "The leak is at ⟦L00⟧, shipped in ⟦L01⟧."
returned     "Leak at ⟦L00⟧, fixed in ⟦L01⟧."
restored     "Leak at judge.py:572, fixed in d256e25a."
```

### 🔑 Why this changes the problem class

The model is no longer asked to **transcribe** a high-entropy string — a task at which every model fails at some rate. It is asked to **not touch an opaque token**. Those are different difficulties, and the second is both far easier and, critically, **cheaply verifiable without comparing content**.

### Placeholder design — the details that decide whether it works

| Property | Choice | Why |
|---|---|---|
| Delimiters | `⟦` `⟧` (U+27E6/27E7) | Effectively absent from natural prose and from our DMs. **Not** `<>` (reads as HTML, models rewrite it), **not** `{}` (reads as a template slot to fill), **not** backticks (models strip or reflow them) |
| Body | `L` + zero-padded ordinal | Short, low-entropy, no semantic content to "improve" |
| Numbering | **Sequential from 00** | Free error detection — a gap proves omission without any content check |
| Repeats | Same literal → **same** placeholder | Multiplicity becomes checkable, and repeated shas stay consistent |
| Length | 5–6 chars | Token-cheap; the placeholder must not cost more than the literal it replaces |

### Extraction tiers

Measured cost of freezing, by tier:

| Tier | Contents | % of characters frozen | Compressible remainder |
|---|---|---|---|
| **HARD** | paths, `file:line`, shas, UUIDs, backticked spans, `:PORT`, ISO dates | **4.4%** | 96% |
| **HARD + SOFT** | + double-quoted spans, numbers-with-units, CONST names | **10.8%** | 89% |

Even in the 250+ band, HARD+SOFT freezes only **14.4%**. ⇒ **Freezing does not eat the compression budget.** This was the main worry going in and the measurement retires it.

**Recommend HARD+SOFT.** False positives are nearly free — freezing something that didn't need it costs a few tokens and loses no meaning. False negatives are the expensive direction. Tune for recall.

### 🔴 Fail closed, never fail silent

If restoration cannot be completed exactly — a placeholder missing, duplicated, or mangled — **deliver the original uncompressed.** Log it, count it, move on.

This makes the system's worst case *"no compression today"* rather than *"a corrupted line number someone acts on."* Rick has accepted a non-zero error rate (§4), which is what makes a fail-closed path affordable: it is allowed to fire occasionally.

## 4. Test methodology — structural fidelity

**Rick's accepted error budget**, 2026-08-06: *"I'm fine with the following error rates: 99.9% → 6.1/day, 99.99% → 0.6/day, because I'm not seeking perfection and humans are far worse at this kind of accuracy."*

Recorded because it sets the bar: **99.9% per-literal fidelity is a pass.** Perfection is not the target, and a fail-closed path covers the remainder.

### Corpus-primary, and why

**The corpus generates its own ground truth.** Extract literals from the original with the regex tier, then assert each survives. No human labeling, real text, unlimited scale. Synthetic sets are for adversarial cases the corpus does not naturally contain — not for the measurement itself.

### The six checks

| # | Check | Catches |
|---|---|---|
| **1** | **Set equality** — output placeholder set == input set | omission, hallucination |
| **2** | **Multiplicity** — each placeholder appears the same number of times | dropped repeats |
| **3** | **Boundary integrity** — no split, no absorbed neighbours (`⟦L07⟧s` ≠ `⟦L07⟧`), no altered delimiters | the most likely model error |
| **4** | **No invented placeholders** — nothing placeholder-shaped that wasn't sent | confabulation |
| **5** | **Order** — sequence largely monotonic; inversions raise a **relocation** warning | see below |
| **6** | **Round-trip byte equality** after restoration | the guarantee; trivially true if 1–4 hold |

**Checks 1–4 are the substance. Check 6 is the point**: fidelity stops being statistical and becomes structural.

### The failure taxonomy, and the one that matters

| Mode | Severity |
|---|---|
| Omission | detectable by diff; fail-closed handles it |
| Hallucination | rare, detectable |
| **🔴 Mutation** | with placeholders, this is *reduced to* "the model altered an opaque token" — visible, not silent. **This is the entire benefit of the protocol** |
| **🔴 Relocation** | placeholder survives perfectly but attaches to the wrong claim |

**Relocation is the honest limit of the method.** *"The bug is at `⟦L00⟧`"* becoming *"the fix is at `⟦L00⟧`"* passes every structural check and is still wrong. Check 5 flags reordering as a proxy, but only a semantic check or a human catches the real thing.

⇒ **A sampled human read stays in the loop** — say 20 DMs/week — scored for meaning preservation, not bytes. Do not let the structural suite's green imply semantic safety.

### Synthetic adversarial set (~50 cases)

For what the corpus won't produce naturally:

- Two shas differing by one character in the same message
- A line number inside a quoted string, and the same digits as a prose quantity
- A path that reads like prose (`src/for/example.py`)
- A literal at the very start and very end of the body
- The same literal repeated with one instance deliberately different
- A body that is *entirely* literals with almost no prose
- Text that already contains `⟦` `⟧` (injection against the placeholder scheme itself)
- Nested/adjacent literals (a sha inside a backticked span inside a quote)

### 🔴 Negative control — non-negotiable

**Run the whole suite with freezing disabled and confirm it goes red.** A literal-preservation suite that has never failed is not evidence; it is an untested assertion. Delete the guard, watch it break, restore it. This repo has shipped four unfalsifiable checks in one session before (2026-07-22) — that is why this line is here.

| Axis | Metric |
|---|---|

| **Cost** | $/M blended, against the ≈$1.70 ceiling |
| **Latency** | p50 / p99 — this sits in the DM delivery path |

**Report as a Pareto frontier, not a single winner.** A model preserving everything while compressing 10% is useless; one compressing 60% while breaking a placeholder per 100 DMs is disqualified regardless of price.

⚠️ **Fidelity is a gate, not a score.** Rank on compression and cost *among* models that clear 99.9%. Do not let a cheap model trade fidelity for ratio.

## 6. Risks

**1. The covertness is load-bearing and fragile.** If agents infer compression is happening, the rational response is to **pad** so meaning survives the squeeze — inverting the effect. One session noticing "my DM arrived different" is enough. See §8 Q1.

**2. Placeholder injection.** A DM that already contains `⟦L00⟧` — deliberately or by accident — could collide with the scheme. Escape on the way in; the adversarial set tests it.

**3. Latency in the delivery path.** A DM now waits on an API round-trip. Needs a timeout with fail-open-to-original, and a p99 budget set before build.

**4. Quality is assumed until measured.** The claim that compression raises signal-to-noise rather than just shortening is a hypothesis. The judge already stamps `directness` and `tone` per DM, so it is measurable from day one — measure it, don't assert it.

## 8. Open questions for Rick

1. **Covert or disclosed?** Covert is what makes any behavioral effect possible, but §6.1 says the secret is fragile and inverts when broken. Disclosed, this is honest transport compression with no behavioral claim — and still banks 32,028 tokens/day.
2. **HARD or HARD+SOFT extraction?** I recommend HARD+SOFT: 10.8% frozen versus 4.4%, and false positives cost almost nothing while false negatives are the expensive direction.

## 9. For the expert reviewer

Specific things worth a second opinion, rather than a general read:

1. **Placeholder format.** `⟦L00⟧` — is there a tokenizer or a model family where this splits badly, gets normalized, or gets "corrected"? A format that survives one vendor and not another would be an expensive discovery in phase 3.
2. **Extraction recall.** §1's taxonomy came from our own corpus. What immutable classes are missing that a fresh eye would name? Version strings, semver ranges, regex literals, base64 blobs, timestamps with offsets?
3. **Is fail-closed the right default**, or should a failed restore retry once at temperature 0 before giving up?
4. **Relocation** (§4) — is there a cheap automated proxy better than order-monotonicity? This is the failure the structural suite cannot see.
5. **Is the leaderboard's fidelity gate at 99.9% set in the right place**, given Rick has explicitly accepted ~6 corruptions/day as tolerable and a fail-closed path catches structural failures before delivery?
