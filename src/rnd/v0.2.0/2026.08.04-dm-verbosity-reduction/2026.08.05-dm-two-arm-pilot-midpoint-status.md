## 0. Words or tokens — the answer, first, because two different units are in play

This is not pedantry: the effect and the cost are measured in **different units**, and quoting one figure as if it were the other is how a 24-point number gets compared to a 246-point number.

| Quantity | Unit | Where it comes from |
|---|---|---|
| **Effect size** (co-primary A/B: −24.8, −25.4) | **words** | `excess_words( w ) = max( w − 60, 0 )` — words past a 60-word target (`analyze_arms.py:137`) |
| **The gate itself** (what refuses a draft) | **words** | `REJECT_THRESHOLD = 150` words (`analyze_arms.py:47`) |
| **Bunching band** \[140, 149\] | **words** | same threshold, one band below it |
| **All cost figures** (246.4, 194.4, 164.5, 264.6) | **estimated tokens** | `est_tokens = len( body.body ) // 4` (`dm.py:870`) |

⚠️ **`est_tokens` is chars ÷ 4, not a tokenizer count.** The field's own comment says so: *"chars/4 ESTIMATE — no tokenizer before Tuesday."* Every token number in this document and its predecessor inherits that approximation. It is fine for comparing two arms measured the same way; it is **not** a billing figure, and it should never be quoted as one.

For reference, in the same corpus: blind averages **157.4 words** / **246.4 est-tokens** per attempt. The ratio is ~1.57 est-tokens per word, which is what you would expect from chars÷4 on English prose — a sanity check, not a validation.

## 4. The result that actually changed: break-even

The predecessor established the structure — a refusal can never pay for itself on the message it refuses (the draft is sunk; extra cost = the rewrite), so the arm can only win through shorter *future* first attempts. Re-running that arithmetic on the fuller corpus:

| | Tuesday only | **Tue + Wed (now)** |
|---|---|---|
| rewrite est-tokens (the unrecoverable extra) | 16,115 | **46,421** |
| first-try messages available to repay it | 352 | **612** |
| each must be shorter by | 45.8 tok = **22.4%** | 75.9 tok = **30.8%** |
| **observed** first-try gap vs blind | 54.7 tok = **26.8%** | 58.6 tok = **23.8%** |
| verdict | **above** break-even (~3% net saving) | **below** break-even by 7 points |

The observed gap barely moved (26.8% → 23.8%). **The requirement moved** — from 22.4% to 30.8% — because rewrite spend grew faster than the pool of first tries available to repay it: rewrites nearly tripled (16.1k → 46.4k) while first tries not quite doubled (352 → 612).

### The bounds no longer bracket zero

| Credit given to the arm for its shorter first tries | Tuesday | **Tue + Wed** |
|---|---|---|
| all of it | **−3,147** tok *(saving)* | **+10,558** tok *(loss)* |
| none of it | +16,115 tok *(loss)* | **+46,421** tok *(loss)* |

Tuesday's headline was *"a 4.4-point error in the causal assumption flips the sign."* **It no longer flips.** With Wednesday's partial data folded in, the arm loses tokens at both ends of the credit range — the optimistic bound has crossed from saving to loss. The causal question (is the gap caused by the arm, or by different senders in different hours?) still determines *how much* it loses, no longer *whether*.

## 5. What this does and does not license

**Does not license a kill decision.** Wednesday is half-collected, both co-primaries are underpowered, and the break-even calculation is arithmetic on an incomplete corpus, not a test. The 7 missing slots are the difference between a direction and a result.

**Does license lowering expectations about the headline.** The 33.2% published saving is the number most likely to be quoted onward, and it is the one that the retry has already spent. Report both figures side by side — the recommendation from the predecessor doc stands, and today's data strengthens it: the two numbers have moved *apart* (22% → 33% published; 11% → 7.4% all-in loss), so quoting either alone is now more misleading than it was Tuesday, not less.

**Open and unowned**: whether the 5-hour gap is a quiet fleet or a stopped writer (§1). Cheap to settle, and it decides whether tonight's remaining slots will fill on their own.
