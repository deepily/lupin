## The correction this table exists to carry

Pass A's inventory (commit `3311a7d4`) said *"every kwarg on those six is one of exactly four
shapes."* **That was mine and it was wrong.** `_build_swe_team` has three kwargs in two shapes
I never named, and one of them cannot be expressed as table data without changing behaviour.

**Five of the six are expressible as data. `_build_swe_team` is not.** Finding it now is the
point of pass A having run first — the alternative was discovering it tomorrow, halfway
through the refactor, with a table already written around the wrong assumption.

---

## The shapes, as measured

| shape | form | notes |
|---|---|---|
| `CONTEXT` | the bare parameter | `user_id`, `user_email`, `session_id`, `debug`, `verbose` — **identical in all six**, never varies |
| `LITERAL` | a constant | one instance in the whole set: `no_confirm=True` |
| `GET` | `args_dict.get( k )` | default `None` |
| `GET+DEF` | `args_dict.get( k, default )` | literal default |
| `PARSE` | `_parse_*( args_dict.get( k ) )` | `_parse_boolean` · `_parse_optional_int` · `_parse_optional_float` |
| `GET-OR-NONE` | `args_dict.get( k ) or None` | normalises `""` to `None`; only `bug_fix_expediter` |
| 🔴 `ALT-KEY` | `args_dict.get( k1, args_dict.get( k2, default ) )` | **swe_team only** |
| 🔴 `PARSE-OR-DEF` | `_parse_*( args_dict.get( k ) ) or default` | **swe_team only** |

⚠️ **The kwarg name is not always the args key.** `presentation_generator` takes `source_path`
from `"source"`. Every row below names the key explicitly for that reason — a table that
assumed `kwarg == key` would silently read the wrong argument.

## 🔴 `_build_swe_team` — the one that is not data

| kwarg | source, verbatim |
|---|---|
| `task` | `args_dict.get( 'task', args_dict.get( 'prompt', '' ) )` |
| `dry_run_phases` | `_parse_optional_int( args_dict.get( 'dry_run_phases' ) ) or 10` |
| `dry_run_delay` | `_parse_optional_float( args_dict.get( 'dry_run_delay' ) ) or 1.5` |
| *(the other 11)* | ordinary `CONTEXT` / `GET` / `PARSE` — those are fine |

**`task` reads a fallback key.** Try `task`, else `prompt`, else `""`. Nothing else in the six
reads two keys for one kwarg.

**`PARSE-OR-DEF` is not `GET+DEF`, and the difference is behavioural** — measured, not argued:

```
caller passes dry_run_phases=0  ->  GET+DEF row gives 0    the code gives 10
caller passes dry_run_delay=0   ->  GET+DEF row gives 0    the code gives 1.5
```

`or` is falsy-triggered; a `get` default is missing-triggered. Writing swe_team as a
`(key, parser, default)` row **silently turns a caller's explicit 0 into 10**. That is a
behaviour change under a refactor's name, which is what Rick's ruling 2 forbids.

⇒ **Recommendation, accepted by Mr Radio 21:30: swe_team keeps a callable override.** Adding
`ALT-KEY` and `PARSE-OR-DEF` to the table to carry one builder is a table growing to fit a
single row — it makes the table harder to read than the body it replaces, and buys nothing for
the other five.

That puts the real floor at **five of eleven as data, six needing code** — pass A's inventory
said six and four. **The floor moved because a measurement corrected a claim, which is the
whole reason the claim was written down.**

## The equivalence proof, pre-built

Whoever does the refactor does not need to invent this. It snapshots every kwarg the *current*
bodies pass, by spying on the constructor — so the golden data comes from running the real code
rather than from reading it:

```python
import importlib
from unittest.mock import patch
import cosa.rest.agentic_job_factory as F

SIX = {
 "_build_deep_research":            ( "cosa.agents.deep_research.job",                 "DeepResearchJob"               ),
 "_build_claude_code":              ( "cosa.agents.claude_code.job",                   "ClaudeCodeJob"                 ),
 "_build_presentation_generator":   ( "cosa.agents.presentation_generator.job",        "PresentationGeneratorJob"      ),
 "_build_research_to_presentation": ( "cosa.agents.deep_research_to_presentation.job", "DeepResearchToPresentationJob" ),
 "_build_swe_team":                 ( "cosa.agents.swe_team.job",                      "SweTeamJob"                    ),
 "_build_bug_fix_expediter":        ( "cosa.agents.bug_fix_expediter.job",             "BugFixExpediterJob"            ),
}

def capture( builder_name, args_dict ):
    """Every kwarg the builder hands its constructor. Patch the class in ITS OWN module —
    the builders' imports are deferred INSIDE the function, so patching the factory's
    namespace catches nothing."""
    module_path, class_name = SIX[ builder_name ]
    module, seen = importlib.import_module( module_path ), {}
    class Spy:
        def __init__( self, **kwargs ): seen.update( kwargs )
    with patch.object( module, class_name, Spy ):
        with patch.object( F, "_finish", lambda job, *a, **k: job ):
            getattr( F, builder_name )( "cmd", args_dict, "u1", "e@x.com", "s1", False, True, None, False, None )
    return seen
```

**Two traps it already avoids**, both of which cost me a wrong first attempt:
1. **Patch the class in its own module, not in the factory's namespace.** The job-class imports
   are deferred *inside* each builder, so the name is resolved at call time from the source
   module — a patch on `F.DeepResearchJob` is never consulted.
2. **`_finish` must be stubbed**, or the capture stamps queue directives and drags the whole
   queue path into a test that is only asking what the constructor received.

**Argument cases the proof must carry** — an all-absent case alone would miss most of the table:

| case | what it proves |
|---|---|
| `{}` | every default, and that `GET` yields `None` rather than `KeyError` |
| every key populated | every key name, including `source` → `source_path` |
| **falsy values (`0`, `""`, `False`)** | the `PARSE-OR-DEF` / `GET+DEF` split above — **the case that catches swe_team** |
| `{ "prompt": ... }` with no `task` | swe_team's fallback key |

⚠️ **A test that asserts the object constructs is not this proof.** The comparison is
kwarg-by-kwarg against the captured dict, with any excluded field named individually and given
a reason — the same discipline pass A's equivalence suite used.
