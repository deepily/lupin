## 2. The one lesson, and it repeated seven times

> **Every failure in this run was a real check aimed at the wrong property.**

Not sloppiness. In each case someone ran something true, and the thing they measured was
beside the thing the outcome turned on.

| # | Who | The check that ran | The property it missed |
|---|---|---|---|
| 1 | Rio, Rachel, Tiberius, me | Four independent green gates on the slide-count chain | All measured **seams**; none measured the **running system**. Krishna submitted one real job through the front door and it did the wrong thing immediately. |
| 2 | Tiberius | A probe that measured four values on the live path | **Cancelled before the outline** — the one value the demo turned on. |
| 3 | Me | "No truncation notify fired, so the response was complete" | The detector **fails open**. Both worlds are silent. Mr Radio caught it; fix is `cecc18c7`. |
| 4 | Krishna | Summed `timing_seconds` across 32 slides → 93.5 min | The field was a **constant 180s**. María measured the real script (6,891 words ≈ 53 min) and saved twelve slides. |
| 5 | Me | `git commit --only <paths>` with a verified-clean index | `--only` **ignores the index** and commits the working tree of those paths. Swept a peer's whole feature into my commit. |
| 6 | Me | "Class membership — adjacent, safe to leave" | The deciding property was **hunk separability**. `git diff -U0` would have shown a 61-line pure insertion with nothing to cut on. Cost a second removal round. |
| 7 | Me | Handed Krishna a known-reds exclusion list | The victim set **moves with collection order** — the list hides real failures rather than discounting noise. |

**And it did not stop with the run.** On 2026-08-06, one day after writing this lesson down,
I filed that an allowlist cited a board row that "never existed" — derived from a
`task_query` that **hides terminal rows by default**. Both cited rows existed. Tiberius
caught it four minutes after being spawned. Amended on row `c9d3ddcb`.

> **The lesson does not transfer by being written.** I authored the sentence and then
> committed the eighth instance of it inside 24 hours. What would have caught it is not more
> resolve — it is the mechanical habit: **before trusting a check, say out loud what property
> it measures, and ask whether that is the property the decision turns on.**

## 3. What actually cracked the hard one

**P0 `5b3b6af9` — six hours, closed by one question in ninety seconds.**

Symptom: an explicit `target_slide_count: 40` produced a 60-slide outline live, while every
static read of the code showed 40. Five eliminations, all with receipts, all correct.

Cause: Rio's revert-to-verify deleted the `_apply_job_overrides` copy **on the main tree** at
~12:54–12:56. The `lupin-rest-test` container restarted at 12:55:12 inside that window.
Python imports once and reload is off, so that process served copy-less bytes for its entire
life. Krishna submitted 31 seconds later. Rio restored the file before anyone read it, so
every subsequent static read showed the correct code.

**Five green gates and one live red were both correct.** Nobody's measurement was wrong; the
tree they measured and the tree the server booted from were different trees.

What closed it: a **direct yes/no question to Rio about his own revert**. He answered against
his own interest immediately. Banked as `reference_revert_on_main_tree_poisons_the_live_server`.

⇒ **When several careful people disagree with one observation, stop adding measurements and
ask what tree the running process booted from.**

## 4. The deck failure — an hour spent on the wrong hypothesis

The crew chased **truncation** for an hour. It was not truncation.

A single all-at-once elaboration above ~20 slides returns **well-formed JSON containing zero
slides**, reporting `stop_reason: "end_turn"`. Nothing is cut off; the model simply declines
to produce at that size. Fixed by chunking large decks up front
(`LARGE_DECK_CHUNK_THRESHOLD = 20`, commit `087b7ff0`).

**`_elaborate_chunked` had never executed in production** — dead code behind an unreachable
gate. Its first real run built the 32-slide deck.

⇒ Two hazards worth carrying: a **safety net nobody has ever fired** is not a safety net, and
a **well-formed empty result** is the hardest failure to see, because every structural check
passes.

## 7. What the spec got wrong

- **Verification step 3 (a dry run) was vapor.** The dry-run path returns before the
  orchestrator import; `yaml_path` is a string never written; `artifacts["slide_count"] = 0`.
  **A dry run cannot speak to slide count even in principle** — and my implementer cited it
  as a receipt. Retracted mid-run.
- **"Additive-only: unset knob reproduces today's behaviour exactly" was never achievable.**
  Removing a contradiction that biased the outcome necessarily changes the outcome. §6.6
  proved it: duration 20 now yields 20 slides, not 17. Nobody noticed the spec promised
  something impossible until the measurement came back.

⇒ **An acceptance criterion that cannot be true should fail review before the build starts.**
Two reviewers and I read that line; none of us tested it against the change it described.
