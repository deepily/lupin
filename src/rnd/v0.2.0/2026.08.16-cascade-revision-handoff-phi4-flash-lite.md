### §3.F — Statistics, limits, sequencing

**Findings closed** (foundational — the study could have reported noise):
- **§3.1 added the missing inferential statistics — SCIPY-ONLY, no statsmodels dependency.** The plan
  built the discordant 2×2 and never tested it. Now: **McNemar's EXACT test**
  (`scipy.stats.binomtest(min(b,c), b+c, 0.5)`) and a **Wilson score interval** computed **closed-form
  from `scipy.stats.norm`** per plan §3.1.2 — NOT via `statsmodels`. Plus a **PRE-STATED discordant
  floor** (arithmetic bound 6: `b+c=5` → p=0.0625 cannot clear; `b+c=6` → 0.03125).
  - ⚠️ **`statsmodels` is named in §3.1 ONLY as the trap to avoid** — `statsmodels.proportion_confint`
    **defaults to the forbidden Wald interval**. It is **neither installed nor pinned in any
    requirements file** (verified: absent from the interpreter and from `src/cosa/requirements.txt`).
    **Do NOT add it** — a crew that reaches for `statsmodels` hits `ModuleNotFoundError`; the
    closed-form scipy Wilson has no such dependency. If statsmodels is ever added it must be pinned AND
    the Wald-default caveat re-stated at the call site.
  - **scipy version**: pinned `scipy==1.15.2` at `src/cosa/requirements.txt:210`; the interpreter
    measured here was **1.17.1** (two minor versions off the pin). `binomtest` and `norm.ppf` predate
    both, so the reproduced tables (to the digit) are not version-sensitive — but the run must **record
    which scipy it used** so a stats result is never argued over with the library version unknown.
- **§3.2: three permanent production changes now carry owner + teardown** (new client class + INI
  keys + paid Vertex inference), plus the frozen snapshot as a fourth persistent artifact with a
  named retention.
