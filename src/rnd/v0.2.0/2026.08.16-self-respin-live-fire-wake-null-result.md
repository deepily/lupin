## 1. Why the fix never reached the seat

`self_respin` executes inside each session's own long-lived MCP process (`src/lupin_mcp/cosa_voice_mcp.py`), which imports its modules once at process start. **A commit to `src/lupin_mcp/` is inert for every seat already running.** Bouncing `:7999` does nothing for it — the dev server is a different process entirely.

Proof this seat ran the old build, from the marker it wrote:

```json
"pre_clear_status" : "unknown",
"pre_clear_pct"    : null
```

The source in the tree at fire time **refuses to fire at all** unless that field reads `over_budget` (`self_respin_core.py:408`). It fired anyway and recorded `"unknown"`. Both facts cannot come from one build — so the loaded module predates the guard. (Mr Radio reached this same inference independently from the same field.) The seat *was* genuinely over budget, 57.6–57.8%, read minutes earlier; that reading never reached the marker because the code that records it did not exist in the loaded module.

|---|---|---|
| 10 | **10** | **0** |

Anyone firing `self_respin` right now gets the pre-fix verb. **A re-run of the wake test needs a freshly spawned seat** — no existing one qualifies.

This is the third instance of the same error in one day, and it is written in the firing seat's own memento (§4.3): I bounced `:7999` to make a `reap_memento` fix live, and Tiffany pointed out that `reap_memento` also runs in the per-session MCP process. I wrote the lesson down and then fired an experiment hours later against stale code without checking. **Writing the lesson down did not prevent the repeat.**

## 2. The oracle defect: `RETURNED` cannot distinguish a wake from a hello

`_is_confirmed_return` requires a turn whose timestamp is at/after `fired_at`, and nothing more:

```python
last_turn_ts = now - datetime.timedelta( seconds=age )
return last_turn_ts >= fired_at
```

There is no upper bound and no attribution. `classify_marker` also checks the confirmed-return path **before** the deadline check, so a late turn still counts.

Concretely, on a build where `pre_clear_status` is correctly `over_budget`, **this exact run would have classified `RETURNED`** — credited to the verb — when in truth a peer's DM woke the seat **83 seconds past the deadline**. The seat never woke itself at all.

That is a false green, and it is the one that matters: the observer exists to catch a seat that fires and does not come back. A fleet where peers routinely DM each other will manufacture `RETURNED` verdicts for seats that never woke.

**Suggested fix**: the returning turn must be *attributable to the wake injection*, not merely later than `fired_at`. Cheapest discriminator — have the injector write a wake receipt (or stamp the marker) when it actually types, and require that receipt for `RETURNED`. Absent a receipt, a fresh turn inside the window is at best `RETURNED_UNATTRIBUTED`.

### Companion defect (archived — Mr Radio has this one)

A marker carrying `pre_clear_status: "unknown"` can **never** classify `RETURNED`, because `_is_confirmed_return` rejects it on the first line. Run against the live classifier with a maximally favourable synthetic record — same `session_id`, same `tmux_session`, `within_budget`, a 30-second-old turn:

```

```

The seat is demonstrably alive, at low context, on the same seat, writing this document — and the oracle reports it dead. A false alarm is the benign direction, but the marker will alarm indefinitely until removed.

## 4. The clear/wake observation, for the record

Because the loaded build had no wake text to type, this is the expected behaviour of the *old* verb, not a defect in the new one.

## 6. The reusable part

Two checks were available before firing and neither was run: *is the code I am about to exercise the code that is loaded?* and *does the marker this writes contain the field the oracle requires?* Both are one command. The first would have cancelled the experiment; the second would have predicted the `DEAD_NO_RETURN` verdict before the clear.

A near-identical lesson was already written in the memento of the seat that fired. **The remedy is not a better note — it is a guard in the verb**: refuse to fire when the loaded module's build cannot produce a marker the oracle can grade. Prefer the detector to the reminder.
