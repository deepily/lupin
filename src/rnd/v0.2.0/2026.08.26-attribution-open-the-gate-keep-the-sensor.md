## 2. The proposal — four parts, in dependency order

### Part A — Open the gate, keep the sensor  ⬅ the substance

`_apply_dm_tutor` currently returns `body_text, meta` on an attribution failure: the rewrite is
discarded and the sender's full original is delivered. That is the 53–58% refusal.

**Change**: deliver the rewrite. Keep computing the predicate and keep recording it — the corpus
row already carries `tutor_outcome`, so the measurement survives as an outcome value with no new
plumbing. The trend line Krishna built (`attribution_blocked` per day) keeps working, because it
reads the recorded outcome, not the refusal.

| | now | proposed |
|---|---|---|
| Predicate computed | yes | yes |
| Recorded to corpus | yes | yes |
| Trend line still readable | yes | **yes** |
| Rewrite delivered | **no — 53–58% refused** | **yes** |
| Token cost | full original on 53–58% of sends | condensed, as designed |

⚠️ **This is a real loss and it should be stated, not buried.** Today a reader who would have been
misled instead receives the sender's unambiguous original. Under this proposal they receive the
condensed body plus a warning (Part B) and must check for themselves. On the evidence — three
caught incidents in three weeks, zero surviving errors — that trade is defensible. On evidence
nobody has yet gathered, it might not be. Part D is how we would find out.

### Part B — The 3-4 words

Current, one line, appended to every rewrite (dm.py:714):

```
This DM was condensed in transit. Need more detail? Ask the sender one question
```

Proposed, and **only on the messages where the attribution check actually fired**:

```
This DM was condensed in transit. Check who did what. Need more detail? Ask the sender one question
```

**Four words: "Check who did what."**

Why those four. Cheech's near-miss was precisely a *who* error — *"what got squeezed out was
agency and tense"* — and he was one step from calling a scope violation on the wrong person. Four
words in the right place would have stopped it. "Be careful" alone does not say careful of what.

🔴 **Conditional, not blanket — this is the part I want to argue for.** Appending the warning to
every condensed DM makes it wallpaper: it appears on the 47% that are perfectly attributable, gets
tuned out, and is then absent-by-habit exactly where it matters. We already compute the predicate.
Using it to *flag* the specific messages instead of *refusing* them is the whole point of "track
it while leaving the gate open" — the sensor stops being a tax and becomes a signal to the one
reader who needs it.

**Mechanically safe**, checked before proposing:

- The structure exemption in `sentences.py:198` is `^\s*This DM was condensed in transit\..*$` —
  **prefix-anchored with `.*$`**, so appending after `transit.` still matches and the tutor will
  not start rewriting its own footer. The docstring's warning ("it must count as structure") is
  honoured by construction rather than by care.
- Three places hardcode the literal string and must move with it:
  `test_dm_tutor_sentences.py:150`, `test_dm_tutor_fabricated_path.py:48` (`_SPECIMEN_DELIVERED`),
  and the pin at `test_dm_tutor_send_path.py:612` (which exists precisely to catch this drift).
- The notice names no number and carries no measurement, so the unpublished-trigger property is
  unaffected. A *second* variant does not change that.

### Part C — Restore the dropped name, the way we already restore the dropped path

`_restore_dropped_pointers` (dm.py:855) lifts paths out of the model's reach and puts them back.
Its own docstring cites the same Aug-13 Cheech DM and states the argument that applies here
verbatim: *"Asking the model to reproduce a path verbatim is a request that fails silently and
only in the cases that matter… a model is the wrong instrument for exactness."*

Cheech asked for **"dates, shas and actor names"**. Only paths were built. Thirteen days.

**Scope I would actually build**: the 1,561 single-name drops (65.3%). One name lost is
unambiguous — there is exactly one thing to put back.

🔴 **I am NOT claiming this works, and here is why I will not.** A regex says 98.3% of those
bodies contain a pronoun or a passive the name *could* fill. **That number is a weak instrument
and I decline to lean on it** — "contains a passive" is not "the name belongs in that slot." A
path survives losing the sentence around it because it still says where to look; a name does not,
and a name appended on a trailing line is exactly the nonsense `a0151611` banned:
*"a standalone nonsensical out-of-context hash has no place there."*

**So this part ships behind a hand-labelled feasibility read, not before it.** If a human cannot
place the name correctly in a sample, the mechanism does not exist and Part C dies — which is a
fine outcome, because Parts A and B do not depend on it.

### Part D — Ship the prompt lines

Independent of everything above. Proven on 220 bodies: subject-loss 50.0% → 38.6%, 48 fixed
against 23 broken, McNemar **p = 0.004**. Not a cost lever (five points) and never was — it is a
correctness change and stands on that alone.
