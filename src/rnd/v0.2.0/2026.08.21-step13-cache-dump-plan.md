## The command (not run)

Per database, inside a transaction, counts printed either side:

```bash
docker exec lupin-postgres psql -U lupin_dev -d <DB> -c \
  "BEGIN; \
   SELECT 'before', (SELECT count(*) FROM solution_snapshots), (SELECT count(*) FROM canonical_synonyms); \
   DELETE FROM solution_snapshots; \
   DELETE FROM canonical_synonyms; \
   SELECT 'after',  (SELECT count(*) FROM solution_snapshots), (SELECT count(*) FROM canonical_synonyms); \
   COMMIT;"
```

`DELETE` and not `TRUNCATE`: truncate takes an ACCESS EXCLUSIVE lock and, on a live `:7999`, blocks
every reader; delete at 3 and 65 rows costs nothing.

**Backup first**, so a wrong-scope dump is recoverable:
```bash
docker exec lupin-postgres pg_dump -U lupin_dev -d <DB> \
  -t solution_snapshots -t canonical_synonyms > <scratchpad>/cache-backup-<DB>-<ts>.sql
```
