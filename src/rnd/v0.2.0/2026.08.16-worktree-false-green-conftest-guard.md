# Worktree false-green: the conftest `sys.path[0]` trap and a narrow auto-guard

**Date**: 2026-08-16
**Author**: Rio ⚡ (Implementer), under Rachel 🕊️
**Store row**: a9f87d29 · **Related**: bab95a0a (diagnosis filed 18h prior), 59134ab7 (the run that exposed it)
**Status**: design — recommendation ratified (Rachel), implementation deferred to a reviewed change on shared `conftest.py`

---

## 1. The failure, in one sentence

A test run started from inside a git **worktree** can silently import the **main-tree** module instead of the worktree's copy, so a revert-to-verify or a RED check reports **GREEN** because it tested the other tree — a false green that looks exactly like success and arrives through the front door.

## 2. Mechanism

`src/tests/conftest.py` (lines ~13–25) resolves the project root from the `LUPIN_ROOT` env var and does:

```python
lupin_root = os.environ.get( "LUPIN_ROOT" )   # errors loudly if unset
src_path   = os.path.join( lupin_root, "src" )
if src_path not in sys.path:
    sys.path.insert( 0, src_path )            # sys.path[0] — wins over cwd
```

Under pytest, `sys.path[0]` decides which `lupin_mcp` / `cosa` package gets imported. When a reviewer runs pytest **from a worktree** but `LUPIN_ROOT` still points at the **main tree**, `$LUPIN_ROOT/src` sits ahead of the worktree's own `src`, so `import lupin_mcp.reap_memento` loads the **main-tree** file — the one that already carries the fix. The worktree's unfixed copy is never imported, and the "RED check" comes back green.

**Proven 2026-08-16** (row 59134ab7 / reap_memento): a worktree RED check ran **44 green** until `LUPIN_ROOT` was pointed at the worktree, at which point it flipped to the truth — **8 RED / 36 green**. A `reap_memento.__file__` print confirmed the main-tree path was loaded in the green run.

## 3. The precise condition (why the first walk-back was wrong)

The trap is **NOT** "LUPIN_ROOT unset" — `conftest.py` already raises `RuntimeError` when it is unset, so no run reaches collection without it. The real condition is:

> **LUPIN_ROOT is SET and points at a DIFFERENT tree than the one whose test file is being collected.**

Naming the failure that cannot happen (unset) while the real one (set-wrong-tree) goes unguarded is itself part of how this recurred.

## 4. Blast-radius table (why a blanket assertion is unsafe, a narrow one is not)

| Run shape | `LUPIN_ROOT` | Guard fires? | Correct? |
|---|---|---|---|
| main-tree test file | main tree | no | ✅ the common live-seat case — must stay silent |
| worktree test file | same worktree | no | ✅ correct worktree setup — must stay silent |
| worktree test file | a **different** tree | **YES** | ✅ the trap — the only run whose green is a lie |

A *blanket* `assert __file__ under cwd` in conftest would fire for every session's every run and break live seats mid-flight. The narrow predicate fires **only** in row 3.

## 5. Candidates considered

1. **Opt-in env flag / marker** (`LUPIN_ASSERT_TREE=1`) — off by default, a reviewer switches it on. Zero blast radius, but **requires someone to remember** — the exact recall-under-pressure failure that let this recur.
2. **Standalone helper** a reviewer calls explicitly at the top of a worktree check — same opt-in weakness.
3. **`pytest.ini` addopts gated on a marker env** — same opt-in principle.
4. **Doc-only checklist line** — weakest; this is the option that *already failed* (the trap recurred with docs in place and a row filed).
5. **Narrow auto-guard (RECOMMENDED)** — see §6.

## 6. Recommendation — candidate 5, the narrow auto-guard

At collection, assert **only when BOTH** hold:
(a) the test file being collected lives under a **git worktree**, AND
(b) `LUPIN_ROOT` resolves to a **different tree** than that worktree.

Fail loud with a message that names both trees. It **auto-fires in the trap and is silent everywhere else** (§4), so — unlike the opt-in options — it needs no one to remember, which is the property that actually addresses recall-under-pressure.

### Implementation sketch (in `conftest.py`, after the existing `LUPIN_ROOT` bootstrap)

```python
def _enclosing_worktree( path ):
    """The git worktree root enclosing `path`, or None if `path` is not in a worktree
    (a plain `.git` DIR = main clone; a `.git` FILE = a linked worktree)."""
    d = os.path.dirname( os.path.abspath( path ) )
    while True:
        dotgit = os.path.join( d, ".git" )
        if os.path.isfile( dotgit ):   return d          # linked worktree
        if os.path.isdir( dotgit ):    return None        # main clone
        parent = os.path.dirname( d )
        if parent == d:                return None
        d = parent

def pytest_collectstart( collector ):
    fspath = str( getattr( collector, "path", "" ) or getattr( collector, "fspath", "" ) )
    if not fspath.endswith( ".py" ):
        return
    wt = _enclosing_worktree( fspath )
    if wt is None:
        return                                            # main-tree file → silent
    root = os.path.realpath( os.environ[ "LUPIN_ROOT" ] )
    if os.path.realpath( wt ) != root:
        raise RuntimeError(
            f"worktree/LUPIN_ROOT mismatch: collecting {fspath} under worktree {wt}, "
            f"but LUPIN_ROOT={root} — pytest will import the LUPIN_ROOT tree's module, "
            f"not this worktree's. Set LUPIN_ROOT={wt} before trusting red or green."
        )
```

(Exact hook — `pytest_collectstart` vs a `sys.path`-time check — to be settled during implementation; the predicate is the invariant.)

### Test plan

- **Trap fires**: a fake collector whose path is under worktree A + `LUPIN_ROOT=B` → raises, message names both.
- **Same-tree silent**: path under A + `LUPIN_ROOT=A` → no raise.
- **Main-tree silent**: path under a `.git`-dir clone → no raise.
- **Non-`.py` skipped**: a data-file collector → no raise.
- 100% lines/branches on the new code; a must-fail control that predicts the mismatch message before breaking it.

## 7. Why this is a row, not a same-day edit

`conftest.py` is shared across three live crews; a change there deserves review rather than landing mid-afternoon on one seat's say-so. The recommendation is ratified; the edit is deferred to a reviewed change. This doc is the design that change implements.

## 8. The durable lesson

The fix was **already filed on bab95a0a 18 hours earlier and three seats re-derived it anyway** — so the gap was **board-recall under pressure, not documentation**. A doc (candidate 4) is the option that already failed. The control that survives forgetting is the **auto-guard** (candidate 5) plus the operator habit: **assert `<module>.__file__` resolves to the worktree before trusting any red or green.**
