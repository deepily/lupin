## What `--resume-from-merged` Does

The `--resume-from-merged` flag lets you skip the expensive training phases (1-3) and jump directly to post-training validation and quantization using an already-merged adapter directory.

### Phase Map

| Phase | Description | Normal Run | Resume Mode |
|-------|-------------|:----------:|:-----------:|
| 1 | Pre-training validation | Yes | **SKIPPED** |
| 2 | LoRA fine-tuning | Yes | **SKIPPED** |
| 3 | Adapter merge with base model | Yes | **SKIPPED** |
| 4 | Post-training validation (vLLM) | Yes | Yes |
| 5 | Quantization (4-bit, 8-bit, both) | Yes | Yes |
| 5b | Post-quantization validation (vLLM) | Yes | Yes |

When resuming, the trainer:
1. Validates the merged adapter directory exists
2. Sets `self.merged_adapter_dir` to the provided path
3. Starts vLLM server pointing at the merged model
4. Runs post-training validation (if `--post-training-stats`)
5. Quantizes to specified bit widths (if `--quantize-bits`)
6. Runs post-quantization validation (if `--post-quantization-stats`)

The PEFT trainer manages its own vLLM server lifecycle — `_start_vllm_server()` / `_stop_vllm_server()` in `try/finally` blocks handle setup and teardown for each validation phase. No external vLLM instance needed.

## The Incantation

### With `sudo` (nuclear kill button enabled)

The `--nuclear-kill-button` flag requires root privileges to send SIGKILL to vLLM processes if they don't terminate cleanly.

```bash
sudo --preserve-env=HF_HOME,NCCL_P2P_DISABLE,NCCL_IB_DISABLE,LUPIN_ROOT,LUPIN_CONFIG_MGR_CLI_ARGS,DEEPILY_PROJECTS_DIR \
    env "PATH=$PATH" \
    python -m cosa.training.peft_trainer \
        --model mistralai/Ministral-8B-Instruct-2410 \
        --model-name Ministral-8B-Instruct-2410 \
        --test-train-path $LUPIN_ROOT/src/ephemera/prompts/data \
        --lora-dir /mnt/DATA01/include/www.deepily.ai/projects/models/Ministral-8B-Instruct-2410.lora \
        --resume-from-merged /mnt/DATA01/include/www.deepily.ai/projects/models/Ministral-8B-Instruct-2410.lora/merged-on-2026-02-14-at-02-24 \
        --post-training-stats \
        --post-quantization-stats \
        --nuclear-kill-button \
        --validation-sample-size 500 \
        --quantize-bits both
```

### Without `sudo` (no nuclear kill button)

python -m cosa.training.peft_trainer \

## Flag Reference

| Flag | Value | Purpose |
|------|-------|---------|
| `--model` | `mistralai/Ministral-8B-Instruct-2410` | HuggingFace model ID (used for tokenizer) |
| `--model-name` | `Ministral-8B-Instruct-2410` | Short name for config lookups |
| `--test-train-path` | `$LUPIN_ROOT/src/ephemera/prompts/data` | Training/test data directory |
| `--lora-dir` | `.../Ministral-8B-Instruct-2410.lora` | LoRA output directory |
| `--resume-from-merged` | `.../merged-on-2026-02-14-at-02-24` | **Skip phases 1-3**, use this merged model |
| `--post-training-stats` | (flag) | Run Phase 4 validation against merged model |
| `--post-quantization-stats` | (flag) | Run Phase 5b validation against quantized models |
| `--nuclear-kill-button` | (flag) | Allow SIGKILL on stuck vLLM (requires sudo) |
| `--validation-sample-size` | `500` | Number of samples per command for validation |
| `--quantize-bits` | `both` | Quantize to both 4-bit and 8-bit |
