## Executive Summary

### Objective
Implement administrative user management interface allowing administrators to:
- View all users in the system
- Manage user roles (assign/remove admin privileges)
- Control user account status (activate/deactivate)
- Reset user passwords administratively

### Why This Matters
- **Security**: Admins need ability to lock compromised accounts immediately
- **User Support**: Password reset capability without email dependency
- **Role Management**: Dynamic role assignment without database access
- **Compliance**: Centralized user administration for audit trails

### Out of Scope (Future Phases)
- ❌ Audit logs viewer (Priority 2)
- ❌ System settings editor (Priority 3)
- ❌ Bulk user operations
- ❌ User creation via admin panel (registration exists)
- ❌ Advanced analytics

- **Generate temporary password** - Crypto-secure random password

## API Specification

### GET /admin/users

**Description**: List all users with pagination and filtering

**Authorization**: `Depends(require_admin)`

**Query Parameters:**
```typescript
{
  limit?: number = 100,       // Max results per page
  offset?: number = 0,        // Pagination offset
  search?: string = '',       // Search email (LIKE '%search%')
  role?: 'admin' | 'user',   // Filter by role
  status?: 'active' | 'inactive'  // Filter by status
}
```

**Response 200:**
```json
{
  "users": [
    {
      "id": "uuid",
      "email": "user@example.com",
      "roles": ["user", "admin"],
      "email_verified": true,
      "is_active": true,
      "created_at": "2025-10-04T12:00:00",
      "last_login_at": "2025-10-04T14:30:00"
    }
  ],
  "total": 42,
  "limit": 100,
  "offset": 0
}
```

**Response 403**: Not admin

### PUT /admin/users/{user_id}/roles

**Description**: Update user roles

**Authorization**: `Depends(require_admin)`

**Path Parameters:**
- `user_id` (string, required) - User UUID

**Request Body:**
```json

}
```

**Validation Rules:**
- Roles must be valid: ["admin", "user"]

- Array must not be empty

**Response 200:**

**Response 400**: Invalid roles or self-modification
**Response 404**: User not found
**Response 403**: Not admin

## Security Requirements

### Authorization Layer

**All endpoints MUST:**
```python
@router.get("/admin/users")
async def list_users(user: Dict = Depends(require_admin)):
    # Only reachable if user has 'admin' role
```

**Protection Rules:**
1. All `/admin/*` routes require admin role
2. Non-admin requests return 403 Forbidden
3. Unauthenticated requests return 401 Unauthorized

### Self-Protection Rules

**Prevent admin foot-guns:**
```python
# Cannot remove own admin role
if target_user_id == admin_user_id and "admin" not in new_roles:
    raise HTTPException(400, "Cannot remove your own admin role")

# Cannot deactivate self
if target_user_id == admin_user_id and not is_active:
    raise HTTPException(400, "Cannot deactivate your own account")
```

### Audit Trail Requirements

**All admin actions MUST be logged:**
```python
log_auth_event(
    event_type  = "admin_role_update",
    user_id     = admin_user_id,
    email       = admin_email,
    ip_address  = request.client.host,
    details     = f"Updated roles for {target_email}: {old_roles} → {new_roles}",
    success     = True
)
```

**Event Types:**
- `admin_role_update` - Role changes
- `admin_status_update` - Status toggle
- `admin_password_reset` - Password resets
- `admin_user_view` - User detail access (optional)

### Password Security

**Admin password reset:**
```python
import secrets
import string

def generate_temp_password(length=16):
    alphabet = string.ascii_letters + string.digits + "!@#$%^&*"
    password = ''.join(secrets.choice(alphabet) for _ in range(length))
    # Validate meets strength requirements
    return password
```

**Requirements:**
- Crypto-secure randomness (`secrets` module)
- 16+ characters minimum
- Must pass existing password strength validator
- Never logged or stored in plain text
- Returned once in API response

### Session Invalidation

**When user is deactivated:**
- Immediately revoke all refresh tokens
- Access tokens remain valid until expiration (max 30 min)
- WebSocket connections terminated
- Audit log entry created

**Implementation:**
```python
# In toggle_user_status() when deactivating:
from cosa.rest.refresh_token_service import revoke_all_user_tokens

if not is_active:
    revoke_all_user_tokens(target_user_id)
```

```python
    })

    # Old password no longer works
```

## Appendix

### Database Queries

**List users with filters:**
```sql
SELECT id, email, roles, email_verified, is_active, created_at, last_login_at
FROM users
WHERE
  (email LIKE '%' || ? || '%' OR ? IS NULL)  -- search
  AND (roles LIKE '%' || ? || '%' OR ? IS NULL)  -- role filter
  AND (is_active = ? OR ? IS NULL)  -- status filter
ORDER BY created_at DESC
LIMIT ? OFFSET ?
```

**Get user with extra stats:**
```sql
SELECT
  u.*,
  (SELECT COUNT(*) FROM auth_audit_log WHERE user_id = u.id) as audit_count,
  (SELECT COUNT(*) FROM failed_login_attempts WHERE email = u.email) as failed_login_count
FROM users u
WHERE u.id = ?
```

### API Error Responses

**Standard Error Format:**
```json
{
  "detail": "Human-readable error message"
}
```

**Common Errors:**
- 400 Bad Request - Invalid input, self-modification attempt
- 401 Unauthorized - No token or invalid token
- 403 Forbidden - Valid token but insufficient permissions
- 404 Not Found - User ID doesn't exist
- 500 Internal Server Error - Database or server error
