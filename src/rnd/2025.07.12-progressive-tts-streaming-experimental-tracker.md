## Executive Summary

### Problem Identified
Current HybridTTS implementation does "collect-then-play" instead of true progressive streaming, defeating the purpose of ElevenLabs streaming TTS. Audio chunks are collected and only played after `audio_complete` message, resulting in 2-3 second delays even with streaming endpoints.

### Root Cause Analysis
- **Backend**: ✅ Correctly streaming chunks (ElevenLabs → FastAPI → WebSocket)
- **Frontend**: ❌ `playCollectedAudio()` in `hybrid-tts.js` waits for all chunks before playback
- **Line 149**: Only triggers playback on `audio_complete` message
- **Result**: No latency benefit from streaming implementation

### Solution Approach
Build experimental Firefox-first UI that demonstrates true progressive streaming by playing audio chunks immediately as they arrive, bypassing the current collect-then-play pattern.

### Phase 2: Progressive Audio Implementation Strategies

**Strategy A: Web Audio API (Firefox-Optimized)**
```javascript
// Firefox-optimized Web Audio API approach
const audioContext = new (window.AudioContext || window.webkitAudioContext)();
let playbackTime = audioContext.currentTime;

websocket.onmessage = async (event) => {
    if (event.data instanceof Blob) {
        const arrayBuffer = await event.data.arrayBuffer();
        const audioBuffer = await audioContext.decodeAudioData(arrayBuffer);
        
        const source = audioContext.createBufferSource();
        source.buffer = audioBuffer;
        source.connect(audioContext.destination);
        
        // Play immediately at next available time slot
        source.start(playbackTime);
        playbackTime += audioBuffer.duration;
    }
};
```

**Strategy B: Multiple Audio Elements (Fallback)**
```javascript
// Multiple <audio> elements for seamless playback
let audioElementIndex = 0;
const audioElements = [audio1, audio2, audio3]; // Pool for Firefox

websocket.onmessage = (event) => {
    if (event.data instanceof Blob) {
        const audio = audioElements[audioElementIndex % audioElements.length];
        audio.src = URL.createObjectURL(event.data);
        
        // Firefox-specific autoplay handling
        const playPromise = audio.play();
        if (playPromise !== undefined) {
            playPromise.catch(error => {
                console.log('Firefox autoplay prevented:', error);
                // Handle Firefox autoplay policy
            });
        }
        audioElementIndex++;
    }
};
```
