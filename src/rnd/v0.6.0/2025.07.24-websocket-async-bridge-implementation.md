## Executive Summary

This document provides a comprehensive implementation plan to fix critical WebSocket issues in the Lupin/COSA system. The plan addresses two main problems:

1. **Async/Sync Bridge Issues**: RuntimeWarnings when COSA background threads attempt to emit WebSocket messages
2. **Session Management Problems**: Session ID mismatches causing audio playback failures

### Current Issues
- `RuntimeWarning: coroutine 'WebSocketManager.emit_to_user' was never awaited`
- Session ID mismatches between queue and audio WebSockets
- No automatic audio playback when `/api/push` is called
- Multiple WebSocket connections with different session IDs

### Root Causes
- Improper async/sync boundary crossing in WebSocketManager
- Lack of session persistence across page reloads
- Missing user association for audio WebSocket connections

### Expected Outcomes
- Zero RuntimeWarnings in console
- Consistent session IDs across connections
- Automatic audio playback working reliably
- Proper user-specific event routing

## Expert Q&A Summary

Based on code analysis, here are the answers to the expert's questions:

1. **WebSocket Implementation**: Native FastAPI/Starlette WebSockets (not Socket.IO)

  async def emit_to_user(self, user_id: str, event: str, data: dict) -> bool:
      """Emit event only to sessions that subscribed to it"""
      sent_count = 0
      
      for session_id in self.user_sessions.get(user_id, []):
          # Check subscription
          subscriptions = self.session_subscriptions.get(session_id, ["*"])
          
          if "*" in subscriptions or event in subscriptions:
              websocket = self.active_connections.get(session_id)
              if websocket:
                  try:
                      await websocket.send_json({
                          "type": event,
                          "timestamp": datetime.now().isoformat(),
                          **data
                      })
                      sent_count += 1
                  except:
                      self.disconnect(session_id)
      
      return sent_count > 0
  ```

  def update_subscriptions(self, session_id: str, events: List[str], 
                          action: str = "replace"):
      """Allow clients to update subscriptions after connection"""
      if session_id not in self.session_subscriptions:
          return False
      
      if action == "replace":
          self.session_subscriptions[session_id] = events
      elif action == "add":
          current = self.session_subscriptions[session_id]
          self.session_subscriptions[session_id] = list(set(current + events))
      elif action == "remove":
          current = self.session_subscriptions[session_id]
          self.session_subscriptions[session_id] = [e for e in current 
                                                   if e not in events]
      return True
  ```

      """Get statistics about event subscriptions"""
      stats = {
          "total_connections": len(self.active_connections),
          "subscription_counts": {},
          "wildcard_subscribers": 0
      }
      
      for session_id, events in self.session_subscriptions.items():
          if "*" in events:
              stats["wildcard_subscribers"] += 1
          else:

## Code Examples

### Correct Async/Sync Bridge Implementation

```python
# websocket_manager.py
import asyncio
from concurrent.futures import Future
from typing import Optional

class WebSocketManager:
    def __init__(self):
        self.active_connections: Dict[str, WebSocket] = {}
        self.session_to_user: Dict[str, str] = {}
        self.user_sessions: Dict[str, list] = {}
        self.main_loop: Optional[asyncio.AbstractEventLoop] = None
    
    def set_event_loop(self, loop: asyncio.AbstractEventLoop):
        """Store reference to main event loop for thread-safe operations"""
        self.main_loop = loop
        print("[WS] Event loop reference stored for thread-safe operations")
    
    def emit_to_user_sync(self, user_id: str, event: str, data: dict):
        """Thread-safe synchronous wrapper for emit_to_user"""
        if not self.main_loop:
            print(f"[ERROR] No event loop reference - cannot emit to user {user_id}")
            return
        
        if not self.main_loop.is_running():
            print(f"[ERROR] Event loop not running - cannot emit to user {user_id}")
            return
        
        try:
            # Schedule coroutine on main event loop
            future = asyncio.run_coroutine_threadsafe(
                self.emit_to_user(user_id, event, data),
                self.main_loop
            )
            # Don't wait for result to avoid blocking
            print(f"[WS] Scheduled emission of {event} to user {user_id}")
        except Exception as e:
            print(f"[ERROR] Failed to schedule emission: {e}")
```
