### Testing Philosophy Distinction

Our established testing philosophy maintains a clear distinction:

**Quick Smoke Tests** (`quick_smoke_test()` functions):
- **Purpose**: "Does it work in reality?" validation
- **Dependencies**: Real external systems (LanceDB, OpenAI, file system)
- **Location**: Bottom of each module file (not separate files)
- **Output**: Visual ✓/✗ with `du.print_banner()` formatting
- **Scope**: End-to-end workflow validation

**Unit Tests** (`tests/unit/` structure):
- **Purpose**: Comprehensive isolated testing with edge cases
- **Dependencies**: ALL dependencies mocked via MockManager
- **Location**: Separate files in `tests/unit/` directory structure
- **Output**: unittest framework results
- **Scope**: Method-level testing with error conditions

```python
    for input_text, expected in test_cases:
```

```python
def test_hierarchical_search_early_exit( self ):
    """
    Test that hierarchical search exits early on exact matches.

    Validates that the search doesn't continue to expensive similarity
    search when exact matches are found at earlier levels.
    """
    with self.mock_manager.lancedb_mock() as mock_lancedb:
        # Mock CanonicalSynonymsTable to return exact verbatim match
        mock_canonical = Mock()
        mock_canonical.find_exact_verbatim.return_value = "test_snapshot_id"

        manager = LanceDBSolutionManager()
        manager._canonical_synonyms = mock_canonical

        # Test exact verbatim match (should exit at level 1)
        result = manager.get_snapshots_by_question( "What time is it?" )

        # Verify early exit - no normalized or similarity search attempted
        mock_canonical.find_exact_verbatim.assert_called_once_with( "What time is it?" )
        mock_canonical.find_exact_normalized.assert_not_called()
        mock_lancedb.similarity_search.assert_not_called()
```

```python
def test_query_logging_integration( self ):
```
