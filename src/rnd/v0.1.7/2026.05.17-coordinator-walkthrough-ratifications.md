## New scope additions from Rick's clarifications

### A. Unicode all the way down to INI config (from Q8 clarification)

Rick's verbatim: *"if we were to use Unicode all the way down to the configuration manager INI file life would be so much simpler. The key values could be the same as the persona's actual name as it is spelled properly, like María, for example."*

**Implications across the three plans**:

- **Mr Radio's plan**: Regex broadens from `[A-Za-z0-9_-]+` to a unicode-aware character class. Topic file names can carry exact unicode persona names (e.g., `dm-maría.md`). New unit-test cases for unicode persona inputs.
- **Arnold's plan**: The new `~/.lupin/config[owner]` INI section (Q2 ratification) should use unicode keys where applicable. Any cross-referencing to persona names in the owner config uses exact spelling.
- **Cross-cutting**: ConfigurationManager INI keys that reference persona names should accept unicode. The Lupin convention shifts from "ASCII-only persona keys" to "exact unicode spelling" project-wide.

**Follow-up needed (post-ratification, before implementation)**: Save a new feedback memory `feedback_unicode_persona_keys_all_the_way_down` so future sessions inherit this convention. Audit existing INI sections that reference persona names for migration touchpoints.

### B. 100% coverage is non-negotiable, no PR with failing tests (from Q9 clarification)

Rick's verbatim: *"I already demand 100% coverage. There is no PR that's going to happen if I have outstanding tests that are failing. So call it whatever you want but tests are going to get passed before PR has happened."*

**Implications**:

- The "carveout-scoped" framing in Q9 (hybrid) describes which NEW tests get written for Phase 5. It does NOT relax the rule that all existing tests in touched files must pass before PR.
- Any pre-existing test failure in `embedding_provider.py`, `routers/speech.py`, or `fastapi_app/main.py` that surfaces during the Phase 5 work gets fixed in the same phase — no "deferred to follow-up" tickets. (Aligns with `feedback_fix_all_failing_tests`.)
- This rule applies to all three plans, not just Phase 5. Mr Radio's commons DM work and Arnold's owner-stamper work inherit the same gate.
