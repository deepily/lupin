## Summary

Closes the **v0.1.7** development cycle (branch `wip-v0.1.7-2026.04.22-spit-and-polish-for-cjflow-tfe-and-bfe`). What began as "spit and polish for CJ Flow / TFE / BFE" grew into a major **multi-session voice-collaboration** milestone: Lupin's voice loop went from one session to a chorus of named AI collaborators that talk to each other, plus a TypeScript UI rebuild, a multi-repo doc viewer, and a re-architected async job pipeline.

## Highlights

- **Per-session voice personas + chorus mode** — each Claude Code session is allocated a distinct named voice; the voice is the disambiguator in chorus mode. Personas survive `/clear`, `/compact`, and resume; overflow pool ("Extra N") covers more sessions than named slots; new `request_persona` MCP tool.
- **Inter-session commons** — cross-session blackboard (`commons_post`/`read`/`who`), direct messages (`commons_send_to`), and async/sync questions (`commons_ask_async`/`commons_ask_sync`), surfaced in a live Recent Activity stream + broadcast panel.
- **Manager-spawned headless reviewers** — `spawn_sessions`/`dismiss_sessions`/`list_spawned_sessions` automate the cascaded plan-review workflow with idle-TTL reaping and manifest lineage.
- **Speakerphone mode (solo/chorus)** — renamed, hardened successor to conversation mode, driven by a per-turn hook rider.
- **Notifications UI rebuilt in TypeScript** — esbuild-bundled multiplexer behind a hard 100% c8 coverage gate, with a dedicated Jobs pane.
- **Multi-repo document viewer** — path-prefix scope routing across N registered repos, JWT-gated, universal secrets blocklist, inline source-code + image rendering.
- **CJ Flow async multi-lane** — agentic `ThreadPoolExecutor` pool + ghost-job sweeper + `ApiResourceManager` rate limiting + `GET /api/queue/pool-status`; fast-lane sync agents never blocked.
- **Bounded-CC zero-per-token billing** empirically confirmed (2026-05-12); BFE/TFE migrated. Documented cost model for bounded-CC vs firewalled SDK.
- **Heartbeat-poker** liveness abstraction for long-running jobs.
- **WS reconnect circuit-breaker**; **100% line+branch+function coverage** adopted as a Lupin-wide merge gate.

Plus this PR: README "What's New in v0.1.7" headline block + version-history entry; repair of 9 stale unit tests (git_loc_delta v1.1 API + embedding model-server carve-out isolation); a post-PR TODO note (LanceDB→pgvector revisit, filed by Tiberius).
