## Overview

Refine prototype code in `src/rnd/2025.12.31-claude-code-via-mcp-and-cosa-vox/` and move to production locations, focusing on Print Mode (bounded tasks) with Claude Code CLI integration.

## Critical Findings from Exploration

### Ready (No Changes Needed)
- `cosa.cli` notification system is production-ready
- `sender_id` is a native field in NotificationRequest/AsyncNotificationRequest
- API endpoints exist: `/api/notify`, `/api/notify/response`
- SSE streaming for blocking operations works

### Critical Issues to Fix
1. **MCP Tool Naming** - Need to verify naming convention (mcp__cosa__* vs bare names)
2. **Hardcoded Server URL** - Should use COSA_APP_SERVER_URL environment variable
3. **No Logging** - Uses print statements, needs proper logging
4. **Vague Errors** - Error messages need more context

### Deferred (Option B)
- SDK Client mode (interactive sessions)
- Session cleanup race condition (only affects Option B)
- SDK availability validation at init (only affects Option B)

## Dependencies

**Required**:
- Python 3.11+
- fastmcp package
- Lupin server running (port 7999)
- Claude Code CLI (`@anthropic-ai/claude-code`)

**Environment Variables**:
- `COSA_PROJECT` - Project name (required)
- `COSA_APP_SERVER_URL` - Server URL (default: http://localhost:7999)
- `LUPIN_ROOT` - Project root path
- `MCP_DEBUG` - Enable debug logging (optional)

3. `converse()` tool blocks and returns user response
4. `ask_yes_no()` returns boolean correctly
5. Smoke tests pass
6. Installation script works on clean setup
