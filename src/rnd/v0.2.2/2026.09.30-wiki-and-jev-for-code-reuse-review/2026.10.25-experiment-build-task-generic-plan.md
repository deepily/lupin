## Ground rules for the builder

1. Build a TypeScript web client served from the server's static folder, under the page addresses in the feature list.
2. Do not change server code. The server is frozen.
3. Every control is findable by its visible text and ARIA role (label, button, link, region), because the tests find elements no other way.
4. Work phase by phase. A phase ends when its features' acceptance tests pass.
