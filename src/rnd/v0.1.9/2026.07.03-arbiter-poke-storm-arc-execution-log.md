## 1. TL;DR

The `:8001` fleet arbiter repeatedly loop-poked **demonstrably healthy** manager sessions with
"you appear STUCK" messages, ~60s apart, in bursts of up to 3. Two stacked defects:

1. **Detector conflation** (92c7ab1d): `stuck` counted `cap_reached` events with no recency bound and
   no ground-truth liveness check — a busy manager who owns a full board emits `cap_reached` on every
   turn end, so two productive turns flipped `stuck=True`.
2. **Restart replay** (5a1f17f8): the arbiter tailed `~/.claude/heartbeat-events/*.jsonl` from
   **in-memory** offsets. Every `:8001` restart reset them to `{}`, re-reading every file from byte 0
   and re-consuming **historical** `cap_reached` records as if fresh — so a session that had recovered
   hours earlier got loop-poked ~40 min after each redeploy.

Three defense layers landed (bridge-mtime veto · freshness-gate + durable offsets · fire-throttle),
all RED-first at 100% L/B/F, dual-reviewed, merged, deployed 03:12:20Z, and verified dead: **zero
stuck-pokes 03:12Z→05:53Z across multiple post-deploy restarts**, with true-positive detection
(a LEGIT `manager_stale` at 05:45Z) preserved.

## 4. Fixes landed — three layers, all merged

| Layer | Bug | What | Commit → merge | Review |
|---|---|---|---|---|
| Active-session defense | `92c7ab1d` | `_auto_poke` bridge-mtime veto — a session with a fresh session-bridge (ground-truth turn-taking) is never stuck-poked; a genuinely wedged session goes bridge-stale and is STILL poked (true-positive preserved) | `5d4e7baa` → `59ba12e5` | Cheech APPROVE `91bca09f` |
| Honest framing (companion) | `8894e597` | Arbiter pokes drop the false `dm_send` reply affordance (the arbiter has no inbox) — one-way framing: "your bridge/hold/store freshness IS the acknowledgment" | `5d4e7baa` → `59ba12e5` | same combined APPROVE |
| Restart-replay root cause | `5a1f17f8` | (a) **freshness-gate**: a `cap_reached` followed by a later `honored` is *consumed*, never counted (fixture OLD=5 → NEW=0); (b) **durable event offsets** at `io/arbiter/event-offsets.json` — load on init, save each poll, so a restart resumes instead of re-reading from byte 0; (c) **fire-throttle** `arbiter stuck poke min interval seconds` (ships disabled, operator belt) | `303a5ab2` → `20d32319` | Cheech primary `835a6a6a` + Tiffany cross `074f3933`, dual reproduce-not-trust |

Layering: (a) makes replayed records harmless, (b) prevents the replay, (c) rate-limits regardless.
All RED-first, 100% L/B/F on every changed source, 949-test arbiter+app suite green (receipts in the
two companion docs).
