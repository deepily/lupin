## Root cause (CONFIRMED)
`board_sweep.rearm()` (`src/lupin_cli/claude_code/hooks/lib/board_sweep.py:313`) refreshes a
persona's sweep ledger against the live board, but is **never called anywhere in the hooks
tree** — only the read-only `sweep_progress_line()` (line 149) is invoked, from
`stop.py:436` via `_board_sweep_line` (stop.py:392). So a ledger written once is never
refreshed; `reviewed >= live_owed` reads permanently satisfied even days later.
