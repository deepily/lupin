| **1. ### Phase-2 IMPLEMENTED — Option 2 ephemeral per-test schema (✅ BUILT & GREEN)

**Decision trail.** open-Q1 answered: `PredictionDecisionRepository` has **no isolated *unit* coverage** (only two `:8000` integration E2Es) → **BUILD, not port**; this fixture is the repo's first true unit surface. The isolation seam: `ProxyDecisionEmbeddings._pg_*` import `get_db` **at call time** (`from cosa.rest.db.database import get_db` inside each method), so `cosa.rest.db.database.get_db` is cleanly monkeypatchable; and `PredictionDecisionRepository.__init__(self, session)` takes an injected `Session`. A brief detour weighed **Option 3 (txn-rollback)** — attractive because the DI seam already exists — but it was **disqualified at build time by a correctness blocker**: transaction isolation hides your *own uncommitted* writes, **not** the committed base rows, so `test_empty_table_returns_empty_list` (asserts `find_similar == []`) and `test_add_and_retrieve_round_trip` (asserts `results[0]` is its own row) can **never** hold on the shared, populated `public.prediction_decisions`; the only Option-3 escape (in-txn `DELETE FROM prediction_decisions`) is wipe-shaped lock contention on a fleet-shared table and was rejected. **Option 2 (ephemeral empty schema) is required, not merely nicer** — it gives a genuinely empty table so the tests' isolation assumptions hold, with zero locks/contention on `public`. Mr. Radio re-confirmed Option 2 (event 2298).

**The recipe (verbatim — `src/tests/unit/conftest.py`, module-guarded autouse).**
```python
_PG_ISOLATION_MODULES = { "test_data_origin", "test_proxy_decision_embeddings" }

@pytest.fixture( autouse=True )
def _isolate_pg_vector_store( request, monkeypatch ):
    module = request.module.__name__.rsplit( ".", 1 )[ -1 ]
    if module not in _PG_ISOLATION_MODULES:
        yield
        return

    import uuid
    from contextlib   import contextmanager
    from sqlalchemy   import MetaData
    from sqlalchemy.orm import Session
    from cosa.rest.db import database as _db
    from cosa.rest.db.vector_store_models import PredictionDecision

    schema = "test_pdv_" + uuid.uuid4().hex[ :12 ]
    conn   = _db.engine.connect()
    try:
        conn.exec_driver_sql( f'CREATE SCHEMA "{schema}"' )
        # `vector` type/opclass live in public (CREATE EXTENSION vector is DB-global),
        # so public MUST stay on the path for vector(768) to resolve; ROWS land in <schema>.
        conn.exec_driver_sql( f'SET search_path TO "{schema}", public' )
        # Copy ONLY prediction_decisions into the test schema; drop indexes (a few
        # rows seq-scan fine, and this sidesteps any empty-table HNSW/opclass quirk).
        test_md  = MetaData()
        test_tbl = PredictionDecision.__table__.to_metadata( test_md, schema=schema )
        test_tbl.indexes.clear()
        test_tbl.create( bind=conn )
        conn.commit()   # persist the empty schema + table for the store's sessions

        @contextmanager
        def _isolated_get_db():
            session = Session( bind=conn )   # share the one search_path'd connection
            try:
                yield session
                session.commit()
            except Exception:
                session.rollback()
                raise
            finally:
                session.close()

        monkeypatch.setattr( _db, "get_db", _isolated_get_db )
        yield
    finally:
        conn.rollback()   # defensive: clear any aborted txn so cleanup always runs
        conn.exec_driver_sql( f'DROP SCHEMA IF EXISTS "{schema}" CASCADE' )
        conn.exec_driver_sql( "RESET search_path" )   # no leakage back to the pool
        conn.commit()
        conn.close()
```

**Why it is leak-safe + additive** (the cross-connection caveat's resolution, readable for the next person):
- **search_path wiring**: set ONCE on the fixture-owned `conn`; every `_isolated_get_db()` session binds to that same `conn`, so all `_pg_*` calls in a test share one connection + search_path + transaction visibility (an added row is visible to a following `find_similar` in the same test). Because the fixture owns `conn` and issues `RESET search_path` before `close()`, the pooled connection returns clean — no search_path leaks to other sessions.
- **vector-extension visibility**: `CREATE EXTENSION vector` is DB-global (one per database); keeping `public` on the path lets the test schema's `vector(768)` column + `<#>` operator resolve without re-creating the extension per schema.
- **teardown guarantee**: `DROP SCHEMA … CASCADE` removes the throwaway table + all its rows atomically; `public.prediction_decisions` is **never** created-into, locked, deleted-from, or wiped.

**Bogus-path test rewrite (Mr. Radio directive — done in this pass).** `test_find_similar_failure_returns_empty` previously passed a nonexistent `db_path` expecting the LanceDB open to fail → `[]`; that premise is dead under Postgres (db_path inert). Retargeted to the real best-effort contract: monkeypatch `PredictionDecisionRepository.find_similar` to raise, assert the store's `_pg_find_similar` swallows it and returns `[]`.
