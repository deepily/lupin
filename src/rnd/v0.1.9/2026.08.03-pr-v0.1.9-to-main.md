## Body

### v0.1.9 — off LanceDB, onto the cloud, and instruments you can believe

841 commits, 1,269 files, June 21 → August 3 2026. This is the `wip-v0.1.9` working branch, which has been the live branch on both servers for six weeks.

#### The vector store was replaced under the whole platform

LanceDB → PostgreSQL + pgvector, in four lanes: ORM models + Alembic migration, eight per-table repositories behind a runtime backend flag, consumer routing, then the backfill. Cutover ran 2026-07-07 — ~202,000 vectors backfilled, dual-engine equivalence proven against the real legacy call sites, and exact scan chosen over HNSW once the keystone table turned out to be 97.2% duplicate vectors. `vector store backend = postgres` is live on both servers and the LanceDB path is still there as a one-flag rollback.

Beforehand, the 90.46 GB LanceDB table with the broken version chain was rebuilt to 1.07 GB — ~89 GB reclaimed, all 176,877 rows preserved.

#### GCP went from "validated" to operator-usable

- CPU-VM app-restore arc completed and verified end to end; an MTU 1500→1460 mismatch was the last blocker.
- GPU model server costed and split onto Cloud Run.
- The VM got an IAP browser tunnel, a live fleet arbiter, repo-sync tooling, its own pgvector bring-up, and a written bring-up runbook.
- A 38-hour `/embeddings/generate` outage closed by separating one key file that had been serving two consumers with incompatible authorities — a defect invisible on dev precisely because dev's two values coincided by accident.

#### Fleet liveness hardened by measurement

A 3,000-notification flood, a tmux fleet-killer, a Stop-phase turn wedge (a fire-and-forget `notify()` that hung a turn for 54 minutes), arbiter double-delivery, DM double-stamping, ping storms, phantom blocks, and advisory loop-fire were each root-caused and fixed. The heartbeat-hold janitor's sweep reach went from 4 holds to 44 once pointed at the right root.

#### Task store grew verbs and guards

`task_edit` and `task_reassign` shipped. A closed row can now carry a post-terminal addendum, so a gate verdict written after a worker self-closes has somewhere to go. Rows can be parked with a self-expiring chase. A bare unscoped board query hard-fails with an educational error instead of dragging the whole fleet's history back.

#### TypeScript multiplexer reached legacy parity

An adversarial gap matrix, a layout-parity oracle, and focus-bar parity work closed the distance to the legacy notifications UI. 724 TypeScript test cases across 114 files, behind a hard 100% c8 gate on lines, branches, and functions.

#### Instrument rigor became a first-class discipline

A hash-chained, append-only tier-run attestation ledger now answers "did this tier actually run?" The first execution of 8,799 previously-ungated CoSA tests found 4 real failures behind two years of assumed health. A bridge-contact guard and an import-discipline detector caught guards that fired without saying what to fix.

#### Model and data plumbing

Mistral Small 3.2 24B stood up on GPU1 (vLLM pinned at 0.16.0 — 0.26.0 is CUDA-13-only and this driver can't run it). `DEEPILY_DATA_DIR` moved 449 runtime files out of the repo and out of `git clean -xdf`'s reach. An embedding-regeneration pipeline was built for all 578,364 logged texts with an adaptive GPU batch budget — gated, with zero live rows written.
