`TtsQueueStore.current()` before a speak fires (deterministic binding for B4's per-bubble gate). It is a
**post-flip refinement**, not an MVP blocker.

## A/B visual-comparison design (Rick's "re-run the process")

1. **Automated A/B (this session can run it):** a Playwright script that loads
   `:8000/app/notifications?classic=1` (legacy) and `:8000/app/multiplexer` (mux), hydrates both from the
   canonical `notifications-parity-scenario.json` via the `parityFixture.ts` adapters, captures full-page
   screenshots + injects the `CONTRACT_STYLE_GEOM_JS` walker (`parity_oracle.py:77–100`) for a node-by-node
   Tier-2/Tier-3 diff, and emits a **side-by-side report** (legacy | mux | computed-style/geometry deltas).
   Reuses the existing deterministic-font conftest + 1280×720 pin. This is reproducible and AI-run.
2. **Human subjective pass (Rick's Chrome):** the "Claude Code plugin inside Chrome" does **not** exist in
   this headless environment. Rick can run the subjective A/B walkthrough on his own machine (Claude-in-
   Chrome / DevTools), loading the two URLs above for the final visual-feel sign-off — the one
   EXECUTOR:HUMAN tier the Oracle defers.

The automated report feeds B5 (catches residual drift surgically); Rick's pass is the flip sign-off.
