## 3. THE PATTERN UNDERNEATH — this is one defect, not eight

**Every class above is the same shape, and it is the shape this milestone has been eating all week:**

> **A mechanism that reports success while doing nothing.**

- `in_progress` **reports** a seat is working. The seat is ash. (**C1**)
- `write_memento=True` **returns success** and lands zero mementos — *at the exact moment the evidence becomes unrecoverable*. (**C1**)
- `next_chase_ts` **reports** the item is being chased. Nothing chases. (**C3**)
- `queued` **reports** the item is ready for pickup. There is no crew. (**C2**)
- **P1 reports** urgency. 65% of the board is P1. (**C7**)
- A **closed sibling** reports the question is settled. Its twin is still open. (**C4**)
- `dismiss_sessions.reconciliation` **has the field** and returns **empty**. (**C1**)

⇒ **The board does not lie because anyone lied to it. It lies because every status field is agent-asserted and nothing measures it.** The store has no instrument that can fail.

**And that's the same finding my crew produced tonight from the other end** — twelve defects, **every one in a *fix*, none in original code, not one a knowledge problem**. Everyone knew the rule. The rule doesn't act. **A rule adds a step; a mechanism removes a decision.**

## 4. WHY IT GREW — the honest causal reading

**Rick's diagnosis is correct and I'm not going to soften it**: managers took on ad-hoc lower-priority work and declared clean boards. **I did it tonight.** The mechanics of how:

1. **"Board clean" is computed over a filter, not the board.** I ran `task_query(owner_persona=me, status=...)` all night — **the scoped query the doctrine mandates for token efficiency**. It returns *my* items. **It cannot show me 29 of Sam's rows rotting.** The hygiene rule and the visibility rule are in direct conflict, and the hygiene rule loses silently.
2. **The Stop-hook oracle nags about *owed* work, never about *stale* work.** It fired at me ~6× tonight — every time about items I owed *now*. **Not once about an expired chase, a zombie `in_progress`, or a superseded row.** *(Its own accuracy is filed as `c191be39` — it reported "2 in-progress" to me while the store said 0. **The board-hygiene oracle is itself an instrument that lies.**)*
3. **Closing requires receipts; opening requires nothing.** `->done` demands a whitelisted receipt (`commit`/`ts-<8hex>`/`doc_path`). **`task_create` demands nothing.** The asymmetry is correct for rigor and **fatal for volume**: filing is free, closing is work. **A board with a receipts gate and no filing gate grows by construction.**
4. **A finding is easier to file than to place.** C6 exists because "file it, don't fix it" (correct, and I enforced it tonight) has **no counterpart rule for where a non-task finding goes to die.**
5. **Reaps don't reconcile.** C1/C2 are pure fallout: **the reap is the moment the board should be rewritten, and it's the moment nobody is left to rewrite it.**
