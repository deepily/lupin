## 1. THE MARKER PREDICATE

### 1.1 Definition

> **A row is PARK-ELIGIBLE if and only if its BODY contains a ROW-LEVEL HOLD:
> an instruction, attributable to a named authority, that forbids working THIS ROW until a stated condition.**

A candidate must pass **all three** tests. Failing any one disqualifies it.

| # | Test | Passes when | Fails when |
|---|---|---|---|
| **T1** | **SCOPE = ROW** | The prohibition governs *this row's own work* | It governs a sub-step, a fix *shape*, a messaging choice, a different row, or is `⛔` used as **emphasis** inside otherwise-actionable content |
| **T2** | **AUTHORITY** | Attributable to a named ruler (Rick, Sam, María, a manager) or an explicit standing order | It is the author's own hedging — "should probably wait", "may be held", "not mine to make" |
| **T3** | **CONDITION** | A stated release condition — a date, a named event, or a named dependency | No release condition of any kind exists |

### 1.2 T1 is the test that matters, and it is the one both prior catalogs failed

Mr. Radio's own recorded caveat in `954428b3`:

> *"My first predicate said 42%; hand-checking, 19 of 31 hits were `⛔` used as EMPHASIS inside otherwise-actionable rows, not row-level holds."*

This board writes in a house style that uses `⛔`, `DO NOT`, and `NEVER` **constantly** — for cautions about *how to fix* a thing that is otherwise live work. Examples I classified NOT-PARK for exactly this reason:

- `28fc1fb4` — *"⛔ DO NOT 'fix' this by telling seats to write shorter titles."* → a constraint on the **fix shape**. The row is live.
- `86ce4c43` — *"⛔ DO NOT fix any of these with guidance telling seats to write clearer reason strings."* → same shape.
- `8c605225` — *"DO NOT REOPEN `14b3951d`."* → governs a **different row**.
- `d80613ad` — *"⛔ NOBODY QUOTES 'a 5.9 point discrimination gap.'"* → a **messaging** constraint.
- `841b3d21` — *"Do NOT build on"* → a caution that an **instrument is broken**, not that the work is held.

**A predicate that keys on `⛔` or on `DO NOT` returns roughly double the truth.** That is the measured failure mode, twice.

### 1.3 T3 is the test that routes a row AWAY from `parked`

Per Rick's design ruling: **an indefinite hold is not parked — it is DROPPED, with a reason, because dropping is visible.** T3 is what enforces that. A row whose body says "not now" with no stated release condition must NOT be parked; parking it would buy unbounded silence, which is the thing the whole design forbids.

### 1.4 The sieve is not the predicate

The mechanical scan (`scratchpad/park/scan.py`) is a deliberately **high-recall, low-precision sieve** — 33 regex patterns, hit on **54 of 70** corpus rows. It exists only to bound reading, never to decide. Every one of the 54 hits was hand-adjudicated against T1/T2/T3; the 16 sieve-clean rows still require eyeballing (§5, flagged as incomplete).

**Deliberate asymmetry**: a sieve *miss* is unrecoverable (a held row silently rejoins the poke rotation); a sieve *over-hit* costs only reading time. So the sieve is tuned to over-hit, and it does — 54 hits produced 26 parks, a **~52% false-positive rate at the sieve layer, by design**.

## 7. HOW TO REFUTE THIS DOCUMENT

Row-by-row, not in aggregate:

1. Pull the row's body: `task_query(status="queued", project=<p>)`.
2. Find the sentence quoted in this document's `park_reason` column.
3. Attack it on **one** of T1 / T2 / T3:
   - **T1** — does the sentence govern *this row's work*, or a fix shape / a different row / emphasis?
   - **T2** — is a named authority attached, or is it the author hedging?
   - **T3** — is there a stated release condition, or is this an indefinite hold that should be **dropped**?
4. If a row survives all three, it parks. If it fails T3 specifically, it **drops** — visibly, with a reason.

**A refutation that says "the count should be 15" without naming a row is not a refutation.** That is the sin this artifact was commissioned to end.
