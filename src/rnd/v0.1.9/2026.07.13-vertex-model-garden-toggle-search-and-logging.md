## 4. Finding 2 — Request-response logging: the exact API

```
POST v1beta1/projects/{p}/locations/{loc}/publishers/anthropic/models/{model}:setPublisherModelConfig
     → GoogleLongrunningOperation (LRO)
GET  v1beta1/projects/{p}/locations/{loc}/publishers/anthropic/models/{model}:fetchPublisherModelConfig
```

**Auth note (rev.-1 concern REFUTED)**: the project is **in the path** for `set`/`fetch` — no `x-goog-user-project`

**Client note**: we call **raw REST**, not the Python SDK, because `google-cloud-aiplatform==1.92.0` is **pinned in

### 4a. Field semantics (quoted from the schema)

| Field | Meaning |
|---|---|
| `enabled` | *"If logging is enabled or not."* |
