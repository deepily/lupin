## 4. Quota mechanics (why the commands look like this)

- A clamp is a **`QuotaPreference` override** (Cloud Quotas API v1) keyed by service + quotaId + dimensions.
- **Decreases are self-serve and near-immediate** (this is the whole point). Large decreases may require the
  safety-check override `--force`/`ignoreSafetyChecks=QUOTA_DECREASE_PERCENTAGE_TOO_HIGH` — check the
  `--help` output at execution.
- **Rollback = updating the preference back to the default value = an INCREASE request**, which may need
  Google approval and is **not guaranteed instant**. Plan pilot bursts on that asymmetry: easy to tighten,
  slower to loosen. (QuotaPreferences cannot be deleted in v1 — only updated.)
- Dimension `base_model=<model-id>` scopes each clamp to one model; the quota is already per-base-model, so
  one preference per (model × quotaId).

## 8. Verification design — proving the cap is LIVE (the oracle problem)

- The §5 read-backs prove the preference is **configured**. They do NOT prove traffic is **braked**.
- “No 429 observed” is a **null**: under-approach and a working cap are indistinguishable. **A null is not
  evidence until the instrument is proven.**
- **The honest proof is a deliberate over-rate canary that MUST 429** — designed here, NOT fired (it is a
  prediction call = spend = Rick's word + Mr. Radio's hand):

  1. Pick the cheapest model: `gpt-oss-120b-maas` ($0.36/M out).
  2. Temporarily set its Total-TPM preference to **1,000**.
  3. Within one minute, send request #1 sized ~600 total tokens (**must SUCCEED** — proves the instrument can
     see the positive case), then request #2 of the same size (**must 429** — the brake, observed braking).
  4. Restore the preference to 40,000 (§2c value).
  - Cost: ~1,200 tokens ≈ **well under $0.01**.
  - Optional isolation leg (a few cents): fire one `deepseek-v3.2-maas` request during step 3 — it must NOT
    429, proving the `base_model` dimension isolates per model.
- The Opus clamp (if §3-0.4 finds its family) gets its own canary on the same pattern — at Opus prices a
  2-request canary is still < $0.10.
- Steady-state observability: `GlobalOpenapi*` 429s appear in Cloud Monitoring
  (`serviceruntime.googleapis.com/quota/exceeded`) — a standing sanity read, but only the canary calibrates it.
