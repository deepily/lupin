## POST-REVIEW — A FOURTH NEAR-MISS, IN THE REVIEWER'S OWN GATE

Found after the review committed, while arming the deferred CoSA run. Recorded here
because it is the day's recurring defect in its most recursive form.

My wait-gate polled `ps -eo args | grep -E '[-]m pytest'`. That predicate matched:

| `comm` | count | what it actually was |
|---|---|---|
| `bash` | 4 | wrapper scripts whose **body** contains the string `-m pytest` |
| `claude` | 1 | **my own agent process** |
| `python` | 1 | the one real pytest run |

It counted **4** when the truth was **1**, and could never reach zero — so it would
have waited the full 30-minute ceiling and reported `STILL BUSY`, which reads as *peer
contention* rather than *broken instrument*. Closed state indistinguishable from
working, which is the exact failure mode the brief named.

**The recursion**: my own process matched because its prompt is the review brief — and
the brief quotes the offending grep command verbatim, as the instruction to check for
contention. **The warning about prose-matching became the prose that got matched.**

⇒ **The brief itself is a contamination surface.** Any predicate a worker runs over
process state, logs, or the repo can match the instructions that told them to run it.
An agent's own context is live text on the machine it is measuring.

**Fix**: `comm` must *be* python (`ps -eo comm,args | awk '$1 ~ /^python/ && /-m pytest/'`)
— the form the brief itself prescribes, which I dropped when scripting it. The defect
entered in the translation from prescribed command to my convenience rewrite.

### The arm that generalizes: a positive control on every gate

A gate proven only to BLOCK is not proven to WORK. Before trusting a "clear", assert
the gate can read BUSY:

```
echo "=== gate control: host=$( host_pytest ) container=$( cont_pytest ) ==="
```

Logged `host=1 container=0` on arming — the gate demonstrably distinguishes the two
states. Had that arm existed in the first version, `4` would have been visible on line
one instead of a silent 30-minute wait.

**This is owed across every gate shipped today** (row P2 raised): each was verified to
close, none was verified to open on demand. That asymmetry is what let a permanently-shut
gate look like a patient one.
