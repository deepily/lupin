## Symptom (hit LIVE 2026-06-30)

A manager deep in an **approved plan** read as dark/stale and drew a MANAGER-STALE
poke + a Rick advisory, even though it was actively working. Plan-mode work is one
long single-turn tool sequence: **no `Stop` event fires** for the whole plan turn.

## Root cause

`compute_liveness` (`fleet_render.py`) derives `freshest_age_s` from a **six-signal
union** — bridge / event / commons / idle_prompt / dm / hold. Every one is
`Stop`-hook or post-event driven. During a long single-turn tool sequence (plan-mode
drafting, a big multi-Read/Edit run) none of them refresh, so all six age past STALE
(3600s) → `freshest_age_s` climbs past `arbiter manager stale poke threshold seconds`
(2700s) → `_check_manager_staleness` (`arbiter_job.py`) fires case-14 at a live manager.

## Fix — transcript-mtime as a 7th liveness signal

The harness appends a turn to the session's transcript `.jsonl` on **every**
assistant/tool event — including mid-plan. Its mtime is a hook-independent
proof-of-life that bumps when the other six don't. We fold it into the freshest-of
union as a **7th, unconditional, additive, fail-safe** signal — mirroring the
hold-mtime fix (task `70be69f2`) and the dm-as-liveness signal line-for-line.

- `compute_liveness( …, transcript_mtime=None )` → `transcript_age_s` joins the
  union unconditionally (like `hold_age_s`). `None` ⇒ byte-identical to the prior
  6-signal verdict (additive / reversible).
- `build_snapshot( …, transcript_mtimes=None )` threads per-session mtime through.
- `_default_transcript_mtime_fn(session_id)` resolves the bridge via
  `find_session_by_id` → `transcript_path` → `os.path.getmtime`. Injected seam
  `transcript_mtime_fn` (None → real reader), per-session read out-of-band in
  `_publish_fleet_snapshot` so `compute_liveness` stays pure.

### Fail-safe (non-negotiable #1)

A missing bridge, an absent/empty `transcript_path`, or a stat failure all degrade
to **None — no signal, never a spurious-fresh mtime**. A genuinely-dark / exited
session (transcript stops appending, or path gone) therefore **still ages to STALE**;
the signal is purely ADDITIVE (can only make a session read *more* alive).
