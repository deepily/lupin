## The headline, and the only part that generalises past this row

> 🔴 **A POSITIVE CONTROL DRAWN FROM THE SAME CLASS AS YOUR TRUE POSITIVES CANNOT
> DETECT A POPULATION ERROR.**

This repo already teaches "prove the search can find something before you trust a
zero." I did that. **The control passed and the zero was still false**, because
the control and the thing I was hunting were the same *kind* of node, and the
population error was a difference of kind.

⇒ The discharge is one extra sentence when you state a census: **say which of your
searches are STATIC (source text) and which are DYNAMIC (rendered DOM), and never
let one answer for the other.**

## The sequence — two carve-out reasons, both refuted, and why each looked right

The task: decide whether the multiplexer's four accordion panes can be compared
against the legacy client for Rick's ratified *"look exactly"*.

### Reason 1 — "legacy renders no section-level accordion" · **FALSE**

Derived by grepping `notifications.js` (24,884 lines):

```
section-header   0        section-toolbar   4
section-content  0        section-hidden   11
toggle-button    0
```

It looked right because the numbers were real, the file is the client, and there
*is* a plausible alternative mechanism sitting right next to it — `.section-toolbar`
+ `.section-hidden`, a floating toolbar that hides sections. A coherent story with
supporting evidence, and I committed it as a Category-3 carve-out.

**What it missed:** the markup is **static in `notifications.html`**. I searched the
GENERATOR and concluded about the PAGE.

| class | STATIC grep of `notifications.js` | DYNAMIC rendered DOM |
|---|---|---|
| `.section-header` | 0 | **15** |
| `.section-content` | 0 | **20** |
| `.toggle-button` | 0 | **20** |
| `.section-hidden` | 11 | **0** — a toggled state, applied on interaction |

All four panes have one, named by their own handlers:
`toggleSection('fleet-status-section')`, `'task-list-section'`,
`'holding-area-section'`, `'epic-board-section'`.

### 🔴 And the positive control passed while sharing the defect

I declared that census sound because `date-accordion-header` returned **1**. But the
date accordion is **JS-generated** — the one class of node that was never in
question. The control demonstrated only that the search finds JS-generated nodes.

**Note the shape**: this is not "he forgot a control." The control was present,
correct, and structurally incapable of catching the error. A rule that says *use a
positive control* would not have saved this. A rule that says *draw the control from
a different class than your true positives* would.

|---|---|

⇒ My check was written from **the same reading of the code that produced the
fixture**. Two sides, one source — it could only ever agree with me. This is the
repo's existing "a comparison whose two sides come from one source cannot disagree",
arriving on a *self-check* rather than an assertion.

## The five divergences — and the two that did not survive

Measured on both sides. They go to Rick as a ruling: hold parity and lose the
improvements, or keep them and amend what *"exactly"* means. **His phrase, his call.**

| # | divergence | legacy | mux |
|---|---|---|---|
| 1 | collapse referee node | `.collapsed` on the `.section-content` | `[data-collapsed="true"]` on the section ROOT |
| 2 | count identity | `span#<pane>-count` — an **ID**, no class | `span.section-header-count` — a **class** |
| 3 | actions wrapper | buttons directly in `.section-header` | wrapped in `div.section-header-actions` |
| 4 | section root | `div.collapsible-section` | `section#<pane>-pane` |
| 5 | toggle tag | `button.toggle-button` | `span.toggle-button` |

⚠️ **#2 and #5 are the kind a sheet or walker silently cannot see across** — same
role, different handle, so a selector keyed to one reports the other absent.

### 🔴 The two drops are worth more than the five keeps

| candidate | why it looked like a divergence | why it is not |
|---|---|---|
| **Drift group** | legacy renders a 4th epic group "🔴 Drift"; my model run returned **3** groups | drift is a **separate field** on the model (`drift: TaskItem[]`), rendered last by `epicBoardTable.ts`. My count read `groups` only |
| **Epic default state** | legacy renders epic groups COLLAPSED while task groups render EXPANDED | `epicBoardCollapse.ts`: that rule is "the PARITY CONTRACT shared **VERBATIM** with the JS card" — on-Rick expanded, everything else collapsed |

Both would have been **false divergences reported to Rick**. Both died because I read
the mux instead of inferring from a count.

> 🔴 **A COUNT OF THREE WHERE YOU EXPECTED FOUR IS THE MOST PERSUASIVE WRONG ANSWER
> THERE IS.** (María's formulation.) It is arithmetic, it is reproducible, and it is
> about the wrong field.

⇒ **A divergence list that shows only what survived hides the method that produced
it.** Publish the drops beside the keeps.
