### 🚨 CRITICAL Issue 1: Session ID Validation
**Problem**: Tab (\t) and newline (\n) characters accepted in session IDs
**Evidence**: Log lines 146, 149 - "wise\tpenguin" and "wise\npenguin" connected
**Expected**: Should reject all whitespace except single space between words

**Component to Fix**: WebSocket session ID validation
**Unit Tests to Create**:
- `test_session_id_rejects_tab_character()`
- `test_session_id_rejects_newline_character()`
- `test_session_id_accepts_valid_format()`
