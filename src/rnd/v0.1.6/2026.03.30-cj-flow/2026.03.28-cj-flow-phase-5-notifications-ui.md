## Edge Cases

| Scenario | Handling |
|----------|----------|
| Paused + Scheduled | Both badges render; paused card opacity dominates visually |
| WS event but card not rendered | Handler logs, returns. Next `loadQueueJobCards()` call renders correctly |
| REST error on toggle | Optimistic UI reverted, alert shown |
| Admin viewing others' jobs | WS targets job owner only; admin refreshes for updates (acceptable for Phase 5) |
| Scheduled time passes while page open | Badge remains static; `job_state_transition` moves card to run queue |
| Cancel + Pause button coexistence | Cancel is position:absolute (top-left); pause flows in flex layout |
