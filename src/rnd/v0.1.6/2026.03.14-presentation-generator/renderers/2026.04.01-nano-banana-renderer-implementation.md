## Context

The Presentation Generator now handles diagrams (MermaidRenderer), charts (MatplotlibRenderer), and flowcharts (D2Renderer — parallel session). Slides with `visual_type: hero_image`, `infographic`, `title_background`, or `icon` still fall through to PlaceholderRenderer.

NanoBananaRenderer is the first **paid, external API** renderer. It calls Google's Imagen 3 (Nano Banana 2) model via the `google-genai` SDK (v1.29.0, already installed) to generate presentation-quality images from natural-language descriptions.

**Key difference from MatplotlibRenderer**: No local code execution — calls Google's image generation API directly. Needs a shared `GeminiImageClient` (reusable for VeoRenderer later), API key management, cost tracking, and content safety handling.

**SDK verified**: `google-genai==1.29.0` supports native async via `client.aio.models.generate_images()`. No `run_in_executor` needed. Supports `aspect_ratio="16:9"` natively — perfect for slides.

**Dependencies already in place**:
- `google-genai==1.29.0` installed + in requirements.txt
- Gemini API key exists at `src/conf/keys/gemini`
- `cu.get_api_key("gemini")` loads it via canonical pattern
