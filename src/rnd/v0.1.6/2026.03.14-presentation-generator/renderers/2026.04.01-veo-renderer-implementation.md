# VeoRenderer — Implementation Plan

**Date**: 2026-04-01
**Phase**: 10B
**Scope**: Gemini API (Veo 2) → MP4 video + PNG still frame for presentation slides
**Effort**: 1-2 sessions
**Cost**: $0.20/sec at 1080p

---

## Context

Video is the highest-impact visual upgrade for presentations. A 5-8 second ambient title video transforms a static title slide into something cinematic. A process animation replaces a wall-of-text diagram with a watchable walkthrough.

VeoRenderer uses Google's Veo 2 model via the same `google-genai` SDK and `GeminiImageClient` already used by NanoBananaRenderer (Phase 10A). The key difference is Veo 2's **async polling pattern** — `generate_videos()` returns a `GenerateVideosOperation` that must be polled until completion (~30-60 seconds).

**Dual output strategy**: HTML exports get `<video autoplay muted loop>` tags. PDF/PPTX exports get a static PNG frame extracted via ffmpeg. Both are embedded in a single HTML block with graceful degradation.

---

## Design Decisions (Open Questions Resolved)

| Question | Decision | Rationale |
|----------|----------|-----------|
| Video duration | Vary by type: title_video=5s, flow_animation=6s, process_video=8s | Titles are ambient loops (shorter), processes need time to explain |
| Veo model selection | Config-driven via `lupin-app.ini` | Runtime switchable: `veo-2.0-generate-001` ($0.20/sec) default, `veo-3.0-generate-001` ($0.40/sec, has audio) selectable per environment |
| ffmpeg missing | Graceful degradation — skip frame, return video-only HTML | Same lazy-check pattern as D2Renderer; never fail the render |
| Budget control | `video_budget_limit=$5.00` on GeminiImageClient + `max_videos=5` on VeoRenderer | Two-layer defense; $5 = 25 seconds of video |
| Polling timeout | 120 seconds max, 10s intervals | Veo typically 30-60s; 120s gives margin before falling back |
| Marp `<video>` | HTML5 `<video>` with `<img>` fallback inside | Standard HTML degradation; works in Marp HTML, falls back in PDF |
| visual_type naming | `title_video`, `flow_animation`, `process_video` | Matches R&D doc; `process_video` (not `process_explanation`) for consistency with other `*_video` naming |

### Step 2: Add `generate_video()` to GeminiImageClient (~80 lines added)

**File**: `src/cosa/agents/presentation_generator/gemini_client.py`

Add to the class:
- `COST_PER_VIDEO_SECOND = 0.20` module constant
- Constructor: add `video_model: str = "veo-2.0-generate-001"`, `video_budget_limit: float = 5.00` params, `video_cost_total = 0.0`, `videos_generated = 0`
- `async generate_video( self, prompt, output_path, duration_seconds=8 ) -> bool`:
  1. Budget check (video_cost_total vs video_budget_limit)
  2. Call `client.aio.models.generate_videos()` with `model=self.video_model` and `GenerateVideosConfig(number_of_videos=1, duration_seconds=duration_seconds, resolution="1080p", aspect_ratio="16:9")`
  3. Poll loop: `while not operation.done` → `asyncio.sleep(10)` → `client.aio.operations.get(operation)` — max 12 iterations (120s)
  4. Extract `operation.result.generated_videos[0].video.video_bytes`
  5. Write bytes to `output_path`
  6. Track cost: `video_cost_total += duration_seconds * COST_PER_VIDEO_SECOND`
  7. Return True/False
- `_track_video_cost( self, duration_seconds )` helper

### Step 4: Create `renderers/veo_renderer.py` (~180 lines)

**File**: `src/cosa/agents/presentation_generator/renderers/veo_renderer.py`

```python
class VeoRenderer( VisualRenderer ):
    SUPPORTED_TYPES = [ "title_video", "flow_animation", "process_video" ]
```

**Constructor**: `__init__( self, gemini_client=None, max_videos: int = 5, debug=False, verbose=False )`
- `_ffmpeg_available = None` (lazy cache, same pattern as D2Renderer)
- `_videos_rendered = 0` (per-deck counter)

**`render()` flow**:
1. Guard: gemini_client, output_dir
2. Budget check: `_videos_rendered < max_videos`
3. Get `slide_title`, `output_dir`, `slide_index` from kwargs
4. Build prompt via `get_video_prompt()`
5. Get duration via `get_video_duration()`
6. Call `gemini_client.generate_video( prompt, video_path, duration_seconds )`
7. If success + ffmpeg available: extract frame via `_extract_frame()`
8. Return dual-format HTML block or None

**`_extract_frame( video_path, frame_path )`** method:
- `asyncio.get_event_loop().run_in_executor()` wrapping `subprocess.run()`
- Command: `["ffmpeg", "-i", video_path, "-ss", "1", "-frames:v", "1", "-q:v", "2", frame_path, "-y"]`
- Timeout: 15 seconds
- Returns bool (success/failure)

**`_check_ffmpeg_available()`** — lazy cache via `shutil.which("ffmpeg")`

**Return format** (dual output):
```html
<video src="visuals/video-003.mp4" autoplay muted loop
  style="width:100%;max-height:500px;object-fit:cover;">
  <img src="visuals/video-003-frame.png" alt="Slide Title" />
</video>
```
If ffmpeg unavailable (no frame extracted):
```html
<video src="visuals/video-003.mp4" autoplay muted loop
  style="width:100%;max-height:500px;object-fit:cover;">
</video>
```

**`quick_smoke_test()`** at bottom.

## Veo 2 API Polling Pattern (Key Implementation Detail)

```python
async def generate_video( self, prompt, output_path, duration_seconds=8 ) -> bool:
    client = self._get_client()
    config = types.GenerateVideosConfig(
        number_of_videos = 1,
        duration_seconds = duration_seconds,
        resolution       = "1080p",
        aspect_ratio     = "16:9",
    )
    operation = await client.aio.models.generate_videos(
        model  = self.video_model,
        prompt = prompt,
        config = config,
    )
    # Poll for completion (max 120s)
    for _ in range( 12 ):
        if operation.done: break
        await asyncio.sleep( 10 )
        operation = await client.aio.operations.get( operation )

    if not operation.done:
        logger.warning( "Veo: Video generation timed out (120s)" )
        return False

    if operation.result and operation.result.generated_videos:
        video = operation.result.generated_videos[ 0 ].video
        if video and video.video_bytes:
            with open( output_path, "wb" ) as f:
                f.write( video.video_bytes )
            self._track_video_cost( duration_seconds )
            return os.path.exists( output_path )

    return False
```
