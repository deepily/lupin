## What Went Wrong

### 1. Opus never ran through test-suite endpoint
The test-suite endpoint path was never validated with Opus. The successful run bypassed it via manual background process.

### 2. Haiku produced 0 slides (silent quality failure)
- Pipeline reported state=COMPLETED
- YAML written with `total_slides: 0, slides: []`
- No assertion catches "completed with 0 slides"
- 3 API calls vs Opus's 10 — content phases likely collapsed

### 3. Smoke test timeout insufficient
- `DEFAULT_TIMEOUT=600` (10 min)
- Test-suite wrapper adds ~400s scheduling + startup overhead
- Only ~200s remaining for the actual pipeline
- Phase D Haiku timed out at 607s

### 4. Docker credential gap
- Server runs in Docker with `$HOME=/root`
- `~/.lupin/test-env.sh` doesn't exist inside container
- Quick-fixed via `docker cp`; permanent volume mount needed

### 5. Job persistence gap
- `"test_suite"` added to `AGENTIC_JOB_TYPES` (FIXED)
- `mark_interrupted_jobs()` marks but does NOT re-enqueue — long-running jobs lost on restart
