# Plan: Claude Agent SDK Upgrade 0.1.36 → 0.1.52

## Context

The SDK is pinned at 0.1.36 (16 patches behind). Two critical bugs affect our version: (1) fine-grained tool streaming regression (fixed 0.1.49) and (2) hook output field conversion bug (fixed 0.1.48). Neither is actively exploited in our code, but upgrading resolves them and picks up reliability fixes (CLI discovery blocking async event loop, SIGKILL fallback, non-JSON stdout corruption). The upgrade also introduces `RateLimitEvent` — a new message type that our streaming iterators must handle to avoid silently dropping rate-limit signals.

**Analysis doc**: `src/rnd/v0.1.6/2026.03.30-claude-agent-sdk-upgrade-0.1.36-to-0.1.52.md`

## Scope: Minimal stability upgrade (not feature adoption)

5 files modified. ~15 lines added. No feature adoption (session_id injection, dontAsk, get_context_usage, task_budget deferred to separate work).
