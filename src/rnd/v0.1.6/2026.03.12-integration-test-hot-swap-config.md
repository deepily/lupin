# Integration Test Isolation — Hot-Swap Config Plan

## Context

All test suites pass (unit 2075/2075, smoke 27/27, WebSocket 49/50) except integration tests, which fail with `400: Email already registered` due to missing database isolation guards. The dev server is always running on port 7999 — there's not enough GPU RAM for a second FastAPI instance.

**New approach**: Instead of starting a separate test server, hot-swap the running dev server's config block and database connection via `/api/init`. The integration test runner will:
1. Swap to `[Lupin: Testing]` config + `lupin_db_test` → run tests → swap back to `[Lupin: Development]`

**Two obstacles to solve**:
1. `/api/init` creates a new ConfigurationManager but doesn't update the `_config_mgr` singleton in `dependencies/config.py` — the app keeps using the old one
2. The database `engine`, `SessionLocal`, `ScopedSession` are module-level globals in `database.py`, created once at import time — swapping config doesn't change the DB connection

## Phase 1: Hot-Swap Experiment

**Purpose**: Prove we can toggle the running server between Development and Testing config blocks, including the database connection.

### Step 1a: `/api/server-info` Endpoint

**File**: `src/cosa/rest/routers/system.py`

Add `GET /api/server-info` (no auth, infrastructure metadata) so we can observe the current state:

```python
@router.get( "/api/server-info", response_class=JSONResponse )
async def get_server_info( config_mgr: ConfigurationManager = Depends( get_config_manager ) ):
    from cosa.rest.db import database as db_module
    env = os.environ.get( "LUPIN_ENV", "development" ).lower()
    return {
        "config_block_id" : config_mgr.config_block_id,
        "database_url"    : str( db_module.engine.url ).replace( str( db_module.engine.url.password or "" ), "***" ),
        "environment"     : env
    }
```

### Step 1b: `swap_database()` Function

**File**: `src/cosa/rest/db/database.py`

Add a function that replaces the module-level `engine`, `SessionLocal`, and `ScopedSession` globals:

```python
def swap_database( new_env: str ) -> str:
    """
    Hot-swap the database connection to a different environment.

    Requires:
        - new_env is one of: "development", "testing", "production"

    Ensures:
        - LUPIN_ENV is updated
        - engine, SessionLocal, ScopedSession are recreated
        - Old engine is disposed (connections released)
        - Returns the new database URL (password masked)
    """
    global engine, SessionLocal, ScopedSession

    os.environ[ "LUPIN_ENV" ] = new_env

    # Dispose old engine (releases connection pool)
    engine.dispose()

    # Recreate with new settings
    engine       = create_engine( get_database_url(), **get_pool_config() )
    SessionLocal = sessionmaker( autocommit=False, autoflush=False, bind=engine )
    ScopedSession = scoped_session( SessionLocal )

    # Verify connection works
    with engine.connect() as conn:
        conn.execute( text( "SELECT 1" ) )

    db_url = str( engine.url )
    masked = db_url.replace( str( engine.url.password or "" ), "***" )
    return masked
```

### Step 1c: Update `/api/init` to Accept Config Block ID

**File**: `src/cosa/rest/routers/system.py`

Modify `/api/init` to:
1. Accept optional `config_block_id` query parameter
2. Update the `_config_mgr` singleton (not create a throwaway instance)
3. Call `swap_database()` to switch the DB connection
4. Return the new state

```python
@router.get( "/api/init", response_class=JSONResponse )
async def init( config_block_id: Optional[str] = None ):
    try:
        from cosa.rest.db.database import swap_database
        import cosa.rest.dependencies.config as config_module

        config_mgr = config_module.get_config_manager()

        if config_block_id is not None:
            block_id = config_block_id.replace( "+", " " )
            env_map  = {
                "Lupin: Testing"     : "testing",
                "Lupin: Development" : "development",
                "Lupin: Production"  : "production"
            }
            new_env = env_map.get( block_id, "development" )

            # Reinitialize config manager with new block
            config_mgr.init( config_block_id=block_id )

            # Swap database connection
            new_db_url = swap_database( new_env )
        else:
            config_mgr.init()
            new_db_url = "(unchanged)"

        # Reload snapshots
        import fastapi_app.main as main_module
        if hasattr( main_module, 'snapshot_mgr' ) and main_module.snapshot_mgr:
            main_module.snapshot_mgr.reload()

        return {
            "status"          : "success",
            "config_block_id" : config_mgr.config_block_id,
            "database_url"    : new_db_url,
            "environment"     : os.environ.get( "LUPIN_ENV", "development" ),
            "timestamp"       : datetime.now().isoformat()
        }
    except Exception as e:
        return {
            "status"    : "error",
            "message"   : f"Init failed: {str( e )}",
            "timestamp" : datetime.now().isoformat()
        }
```

## Phase 2: Integration Test Runner Refactor

**Purpose**: Rewrite `run-integration-tests.sh` to use hot-swap instead of starting its own server.

**File**: `src/tests/run-integration-tests.sh`

**New flow**:
1. Verify dev server is running on port 7999 (fail if NOT running — opposite of current behavior)
2. Call `/api/server-info` to record original config block
3. Call `/api/init?config_block_id=Lupin:+Testing` to swap to test DB
4. Verify via `/api/server-info` that swap succeeded (database contains `lupin_db_test`)
5. Run pytest against the live server
6. **Always** swap back via `/api/init?config_block_id=Lupin:+Development` (in trap handler)

```bash
# Cleanup: ALWAYS swap back, even on test failure or Ctrl+C
ORIGINAL_BLOCK=""
cleanup() {
    if [ -n "$ORIGINAL_BLOCK" ]; then
        echo "Restoring original config: $ORIGINAL_BLOCK"
        python3 -c "import urllib.request; urllib.request.urlopen( 'http://localhost:$PORT/api/init?config_block_id=${ORIGINAL_BLOCK// /+}' )"
    fi
}
trap cleanup EXIT INT TERM
```

**Implementation note**: Used Python `urllib` for health checks instead of `lsof` because the dev server may run inside Docker (where `lsof` can't see the port).

## Phase 3: `clean_test_db` Fixture Hardening

**File**: `src/tests/integration/conftest.py`

Add safety assertions:
- Verify `engine.url` contains `lupin_db_test` before any destructive operations
- Verify `users` table is empty after `drop_all` + `create_all`

**Important**: The fixture must re-import `engine` from `database.py` each time (since hot-swap replaces the module-level global).

```python
@pytest.fixture( scope="function" )
def clean_test_db():
    # Re-import to get the current (possibly swapped) engine
    from cosa.rest.db import database as db_module
    from cosa.rest.postgres_models import Base
    from sqlalchemy import text

    engine = db_module.engine
    db_url = str( engine.url )
    assert "lupin_db_test" in db_url, \
        f"SAFETY: clean_test_db must only run against lupin_db_test, got: {db_url}"

    Base.metadata.drop_all( bind=engine )
    Base.metadata.create_all( bind=engine )

    with engine.connect() as conn:
        count = conn.execute( text( "SELECT count(*) FROM users" ) ).scalar()
        assert count == 0, f"SAFETY: users table not empty after clean ({count} rows)"

    yield
```
