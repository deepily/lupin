# Plan: Verify E2E UI Test Suite Health — Permanent Background Execution

## Context

The E2E UI test suite (~298 tests, 29 files) takes **~19 minutes** to run. Claude Code's Bash tool has a **10-minute max timeout** (600,000ms). In Session 372c, the timeout caused:
1. Test run timed out mid-execution
2. Re-run attempted while first run's trap handler was still active
3. Hot-swap collision: config block restored to production while second run expected test DB
4. Result: 23 spurious `RuntimeError: Server database is NOT lupin_db_test!` errors

**Goal**: Make the E2E test runner **natively support background execution** so this class of problem never recurs — whether invoked by Claude Code or by a human in a hurry.

## Approach: Add `--background` Flag to `run-e2e-ui-tests.sh`

Modify the existing script to support a `--background` (or `--bg`) flag that:

1. **Re-execs itself** via `nohup` with output redirected to a timestamped log file
2. **Prints the PID and log file path** so the caller can monitor
3. **Returns immediately** (exit 0) so Claude Code's Bash tool never times out
4. **Creates a PID file** (`/tmp/e2e-ui-tests.pid`) to prevent overlapping runs
5. **Cleans up PID file** on completion (in the existing trap handler)

### Script Changes to `src/scripts/run-e2e-ui-tests.sh`

**Add near top of script** (after shebang, before existing logic):

```bash
# --- Background execution support ---
LOG_DIR="/tmp"
PID_FILE="/tmp/e2e-ui-tests.pid"

# Check for --background / --bg flag
BG_MODE=false
REMAINING_ARGS=()
for arg in "$@"; do
    case "$arg" in
        --background|--bg)
            BG_MODE=true
            ;;
        *)
            REMAINING_ARGS+=("$arg")
            ;;
    esac
done

# Prevent overlapping runs (regardless of mode)
if [ -f "$PID_FILE" ]; then
    EXISTING_PID=$(cat "$PID_FILE")
    if kill -0 "$EXISTING_PID" 2>/dev/null; then
        echo "ERROR: E2E test run already in progress (PID $EXISTING_PID)"
        echo "Log: $(readlink -f /tmp/e2e-ui-latest.log 2>/dev/null || echo 'unknown')"
        echo "To force: rm $PID_FILE"
        exit 1
    else
        echo "WARNING: Stale PID file found (PID $EXISTING_PID no longer running). Cleaning up."
        rm -f "$PID_FILE"
    fi
fi

# If --background requested, re-exec via nohup and exit
if [ "$BG_MODE" = true ]; then
    LOG_FILE="$LOG_DIR/e2e-ui-$(date +%Y%m%d-%H%M%S).log"
    ln -sf "$LOG_FILE" /tmp/e2e-ui-latest.log

    nohup "$0" "${REMAINING_ARGS[@]}" > "$LOG_FILE" 2>&1 &
    BG_PID=$!
    echo "$BG_PID" > "$PID_FILE"

    echo "E2E UI tests running in background"
    echo "  PID:  $BG_PID"
    echo "  Log:  $LOG_FILE"
    echo "  Link: /tmp/e2e-ui-latest.log"
    echo ""
    echo "Monitor:  tail -f $LOG_FILE"
    echo "Status:   kill -0 $BG_PID 2>/dev/null && echo running || echo done"
    echo "Results:  grep -E '(passed|failed|error)' $LOG_FILE"
    exit 0
fi

# Record our PID (for overlap detection in foreground mode too)
echo "$$" > "$PID_FILE"
```

**Add to existing trap handler** (the cleanup function):

```bash
# Add PID file cleanup to existing trap
rm -f "$PID_FILE"
```

### Documentation

Add a comment block in the script explaining **why** background mode exists:

```bash
# Background mode (--background / --bg):
#   The E2E suite runs ~19 minutes (298 tests × Playwright × Chromium).
#   Claude Code's Bash tool has a 10-minute max timeout. When the timeout
#   fires mid-run, the trap handler restores the production config block.
#   If a second run is then attempted, the config hot-swap collides with
#   the first run's cleanup, causing "Server database is NOT lupin_db_test!"
#   errors across the board (Session 372c: 23 spurious errors).
#
#   --bg re-execs via nohup so the caller returns immediately.
#   A PID file prevents overlapping runs. The symlink /tmp/e2e-ui-latest.log
#   always points to the most recent run's output.
```
