## 🚨 Critical Bugs That Affect You Directly

### 1. Fine-Grained Tool Streaming Regression
**Fixed in:** `0.1.48` (env-var workaround) → cleanly resolved upstream in `0.1.49`

`include_partial_messages=True` was **not delivering `input_json_delta` events**. This regression affected **versions 0.1.36 through 0.1.47** for users without the server-side feature flag.

> If your streaming pipeline relies on partial tool-input delivery, this was silently burning you from day one at your current pin.

### 2. Hook Output Field Conversion Bug
**Fixed in:** `0.1.48` batch

Python-safe field names (`async_`, `continue_`) in hook outputs were **not being converted to CLI format** (`async`, `continue`). Hook control fields were **silently ignored**, preventing proper hook behavior in `UserPromptSubmit`, `PreToolUse`, and `PostToolUse` callbacks.

**Also in this batch:** Strongly-typed hook inputs via `TypedDict`:
- `PreToolUseHookInput`
- `PostToolUseHookInput`
- `UserPromptSubmitHookInput`

Full IDE autocomplete and type safety now available on hook callback parameters.

## Operational Notes

### Version Check Escape Hatch

Disables the Claude Code version validation. Only recommended if you have Claude Code `2.0.0+` installed. Useful for reproducible Docker/home-lab environments where you're pinning the bundled CLI.
