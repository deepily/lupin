## Phase 3 Detailed Fixes

### 3.1 JWT Service Timing - 2 tests
**File**: `src/tests/unit/test_jwt_service.py`
**Tests**: `test_access_token_expiration_set_correctly`, `test_refresh_token_expiration_set_correctly`

**Root Cause**: Timezone mismatch - `fromtimestamp()` interprets in local time, but `utcnow()` is UTC.

**Fix** (lines 62 and 128):
```python
# BEFORE (broken):
exp_time = datetime.fromtimestamp( payload["exp"] )

# AFTER (fixed):
exp_time = datetime.utcfromtimestamp( payload["exp"] )
```

---

### 3.2 Config Loader - 2 tests
**File**: `src/tests/unit/test_config_loader.py`
**Tests**: `test_config_file_middle_precedence`, `test_missing_required_fields_raises_error`

**Root Cause**: `LUPIN_ENV=development` is set in environment, tests don't clear it.

**Fix**: Add `monkeypatch.delenv( 'LUPIN_ENV', raising=False )` to each failing test.
