## Feature 1 — Click-to-copy the task ID

**Behavior**: Clicking a row's **ID cell** copies that task's **full** id (the UUID) to the clipboard, with brief visual confirmation. (The cell *displays* only the first 8 chars, but the full id is the useful thing to copy for store/commit/`task_query` lookups. → **Design decision for Rick to confirm/flip**: copy full UUID (recommended) vs. copy the visible 8-char prefix.)

**Current state (anchors)**:
- ID cell built at `taskListTable.ts:193` → `td( "task-col-id", taskIdLabel( task ) )`; plain `<td class="task-col-id">`, `textContent` = `id.slice(0,8)` (`taskListModel.ts:165`).
- The full id is already on the row: `<tr data-task-id="<full-id>">` (`taskListTable.ts:190`).
- Clicks are delegated at the container level in `TaskListRenderer.ts:178` (same pattern the Detail-emoji overlay uses at `TaskListRenderer.ts:303–313`).
- **No** existing click handler on the ID cell. **No** shared clipboard util (`navigator.clipboard.writeText()` is used inline in `notifications.js` ~1650/~2200 with a ✅ icon-swap after ~1.2s — reuse that UX pattern).

**Implementation**:
1. In the container-level delegated click handler (`TaskListRenderer.ts`), add a branch: if the click target is (or is within) `.task-col-id`, resolve the owning `<tr>`, read its `data-task-id`, call `navigator.clipboard.writeText( fullId )`.
2. **Feedback**: briefly swap the cell to a "Copied ✓" state (add a `.task-id-copied` class for ~1.2s, then revert) — mirror the notifications.js checkmark pattern. Do NOT reflow the row width (avoid a ±1px snapshot churn — keep the copied state same-width, e.g. overlay/color change, not a text-length change).
3. **Affordance + a11y** (`task-list.css`, `.task-col-id`): `cursor: pointer`; `title="Click to copy ID"`; add `role="button"` + `tabindex="0"` to the ID cell and handle Enter/Space in the delegated keydown path so it's keyboard-operable.

**Acceptance**:
- Click ID cell → full UUID on clipboard; transient "copied" confirmation; row width unchanged.
- Keyboard: focus ID cell + Enter/Space → same copy.
- Empty/again clicks don't throw; graceful when `navigator.clipboard` is unavailable (guard + no-op).
