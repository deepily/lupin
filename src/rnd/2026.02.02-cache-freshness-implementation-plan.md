# Cache Freshness Policy Implementation Plan

**Bug**: Cache Hit Behavior - `running_fifo_queue.py:_format_cached_result()` returns cached `answer_conversational` without re-executing code

**Session**: 119 (Bug Fix Mode)
**Status**: Implementation Ready
**Date**: 2026-02-02

---

## Problem Summary

Currently, when a cache hit occurs:
1. SolutionSnapshot stores **both** the code AND the formatted answer
2. On cache hit, only `answer_conversational` is returned via `_format_cached_result()`
3. The stored code is **never** re-executed
4. No freshness mechanism exists

This breaks for time-sensitive queries:
- "What time is it?" - Returns stale cached time
- "What's the weather?" - Returns outdated weather
- Any query that depends on external APIs or current datetime

---

## Design Decision: Binary Freshness Policy

**Simplified approach** - Two policies only:

| Policy | Behavior | Examples |
|--------|----------|----------|
| `IMMUTABLE` | Return cached answer as-is | 4+4, sqrt(144), unit conversions |
| `VOLATILE` | Re-execute code every time | "What time is it?", weather, API calls |

**Rationale for no TTL complexity**:
- Keeps implementation simple and predictable
- Avoids timestamp comparison bugs
- If data changes, just re-execute - modern code execution is fast

---

## Policy Assignment (Three-Tier)

### Tier 1: Agent Explicitly Sets Policy (Highest Priority)
Each agent class can override `cache_freshness_policy` property:

```python
# In DateAndTimeAgent
@property
def cache_freshness_policy( self ) -> str:
    return "volatile"  # Always re-execute for time queries
```

### Tier 2: Auto-Detection from Code Patterns (Fallback)
When snapshot has no explicit policy, detect from code patterns:

| Code Pattern | Detected Policy |
|--------------|-----------------|
| `datetime.now()`, `time.time()`, `date.today()` | VOLATILE |
| `requests.*`, `httpx.*`, `urllib.*` | VOLATILE |
| `pd.read_csv`, file I/O operations | VOLATILE |
| Pure arithmetic, string operations | IMMUTABLE |

### Tier 3: Config Default per Agent Type (Last Resort)
Configuration keys for agent-level defaults:

| Agent | Default Policy | Config Key |
|-------|---------------|------------|
| MathAgent | IMMUTABLE | `cache_freshness_default_for_math` |
| DateAndTimeAgent | VOLATILE | `cache_freshness_default_for_date_and_time` |
| WeatherAgent | VOLATILE | `cache_freshness_default_for_weather` |
| CalendarAgent | VOLATILE | `cache_freshness_default_for_calendar` |
| TodoListAgent | VOLATILE | `cache_freshness_default_for_todo_list` |

```python
"""
Cache Freshness Policy module for determining when to re-execute cached solutions.

Two policies:
- IMMUTABLE: Cached answer is always valid (math, conversions)
- VOLATILE: Code must be re-executed every time (datetime, weather, APIs)
"""

from enum import Enum
import re
from typing import Optional, List

class CacheFreshnessPolicy( Enum ):
    """
    Binary cache freshness policy.

    IMMUTABLE: Return cached answer as-is
    VOLATILE: Re-execute code to get fresh answer
    """
    IMMUTABLE = "immutable"
    VOLATILE  = "volatile"

# Code patterns that indicate volatile data sources
VOLATILE_CODE_PATTERNS = [
    # Time-sensitive
    r"datetime\.now\s*\(",
    r"datetime\.today\s*\(",
    r"date\.today\s*\(",
    r"time\.time\s*\(",
    r"time\.localtime\s*\(",
    r"time\.gmtime\s*\(",

    # External APIs
    r"requests\.(get|post|put|delete|patch)\s*\(",
    r"httpx\.(get|post|put|delete|patch)\s*\(",
    r"urllib\.request\.urlopen\s*\(",
    r"aiohttp\.",

    # File I/O (state may change)
    r"open\s*\([^)]+,\s*['\"]r",  # Reading files
    r"pd\.read_csv\s*\(",
    r"pd\.read_excel\s*\(",
    r"json\.load\s*\(",
]

# Compiled patterns for performance
_VOLATILE_PATTERNS = [ re.compile( pattern, re.IGNORECASE ) for pattern in VOLATILE_CODE_PATTERNS ]


def detect_policy_from_code( code: List[str] ) -> CacheFreshnessPolicy:
    """
    Auto-detect cache policy from code patterns.

    Requires:
        - code is a list of code strings (lines or blocks)

    Ensures:
        - Returns VOLATILE if any volatile patterns detected
        - Returns IMMUTABLE if code appears to be pure computation

    Raises:
        - None
    """
    if not code:
        return CacheFreshnessPolicy.IMMUTABLE

    code_text = "\n".join( code ) if isinstance( code, list ) else code

    for pattern in _VOLATILE_PATTERNS:
        if pattern.search( code_text ):
            return CacheFreshnessPolicy.VOLATILE

    return CacheFreshnessPolicy.IMMUTABLE


def get_effective_policy(
    explicit_policy: Optional[str],
    code: List[str],
    agent_class_name: Optional[str],
    config_mgr
) -> CacheFreshnessPolicy:
    """
    Determine effective cache policy using three-tier fallback.

    Tier 1: Explicit policy from snapshot or agent (highest priority)
    Tier 2: Auto-detect from code patterns
    Tier 3: Agent-level default from config

    Requires:
        - code is a list of strings
        - config_mgr is a valid ConfigurationManager or None

    Ensures:
        - Returns a valid CacheFreshnessPolicy
        - Never returns None

    Raises:
        - None
    """
    # Tier 1: Explicit policy
    if explicit_policy:
        try:
            return CacheFreshnessPolicy( explicit_policy )
        except ValueError:
            pass  # Invalid policy string, fall through

    # Tier 2: Auto-detect from code
    detected = detect_policy_from_code( code )
    if detected == CacheFreshnessPolicy.VOLATILE:
        return detected

    # Tier 3: Agent-level default from config
    if config_mgr and agent_class_name:
        # Map agent class name to config key
        agent_key_map = {
            "MathAgent"        : "cache_freshness_default_for_math",
            "DateAndTimeAgent" : "cache_freshness_default_for_date_and_time",
            "WeatherAgent"     : "cache_freshness_default_for_weather",
            "CalendarAgent"    : "cache_freshness_default_for_calendar",
            "CalendaringAgent" : "cache_freshness_default_for_calendar",
            "TodoListAgent"    : "cache_freshness_default_for_todo_list",
        }

        config_key = agent_key_map.get( agent_class_name )
        if config_key:
            default_policy = config_mgr.get( config_key, default="immutable" )
            try:
                return CacheFreshnessPolicy( default_policy )
            except ValueError:
                pass

    # Final fallback: IMMUTABLE (safest for performance)
    return CacheFreshnessPolicy.IMMUTABLE


def quick_smoke_test():
    """Quick smoke test for cache freshness policy module."""
    import cosa.utils.util as du

    du.print_banner( "Cache Freshness Policy Smoke Test", prepend_nl=True )

    # Test 1: Enum values
    print( "Testing enum values..." )
    assert CacheFreshnessPolicy.IMMUTABLE.value == "immutable"
    assert CacheFreshnessPolicy.VOLATILE.value == "volatile"
    print( "  IMMUTABLE.value =", CacheFreshnessPolicy.IMMUTABLE.value )
    print( "  VOLATILE.value =", CacheFreshnessPolicy.VOLATILE.value )

    # Test 2: Code pattern detection
    print( "\nTesting code pattern detection..." )

    # Math code should be IMMUTABLE
    math_code = [ "result = 4 + 4", "print( result )" ]
    assert detect_policy_from_code( math_code ) == CacheFreshnessPolicy.IMMUTABLE
    print( "  math_code -> IMMUTABLE" )

    # DateTime code should be VOLATILE
    time_code = [ "from datetime import datetime", "result = datetime.now()" ]
    assert detect_policy_from_code( time_code ) == CacheFreshnessPolicy.VOLATILE
    print( "  time_code -> VOLATILE" )

    # API code should be VOLATILE
    api_code = [ "import requests", "response = requests.get( url )" ]
    assert detect_policy_from_code( api_code ) == CacheFreshnessPolicy.VOLATILE
    print( "  api_code -> VOLATILE" )

    # File read code should be VOLATILE
    file_code = [ "df = pd.read_csv( 'data.csv' )" ]
    assert detect_policy_from_code( file_code ) == CacheFreshnessPolicy.VOLATILE
    print( "  file_code -> VOLATILE" )

    # Test 3: Empty code
    print( "\nTesting empty code handling..." )
    assert detect_policy_from_code( [] ) == CacheFreshnessPolicy.IMMUTABLE
    print( "  empty_code -> IMMUTABLE (safe default)" )

    print( "\n Cache Freshness Policy smoke test completed" )

    quick_smoke_test()

def _is_cache_immutable( self, snapshot: SolutionSnapshot ) -> bool:
    """
    Check if cached snapshot can return answer without re-execution.

    Requires:
        - snapshot is a valid SolutionSnapshot

    Ensures:
        - Returns True if policy is IMMUTABLE
        - Returns False if policy is VOLATILE
        - Respects feature flag (returns True if feature disabled)
    """
    # Check feature flag
    cache_freshness_enabled = self.config_mgr.get(
        "cache_freshness_enabled",
        default=False,
        return_type="boolean"
    ) if hasattr( self, 'config_mgr' ) else False

    if not cache_freshness_enabled:
        # Feature disabled - treat all cache hits as immutable (current behavior)
        return True

    from cosa.memory.cache_freshness_policy import CacheFreshnessPolicy

    policy = snapshot.effective_cache_policy
    return policy == CacheFreshnessPolicy.IMMUTABLE


def _handle_volatile_cache(
    self,
    cached_snapshot: SolutionSnapshot,
    original_job: Any,
    truncated_question: str,
    run_timer: sw.Stopwatch
) -> Any:
    """
    Handle VOLATILE cache hit by re-executing stored code.

    Requires:
        - cached_snapshot has valid code to re-execute
        - original_job provides current user context

    Ensures:
        - Re-executes cached code to get fresh output
        - Updates answer with fresh result
        - Preserves runtime stats tracking
        - Returns properly formatted result
    """
    msg = f"Re-executing VOLATILE cached solution for [{truncated_question}]..."
    du.print_banner( msg=msg, prepend_nl=True )

    # Calculate time already spent
    run_timer.stop()
    cache_lookup_ms = run_timer.get_elapsed_millis()

    # Create execution timer for the re-run
    exec_timer = sw.Stopwatch( "Re-executing cached code..." )

    # Re-execute the stored code
    code_response = cached_snapshot.run_code( debug=self.debug, verbose=self.verbose )

    exec_timer.print( "Code re-execution complete", use_millis=True )

    if code_response.get( "return_code" ) == 0:
        # Success - format the fresh output
        cached_snapshot.run_formatter()

        # Get current user context
        current_user_id    = original_job.user_id
        current_session_id = original_job.session_id

        # Create user-contextualized copy for done queue
        done_queue_entry = cached_snapshot.for_current_user(
            user_id=current_user_id,
            session_id=current_session_id
        )

        # Preserve original job's id_hash for user association
        done_queue_entry.id_hash = original_job.id_hash

        # Emit the fresh answer
        self._notify( cached_snapshot.answer_conversational, job=done_queue_entry )

        # Emit job state transition
        job_id  = done_queue_entry.id_hash
        user_id = self.user_job_tracker.get_user_for_job( job_id )

        from datetime import datetime
        completed_at = datetime.now().isoformat()
        started_at   = original_job.started_at

        duration_seconds = None
        if started_at and completed_at:
            try:
                start = datetime.fromisoformat( started_at ) if isinstance( started_at, str ) else started_at
                end   = datetime.fromisoformat( completed_at )
                duration_seconds = ( end - start ).total_seconds()
            except Exception:
                pass

        metadata = {
            'response_text'   : cached_snapshot.answer_conversational,
            'abstract'        : None,
            'report_link'     : None,
            'cost_summary'    : None,
            'error'           : None,
            'question_text'   : cached_snapshot.last_question_asked,
            'agent_type'      : cached_snapshot.job_type,
            'timestamp'       : cached_snapshot.created_date,
            'is_cache_hit'    : True,  # Still a cache hit (code reuse)
            'is_volatile_reexec': True,  # But code was re-executed
            'status'          : 'completed',
            'has_interactions': bool( original_job.session_id ),
            'started_at'      : started_at,
            'completed_at'    : completed_at,
            'duration_seconds': duration_seconds
        }
        emit_job_state_transition( self.websocket_mgr, job_id, 'run', 'done', user_id, metadata )

        # Queue management
        self.pop()
        self.jobs_done_queue.push( done_queue_entry )

        print( f" VOLATILE cache - code re-executed with fresh data" )

        # Update runtime stats
        cached_snapshot.update_runtime_stats( exec_timer )
        self.snapshot_mgr.save_snapshot( cached_snapshot )

        return done_queue_entry

    else:
        # Code execution failed - fall back to error handling
        return self._handle_error_case( code_response, original_job, truncated_question )
```

## Notes from Code Analysis

### Current Cache Hit Flow (`_format_cached_result`)

1. Gets `cached_snapshot` from LanceDB search
2. Creates user-contextualized copy with `for_current_user()`
3. Returns `answer_conversational` directly
4. **Never touches** `run_code()` or `run_formatter()`

### Code Re-execution Path (`_handle_solution_snapshot`)

Shows that SolutionSnapshot already has `run_code()` method:
```python
_ = running_job.run_code()
formatted_output = running_job.run_formatter()
```

This confirms we can re-use this pattern for VOLATILE cache hits.

### Agent Property Pattern

MathAgent already has a static `apply_formatting()` method that SolutionSnapshot can call.
This pattern validates that agent-specific behavior can be accessed from snapshots.
