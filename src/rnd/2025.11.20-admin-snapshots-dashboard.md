# Admin Solution Snapshots Search Dashboard - Implementation Plan

**Date**: 2025.11.20
**Status**: Planning Complete - Ready for Implementation
**Estimated Effort**: 7-11 hours (1-1.5 days)
**Pattern**: Feature Development (Planning is Prompting Pattern 3)

---

## Executive Summary

Build a plain vanilla HTML+JavaScript admin dashboard for searching and managing LanceDB solution snapshots. This establishes the foundation for future admin tools while providing immediate value for snapshot management.

---

## Requirements (From Interactive Requirements Elicitation)

### Searchable Fields
- **Question**: Original user question (verbatim)
- **Question Normalized**: Normalized version (operators preserved)
- **Question Gist**: Condensed semantic summary

### Functional Requirements
- **Search**: Simple text search (single input box, Google-style)
- **Display**: Table rows with question preview, gist, created date, actions
- **Integration**: New admin dashboard page (foundation for future admin tools)
- **Authentication**: JWT role check (reuse existing admin middleware)
- **Scale**: <1000 snapshots (instant search, no complex pagination needed)
- **Actions**:
  - View full details (modal overlay)
  - Delete with confirmation dialog

### Non-Functional Requirements
- Consistent with existing Lupin UI patterns (Fresh Queue style)
- Mobile-friendly responsive design
- User-friendly error messages
- Dual-layer security (frontend + backend admin checks)

## Data Model (LanceDB Solution Snapshots)

### Location
- **Database Path**: `/src/conf/long-term-memory/lupin.lancedb/`
- **Table Name**: `solution_snapshots`
- **Storage Backend**: Local (configurable to GCS)

### Schema (Relevant Fields)
```python
# Primary identifiers
id_hash: string              # MD5 hash of question (unique identifier)
user_id: string             # Owner/creator

# Main content fields (searchable)
question: string            # Original user question
question_normalized: string # Normalized version
question_gist: string       # Condensed semantic summary
answer: string
answer_conversational: string

# Temporal data
created_date: string
updated_date: string

# Vector embeddings (1536 dimensions - OpenAI)
question_embedding: list<float32, 1536>
question_normalized_embedding: list<float32, 1536>
question_gist_embedding: list<float32, 1536>
```

### Access Layer
- **Manager Class**: `LanceDBSolutionManager` (`/src/cosa/memory/lancedb_solution_manager.py`)
- **Factory**: `SolutionSnapshotManagerFactory` (`/src/cosa/memory/solution_manager_factory.py`)

#### 1.1 Search Endpoint
```python
@router.get(
    "/snapshots/search",
    response_model=SearchResponse,
    summary="Search solution snapshots",
    description="Search snapshots by question text. Requires admin role."
)
async def search_snapshots(
    q: str,                                    # Query text
    limit: int = 50,                          # Results limit
    admin_user: Dict = Depends(require_admin) # Admin check
) -> SearchResponse:
    """
    Search solution snapshots using vector similarity search.

    Searches across:
    - question (original text)
    - question_normalized (processed text)
    - question_gist (semantic summary)

    Returns:
        List of snapshots with id_hash, question preview, gist, created_date
    """
```

**Implementation Notes**:
- Use `LanceDBSolutionManager.get_snapshots_by_question()`
- Leverage existing vector similarity search (question_embedding)
- Truncate question to 100 characters for preview
- Return fields: id_hash, question_preview, question_gist, created_date, score

#### 1.2 Details Endpoint

### Phase 3: Frontend JavaScript Logic (2-3 hours)

**File**: `/src/fastapi_app/static/html/admin/js/admin-snapshots.js`

#### 3.1 Initialization & Authentication
```javascript
// Admin Snapshots Dashboard
class AdminSnapshotsDashboard {
    constructor() {
        this.currentUser = null;
        this.isAdmin = false;
        this.searchResults = [];
        this.selectedSnapshotId = null;
    }

    async init() {
        // Check authentication
        await this.setupAuthentication();

        // Setup event listeners
        this.setupEventListeners();

        // Display user info
        this.displayUserInfo();
    }

    async setupAuthentication() {
        const token = getAccessToken();

        if (!token) {
            // Redirect to login
            window.location.href = '/static/html/auth/login.html?redirect=/static/html/admin/snapshots.html';
            return;
        }

        // Check token expiration
        if (isTokenExpired(token)) {
            const refreshed = await refreshAccessToken();
            if (!refreshed) {
                window.location.href = '/static/html/auth/login.html';
                return;
            }
        }

        // Extract user info
        const payload = parseJWTPayload(token);
        this.currentUser = payload.email;
        this.isAdmin = (payload.roles || []).includes('admin');

        // Check admin role
        if (!this.isAdmin) {
            alert('Admin access required');
            window.location.href = '/static/html/auth/profile.html';
            return;
        }
    }

    displayUserInfo() {
        document.getElementById('user-email').textContent = this.currentUser;
    }
}
```

#### 3.2 Search Functionality
```javascript
    setupEventListeners() {
        // Search button
        document.getElementById('search-btn').addEventListener('click', () => {
            this.performSearch();
        });

        // Enter key in search input
        document.getElementById('search-input').addEventListener('keypress', (e) => {
            if (e.key === 'Enter') {
                this.performSearch();
            }
        });

        // Logout button
        document.getElementById('logout-btn').addEventListener('click', () => {
            clearTokens();
            window.location.href = '/static/html/auth/login.html';
        });
    }

    async performSearch() {
        const query = document.getElementById('search-input').value.trim();

        if (!query) {
            this.showError('Please enter a search query');
            return;
        }

        this.hideError();
        this.showLoading();

        try {
            const response = await this.apiCall(`/admin/snapshots/search?q=${encodeURIComponent(query)}`);

            this.searchResults = response.results;
            this.displayResults();
            this.updateResultsCount(response.total, query);

        } catch (error) {
            this.showError(`Search failed: ${error.message}`);
        } finally {
            this.hideLoading();
        }
    }

    async apiCall(endpoint, method = 'GET', data = null) {
        const url = `http://localhost:7999${endpoint}`;
        const token = getAccessToken();

        const headers = {
            'Content-Type': 'application/json',
            'Authorization': `Bearer ${token}`
        };

        const options = { method, headers };
        if (data && method !== 'GET') {
            options.body = JSON.stringify(data);
        }

        const response = await fetch(url, options);

        if (!response.ok) {
            if (response.status === 401) {
                // Try refresh token
                const refreshed = await refreshAccessToken();
                if (refreshed) {
                    return this.apiCall(endpoint, method, data);
                }
                throw new Error('Authentication failed');
            }

            const errorData = await response.json();
            throw new Error(errorData.detail || 'Request failed');
        }

        return await response.json();
    }
```

#### 3.3 Results Display
```javascript
    displayResults() {
        const tbody = document.getElementById('results-tbody');
        tbody.innerHTML = '';

        if (this.searchResults.length === 0) {
            document.getElementById('empty-state').style.display = 'block';
            document.getElementById('results-table').style.display = 'none';
            return;
        }

        document.getElementById('empty-state').style.display = 'none';
        document.getElementById('results-table').style.display = 'table';

        this.searchResults.forEach(result => {
            const row = this.createResultRow(result);
            tbody.appendChild(row);
        });
    }

    createResultRow(result) {
        const row = document.createElement('tr');

        // Question preview
        const questionCell = document.createElement('td');
        questionCell.textContent = result.question_preview;
        questionCell.className = 'question-preview';
        row.appendChild(questionCell);

        // Gist
        const gistCell = document.createElement('td');
        gistCell.textContent = result.question_gist;
        row.appendChild(gistCell);

        // Created date
        const dateCell = document.createElement('td');
        dateCell.textContent = this.formatDate(result.created_date);
        row.appendChild(dateCell);

        // Actions
        const actionsCell = document.createElement('td');
        actionsCell.className = 'actions-cell';

        // View button
        const viewBtn = document.createElement('button');
        viewBtn.textContent = 'View';
        viewBtn.className = 'btn-small btn-primary';
        viewBtn.onclick = () => this.viewDetails(result.id_hash);
        actionsCell.appendChild(viewBtn);

        // Delete button
        const deleteBtn = document.createElement('button');
        deleteBtn.textContent = 'Delete';
        deleteBtn.className = 'btn-small btn-danger';
        deleteBtn.onclick = () => this.confirmDelete(result.id_hash, result.question_preview);
        actionsCell.appendChild(deleteBtn);

        row.appendChild(actionsCell);

        return row;
    }

    formatDate(dateString) {
        const date = new Date(dateString);
        return date.toLocaleString();
    }

    updateResultsCount(total, query) {
        const countEl = document.getElementById('results-count');
        countEl.textContent = `Found ${total} result${total !== 1 ? 's' : ''} for "${query}"`;
    }
```

#### 3.5 Delete Functionality
```javascript
    confirmDelete(idHash, questionPreview) {
        this.selectedSnapshotId = idHash;

        // Show preview in confirmation modal
        document.getElementById('delete-preview').textContent = questionPreview;

        // Show modal
        document.getElementById('delete-modal').style.display = 'flex';

        // Setup confirm button
        const confirmBtn = document.getElementById('confirm-delete-btn');
        confirmBtn.onclick = () => this.deleteSnapshot();
    }

    async deleteSnapshot() {
        if (!this.selectedSnapshotId) return;

        try {
            await this.apiCall(`/admin/snapshots/${this.selectedSnapshotId}`, 'DELETE');

            // Remove from results
            this.searchResults = this.searchResults.filter(
                r => r.id_hash !== this.selectedSnapshotId
            );

            // Refresh display
            this.displayResults();
            this.updateResultsCount(this.searchResults.length, document.getElementById('search-input').value);

            // Close modal
            this.closeDeleteModal();

        } catch (error) {
            this.showError(`Failed to delete snapshot: ${error.message}`);
            this.closeDeleteModal();
        }
    }

    closeDeleteModal() {
        document.getElementById('delete-modal').style.display = 'none';
        this.selectedSnapshotId = null;
    }
```

## Technical Considerations

### Security
- **Frontend**: Check admin role in JWT, hide UI for non-admins
- **Backend**: Use `require_admin` dependency on all endpoints
- **Input Validation**: Sanitize search queries to prevent injection
- **Token Refresh**: Auto-refresh expired tokens during API calls

### Performance
- **Small Dataset**: <1000 snapshots allows instant search
- **Vector Search**: Leverage LanceDB's optimized similarity search
- **No Pagination Needed**: Display all results (reasonable with small dataset)
- **Caching**: Browser caches static assets (CSS, JS)

### Error Handling
- **Network Errors**: User-friendly messages ("Connection failed, please try again")
- **Auth Errors**: Automatic token refresh on 401, redirect on failure
- **404 Errors**: "Snapshot not found" message
- **403 Errors**: "Admin access required" with redirect

### Extensibility
- **Admin Dashboard Framework**: This page establishes patterns for future admin tools
- **Modular Design**: Each component (search, table, modal) is reusable
- **API Versioning**: Endpoints can be versioned (/api/v1/admin/...)
- **Feature Flags**: Can add feature toggles for experimental features
