The TTS preview-and-pause cost-reduction feature splits every long-form TTS message into sentences client-side and only synthesizes the first `<fraction>` portion via the TTS provider, auto-pausing and dispatching the remainder on user resume. The JS-side helpers and queue evolution live in parent Lupin (`notifications.js`); CoSA exposes the 4 feature-flag values to the client via the existing `/api/config/client` fetch path.

Opt-out for action-required + short messages (< `min_chars`). Semicolons excluded from sentence-split by default to avoid over-segmenting complex sentences.
