## §5. Date-window quirk + workaround

Live-tested today: `git_loc_delta --today` returns 0 rows even when there ARE commits today (verified via `git log --since="2026-05-19 00:00:00" --oneline` returning 10 commits). Root cause: git's bare-date `--since 2026-05-19` interpretation (without a time component) silently excludes today's commits — a git quirk, not a tool bug. Same applies to bare `--since 2026-05-19`. Workaround used in this session: `--since 2026-05-18 --until 2026-05-19` (explicit two-day window with the aggregator's per-date bucketing dropping the empty 2026-05-18 bucket cleanly).

This is worth filing into the bug-fix queue as a usability gap on `--today` mode if Rick wants it formalized — but the daily ritual works fine with the explicit `--since/--until` form. Not blocking.
