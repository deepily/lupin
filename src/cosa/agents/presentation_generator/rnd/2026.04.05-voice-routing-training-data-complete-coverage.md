#### 4a. Conditional-args format extension (NEW)

Current format supports one boolean-ish value per arg. To route `"Mexican Spanish" → target_languages=["es-MX"]`, extend to a LIST of `{value, triggers}` objects per arg:

```json
"agent router go to podcast generator" : {
    "template_file"    : "/src/ephemera/prompts/data/synthetic-data-agent-routing-podcast-generator.txt",
    "placeholders"     : { "RESEARCH_TOPIC" : "research_topics" },
    "args_key"         : "topic",
    "conditional_args" : {
        "dry_run" : { "value": "True", "triggers": ["dry run", "dry-run", "trial run", "test run"] },
        "target_languages" : [
            { "value": "[\"es-MX\"]", "triggers": ["mexican spanish", "in mexican", "mexico spanish"] },
            { "value": "[\"es-ES\"]", "triggers": ["peninsula spanish", "peninsular spanish", "castilian spanish", "castillian spanish", "spanish from spain", "iberian spanish"] },
            { "value": "[\"es-AR\"]", "triggers": ["argentinian spanish", "argentine spanish", "argentina spanish", "rioplatense"] },
            { "value": "[\"en\"]", "triggers": ["in english", "english language", "english audio"] },
            { "value": "[\"fr\"]", "triggers": ["in french", "french language", "french audio"] },
            { "value": "[\"de\"]", "triggers": ["in german", "german language", "german audio"] }
        ]
    }
}
```

**Code change required**: `src/cosa/training/xml_coordinator.py` conditional-args parser must detect `isinstance(spec, list)` and iterate, applying the first matching `{value, triggers}` pair. Backward-compatible with existing dict form. ~15 lines of code.

**Utterance coverage**: podcast template adds lines like:
- `create a podcast about RESEARCH_TOPIC in mexican spanish`
- `generate a podcast on RESEARCH_TOPIC castilian spanish please`
- `podcast about RESEARCH_TOPIC in argentinian spanish`
etc. — ~20-30 language-variant lines.
